# Dingo v0.73.4 application sources

The files in `dingo-dev-guides/` are the editable source for the v0.73.4
application download. Update these files in the repository; do not edit the
generated archive directly.

`npm run package:dingo-examples` rebuilds the archive at
`/downloads/dingo/dev-guides/dingo-application-examples-v0.73.4.tar.gz`.
The docs development and build commands generate it automatically.
