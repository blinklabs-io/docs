## v0.26.0 - Stronger profile security, observability, and operational controls

**Version:** 0.26.0

### Summary

This release strengthens profile isolation and credential protection, adds clearer operational metrics and readiness behavior, improves startup and publishing reliability, and introduces new controls for transaction fees, TLS bundles, and Confidential Space keys.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ New Features

* Added bounded cached history for label 17 surveys, retaining up to 20,000 rows or 32 MiB and returning HTTP 503 when the limit is exceeded.

* Improved KES monitoring with a Prometheus histogram for signing duration for each profile.

* Configured the metrics listener with a selectable address, using loopback by default, and made readiness handling work with wildcard listener addresses.

* Expanded Prometheus metrics to report guard, key, and signing activity for each profile.

* Secured remote KES key staging and installation with an mTLS pinned control role while keeping remote drop key operations local only.

* Reused the decoded final survey label page to avoid decoding the same page more than once.

* Strengthened startup reliability by retrying a transient first PostgreSQL connection for up to 20 seconds.

* Clarified slot guard refusal warnings with structured, client aware details.

* Enabled capability revocation to take effect immediately and remain durable across a crash.

* Prevented cross origin wallet creation and restoration requests.

* Added cached, bounded `/readyz` probes that run every 10 seconds and use a 3 second timeout and freshness window.

* Bound signer inventory attestations to their profiles.

* Scoped operational certificate grants to their callers and remote signing to their profiles.

* Added key bound connector pairing with single use signed challenges and session tickets.

* Preserved prerelease classification and suffixes when publishing versions.

* Introduced a one time Confidential Space workflow for importing a pool cold key.

* Accepted Secret Manager TLS bundles through `--tls-secret`.

* Added `tx build --max-fee` with a default maximum of 2,000,000 lovelace.

* Separated Confidential Space cold keys by profile with the `bursa-confidential-space-key/3` envelope and import protocol `/2`.

* Fixed the Windows amd64 MSYS2 cgo publishing `PATH` so publishing can locate its required tools.
