## v0.21.0 - Expanded Cardano compatibility and network support

- **Date:** 2026-10-25
- **Version:** 0.21.0

### Summary

This release expands Cardano CLI compatibility across certificates, keys, pool registration, governance, and transaction workflows. It also adds network selection and hardware signing options, strengthens API and URI validation, and updates the Dingo and Apollo UI dependencies.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ New Features

* Added optional `--deposit` support to stake registration certificates and `--deposit-refund` support to stake deregistration certificates. Bursa now emits the Conway certificate forms when either flag is present, including an explicit zero, while retaining Shelley output when the flags are omitted.
* Updated VRF and KES key envelopes to use the type names expected by `cardano-cli` 11.0. VRF signing files now store the seed followed by the public key, and `vrf_sk` output follows the same format.
* Expanded pool registration with repeatable owner and relay options. Bursa defaults owners from the reward account's stake key and produces deterministic owner sets that match `cardano-cli`, with support for IPv4, IPv6, host, and multi-host relays.
