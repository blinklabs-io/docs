## v0.27.0 - Stronger security, key management, and operational reliability

**Version:** 0.27.0

### Summary

This release strengthens firmware reset and signing-log security, improves iOS data protection and PostgreSQL recovery, adds pool ID derivation, standardizes pool relay networking, and updates supporting cloud, authentication, platform, and cryptography dependencies.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ New Features

* Improved firmware reset security by requiring host-key authentication after host-key registration while preserving reset access during bootstrap. Bursa now refuses to append a signing-log entry when any earlier record in the chain has changed.

* Expanded iOS contact protection by excluding every existing contact file from backups. Startup now stops when the system cannot apply an exclusion to any required file.

* Introduced `bursa key pool-id` to derive a pool ID from a cold verification key or mnemonic, select a CIP-1853 index, emit bech32 or hexadecimal output, validate input, and write the result with secure `0600` permissions.

* Reduced PostgreSQL recovery delays by limiting watermark pool pings to `300ms`. Dead idle connections now fail fast within the caller's timeout.

* Standardized pool relay IPv6 values on network-order bytes and updated the Cardano networking library to `v0.220.1` with refreshed cryptography support.

* Refined JWT validation with `keyfunc/v3` `v3.9.2`: whitelist checks now apply to tokens without a `kid` header, while unknown key IDs fail faster when no remote resources exist.

* Updated platform support with `golang.org/x/sys` `v0.50.0`.

* Refreshed Google Cloud integration dependencies with KMS `v1.37.0` and long-running operation support `v1.5.0`.

* Enhanced AWS credential support with `v1.21.1` and its related modules.

* Removed GitHub environments from the project configuration.
