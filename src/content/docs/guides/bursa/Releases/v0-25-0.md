## v0.25.0 - Expanded KES agent controls and safer transaction approvals

- **Date:** 2026-11-14
- **Version:** 0.25.0
- **Comparison:** [v0.24.0...v0.25.0](https://github.com/blinklabs-io/bursa/compare/v0.24.0...v0.25.0)

### Summary

This release adds command line controls for KES agents, enriches governance certificate summaries, and verifies auxiliary transaction data before approval signing.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ New Features

* Added the `bursa kes-agent control` command with `info`, `gen-staged-key`, `install-key`, and `drop-key` operations. The command discovers the control socket from `kes_agent.control_socket` or an explicit `--socket` value, supports profile selection, returns JSON with hexadecimal key fields, limits requests to 30 seconds, returns promptly when cancellation unblocks socket input/output, and returns a non-zero status when the agent refuses a request. Key generation avoids overwriting KES verification-key envelope files, installation accepts operational-certificate envelopes, and key removal validates `staged`, `active`, or `all` targets.

* Improved governance certificate summaries by displaying the anchor URL and hash for DRep registration and update certificates and committee cold-key resignation certificates. Updates without an anchor now display `anchor none`.

* Secured approval flows by displaying verified auxiliary transaction metadata and refusing to sign when auxiliary data is missing, mismatched, unhashed, unsupported, undecodable, scripted, or too large to render.
