## v0.29.0 - Select per-profile KES agent network scopes

**Version:** 0.29.0

### Summary

This release enables operators to set an optional `network_magic` value for KES agent profiles. Non-zero values isolate pool identity and shared records for profiles that otherwise use the same cold verification key and `system_start`; an unset or `0` value preserves the legacy scope and existing shared records.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ New Features

* Added optional network selection to the single-pool/default profile through `KESAGENT_NETWORK_MAGIC` and to YAML profiles through `kes_agent.network_magic` or `kes_agent.profiles[].network_magic`.

* Enhanced profile isolation by separating pool identity, shared KES guard state, and shared key-store records when profiles use different non-zero `network_magic` values, allowing profiles with the same cold verification key and `system_start` to coexist without duplicate-pool detection or shared record collisions.

* Maintained the legacy scope and existing shared records when `network_magic` is unset or `0`; changing the value after shared records exist selects a new scope and prevents reuse of the prior signed-slot record, period floor, or shared keys for that profile identity.
