## v0.23.0 - Profile aware signing, durable custody, and stronger KES controls

- **Version:** 0.23.0
- **Comparison:** [v0.22.0...v0.23.0](https://github.com/blinklabs-io/bursa/compare/v0.22.0...v0.23.0)

### Summary

This release adds profile aware signing and storage, strengthens Nitro authorization and operational certificate custody, expands KES agent controls, improves Armory migration and simulation workflows, and tightens authentication, storage, and connector behavior.
