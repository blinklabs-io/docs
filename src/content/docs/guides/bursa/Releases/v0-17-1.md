## v0.17.1 - Improve governance vote diagnostics

- **Date:** 2026-09-19
- **Version:** 0.17.1

### Summary

This patch release improves governance vote diagnostics by reporting one warning for unsupported vote categories in each governance data request while preserving governance totals.

### 🐛 Bug Fixes

* Improved governance reporting: Bursa now combines repeated warnings about unsupported vote categories into one warning for each governance data request, with counts by category and a total, while continuing to exclude those categories from governance totals.
