## v0.17.1 - Improve governance vote diagnostics

- **Date:** 2026-09-19
- **Version:** 0.17.1

### Summary

This patch release improves governance vote diagnostics by consolidating warnings for unsupported vote categories into one warning for each governance data request while preserving governance totals.

### 🐛 Bug Fixes

* Improved governance reporting by combining repeated warnings about unsupported vote categories into one warning for each governance data request, including counts for each category and the total number Bursa skips while Bursa continues to exclude those categories from governance totals.
