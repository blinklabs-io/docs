## v0.21.1 - Safer signing, stronger session controls, and Cardano compatibility

- **Date:** 2026-10-27
- **Version:** 0.21.1
+ **Comparison:** [v0.21.0...v0.21.1](https://github.com/blinklabs-io/bursa/compare/v0.21.0...v0.21.1)

### Summary

This release strengthens KES and external signer controls, makes vault and session security state authoritative across reloads, improves resource limits and failure handling, and expands compatibility with `cardano-cli` 11.0 and Conway transaction features.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ New Features

* Improved KES key pushes by requiring successful authorization for the exact active period and retrying after guard state persistence failures.
* Updated the Google Cloud Secret Manager integration from `1.22.0` to `1.23.0`.
* Enhanced idle lock behavior by registering activity listeners before the lock becomes active, so activity during the enabling update remains visible to the lock timer.
* Secured external signer policy hooks by requiring authenticated HTTPS, rejecting redirects and trailing response data, expanding `OperationSummary`, and failing closed when summaries are incomplete.
* Refined signer validation by requiring 1 to 162 distinct resolved key hashes before signing work begins and reducing raw signer data in audit failures.

### 🔒 Security

* Bounded memory use for concurrent script validation request bodies and returned HTTP `503` when no body admission slot was available.
* Modernized container registry login workflows by updating `docker/login-action` to `4.7.0`.
* Protected release signing jobs with a `release-signing` GitHub Environment restricted to the `main` branch and version tags.
* Aligned VRF and KES key envelopes and the VRF signing key layout with `cardano-cli` `11.0`.
* Enforced server controlled vault auto lock across UI reloads, added `POST /vault/activity`, and reconciled UI lock state with the server.

### Additional Changes

* Expanded signer limits to include ledger value effects such as treasury donations and certificate or proposal deposits, and exposed completeness metadata.
* Refreshed mnemonic support by updating `go-bip39` to `0.2.1`.
* Added a 10 second deadline for completing KES agent frames and documented reconnect behavior.
* Introduced pool registration owner and relay flags with `cardano-cli` compatible encoding.
* Enabled optional Conway stake registration and deregistration deposit flags.
* Scoped GCP wallet Secret Manager access by validating and restricting its namespaces.
* Strengthened mnemonic generation by using `POST` requests with `no-store` and `no-cache` behavior.
* Upgraded `gax-go/v2` to `2.27.0` and refreshed its transitive dependencies.
* Patched `fast-uri` to `3.1.9`.
* Authenticated wallet control and connector consent sessions through a launch URL token and an `HttpOnly` cookie.
* Advanced SQLite support by updating `modernc.org/sqlite` to `1.61.0`.
* Encoded abstain and no confidence DRep targets as Conway arrays.
* Verified the WebView2 publisher for unpinned Windows bundles.
* Validated JWKS redirect transports and limited redirect chains.
* Simplified UI maintenance by updating Dingo to `0.88.1` and Apollo to `2.2.0`.
* Redacted generated OpenAPI client debug HTTP logs so `Debug` output shows only the request method and response status, and tightened multipart form handling.
* Added `bursa-wallet -n`/`--network` selection with `BURSA_NETWORK` fallback and a preview default; validated `musashi` and `dijkstra` protocol magic, rejected unknown network names and stray positional arguments, skipped Mithril bootstrap when no aggregator exists, added API and OpenAPI support with HTTP `404` wallet errors, labeled networks in the UI, and hid explorer links.
* Applied configured signer policy limits to collateral inputs, collateral returns, and total collateral; required `total_collateral` when collateral inputs exist and exposed collateral fields in `TxInspection` and `OperationSummary`.
* Stabilized the serving error race test so concurrent error handling remains deterministic.
* Upgraded `aws-sdk-go-v2` to `1.47.4` and `smithy-go` to `1.28.6`.
* Hardened release tag creation by validating tags before creation, preventing shell interpretation of tag values in archive names and Makefile linker flags, and rejecting `+build` metadata.
* Scoped connector grants to the origin plus `wallet_id` and `account_index`, rechecked identity after queued approvals, serialized protected calls with account rebinding, and required renewed consent for legacy origin only grants.
* Standardized DRep and constitutional committee key envelope names for `cardano-cli`, continued loading legacy names, and corrected `cc-hot` and `cc-cold` signer mapping.
* Introduced `--era` for `tx sign`, `tx witness`, and `tx assemble`, emitted era specific envelopes and witness encoding, and rejected ambiguous raw CBOR without an era declaration.
