## v0.19.0 - Governance participation, tray updates, and wallet improvements

- **Date:** 2026-10-09
- **Version:** 0.19.0

### Summary

This release adds in-wallet governance surveys, more flexible address parsing, manual tray update checks, and responsive wallet improvements. It also strengthens wallet connections and makes build and dependency updates more consistent.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ New Features

* Added text, hexadecimal, and base64 forms to `POST /api/address/parse`, so address requests accept more input formats. The service now bounds API and metrics request times, regenerates OpenAPI artifacts deterministically, detects specification drift, and handles OpenAPI tokens more safely.
* Improved in-wallet CIP-179 surveys and polls with governance links, sealed responses, and wallet API and UI routes, allowing governance participation from within Bursa.
* Refined responsive wallet and asset views, NFT media states, quote only swap flow, and design preview to provide clearer behavior across screen sizes and media availability.

### ⛓️‍💥 Breaking Changes

* Updated the desktop tray with manual update checks and embedded version metadata, and made `--signing-key-file` required for BLS key generation so the signing key source is explicit.

### 🔒 Security

* Strengthened wallet connections by hardening pairing and revocation, bounding chain and submission lifetimes, caching governance reads, and removing unused governance response fields.

### Additional Changes

* Expanded the browser extension's `brace-expansion` dependency to maintain its current dependency support.
* Modernized the web application's `brace-expansion` dependency to maintain its current dependency support.
* Upgraded service communication support by moving `grpc` from `1.83.2` to `1.84.0`.
* Refreshed extension source map support by moving `source-map-js` from `1.2.1` to `1.2.2`.
* Enhanced web source map support by moving `source-map-js` from `1.2.1` to `1.2.2`.
* Advanced database access support by moving `pgx` from `5.10.0` to `5.11.0`.
* Broadened Google API integration support by moving `google.golang.org/api` from `0.297.0` to `0.300.0`.
* Optimized container build setup by moving the Docker Buildx setup action from `4.3.0` to `4.4.1`.
* Corrected input validation support by moving `validator` from `10.30.4` to `10.30.5`.
* Extended cloud secret management support by moving Secret Manager from `1.21.0` to `1.22.0`.
* Staged and gated CI jobs while limiting concurrency for more controlled build and test execution.
* Revised embedded SQLite support by moving `modernc.org/sqlite` from `1.58.0` to `1.59.0`.
* Aligned Cardano chain integration by moving `gouroboros` from `0.205.5` to `0.210.0`.
* Raised address handling support by moving `ip-address` from `10.4.0` to `10.7.3`.
* Updated CBOR data handling by moving `cbor` from `2.9.3` to `2.9.4`.
* Increased extension test coverage for origins, timeouts, errors, and pairing flows.
* Integrated protobuf support while updating Trezor Connect Web from `9.7.3` to `10.0.1`.
* Accelerated container publishing by moving the Docker build and push action from `7.3.0` to `7.4.0`.
* Simplified Windows build setup by moving the MSYS2 setup action from `2.32.0` to `2.33.0`.
* Documented the validated `openexternal` path for `gosec` so security scanning uses the established invocation.
