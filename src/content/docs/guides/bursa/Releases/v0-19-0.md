## v0.19.0 - Governance participation, tray updates, and wallet improvements

- **Date:** 2026-10-09
- **Version:** 0.19.0

### Summary

This release adds in-wallet governance surveys, more flexible address parsing, manual tray update checks, and responsive wallet improvements. It also strengthens connector handling and makes build and dependency updates more consistent.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ New Features

* Added text, hexadecimal, and base64 input parsing to `POST /api/address/parse`, bounded API and metrics HTTP timeouts, regenerated OpenAPI artifacts, deterministic generation and drift detection, and safer token handling during OpenAPI generation.
* Improved in-wallet CIP-179 surveys and polls with governance linkage, sealed responses, and wallet API and UI routes, allowing governance participation from within Bursa.
* Refined responsive wallet and asset views, NFT media states, quote only swap flow, and design preview to provide clearer behavior across screen sizes and media availability.

### ⛓️‍💥 Breaking Changes

* Updated the desktop tray with manual update checks and embedded version metadata, and made `--signing-key-file` required for BLS key generation so signing key input is explicit.

### 🔒 Security

* Strengthened connector pairing and revocation, bounded chain and submission lifetimes, cached governance reads, and removed unused governance response fields to make wallet connections and governance interactions more predictable.

### Additional Changes

* Expanded the `brace-expansion` dependency update in `ui/extension` to keep the browser extension dependency set current.
* Modernized the `brace-expansion` dependency update in `ui/web` to keep the web dependency set current.
