## v0.17.0 - hardware signing, wallet reliability, and release hardening

- **Date:** 2026-09-19
- **Version:** 0.17.0
- **Release comparison:** [v0.16.0...v0.17.0](https://github.com/blinklabs-io/bursa/compare/v0.16.0...v0.17.0)

### Summary

This release adds optional hardware security module signing, strengthens wallet and storage protections, improves Cardano network compatibility, and makes release artifacts and publishing workflows more predictable.

### ✨ New Features

* Added an optional PKCS#11 Ed25519 hardware security module signer behind the `pkcs11` build tag. Configuration selects the module, token, slot, PIN, and allowed keys; signing remains on the token, and PKCS#11 keys do not support CIP-8.
* Standardized address derivation on account stake key index `0` while allowing payment key indexes to vary, producing consistent account addresses.

### ⛓️‍💥 Breaking Changes

* Changed HD-derived signing key exports to extended Ed25519-BIP32 envelopes, preserved non-extended pool-cold exports, and added identity, migration, and envelope contract guidance.
* Replaced legacy testnet API network names with the canonical `mainnet`, `preprod`, and `preview` values and updated the OpenAPI and Swagger documentation.
* Switched Linux and FreeBSD CLI release assets to `tar.gz` archives, replaced official Intel macOS wallet builds with arm64 builds, pinned the macOS runner, and attested the uploaded asset.
* Stopped mobile workflows from running automatically on version tags, made mobile builds manual, and aligned macOS installer signing with `APPLE_CERTIFICATE_PASSWORD`.

### 🔐 Security and Reliability

* Updated `github.com/blinklabs-io/gouroboros` from `0.186.0` to `0.189.1` and refreshed related modules, bringing upstream corrections for local state queries, Leios fetch, Conway withdrawals, Byron EBB handling, and chain synchronization shutdown.
* Improved Docker Hub and GHCR publishing with `docker/login-action` `4.6.0`, scoped Buildx configuration to the publishing step, and clarified Docker Hub OIDC errors.
* Migrated memory locking from `syscall.Mlock` and `syscall.Munlock` to `x/sys/unix` for BSD builds and added cross compilation checks for darwin/arm64, FreeBSD amd64/arm64, Linux amd64/arm64, and Windows amd64/arm64.
* Coordinated `ch-go` `0.65.0` with `clickhouse-go/v2` `2.32.0` in the UI to avoid compress API incompatibility and address `GO-2025-3603`.
* Refined the SQLite layer with `modernc.org/sqlite` `1.57.0`, defensive DSN handling, updated virtual table registration behavior, and SQLite durability fixes.

* Bounded BC-UR camera decoding by part, total bytes, part count, sequence, frame, and elapsed time; terminal errors stop processing and clean up camera resources.
* Made Docker multi architecture manifest publishing deterministic by composing versioned manifests from published architecture tags before applying floating aliases, preserving attestation digests, and adding contract tests.
* Advanced `github.com/blinklabs-io/gouroboros` from `0.193.0` to `0.193.3` with peer discovery, consensus, ledger, governance, and local state query fixes.
* Added null-origin Shelley header decoding compatibility while upgrading `github.com/blinklabs-io/gouroboros` from `0.197.0` to `0.202.2`.
* Hardened Windows SQLite URI and path handling and file permissions, bounded script validation and UI request bodies, improved vault durability error reporting, protected wallet files, strengthened multisig migration, bounded activity and notifier lifetimes, and corrected connector unpair errors.

### Additional Changes

* Updated `actions/setup-java` from `5.4.0` to `5.5.0` in the Windows signing workflow.
* Expanded test coverage for key, certificate, address, CLI, version, and logging capabilities without changing runtime behavior.
* Refreshed `actions/setup-node` to `7.0.0` in mobile, publishing, and UI workflows.
* Raised `PostCSS` in `ui/extension` from `8.5.22` to `8.5.25`.
* Enhanced Google API integrations by updating `google.golang.org/api` from `0.293.0` to `0.295.0`.
