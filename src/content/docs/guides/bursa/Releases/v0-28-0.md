## v0.28.0 - Attest staged keys with trusted KES agents

**Version:** 0.28.0

### Summary

This release lets operators using an attested TLS KES agent authorize operational certificate issuance for staged keys without changing `opcerts[].kes_vkeys` or restarting Bursa for each key.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ New Features

* Added `--attestation-out` to `gen-staged-key`, allowing an attested TLS KES agent to produce a signed staged-key attestation.

* Authorized operational certificate issuance for staged keys when a valid attestation matches a trusted agent in `opcerts[].kes_agents`.

* Configured trusted KES agents with an `spki_sha256` pin and an optional `profile` under `opcerts[].kes_agents`.

* Validated trusted KES agent configuration at startup so Bursa rejects invalid authorization pins before operation begins.

* Refused invalid staged-key attestations during operational certificate issuance.

* Preserved the existing `opcerts[].kes_vkeys` authorization path for requests without attestations.
