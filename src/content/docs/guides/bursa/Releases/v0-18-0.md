## v0.18.0 - Dijkstra BLS stake pool keys and wallet protection

- **Date:** 2026-09-21
- **Version:** 0.18.0

### Summary

This release adds Dijkstra-era BLS stake pool key tooling, accepts more Unicode forms in wallet mnemonics, and prevents wallet files from entering mobile device backups.

### ✨ New Features

- Added `bursa key bls` support for generating and locally verifying Dijkstra-era BLS12-381 MinSig stake pool material for Leios and Peras without a mnemonic. The command produces `cardano-cli`-compatible signing and verification key envelopes, verifies proof of possession, and emits registration JSON with lowercase hexadecimal `publicKey` and `possessionProof` values. Bursa protects generated files with owner-only output permissions and rejects colliding or symlink-equivalent output paths.

### ⛓️‍💥 Breaking Changes

- Made the recovery phrase necessary when restoring wallets on an iOS device because restored devices no longer recover wallet files from backups.

### 🐛 Bug Fixes

- Improved mnemonic handling by normalizing input to Unicode NFKD before splitting and BIP39 lookup in both the root wallet and UI wallet. The wallet accepts NFC text, ideographic spaces, and full-width Latin characters while still rejecting invalid mnemonics and preserving caller-supplied buffers.

### Additional Changes

- Excluded iOS `Application Support/Bursa` and legacy `Documents` wallet directories from iCloud and iTunes backups. All Android data domains no longer participate in device transfer or cloud backup. Bursa reports iOS exclusion failures in a one-time startup alert, retries the exclusion on the next launch, and protects migration fallback paths.
