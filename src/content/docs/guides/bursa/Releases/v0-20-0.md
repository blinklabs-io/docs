## v0.20.0 - Secure wallet storage, browser support, and protocol improvements

- **Date:** 2026-10-20
- **Version:** 0.20.0

### Summary

This release expands secure wallet storage and remote key custody, adds Firefox support for the connector, separates mobile node data from wallet data, and strengthens Cardano protocol, database, cryptographic, and transfer reliability.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ New Features

* Added AWS Secrets Manager wallet storage, AWS KMS and age SOPS key support, storage encryption and startup validation, authenticated wallet operations across backends, consistent not found responses, durable watermark enforcement, cancellation propagation, and vault boundary coverage.
* Enabled Firefox connector packaging and runtime support with target specific manifests, deterministic archives, Firefox origin handling, cross browser CIP-30 end to end coverage, automated packaging and linting, and `moz-extension://` authorization.
* Introduced attested remote key custody for AWS Nitro Enclaves and GCP Confidential Space. Nonce and purpose bound signing now covers transaction hashes, operational certificates, and CIP-8, while platform attestation checks, hardened HTTP and Unix transports, JWKS redirect controls, and typed KES Praos header signing protect custody operations.
* Separated mobile node databases from wallet data, migrated legacy `<DataDir>/db` data once, removed the iOS temporary directory fallback, and applied platform appropriate protection and backup settings to iOS and Android node directories.

### 🔒 Security

* Corrected CBOR handling so null and undefined values clear interface values to nil, stale map entries do not persist, and invalid input receives stricter errors.
* Hardened age and SOPS handling with upstream validation that can reject malformed recipients and oversized or multi recipient inputs.
* Improved SQLite reliability with stronger write ahead logging fault recovery and support for large parameter bindings, while tightening virtual file system close behavior and module version requirements.
* Expanded Cardano node communication with node to client protocol versions 22 and 23, stricter consensus and pipeline validation, finite E34 leader eligibility, and ledger, CBOR, and DMQ corrections.
* Refined Cardano integration with stricter ledger and CBOR decoding plus local state query and protocol corrections.
* Updated cryptographic and SSH handling through `golang.org/x/crypto` improvements, including upstream SSH and ACME capabilities and parsing fixes.

### 🐛 Bug Fixes

* Resolved desktop notifier process handling by collecting `cmd.Wait` results through both reaping paths and logging non nil errors at debug level.

### Additional Changes

* Modernized extension tooling with `web-ext` reload, glob, and signing fixes plus safer shell quoting.
* Replaced skipped wallet client checks with request, response, and error decoding coverage, stabilized CLI hash output assertions, and added race testing for OpenAPI code and continuous integration for the extension.
* Enhanced UI artifact transfers so rate limited requests honor the server's `Retry-After` guidance.
* Reinforced mobile, publishing, and UI artifact transfers with improved retry behavior when services apply rate limits.
* Clarified Unicode and bidirectional text handling through `golang.org/x/text` improvements and safer bidirectional rule initialization.
* Added metric format negotiation options while updating Prometheus client interfaces and related dependencies for Go 1.26.
* Updated embedded node UTxO RPC transaction submission with 30 second dial, request, and context limits, validated transaction reference lengths, replaced Firefox `web-ext` linting with `addons-linter`, refreshed `js-yaml`, and connected the UTxO RPC SDK.
* Bounded mobile and UI artifact downloads with improved retry and backoff handling for HTTP 429 responses.
* Refreshed AWS service integration through AWS SDK v2 `1.47.3` and `smithy-go` `1.28.5`.
* Advanced web application reliability with Vite `6.4.4` fixes for HTML transformation, transform identifiers, safe module paths, and launch editor integration.
* Validated Node.js setup across mobile, publishing, and UI workflows while retaining Node 22 and adding version checks, manifest retries, `mise.toml`, and absolute `node-version-file` support.
* Retained Node 22 in the UI workflow while improving its setup action.
* Streamlined Temurin Java setup in mobile and publishing workflows.
