## v0.20.0 - Secure wallet storage, browser support, and protocol improvements

- **Date:** 2026-10-20
- **Version:** 0.20.0

### Summary

This release expands secure wallet storage and remote key custody, adds Firefox support for the connector, separates mobile node data from wallet data, and strengthens Cardano protocol, database, cryptographic, and transfer reliability.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ New Features

* Added AWS Secrets Manager wallet storage, AWS KMS and age SOPS key support, storage encryption and startup validation, authenticated wallet CRUD across any backend, consistent `404` responses, generic persistence errors, durable watermark enforcement, cancellation propagation, and vault boundary coverage.
* Enabled Firefox connector packaging and runtime support with target specific manifests, deterministic archives, Firefox origin handling, cross browser CIP-30 end to end coverage, automated packaging and linting, and `moz-extension://` authorization.
* Introduced attested remote key custody for AWS Nitro Enclaves and GCP Confidential Space. Nonce and purpose bound signing now covers transaction hashes, operational certificates, and CIP-8, while platform attestation checks, hardened HTTP and Unix transports, JWKS redirect controls, and typed KES Praos header signing protect custody operations.
* Separated mobile node databases from wallet data, migrated legacy `<DataDir>/db` data once, removed the iOS temporary directory fallback, and applied platform appropriate protection and backup settings to iOS and Android node directories.

### 🔒 Security

* Corrected CBOR handling after updating from `2.9.4` to `2.9.6`, so null and undefined values clear interface values to nil, stale map entries do not persist, and invalid input receives stricter errors.
* Hardened age and SOPS handling by updating `filippo.io/age` from `1.3.1` to `1.3.2`, adding validation that can reject malformed recipients and oversized or multi recipient inputs.
* Improved SQLite from `1.59.0` to `1.60.1`, including its libc and tooling dependencies, with stronger write ahead logging fault recovery and support for large parameter bindings, while tightening virtual file system close behavior and module version requirements.
* Expanded `gouroboros` from `0.212.5` to `0.213.3` with Go `1.26.8`, node to client protocol versions 22 and 23, stricter consensus and pipeline validation, finite E34 leader eligibility, and ledger, CBOR, and DMQ corrections.
* Refined `gouroboros` `0.212.5` integration from `0.210.0` with stricter ledger and CBOR decoding plus local state query and protocol corrections.
* Updated `golang.org/x/crypto` from `0.57.0` to `0.58.0`, along with `x/sys` and `x/term`, adding upstream SSH and ACME capabilities and cryptographic and SSH parsing fixes.

### 🐛 Bug Fixes

* Resolved desktop notifier process handling by collecting `cmd.Wait` results through both reaping paths and logging non nil errors at debug level.

### Additional Changes

* Modernized extension tooling by updating `web-ext` from `10.7.0` to `10.8.0`, along with `shell-quote` and `fx-runner`, with reload, glob, and signing fixes plus safer shell quoting.
* Replaced skipped wallet client checks with `httptest` request, response, and error decoding coverage, stabilized CLI hash output assertions, and added race testing for OpenAPI code and continuous integration for the extension.
* Enhanced UI artifact uploads by updating `actions/upload-artifact` from `7.0.1` to `7.0.2`, so rate limited requests honor the server's `Retry-After` guidance.
* Reinforced mobile, publishing, and UI artifact uploads by updating `actions/upload-artifact` from `7.0.1` to `7.0.2` and improving retry behavior when services apply rate limits.
* Clarified Unicode and bidirectional text handling by updating `golang.org/x/text` from `0.42.0` to `0.43.0`, along with `x/sync` and `x/tools`, and safer bidirectional rule initialization.
* Added metric format negotiation options while updating Prometheus client interfaces from `1.24.1` to `1.25.0` and related dependencies, which now require Go 1.26.
* Updated embedded node UTxO RPC transaction submission with 30 second dial, request, and context limits, validated transaction reference lengths, replaced Firefox `web-ext` linting with `addons-linter`, refreshed `js-yaml`, and connected the UTxO RPC SDK.
* Bounded mobile and UI artifact downloads by updating `actions/download-artifact` from `8.0.1` to `8.0.2` and improving retry and backoff handling for HTTP 429 responses.
* Refreshed AWS service integration through AWS SDK v2 `1.47.1` to `1.47.3` and `smithy-go` `1.28.1` to `1.28.5`.
* Advanced web application reliability with Vite `6.4.3` to `6.4.4` fixes for HTML transformation, transform identifiers, safe module paths, and launch editor integration.
* Validated Node.js setup across mobile, publishing, and UI workflows by updating `actions/setup-node` from `7.0.0` to `7.1.0`, retaining Node 22 and adding version checks, manifest retries, `mise.toml`, and absolute `node-version-file` support.
* Retained Node 22 in the UI workflow while updating `actions/setup-node` from `7.0.0` to `7.1.0`.
* Streamlined Temurin Java setup by updating `actions/setup-java` from `6.0.1` to `6.1.0` in mobile and publishing workflows.
