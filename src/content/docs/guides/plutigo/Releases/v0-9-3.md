## v0.9.3

**Title:** Improve encoding and cryptographic validation

**Version:** v0.9.3

This release improves FLAT encoding efficiency, expands cryptographic capabilities and validation, and corrects CBOR null handling.

### Performance

* Improved FLAT encoding so large words process in linear time.

### Cryptography

* Expanded cryptographic capabilities with 49-bit MamaBear and KZG committers, corrected BLS12-381 and Jubjub generators, and updated Bandersnatch EdDSA backend behavior. Stricter deserialization and proof validation now reject malformed inputs instead of causing panics or allowing invalid proofs to verify. This upgrade requires Go 1.26.8 or later; regenerate affected BLS12-381, Jubjub, and Bandersnatch EdDSA points, keys, and signatures, and recompute MamaBear Poseidon2 digests.

### Reliability

* Corrected CBOR decoding: null and undefined values now set a Go interface to `nil` rather than retaining a prior value, and map decoding removes stale entries for null keys or values. More comprehensive validation can now reject inputs that previously passed, while the API remains unchanged.
