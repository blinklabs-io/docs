## v0.9.3

**Title:** Improve encoding and cryptographic validation

**Version:** v0.9.3

**Release:** [v0.9.3](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.3)

**Comparison:** [v0.9.2...v0.9.3](https://github.com/blinklabs-io/plutigo/compare/v0.9.2...v0.9.3)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release improves FLAT encoding, expands cryptographic capabilities and validation, and corrects CBOR null handling.

### Performance

* Improved FLAT encoding so big words process in linear time.

### Cryptography

* Updated `github.com/consensys/gnark-crypto` from v0.21.0 to v0.22.0 and raised the minimum Go version to 1.26.8. The dependency upgrade also includes stricter deserialization and proof validation that reject malformed inputs instead of causing panics or allowing invalid proofs to verify.

### Reliability

* Corrected CBOR decoding: null and undefined values now set a Go interface to `nil` rather than retaining a prior value, and map decoding removes stale entries for null keys or values. More comprehensive validation can now reject inputs that previously passed, while the API remains unchanged.
