## v0.9.7

**Title:** Normalize UPLC `Value` constants

**Version:** v0.9.7

**Release:** [v0.9.7](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.7)

**Comparison:** [v0.9.6...v0.9.7](https://github.com/blinklabs-io/plutigo/compare/v0.9.6...v0.9.7)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release normalizes non-canonical UPLC `Value` constants during text parsing, FLAT decoding, and `syn.NewValue` construction.

### Compatibility

* Improved text parsing, FLAT decoding, and `syn.NewValue` so each accepts unsorted policy and token entries, duplicate policy IDs and token IDs, empty token and policy lists, and zero-quantity entries rather than rejecting these non-canonical forms.

### Normalization

* Refined normalization to merge duplicate policy IDs and token IDs by adding quantities, sort policy and token keys lexicographically, remove zero-total tokens and empty policies, and enforce key-length and signed 128-bit quantity bounds, including after merges.
* Expanded decoding to cover both owned and arena-backed paths while preserving arena allocation behavior.
