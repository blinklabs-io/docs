## v0.9.7

**Title:** Normalize UPLC `Value` constants

**Version:** v0.9.7

**Release:** [v0.9.7](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.7)

**Comparison:** [v0.9.6...v0.9.7](https://github.com/blinklabs-io/plutigo/compare/v0.9.6...v0.9.7)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release normalizes non-canonical UPLC `Value` constants across text parsing, FLAT decoding, and `syn.NewValue`.

### Compatibility

* Improved text parsing, FLAT decoding, and `syn.NewValue` so they accept unsorted policy and token entries, duplicate policy IDs and token IDs, empty token and policy lists, and zero-quantity entries instead of rejecting these non-canonical forms.
