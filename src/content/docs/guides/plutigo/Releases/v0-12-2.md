## v0.12.2

**Title:** Improve evaluator and decoder performance

**Version:** v0.12.2

**Release date:** 2026-11-12

**Release:** [v0.12.2](https://github.com/blinklabs-io/plutigo/releases/tag/v0.12.2)

**Comparison:** [v0.12.0...v0.12.2](https://github.com/blinklabs-io/plutigo/compare/v0.12.0...v0.12.2)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release improves evaluator and decoder performance and makes profile generation more representative of the mainnet replay corpus while keeping profile-guided optimization opt-in.

### Improve Profile-Guided Optimization Workflows

* Improved the opt-in PGO workflow by switching `bench-pgo` to `tests/mainnet.pgo`, generating that profile from `BenchmarkRecentMainnetCorpus` with CGO disabled, cleaning `replay.test`, preserving test status, and documenting the mainnet replay corpus profile and refresh workflow.

### Optimize CEK List Evaluation

* Optimized CEK list evaluation by skipping shared list lookups until a cons list exists, caching `List()` results for head, tail, and null checks, and preserving element results.

### Accelerate FLAT Decoding

* Refined FLAT fixed-width tag and index reads with a two-byte window and arithmetic bit-position updates, removed `incrementBufferByBit`, and preserved decoder position state when the buffer ends or `NotEnoughBits` occurs.
