## v0.10.2

**Title:** Improve SHA-256 performance and reduce dependencies

**Version:** v0.10.2

**Release:** [v0.10.2](https://github.com/blinklabs-io/plutigo/releases/tag/v0.10.2)

**Comparison:** [v0.10.1...v0.10.2](https://github.com/blinklabs-io/plutigo/compare/v0.10.1...v0.10.2)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release improves SHA-256 performance by using the Go standard library, which can use platform acceleration where supported and avoids the previous implementation's pure Go fallback on affected platforms. It preserves SHA-256 outputs and removes unnecessary third-party dependencies.

### Performance

* Improved SHA-256 processing by using Go's standard cryptography library, enabling platform acceleration where supported and improving performance on platforms where the previous implementation used a pure Go fallback while preserving output compatibility.
* Updated performance benchmark names and baseline measurements to reflect the new SHA-256 implementation.

### Dependency Maintenance

* Removed the third-party SHA-256 implementation and its indirect CPU feature dependency, reducing the number of dependencies required by Plutigo.
