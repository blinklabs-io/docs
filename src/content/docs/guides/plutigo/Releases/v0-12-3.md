## v0.12.3

**Title:** Enforce version-aware Data case evaluation

**Version:** v0.12.3

**Release date:** 2026-11-15

**Release:** [v0.12.3](https://github.com/blinklabs-io/plutigo/releases/tag/v0.12.3)

**Comparison:** [v0.12.2...v0.12.3](https://github.com/blinklabs-io/plutigo/compare/v0.12.2...v0.12.3)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release makes case-on-Data behavior depend on the program and protocol versions, reduces allocation overhead during prepared-program evaluation, and adds a Plutus V3 flat benchmark.

### Enforce Version-Aware Data Case Handling

* Fixed case-on-Data evaluation so UPLC 1.1.0 programs receive `ScriptError 'Casing on data is not supported'` at protocol major 12 and later, while UPLC 1.2.0 programs can use the feature from protocol major 12.

### Reduce Prepared-Program Evaluation Overhead

* Reduced allocations during the pre-run structure walk to make prepared-program evaluation more efficient.

### Add a Plutus V3 Flat Benchmark

* Added a prepared-program flat benchmark and configured flat benchmarks to evaluate as Plutus V3.
