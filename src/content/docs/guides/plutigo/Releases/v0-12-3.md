This release makes case-on-Data behavior depend on the program and protocol versions, reduces allocation overhead during prepared-program evaluation, and adds a Plutus V3 flat benchmark.

### Enforce Version-Aware Data Case Handling

* Fixed case-on-Data evaluation so UPLC 1.1.0 programs receive `ScriptError 'Casing on data is not supported'` at protocol major 12 and later, while UPLC 1.2.0 programs can use the feature from protocol major 12.
