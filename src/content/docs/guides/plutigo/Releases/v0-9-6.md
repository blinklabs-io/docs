## v0.9.6

**Title:** Allow trusted ledger data to bypass the aggregate node cap

**Version:** v0.9.6

**Release:** [v0.9.6](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.6)

The aggregate PlutusData node cap now lets scripts use large ledger-supplied inline datums without rejecting the trusted values.

### Reliability

* Improved script execution for large ledger-supplied inline datums through `Machine.RunContextWithTrustedDataArguments(ctx, term, arguments...)`, which wraps supplied `PlutusData` arguments as trusted data constants while continuing to validate surrounding terms and applications. The runtime excludes trusted constants from the aggregate `maxDischargeWork` PlutusData node cap. Existing `Run` and `RunContext` methods continue to pass no trusted data and retain their prior behavior. If `ctx` is nil, the method uses `context.Background`, so evaluation proceeds without cancellation. Cancellation is honored when a cancellable context is provided. The method rejects typed-nil data, too many arguments, and malformed builtin tags.
