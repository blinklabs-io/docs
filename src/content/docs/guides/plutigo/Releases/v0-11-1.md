## v0.11.1

**Title:** Improve pooled evaluation reuse and preparation speed

**Version:** v0.11.1

**Release:** [v0.11.1](https://github.com/blinklabs-io/plutigo/releases/tag/v0.11.1)

**Comparison:** [v0.11.0...v0.11.1](https://github.com/blinklabs-io/plutigo/compare/v0.11.0...v0.11.1)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|

| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release improves pooled machine reuse and prepares programs more efficiently, reducing repeated allocation and evaluation time for repeated script execution.

### Retain Pooled Machine Resources

* Improved repeated script execution by retaining pooled machine arenas across runs, tracking the next run's budget explicitly with `Machine.SetExBudget(budget ExBudget)`, and shrinking value arena chunks only after 16 consecutive smaller runs. This reduces repeated allocation while preserving resources for workloads that remain large.

### Prepare Programs Faster

* Accelerated prepared program creation by combining De Bruijn decoding with protocol context and scope validation in one pass. `DecodeInfo` and retained memory accounting expose preparation details, `cek.PrepareProgram` avoids a second structure walk, and `PreparedProgram.RetainedBytes()` reports retained memory. The Lantr benchmark reports about 20% less time across `PrepareProgram` and `RunPreparedScriptContext` iterations.
