## v0.11.2

**Title:** Load compressed replay corpora and validate recent mainnet behavior

**Version:** v0.11.2

**Release:** [v0.11.2](https://github.com/blinklabs-io/plutigo/releases/tag/v0.11.2)

**Comparison:** [v0.11.1...v0.11.2](https://github.com/blinklabs-io/plutigo/compare/v0.11.1...v0.11.2)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release lets replay callers load gzip-compressed corpora directly while retaining decompressed-size limits and cancellation handling. It also expands parity and throughput validation to a recent mainnet dataset containing 1,360 evaluations.

### Load Compressed Replay Corpora

* Added direct gzip decompression for replay corpus files with a `.gz` suffix, so callers can load compressed JSON without a separate decompression step. The loader continues to enforce the existing decompressed-size limits and honor cancellation while it reads compressed data.

### Validate Recent Mainnet Behavior

* Expanded replay parity checks and throughput benchmarks to a recent mainnet corpus of 1,360 evaluations, covering 32 PlutusV1, 962 PlutusV2, and 366 PlutusV3 evaluations. The corpus includes gzip-compressed assets and helps detect parity regressions while measuring performance against current mainnet workloads.
