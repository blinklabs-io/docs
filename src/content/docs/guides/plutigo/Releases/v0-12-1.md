This release trims the allocation overhead of shared list storage while preserving execution time within measurement noise and maintaining compatibility with existing integrations.

### Trim Shared Container Overhead

* Improved list and map values from `mkCons` so lazy unwrapping returns the original containers without allocating.
* Streamlined evaluator data walking by resolving each container's children once, then using specialized cursors to advance through them without repeating type checks.
* Consolidated CBOR length state and lazy sources in typed shared headers for `List`, `Map`, and `Constr`.
* Rejected cons-cell lengths outside the `int32` range and reported overflow as `InternalError`.
* Reduced allocations per pass by approximately 4–5% and bytes per pass by approximately 5%, while execution time remained unchanged within measurement noise.

### Verify Container Safety

* Added tests for allocation-free lazy unwrapping, container size invariants, and length overflow handling.

### Preserve Compatibility

* Preserved existing integration behavior without introducing breaking changes.
