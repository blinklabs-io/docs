This release trims the allocation overhead of shared list storage while preserving execution time within measurement noise and maintaining compatibility with existing integrations.

### Trim Shared Container Overhead

* Improved shared list and map values created with `mkCons` so lazy unwrapping returns the original containers without allocating.
* Streamlined evaluator data walking by resolving each container's children once and advancing with specialized cursors instead of repeating type checks.
* Consolidated CBOR length state and lazy data sources in typed shared headers for `List`, `Map`, and `Constr`.
