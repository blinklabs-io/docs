## v0.11.6

**Title:** Cache repeated large Blake2b inputs

**Version:** v0.11.6

**Release date:** 2026-11-06

**Release:** [v0.11.6](https://github.com/blinklabs-io/plutigo/releases/tag/v0.11.6)

**Comparison:** [v0.11.5...v0.11.6](https://github.com/blinklabs-io/plutigo/compare/v0.11.5...v0.11.6)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release reduces repeated hashing work for eligible large `ByteString` inputs during a single evaluation while preserving existing budget accounting.

### Improve Repeated Large Input Hashing

* Improved repeated Blake2b-256 hashing for identical `ByteString` inputs from 4 KiB through 1 MiB during a single evaluation by reusing eligible results. The evaluator retains up to 64 recent inputs or 1 MiB of copied input data, clears them when evaluation ends, and applies the existing budget charge before reusing a result.
