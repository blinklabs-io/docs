## v0.9.11

**Title:** Upgrade the Plutigo Go toolchain

**Version:** v0.9.11

**Release:** [v0.9.11](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.11)

**Comparison:** [v0.9.10...v0.9.11](https://github.com/blinklabs-io/plutigo/compare/v0.9.10...v0.9.11)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release updates the Go version and improves reliability for deeply nested PlutusData JSON without changing configured safety limits.

### Toolchain

* Updated the Go version from `1.26.8` to `1.26.10`.
* Aligned automated analysis with the `1.26.x` Go version.

### JSON Decoding

* Improved decoding for valid, deeply nested PlutusData JSON by using an alternate decoding path when the default decoder reaches its internal nesting limit, while preserving the configured maximum depth and node limits.
* Standardized errors from alternate decoding so incomplete input produces consistent results across Go versions.
* Preserved stable `DecodeJSON` errors when JSON starts with a value other than an object.

### Validation

* Expanded test coverage across decoding errors, incomplete input, depth limits, deeply nested values, and stable errors for deeply incomplete input.
