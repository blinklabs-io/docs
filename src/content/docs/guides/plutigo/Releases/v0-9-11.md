## v0.9.11

**Title:** Upgrade the Plutigo Go toolchain

**Version:** v0.9.11

**Release:** [v0.9.11](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.11)

**Comparison:** [v0.9.10...v0.9.11](https://github.com/blinklabs-io/plutigo/compare/v0.9.10...v0.9.11)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release upgrades the Go toolchain and improves JSON decoding for deeply nested PlutusData while preserving configured safety limits.

### Toolchain

* Updated the Go toolchain from `1.26.8` to `1.26.10`.
* Aligned CI analysis with the `1.26.x` toolchain.

### JSON Decoding

* Improved decoding for deeply nested valid PlutusData JSON by using a deep parser when the standard decoder reaches its internal nesting limit, while preserving the configured maximum depth and node limits.
* Standardized deep parser errors so truncated input produces consistent results across Go versions.
* Preserved stable error text when `DecodeJSON` receives a top level value that is not an object.

### Validation

* Expanded test coverage for deep parser error parity, truncated input, depth limits, preservation of deeply nested values, and stable errors for deeply truncated input.
