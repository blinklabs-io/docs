## v0.2.0 (July 31, 2026)

**Title:** Align V4 builtins, replay tooling, and test coverage

**Date:** July 31, 2026

**Version:** v0.2.0

This release aligns Plutigo with current Plutus V4 builtin behavior, refreshes conformance and CI support, improves CEK execution speed, and adds mainnet replay tooling and corpus coverage.

### ✨ What's New

This release expands runtime validation and adds replay support for mainnet script traces so Plutigo can better exercise real world execution paths.

* Added **mainnet script replay runner:** The new `plutigo-replay` CLI loads replay corpora strictly, runs script replays, and writes execution reports for review.
* Expanded **mainnet replay corpus coverage:** The checked in replay corpus now adds test coverage, benchmark support, and legacy integer cost model compatibility for Variant D.
* Aligned **V4 builtin coverage:** Plutus V4 builtin availability and tags now match the upstream specification, and the related conformance fixtures now reflect the current builtin set.
* Improved **CEK environment lookups:** Indexed ancestor lookup and supporting arena management reduce the work needed during execution.

### 🔧 Fixes

This update corrects execution and validation behavior so conformance checks reflect current runtime rules.

* Fixed **conformance coverage:** The updated test suite now reflects PV11 semantics, builtin cost models, parser validation, and crypto behavior more accurately.
* Replaced **keccak_256 implementation:** Plutigo now uses the legacy Keccak implementation from `x/crypto`, removes the `go-ethereum` dependency, and keeps builtin coverage tests aligned with the new path.

### 📋 What You Need to Know

This release keeps release processes current and reduces unnecessary repository automation while preserving execution and validation alignment.

* Refreshed **Go setup workflow:** The pinned `actions/setup-go` reference now tracks version `v7.0.0`, keeping build workflows current.
* Updated **checkout workflow:** The pinned `actions/checkout` reference now tracks version `v7.0.1`, keeping build workflows current.
* Simplified **CI maintenance:** The issue close date automation and its related workflow no longer run, reducing unnecessary repository automation.

### 🙏 Thank You

Thank you for using Plutigo.
