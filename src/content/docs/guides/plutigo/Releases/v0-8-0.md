## v0.8.0

**Title:** Expand Plutus V4 support and update context APIs

**Version:** v0.8.0

**Release:** [v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**Comparison:** v0.7.2...v0.8.0

This release completes the published Plutus V4 cost model, adds V4 script context construction and serialization, reorganizes the V4 API, and updates repository review ownership.

### New Features

* Expanded the published Plutus V4 cost model for `Policies` and `AssetCount`: the V4 parameter vector now contains 361 entries rather than 357, with four `policies-*` names added. Affected V4 evaluations now produce different CEK budget outcomes.

* Added V4 script context builders and serializers for addresses, outputs, purposes, transaction information, nested top transaction information, and script contexts. Omitted output datums encode as `NoOutputDatum`.

### Breaking Changes

* Updated the V4 script context API by moving its builders from the removed `plutus/v4` package into `lang` and introducing `*V4` types and data APIs. The migration requires updated imports, type names, and helper aliases.

### Additional Changes

* Refined the global `.github/CODEOWNERS` rule by removing `@agaffney` and leaving `@wolf31o2` as the sole owner for affected paths. This changes review and notification routing without changing runtime behavior.
