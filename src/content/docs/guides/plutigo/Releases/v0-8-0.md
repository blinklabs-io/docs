## v0.8.0

**Title:** Expand Plutus V4 support and update context APIs

**Version:** v0.8.0

**Release:** [v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**Comparison:** v0.7.2...v0.8.0

This release completes the published Plutus V4 cost model, expands V4 script context construction and serialization, updates the V4 API organization, and changes repository review ownership.

### New Features

* Expanded the published Plutus V4 cost model for `Policies` and `AssetCount`. The V4 parameter vector now contains 361 entries instead of 357, including four `policies-*` names, which changes CEK budget outcomes for affected V4 evaluations.

* Added V4 script context builders and serializers for addresses, outputs, purposes, transaction information, nested top transaction information, and script contexts. Omitted output datums now use the correct `NoOutputDatum` encoding.
