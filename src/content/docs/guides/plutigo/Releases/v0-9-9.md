## v0.9.9

**Title:** Reject noncanonical Value constants

**Version:** v0.9.9

This release makes public UPLC text parsing and Flat decoding reject noncanonical `Value` constants instead of normalizing them.

### Parsing

* Improved public UPLC text parsing through `Parse` and `ParseWithContext` so it rejects noncanonical `Value` constants rather than normalizing them.

### Decoding

* Strengthened Flat decoding so it rejects noncanonical `Value` constants rather than normalizing them.

### Validation

* Corrected handling for malformed `Value` literals with duplicate or out of order policy or token keys, empty inner token maps, zero quantity entries, or quantities outside the signed 128 bit range.

### Compatibility

* Updated compatibility behavior so clients that relied on malformed `Value` literals being accepted and normalized now receive parse or decoding errors.

For reference, see [PR #493](https://github.com/blinklabs-io/plutigo/pull/493).
