## v0.10.1

**Title:** Correct Plutus V4 evaluation and add scoped flat execution

**Version:** v0.10.1

**Release:** [v0.10.1](https://github.com/blinklabs-io/plutigo/releases/tag/v0.10.1)

This release corrects Plutus V4 evaluation behavior, adds allocation scaling coverage, and provides a scoped flat execution path with explicit compatibility checks for callers.

### Evaluator Compatibility
* Corrected Plutus V4 data choice evaluation to use six arguments, removed the V4 only seventh `Value` branch, aligned builtin arity handling with the reference evaluator, and fixed six argument case applications. Scripts that depend on the removed seventh `Value` branch now fail and require migration.

### Allocation Safeguards
* Added allocation scaling coverage for hexadecimal byte strings, strings, escaped newlines, and nested pair literals; the test enforces an 8x allocation cap when inputs scale from 1x to 4x.
