This release improves evaluator performance and allocation efficiency across integer arithmetic, data construction, constant creation, and reusable evaluation resources.

### Optimize Large-Operand Division

* Improved large-operand `divideInteger` evaluation by computing the quotient and remainder once and reusing a read-only constant for floor adjustment. Tests cover floor semantics and input immutability, with about 7.5% fewer allocations and 5% less time on a 1,360-validator corpus.

### Build Dynamic Integer Constants Efficiently

* Reduced allocations for dynamic `int64` constants by constructing each value in one allocation and keeping caching local to each evaluation machine. Parallel evaluation no longer contends on a process-wide cache lock.

### Improve Data List Construction

* Enhanced list construction so adding data heads to empty typed `list(data)` constants uses data-list representations, while adding data-pair heads to `list(pair data data)` values uses data-map representations. The evaluator validates declared `ProtoPair` types and rejects mismatched types, reducing allocations by about 28% and time by 9% on a recent mainnet corpus.

### Standardize Go Formatting

* Standardized Go formatting with `golines` and `gci`, and resolved a formatter and lint failure in `data/walk.go` without changing runtime behavior.

### Retain Value Arena Chunks

* Preserved CEK value arena chunks when script sizes change by using fixed 512-slot chunks, per-arena retention, bounded retention, and 16-run shrink hysteresis. This reduces bytes allocated by about 75% and single-threaded time by 6% per corpus pass.
