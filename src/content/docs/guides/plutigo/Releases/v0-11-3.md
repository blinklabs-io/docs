This release improves evaluator performance and allocation efficiency across integer arithmetic, data construction, constant creation, and reusable evaluation resources.

### Optimize Large-Operand Division

* Improved large-operand `divideInteger` evaluation by computing the quotient and remainder once and reusing a read-only constant for floor adjustment. Tests cover floor semantics and input immutability, with about 7.5% fewer allocations and 5% less time on a 1,360-validator corpus.

### Build Dynamic Integer Constants Efficiently

* Reduced allocations for dynamic `int64` constants by constructing each value in one allocation and keeping caching local to each evaluation machine. Parallel evaluation no longer contends on a process-wide cache lock.
