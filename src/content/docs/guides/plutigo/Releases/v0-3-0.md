## v0.3.0 (August 7, 2026)

**Title:** Improve decoder reuse checks and align final slippage handling

**Date:** August 7, 2026

**Version:** v0.3.0

This release improves decoder reuse checks and aligns cek final slippage handling with the reference behavior, making repeated runs and result comparisons more reliable.

### ✨ What's New

This release strengthens repeated decoder reuse checks so repeated runs stay predictable.

* Improved **decoder reuse validation:** Reused decoders now replace retained numeric state after `Reset()`, and the test suite also covers shared decoder reuse.

### 🔧 Fixes

This update restores final slippage handling so execution follows the reference path consistently.

* Fixed **final slippage handling:** Cek no longer skips the final slippage check on the alternate path, which keeps the outcome aligned with the expected behavior.

### 📋 What You Need to Know

This release matters for workflows that reuse decoders across runs or compare cek output against the reference path.

### 🙏 Thank You

Thank you for using Plutigo.
