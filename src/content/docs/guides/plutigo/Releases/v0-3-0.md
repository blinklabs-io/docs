## v0.3.0 (August 7, 2026)

**Title:** Improve decoder reuse validation and align final slippage handling

**Date:** August 7, 2026

**Version:** v0.3.0

This release improves decoder reuse validation and aligns cek final slippage handling with the reference behavior, making repeated runs and result comparisons more reliable.

### ✨ What's New

This release strengthens repeated decoder reuse checks so state handling stays predictable across successive runs.

* Improved **decoder reuse validation:** Reused decoders now overwrite retained numeric state after `Reset()`, and the test suite also covers shared De Bruijn decoder reuse.

### 🔧 Fixes

This update restores cek final slippage handling so execution follows the reference path consistently.

* Fixed **final slippage handling:** Cek no longer skips the final slippage check in the non reference path, which keeps the outcome aligned with the expected behavior.

### 📋 What You Need to Know

This release is most relevant for workflows that reuse decoders across runs or compare cek output against the reference path.

### 🙏 Thank You

Thank you for using Plutigo.
