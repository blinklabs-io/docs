## v0.6.0 (September 7, 2026)

**Title:** Improve evaluation reliability, data handling, and conformance coverage

**Date:** September 7, 2026

**Version:** v0.6.0

**Comparison:** v0.5.1...v0.6.0

This release improves Plutigo evaluation reliability, data handling, JSON safety, cost model isolation, and conformance verification.

### ✨ New Features

* Added **explicit Plutus data normalization:** `data.Normalize` now deep copies constructor, map, and list trees, resets definite and indefinite encoding state, copies mutable constructor tags, and handles value form containers. Applying it at the script or evaluator boundary gives scripts a fresh canonical encoding without changing `Decode` wire fidelity.

### 🔧 Fixes

* Improved **evaluation error reporting:** CEK evaluation now preserves script, builtin, and type error classes, matches context cancellation and deadline errors, maps unexpected evaluator failures to internal errors, and maps unexpected builtin failures to builtin errors. This makes failures easier to classify and handle reliably.

* Bounded **JSON parsing:** Plutigo now checks nesting depth and node count while parsing, before allocating the complete tree, and reports parser limit errors while accepting structures at the semantic boundary. This reduces resource exhaustion risk while preserving valid boundary cases.

* Isolated **cost model settings:** Each evaluation now receives independent builtin cost settings, preventing shared mutable defaults, data races, and nondeterministic execution unit results during concurrent evaluations.
