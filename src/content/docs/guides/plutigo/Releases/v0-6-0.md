## v0.6.0 (September 7, 2026)

**Title:** Improve evaluation reliability, data handling, and conformance coverage

**Date:** September 7, 2026

**Version:** v0.6.0

**Comparison:** v0.5.1...v0.6.0

This release improves Plutigo evaluation reliability, data handling, JSON safety, cost model isolation, and conformance verification.

### ✨ New Features

* Added **explicit Plutus data normalization:** `data.Normalize` now deep copies constructor, map, and list trees, resets definite and indefinite encoding state, copies mutable constructor tags, and handles value form containers. Applying it at the script or evaluator boundary gives scripts a fresh canonical encoding without changing `Decode` wire fidelity.
