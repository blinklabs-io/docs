## v0.9.8

**Title:** Improve cancellation during built-in evaluation

**Version:** v0.9.8

**Release:** [v0.9.8](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.8)

**Comparison:** [v0.9.7...v0.9.8](https://github.com/blinklabs-io/plutigo/compare/v0.9.7...v0.9.8)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release makes canceled evaluations stop expensive built-in work sooner and preserves the original cancellation errors for reliable detection.

### Reliability

* Improved cancellation handling so evaluations stop expensive built-in work sooner when the active context is canceled or reaches its deadline.
* Extended cancellation checks across BLS12-381 multi-scalar multiplication and value operations, including coin insertion, scaling, union, and containment.

### Error Handling

* Preserved direct `errors.Is` matching for `context.Canceled` and `context.DeadlineExceeded` while returning `InternalError` for other value-construction failures.
