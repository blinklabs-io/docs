## v0.7.1 (September 16, 2026)

**Title:** Configure data decoding depth and standardize release automation

**Date:** September 16, 2026

**Version:** v0.7.1

**Comparison:** v0.7.0...v0.7.1

This release gives applications direct control over the maximum nesting depth accepted during data decoding and standardizes repository release automation.

### 🔧 Fixes

* Improved **data decoding control:** Applications can now configure `MaxDecodeNestingDepth` to set the maximum nesting depth accepted during decoding.

### 📦 Additional Changes

* Standardized **release automation:** Repository workflows now use consistent checkout settings.

### 🙏 Thank You

Thank you for using Plutigo.
