## v0.11.4

**Title:** Cap aggregate evaluation memory

**Version:** v0.11.4

**Release date:** 2026-11-05

**Release:** [v0.11.4](https://github.com/blinklabs-io/plutigo/releases/tag/v0.11.4)

**Comparison:** [v0.11.3...v0.11.4](https://github.com/blinklabs-io/plutigo/compare/v0.11.3...v0.11.4)

|---------------------|------------|
| mainnet             | ⛔         |

| preview-testnet     | ✅         |
| musashi             | ✅         |

This release improves memory stability for pooled evaluators by controlling retained working capacity.

### Improve Pooled Evaluator Memory

* Improved pooled evaluator memory management by enforcing a shared 32 MiB retention budget across retained value storage, rotating allocation order after resets so later storage pools continue receiving capacity, and releasing oversized list storage during reset and preparation. Coverage verifies the aggregate limit and rotation behavior.
