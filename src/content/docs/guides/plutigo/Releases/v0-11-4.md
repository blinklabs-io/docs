## v0.11.4

**Title:** Cap aggregate value arena retention

**Version:** v0.11.4

**Release date:** 2026-11-05

**Release:** [v0.11.4](https://github.com/blinklabs-io/plutigo/releases/tag/v0.11.4)

This release improves memory management for pooled CEK machines by limiting retained value arena capacity to a shared 32 MiB budget.

### Cap Shared Value Arena Retention

* Improved pooled CEK machine memory management by enforcing a shared 32 MiB retention budget across all value arenas, rotating arena allocation order after resets so later arenas continue receiving capacity, and releasing oversized chunk-list backing capacity during reset and preparation. Coverage verifies the aggregate limit and rotation behavior.
