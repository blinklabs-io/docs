This release reduces unnecessary allocation while the evaluator processes lists and clarifies the ownership rules for the data and protocol list APIs.

### Reduce Evaluator Allocations

* Improved lists built with `mkCons` by retaining their persistent storage and materializing values only when an operation needs size or cost information, reducing eager copying for list, map, and constructor data.
* Preserved the cons-cell representation during list, map, and constructor decomposition and `Data` case matching, keeping these operations constant-time.
