This release improves evaluation performance, enables reusable validated programs, changes cancellation polling timing, and updates CBOR support.

### Improve Quadratic Cost Evaluation

* Improved bounded integer cost calculations for `divideInteger` operations with a fast 64 bit path. Larger inputs use arbitrary precision arithmetic, and the evaluator caps results at 64 bit limits when required, preserving behavior for out of range inputs while avoiding per call arbitrary precision allocations in typical calculations.

### Reuse Prepared Programs

* Added `cek.PrepareProgram`, `cek.PrepareDecodedProgram`, and `cek.RunPreparedScriptContext` so repeated script evaluations can reuse immutable validated programs. When scope modes, argument chain depths, and work limits remain compatible, evaluations skip repeated structure and scope checks while preserving outcomes, errors, budgets, and PV11/PV12 scope behavior. Prepared programs also support concurrent reuse.

### Adjust Cancellation Polling

* Refined cancellation handling during context aware evaluation. The evaluator checks cancellation after charging each slippage sized step batch, which reduces polling overhead and preserves budget accounting. Cancellation can arrive later than before, and the evaluator charges executed costs before returning.

### Update CBOR Support

* Updated CBOR support to version `2.10.0`, bringing upstream performance, allocation, and bug fixes along with the `toindefarray` tag option.
