This release improves evaluator performance, enables reusable validated programs, changes cancellation polling timing, and updates CBOR support.

### Improve Quadratic Cost Evaluation

* Improved bounded integer cost calculations for `divideInteger` operations with a fast `int64` path. Larger inputs use arbitrary precision arithmetic, and results saturate at `int64` limits when required, preserving behavior for out of range inputs while avoiding per call `big.Int` allocations in typical calculations.
