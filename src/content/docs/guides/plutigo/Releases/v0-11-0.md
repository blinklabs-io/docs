## v0.11.0

**Title:** Improve CEK evaluation efficiency and reuse

This release improves evaluator performance, enables reusable validated programs, changes cancellation polling timing, and updates CBOR support.

### Improve Quadratic Cost Evaluation

* Improved bounded integer cost calculations for `divideInteger` operations with a fast `int64` path. Larger inputs use arbitrary precision arithmetic, and results saturate at `int64` limits when required, preserving behavior for out of range inputs while avoiding per call `big.Int` allocations in typical calculations.

### Reuse Prepared Programs

* Added `cek.PrepareProgram`, `cek.PrepareDecodedProgram`, and `cek.RunPreparedScriptContext` so repeated evaluations can reuse immutable validated programs. Compatible scope modes, argument chain depths, and work limits allow evaluations to skip repeated structure and scope checks while preserving outcomes, errors, budgets, and PV11/PV12 scope behavior. Prepared programs also support concurrent reuse.

### Adjust Cancellation Polling

* Refined context aware evaluation to check cancellation after charging each slippage sized step batch. This reduces polling overhead and preserves budget accounting, but cancellation can arrive later than before, and executed costs are charged before evaluation returns.

### Update CBOR Support

* Updated CBOR support to version `2.10.0`, bringing upstream performance, allocation, and bug fixes along with the `toindefarray` tag option.
