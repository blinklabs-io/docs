## v0.12.4

**Title:** Update dependencies and reject unsupported data tags

**Version:** v0.12.4

**Release date:** 2026-11-16

**Release:** [v0.12.4](https://github.com/blinklabs-io/plutigo/releases/tag/v0.12.4)

This release updates the Go dependencies and refines FLAT data constant decoding for the Value constructor across ledger languages V1–V4.
This release updates the Go libraries used by Plutigo and makes FLAT data constant decoding reject the `Value` constructor for ledger languages V1–V4.

### Update Go Dependencies

* Updated `golang.org/x/crypto` to v0.59.0 and `golang.org/x/sys` to v0.50.0.

### Reject Unsupported Value Tags in FLAT Data

* Improved FLAT data constant decoding across ledger languages V1–V4 by rejecting CBOR tag `1401` in `data.DecodePrefix` and the shared arena path with `unknown CBOR tag for PlutusData: 1401`; `DecodeWithValue` and the UPLC text parser continue to support `Value`. Boundary tests cover tag handling and exported decoders.
