## v0.9.10

**Title:** Align Plutus evaluation and validation behavior

**Version:** v0.9.10

**Release:** [v0.9.10](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.10)

**Comparison:** [v0.9.4...v0.9.10](https://github.com/blinklabs-io/plutigo/compare/v0.9.4...v0.9.10)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release aligns Plutus evaluation costs, validation rules, and protocol-dependent behavior with current Plutus semantics while updating cryptographic dependencies.

### Reliability

* Corrected CEK default evaluation cost selection for Plutus semantics Variant A by embedding reference cost parameters and applying them to Plutus V1 and V2 before protocol 9. Regression coverage now includes protocol 8 and protocol 9 boundary cases.

### Compatibility

* Introduced protocol-gated `case` on `Data` behavior and rejected `constr` and `case` in flat programs before UPLC 1.1.0, aligning accepted programs with current Plutus behavior.

### Validation

* Refined value-builtin default costs and hardened validation to reject open De Bruijn variables, aligning evaluation and validation with current Plutus behavior.

### Dependencies

* Updated `golang.org/x/crypto` to v0.58.0 and indirect `golang.org/x/sys` to v0.49.0. This maintenance update changes dependency versions only.
