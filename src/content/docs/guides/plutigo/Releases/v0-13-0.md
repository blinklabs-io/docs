This release enables Plutus batch 7 builtins at Dijkstra protocol version 12 and refreshes developer guidance for evaluation, FLAT execution, Plutus V4 references, and reproducible benchmarks.

### Enable Plutus Batch 7 Builtins

* Added `multiIndexArray`, `policies`, `assetCount`, `keepPolicies`, and `dropPolicies` for Plutus V1–V4 at Dijkstra protocol version 12, allowing batch 7 programs to run at that protocol version.

### Filter Policies Correctly

* Improved `keepPolicies` and `dropPolicies` filtering to return correct results and reject inputs containing more than 256 policy IDs.

### Align Execution and Conformance Data

* Updated CEK implementations, cost models, parameter tables, and conformance fixtures to match upstream expectations.
