## v0.13.0

**Title:** Enable batch 7 builtins and refresh developer guidance

**Version:** v0.13.0

**Release date:** 2026-11-18

**Release:** [v0.13.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.13.0)

**Comparison:** [v0.12.4...v0.13.0](https://github.com/blinklabs-io/plutigo/compare/v0.12.4...v0.13.0)

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

This release enables Plutus batch 7 builtins at Dijkstra protocol version 12 and refreshes developer guidance for evaluation, FLAT execution, Plutus V4 references, and reproducible benchmarks.

### Enable Plutus Batch 7 Builtins

* Added `multiIndexArray`, `policies`, `assetCount`, `keepPolicies`, and `dropPolicies` for Plutus V1–V4, enabling batch 7 programs at Dijkstra protocol version 12.

### Filter Policies Correctly

* Improved `keepPolicies` and `dropPolicies` filtering to return correct results and reject inputs containing more than 256 policy IDs.

### Align Execution and Conformance Data

* Updated CEK implementations, cost models, parameter tables, and conformance fixtures to match upstream expectations.

### Refresh Developer Guidance

* Clarified that Plutigo requires Go 1.26.11 or newer and corrected guidance for `cek.NewEvalContext`, `cek.EvaluateText`, FLAT execution, Plutus V4 file references, and reproducible benchmark procedures.
