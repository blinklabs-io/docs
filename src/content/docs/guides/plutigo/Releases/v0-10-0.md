## v0.10.0

**Title:** Harden evaluator and align Plutigo with PV11

**Version:** v0.10.0

This release strengthens evaluation and data processing against resource exhaustion and consensus divergence, with conformance verified against `cardano-node` 11.1.3 (PV11). It also adds migration options for integrations and updates the `btcec/v2` dependency without changing runtime behavior.

### Evaluator Security and Conformance

* Improved evaluator resilience against resource exhaustion and consensus divergence with panic recovery and `RunScriptContext` based evaluation.
* Added zero width FLAT memoization plus lexer, parser, and FLAT varint limits to bound resource use during script processing.
* Added structurally shared `Value` helpers and persistent runtime lists to make evaluation more robust.
* Enforced libsodium strict Ed25519 verification for consistent signature validation.
* Applied PV11 bounded builtin arguments and charge then check budget semantics, including piecewise costs for data and list operations.
* Added De Bruijn slippage batching with `DefaultSlippage=200` to improve evaluation consistency.
