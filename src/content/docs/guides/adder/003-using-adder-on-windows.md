# Using Adder on Windows

Adder is a packaged desktop application that runs in the system tray and provides a streamlined, user‑friendly experience for monitoring Cardano blockchain activity.

## Step 1 - Download the Adder installer
The easiest way to install Adder on Windows is by using the MSI installer available on the Blink Labs GitHub Releases page.

### Step 1.1 - Go to the Adder Releases page: 
<a href="https://github.com/blinklabs-io/adder/releases" target="_blank">https://github.com/blinklabs-io/adder/releases</a>

### Step 1.2 - Download the latest Windows MSI installer 
Select the appropriate version for your system (adder_<version>_windows_amd64.msi or adder_<version>_windows_amrm64.msi).
![adder-release_versions](/adder-release_versions.webp)

### Step 1.3 - Once the download is complete, click `open` to open the .msi file.
   ![adder-windows-open-msi](/adder-windows-open-msi.webp)
### Step 1.4 - Click `run` to start the installation.
![adder-windows-run-msi](/adder-windows-run-msi.webp)
