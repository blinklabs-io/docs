## v0.197.0

**Version:** v0.197.0

This release strengthens relay boundary validation, clarifies reward withdrawal rules across ledger eras, and adds repeatable script view performance benchmarks.

### 💪 Improvements

* Fixed **pool relay boundary handling:** Relay serialization and parsing now reject ports above `65535` and hostnames longer than `128` bytes in the applicable single host and multiple host formats, while accepting valid boundary values. Validation returns clear errors for invalid port and hostname lengths.
