## v0.207.0

**Title:** Improve shutdown signaling, panic handling, and pool metadata compatibility

**Version:** v0.207.0

This release makes protocol shutdown observable sooner, improves diagnostics when protocol and pipeline workers panic, and accepts pool metadata hashes with lengths other than 32 bytes.

### New Features
* Improved panic handling for protocol and pipeline workers by recovering panics and reporting diagnostics. Ordered pipeline processing continues, while a fatal worker failure cancels the pipeline when necessary.
* Added `(*protocol.Protocol).StopChan()` so callers can observe a shutdown request immediately when `Stop()` runs; the channel remains distinct from `DoneChan()`, which signals completed shutdown.

### Breaking Changes
* Expanded local state query pool metadata decoding to use `ledger/common.PoolMetadataHash`; callers now receive the exported field as this type instead of fixed-width `ledger.Blake2b256`, and metadata hashes with lengths other than 32 bytes are accepted.
