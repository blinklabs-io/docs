## v0.218.0

**Title:** Improve Plutus evaluation and Leios committee access

**Version:** v0.218.0

This release improves Plutus evaluation efficiency, expands Leios committee access, and strengthens local state query decoding.

### New Features

* Added Shelley localstatequery query 41 and `Client.GetLeiosCommittee()` to retrieve the current and optional next Leios voting committees. The decoder bounds the number of seats and accepts an optional BLS key only when it is exactly 96 bytes.

### Performance

* Improved Plutus evaluation speed and memory use by updating `github.com/blinklabs-io/plutigo` from v0.11.2 to v0.11.3 without changing evaluation results.

* Expanded Plutus machine reuse with a mutex-protected LIFO free list for each language version and `EvalContext`. Reuse continues across garbage collection, idle retention stays bounded by `GOMAXPROCS`, and nil pooled pointers are handled safely.

* Refined Plutus memory retention by updating `github.com/blinklabs-io/plutigo` to v0.11.4, which caps retained value-arena memory at 32 MiB and complements the machine reuse improvements.
