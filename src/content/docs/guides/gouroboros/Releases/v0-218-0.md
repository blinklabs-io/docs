## v0.218.0

**Title:** Improve Plutus evaluation and Leios committee access

**Version:** v0.218.0

This release improves Plutus evaluation efficiency, expands Leios committee access, and strengthens local state query decoding.

### New Features

* Added Shelley localstatequery query 41 and `Client.GetLeiosCommittee()` to retrieve the current and optional next Leios voting committees. The decoder bounds the number of seats and accepts an optional BLS key only when it is exactly 96 bytes.
