## v0.206.1

**Title:** Bound peer responses and strengthen validation

**Version:** v0.206.1

This release limits peer sharing responses, expands ledger verification coverage without changing production behavior, and rejects malformed pool relay data during decoding.

### Bug Fixes
* Fixed **SharePeers response limits:** responses now use `MaxPendingMessageBytes=5,760` and `MaxSharedPeers=230`; the server truncates replies to the requested amount and the maximum, while the client rejects over-limit responses with `ErrTooManyPeersShared`. Protocol-limit documentation and tests cover these boundaries.

### Additional Changes

* Expanded **ledger verification coverage:** tests now use real mainnet Conway fixtures and the production `NewBlockFromCbor`, `VerifyBlock`, `VerifyKes`, and `VerifyKesComponents` paths to validate block body hashes, VRF data, and KES data. Production behavior does not change.
