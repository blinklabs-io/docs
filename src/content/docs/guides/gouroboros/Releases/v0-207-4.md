## v0.207.4

**Title:** Improve protocol pipelining and witness validation

**Version:** v0.207.4

This release improves pipelined protocol operations, strengthens Conway and Byron witness validation, and refines benchmark workflow scheduling.

### Bug Fixes
* Improved pipelined protocol message handling by synchronizing connection state with readiness signals, rechecking queued messages after state transitions settle, preserving held messages, and validating each message in a batch. Valid state advancement no longer triggers fatal connection shutdowns, and ChainSync `MsgRequestNext` requests can be sent back to back before replies arrive.
* Rejected Conway transactions with explicitly present but empty witness sets in fields 0 through 7 during CBOR decoding while preserving valid absent fields and zero value witness set encoding, so malformed transactions fail earlier.
* Updated benchmark checks to run for published releases, manual requests, and authorized `/benchmark` comments instead of every push to `main`.
* Hardened Byron witness validation by rejecting unsupported constructors, including constructor 3, and requiring exact key and signature lengths for constructors 0 and 2, preventing malformed transaction or block witnesses from being accepted.
