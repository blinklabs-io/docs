## v0.191.3 (August 5, 2026)

**Title:** Tighten address decoding, CBOR round-tripping, and block validation

**Date:** August 5, 2026

**Version:** v0.191.3

This release tightens ledger address decoding, preserves original CBOR bytes across round-trips, makes consensus validation TPraos aware, and keeps block requests tied to the caller context.

### 💪 Improvements

* Fixed **Bech32 address decoding:** invalid Bech32 addresses no longer fall back to Base58.

* Tightened **address payload decoding:** trailing bytes now fail validation instead of passing through.

* Restored **CBOR round-tripping:** `Datum` and `SetType` keep their original bytes during `MarshalCBOR`.

* Improved **consensus validation:** generic header validation and block building now follow TPraos rules.

* Refined **leiosfetch request handling:** block requests now respect the caller context and treat timeouts as non-fatal.

* Enforced **block verification limits:** `VerifyBlock` now applies execution and size limits across the full block.

Thank you for following gOuroboros releases.
