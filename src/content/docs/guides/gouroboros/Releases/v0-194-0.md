## v0.194.0 (August 21, 2026)

**Title:** Improve fork selection and transaction script validation

**Date:** August 21, 2026

**Version:** v0.194.0

This release improves chain selection across deep forks, narrows Plutus V1 inline datum validation to scripts required by transaction purposes, and refreshes dependencies and formatting.

### 💪 Improvements

* Improved **deep fork selection:** Deep forks that roll back more than `k` blocks now use integer block counts within the configured Genesis window for density based selection, while shallow forks continue to use ordinary longest chain selection with VRF tiebreaking. The updated `ChainTip` and selector interfaces expose the fork point and window block count through `ForkPoint` and `BlocksInWindow`, and `WindowedChainTip` routes block based rollback handling. `ComputeGenesisWindow` now uses ceiling division. Implementations that provide `ChainTip` or call selector APIs must adopt the updated interfaces. When window support is unavailable, selection falls back to legacy density and emits a one time warning.

* Fixed **Plutus V1 inline datum validation:** Transaction validation now examines resolved consumed inputs, reference inputs, and produced outputs only for scripts required by the transaction purposes. Unrelated Plutus V1 reference scripts can coexist with inline datums, while validation still rejects inline datums when a required Plutus V1 script is present and reports unresolved input errors only once.

* Updated **protobuf dependencies:** The root module and eight example modules now use `google.golang.org/protobuf` `v1.36.12`, with their dependency checksums refreshed so examples that use `../..` replacements resolve consistently without changing the public API or runtime behavior.
