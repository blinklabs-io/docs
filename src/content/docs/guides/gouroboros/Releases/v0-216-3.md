## v0.216.3

**Title:** Improve protocol reliability and decoding safety

**Version:** v0.216.3

This release improves local protocol handling, memory use during block decoding, canonical query encoding, chain validation, restart recovery, Dijkstra datum checks, and defensive decoding.

### New Features

* Improved LocalTxMonitor mempool checks by postponing transaction parsing until `HasTx`. It now caches transaction IDs, prunes them across snapshots, clears them on `Release`, compares raw ID bytes, and reports parse failures with the transaction index and era.

* Reduced memory retained by Shelley-family block-header decoding by sharing CBOR backing storage across header bodies and byte-string fields. Treat shared byte strings as immutable, or copy them before mutation.

* Canonicalized local state query pool ID sets as tag `258` definite-length arrays of sorted unique IDs. The decoder now rejects sets larger than `10,000` IDs and uses the updated empty `GetStakePoolParams` encoding.

### Bug Fixes

* Validated Byron main-chain and epoch-boundary body proofs during block-local validation. Byron validation now skips ETA0 lookup.

* Preserved the first client message across server mini-protocol restarts for chainsync, blockfetch, txsubmission, peersharing, leiosnotify, leiosfetch, and leiosvotes.

* Expanded top-level Dijkstra supplemental datum checks to accept justifications from subtransaction outputs, collateral returns, and reference-input UTxOs while keeping subtransaction isolation and legacy behavior.

* Limited recognized predicate failure field lists to `16` entries before allocation and kept unknown constructors as raw CBOR.

* Corrected TPraos `DebugChainDepState` decoding to use the actual layout, return epoch, previous-epoch, and lab nonces, and reject malformed fields.

* Streamlined metadata JSON conversion by rendering error paths only when needed. Successful conversions avoid those allocations while the converter preserves error text and wrapping.

* Hardened `cbor.Rat` distribution-reply decoding by limiting replies to two elements, validating integer and bignum forms, and rejecting malformed rational inputs before making large allocations.
