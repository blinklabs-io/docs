## v0.216.3

**Title:** Improve protocol reliability and decoding safety

**Version:** v0.216.3

This release improves local protocol handling, memory use during block decoding, canonical query encoding, chain validation, restart recovery, Dijkstra datum checks, and defensive decoding.

### New Features

* Improved LocalTxMonitor mempool checks by deferring transaction parsing until `HasTx`, caching transaction IDs, pruning IDs across snapshots, clearing them on `Release`, comparing raw ID bytes, and reporting parse failures with the transaction index and era.

* Reduced retained memory while decoding Shelley-family block headers by sharing CBOR backing storage across header bodies and byte-string fields. Consumers should treat these shared byte strings as immutable or copy them before mutation.

* Canonicalized local state query pool ID sets as tag `258` definite-length arrays of sorted unique IDs, rejected sets larger than `10,000` IDs, and updated the empty `GetStakePoolParams` encoding.

### Bug Fixes

* Validated Byron main-chain and epoch-boundary body proofs during block-local validation and skipped ETA0 lookup for Byron blocks.

* Preserved the first client message sent when server mini-protocols restart across chainsync, blockfetch, txsubmission, peersharing, leiosnotify, leiosfetch, and leiosvotes.

* Expanded top-level Dijkstra supplemental datum checks to accept justifications from subtransaction outputs, collateral returns, and reference-input UTxOs while preserving subtransaction isolation and legacy-mode behavior.
