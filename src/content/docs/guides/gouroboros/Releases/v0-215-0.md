## v0.215.0

**Title:** Register the Dijkstra test network

**Version:** v0.215.0

**Release Date:** 2026-10-24

This release registers Cardano's Dijkstra test network so clients can select it by name (`dijkstra`) or network magic (`6`) and discover peers through its bootstrap relay.

### New Features

* Added the Dijkstra test network with name `dijkstra`, network magic `6`, and bootstrap peer `dijkstra-node.play.dev.cardano.org:3001`. Clients can select the network by either value.
