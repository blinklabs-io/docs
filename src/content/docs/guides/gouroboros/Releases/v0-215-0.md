## v0.215.0

**Title:** Register the Dijkstra test network

**Version:** v0.215.0

**Release Date:** 2026-10-24

This release adds configuration for Cardano's Dijkstra test network, allowing clients to connect by name or network magic and discover peers through the configured bootstrap relay.

### New Features

* Added the Dijkstra test network as `dijkstra` with network magic `6` and bootstrap peer `dijkstra-node.play.dev.cardano.org:3001`. Clients can use either the name or magic value to select the network.
