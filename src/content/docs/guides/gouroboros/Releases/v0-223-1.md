## v0.223.1

**Title:** Improve request correlation and shutdown completion

**Release date:** 2026-11-28

**Version:** v0.223.1

This release improves correlation between callback requests and records of data sent over the transport across protocol restarts, and ensures shutdown waits for completion publication. It introduces no breaking changes and does not change the CLI, configuration, or installation requirements.

### New Features

* Added `Client.WriteObservationSession()`, which returns a session identifier for records of data sent over the transport. The identifier remains stable across protocol restarts and is zero when recording is disabled.

### Bug Fixes

* Improved callback request tracking by allowing request IDs to match records of data sent over the transport even when connection addresses are reused or protocols restart.

* Corrected protocol shutdown so it waits for both protocol loops to finish and completion to be published before returning. Published completion takes precedence over context cancellation.

* Aligned shutdown and `StopForRestart` with this completion order, reducing shutdown races and keeping `DoneChan` from remaining open.
