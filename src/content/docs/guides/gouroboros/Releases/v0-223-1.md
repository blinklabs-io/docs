## v0.223.1

**Title:** Improve request correlation and shutdown completion

**Release date:** 2026-11-28

**Version:** v0.223.1

This release improves transport write correlation across protocol restarts and ensures shutdown waits for completion publication. It introduces no breaking changes and does not change the CLI, configuration, or installation requirements.

### New Features

* Added `Client.WriteObservationSession()`, which returns the identifier for transport write records. The identifier remains stable across protocol restarts and is zero when recording is disabled.

### Bug Fixes

* Improved callback request correlation by allowing request IDs to match transport write records even when connection addresses are reused or protocols restart.

* Corrected protocol shutdown so it waits for both protocol loops and completion publication before returning. Published completion takes precedence over context cancellation.

* Prevented shutdown and `StopForRestart` from returning before completion publication, reducing shutdown races and keeping `DoneChan` from remaining open.
