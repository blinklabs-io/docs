## v0.205.6

**Title:** Strengthen certificate and data validation

**Version:** v0.205.6

This release strengthens operational certificate validation, hash decoding, CBOR safety, and UTxO output preservation.

### New Features

* Added **operational certificate verification:** `VerifyBlock` now checks cold signatures and reports invalid signatures through `ValidationErrorTypeOpCert`. `ledger.ExtractOpCertFromHeader` exposes operational certificate data from supported Shelley family and Babbage family headers.

### Bug Fixes

* Improved **hash input validation:** Blake2b constructors now reject hashes with the wrong length. Native script witness lookup and JSON decoding also reject wrong length hashes for MultiAsset policy IDs, PoolRegistrationCertificate VRF key hashes, and pool owners.
