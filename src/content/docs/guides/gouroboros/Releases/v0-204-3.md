## v0.204.3

**Title:** Align Dijkstra encoding and honor leadership ranges

**Version:** v0.204.3

Version 0.204.3 aligns Dijkstra block and protocol parameter encoding with the Leios prototype layout while making leadership searches honor caller-defined ranges, including large ranges and prompt cancellation.

### 💪 Improvements

* Improved **Dijkstra Leios compatibility:** Dijkstra block bodies now use the Leios prototype 2026w36 three element `block_body` layout with inline four element `block_transaction` values and required trailing `is_valid` flags. Decoding accepts the new layout and legacy four element bodies, translates legacy invalid transaction indexes into per transaction `TxIsValid` values, preserves validated indexes, decodes both 35 field legacy and 46 field current parameter arrays while rejecting unsupported or indefinite arrays, applies updates through map keys 38–48, and includes Leios genesis fields with `PlutusV4CostModel` at `CostModels[3]`.

* Expanded **leadership range searches:** `FindNextSlotLeadershipContext` now searches the full inclusive range supplied by the caller, so large ranges no longer fail at one million slots. Per slot context cancellation returns `context.Canceled`, while invalid range checks and overflow safe maximum slot termination remain.
