## v0.216.0

**Title:** Improve replay protection and ledger safety

**Version:** v0.216.0

**Release Date:** 2026-10-26

This release strengthens replay protection and peer supplied data handling, improves Dijkstra transaction decoding, and updates Plutus evaluation support.

### New Features

* Updated Plutigo from `v0.9.10` to `v0.10.0`. Pooled Plutus evaluation now uses `Machine.RunScriptContext` without depending on discharge, and raw and normalized redeemers must produce matching `ExUnits`.

### Bug Fixes

* Added replay protection that keeps accepted IDs until they expire and refuses an entire reply when adding it would exceed `MaxReplayEntries`. The default limit is now `126976`, and the operator facing behavior is documented.

* Improved Dijkstra transaction decoding by reading definite and indefinite transaction arrays one entry at a time instead of allocating from a declared count.

* Strengthened rejection reason handling by prechecking peer supplied CBOR with a `131072` item budget and `MaxUntrustedNestedLevels` depth limit, then applying strict decoding to `GenericError`.

* Protected Byron payload parsing by limiting array, map, and tag traversal to `cbor.MaxNestedLevels`.
