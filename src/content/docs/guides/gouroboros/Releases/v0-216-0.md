## v0.216.0

**Title:** Improve replay protection and ledger safety

**Version:** v0.216.0

**Release Date:** 2026-10-26

This release strengthens replay protection and peer supplied data handling, improves Dijkstra transaction decoding, and updates Plutus evaluation support.

### New Features

* Updated Plutigo from `v0.9.10` to `v0.10.0`. Pooled Plutus evaluation now runs without depending on discharge, and raw and normalized redeemers must produce matching execution units.

### Bug Fixes

* Added replay protection that keeps accepted IDs until they expire and refuses an entire reply when adding it would exceed the configured replay entry limit. The default limit is now `126976`, and operators can find the updated behavior documentation.

* Improved Dijkstra transaction decoding by reading transaction arrays one entry at a time instead of allocating from a declared count, for both definite and indefinite arrays.

* Strengthened rejection reason handling by checking peer supplied data against a `131072` item budget and maximum nesting depth before strictly decoding generic errors.

* Protected Byron payload parsing by limiting array, map, and tag traversal to the supported maximum nesting depth.
