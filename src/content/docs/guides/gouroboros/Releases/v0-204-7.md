## v0.204.7

**Title:** Improve authentication, ledger validation, and protocol reliability

**Version:** v0.204.7

This release improves DMQ operational certificate authentication, ledger validation and transaction processing, and LocalStateQuery and handshake protocol reliability.

### 🐛 Bug Fixes

* Fixed **DMQ operational certificate authentication:** Real pool messages now pass CIP-0137 authentication because verification uses raw `OCertSignable` bytes and KES evolution starts from the certificate issuance period. Messages with an earlier payload KES period are rejected.

* Corrected **Shelley genesis slot length encoding:** `slotLength` now serializes as integer microseconds for wire compatibility, and callers receive an error when a value cannot be represented exactly at microsecond precision.

* Improved **transaction validation performance:** Each UTxO lookup is reused within a transaction validation pass. Custom validation rules that inspect optional ledger state capabilities must unwrap the state before making type assertions.
