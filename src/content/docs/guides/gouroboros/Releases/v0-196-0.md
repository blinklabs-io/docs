## v0.196.0 (August 24, 2026)

**Title:** Add Byron PBFT validation and improve CBOR list decoding

**Date:** August 24, 2026

**Version:** v0.196.0

This release adds Byron PBFT validation and improves CBOR decoding for list headers that encode a fixed length in a longer-than-necessary form.

### 💪 Improvements

* Added **Byron PBFT validation:** Both validation paths now check Byron headers and delegations, use genesis data to determine active delegates, apply the `22/100` issuer timing threshold, and follow the `2k` activation and replacement rules. Issuer parsing now prevents replay, and proxy signature checks use the correct verification context for light and heavy proxies.

* Improved **CBOR list decoding:** The decoder now reads list headers that encode a fixed length in a longer-than-necessary form while retaining its optimized path for canonical one-byte headers. Regression coverage protects both forms.

Thank you for following gOuroboros releases.
