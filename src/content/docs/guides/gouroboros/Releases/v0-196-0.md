## v0.196.0 (August 24, 2026)

**Title:** Add Byron PBFT validation and improve CBOR list decoding

**Date:** August 24, 2026

**Version:** v0.196.0

This release adds Byron PBFT validation and improves CBOR decoding for definite length list headers that use non-shortest encodings.

### 💪 Improvements

* Added **Byron PBFT validation:** Stateless and stateful validation now covers Byron headers and delegations, derives active delegate configuration from genesis data, applies the `22/100` issuer window threshold, and enforces the `2k` activation and replacement semantics. Issuer parsing now prevents replay, and proxy signature checks use the correct domain tags for light and heavy proxies.

* Improved **CBOR list decoding:** Dispatch decoding now handles definite length list headers that use non-shortest encodings while retaining the fast path for canonical one-byte headers. Regression coverage protects both forms.

Thank you for following gOuroboros releases.
