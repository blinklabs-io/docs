## v0.207.5

**Title:** Improve validation and protocol compatibility across eras

**Version:** v0.207.5

This release improves validation and compatibility across Plutus, Conway, Dijkstra, Shelley to Babbage, and Byron behavior.

### Bug Fixes
* Improved Plutus validation by decoding auxiliary data according to era, validating embedded native and Plutus scripts, translating TxInfo and certificates according to protocol version, checking Plutus V3 reference inputs for protocol version 11 and later, and correcting Babbage, Conway, and Dijkstra validation.
* Strengthened Conway and Dijkstra CBOR and transaction validation, gated redeemer tags by era, and validated ordered Dijkstra nested transactions while threading state between them.
* Tightened auxiliary data and native script decoding by validating metadata labels, script constructors, key hash widths, trailing data, and Plutus well formedness.
* Added cryptographic validation for Dijkstra Leios certificates and introduced CIP-0140 Peras draft CBOR types with strict VoteCert decoding.
* Corrected certificate deposit and refund accounting across eras using authoritative protocol and ledger state.
* Expanded regression coverage for certificates involving Conway committee members who had already resigned.
