## v0.220.1

**Title:** Improve top level value conservation checks

**Version:** v0.220.1

This release improves Dijkstra legacy mode validation by checking whether each eligible top level body conserves value after certificate and pool effects from subtransactions.

### Bug Fixes

* Improved validation for Plutus V1 through V3 transactions with subtransactions. For valid phase 2 transactions, `UtxoValidateValueNotConservedLegacyModeUtxo` applies the `value-not-conserved-legacy-mode` rule to compare top level value with ledger state after certificate and pool effects. A mismatch rejects the transaction with `ValueNotConservedInLegacyModeError`, which includes consumed and produced amounts. Empty subtransaction batches skip the check, so a batch cannot pass overall conservation while its legacy mode top level body remains unbalanced.
