## v0.220.1

**Title:** Improve top level value conservation checks

**Version:** v0.220.1

This release strengthens transaction validation for Dijkstra legacy mode by checking the top level body after subtransaction certificate and pool effects.

### Bug Fixes

* Improved legacy mode validation for Plutus V1 through V3 transactions with subtransactions. Valid phase 2 transactions now use `UtxoValidateValueNotConservedLegacyModeUtxo` and the `value-not-conserved-legacy-mode` rule to check top level value conservation against ledger state after certificate and pool effects. Failed checks return `ValueNotConservedInLegacyModeError` with consumed and produced amounts, while empty subtransaction batches skip the check. This prevents a batch from passing overall conservation when its legacy mode top level body remains unbalanced.
