## v0.221.0

**Title:** Improve ordering and add opt-in BlockFetch compression

**Version:** v0.221.0

This release stabilizes MIR UTxO-RPC target ordering, strengthens UPLC validation, adds experimental, default-off, opt-in BlockFetch compression for compatible Dijkstra node-to-node versions, and updates supporting dependencies and CI actions.

### New Features

* Added experimental, default-off, opt-in CIP-0150 BlockFetch compression for compatible Dijkstra node-to-node protocol versions. Applications can use raw or Zstandard compressed-block messages while bounded decompression, per-range byte budgets, and client and server handling protect protocol operation.

### Bug Fixes

* Stabilized MIR UTxO-RPC reward target ordering by sorting targets with ledger credential ordering; script targets now precede key targets, and hashes sort in ascending order.

* Expanded `plutigo` to v0.13.0, strengthening coverage for unsupported UPLC versions and validation for canonical cost-model aliases and parameter counts while preserving the historical legacy boundary.

### Additional Changes

* Updated `ouroboros-mock` to v0.21.3 and the indirect `go.yaml.in/yaml/v3` dependency to v3.0.6.

* Refined `github.com/klauspost/compress` from v1.20.3 to v1.20.4.

* Modernized pinned `actions/setup-go` versions in CI workflows from v7.0.0 to v7.1.0 without changing the configured Go versions.
