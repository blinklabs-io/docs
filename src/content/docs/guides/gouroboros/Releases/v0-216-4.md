## v0.216.4

**Title:** Improve CBOR rendering and native script validity handling

**Version:** v0.216.4

This release improves nested CBOR JSON rendering, updates the CBOR library, and preserves native script validity bounds during ledger processing.

### Performance

* Improved CBOR `Value` and `ConstructorDecoder` JSON rendering by recursively appending nested output into one caller-owned `[]byte`. Output, escaping, and deterministic map ordering remain unchanged, while deeply nested values require less allocation and copying.

### Additional Changes

* Updated `github.com/fxamacker/cbor/v2` from `v2.9.6` to `v2.10.0`. The new version includes upstream improvements to encoding and decoding speed and memory use, bug fixes, and the `toindefarray` struct tag option.

### Bug Fixes

* Preserved native script validity bound presence when data is decoded and encoded again, including an explicit lower bound of zero. Presence-aware native script evaluation APIs and era accessors now distinguish omitted bounds from numeric defaults in checks that enforce `after` and `before` limits.
