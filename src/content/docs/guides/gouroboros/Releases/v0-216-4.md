## v0.216.4

**Title:** Improve CBOR performance and ledger validity handling

**Version:** v0.216.4

This release improves nested CBOR JSON rendering, updates CBOR encoding and decoding support, and preserves native script validity bounds during ledger processing.

### Performance

* Improved CBOR AST JSON rendering by appending nested `Value` and `ConstructorDecoder` output into one caller-owned `[]byte`. The output, escaping, and deterministic map ordering remain unchanged, while deeply nested values require less allocation and copying.

### Additional Changes

* Updated `github.com/fxamacker/cbor/v2` from `v2.9.6` to `v2.10.0`. The dependency update provides upstream encoding and decoding performance and memory improvements, bug fixes, and the `toindefarray` struct tag option.

### Bug Fixes

* Preserved native script validity bound presence across decoding and re-encoding, including an explicitly present lower bound of zero. Presence-aware native script evaluation APIs and era accessors now distinguish omitted bounds from numeric defaults when applying after and before checks.
