## v0.217.0

**Title:** Add chainsync lifecycle controls and improve ledger processing

**Version:** v0.217.0

This release adds explicit chainsync lifecycle controls, relaxes nested Shelley metadata validation, improves ledger proof selection and Plutus processing, and aligns DMQ encodings with dmq-node 0.7.2.1.

### New Features

* Added exported `Client.Reintersect(points)` and `Client.StopAfterDrain(ctx)` for clean same connection transitions. Both wait for outstanding `MsgRequestNext` replies to drain before sending `MsgFindIntersect` or `MsgDone`, respectively.
