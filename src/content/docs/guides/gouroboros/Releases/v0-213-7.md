## v0.213.7

**Title:** Protect authenticated message submission and improve 32-bit conformance coverage

**Version:** v0.213.7

This release blocks replayed authenticated local messages and expands VRF conformance coverage for long schedules on 32-bit targets.

### New Features

* Improved authenticated `LocalMessageSubmission` by reserving message IDs before calling the submission callback. Duplicate IDs now return `pcommon.AlreadyReceivedReason`; expired reservations are pruned; and `MaxReplayEntries` bounds replay state with a default of `10,000`. Invalid capacities fail validation, and connections share replay state only when they reuse one `Config`.

### Additional Changes

* Expanded VRF replay conformance checks for 32-bit targets: schedules longer than `4,096` slots now sample every assigned slot and every 64th offset. 64-bit targets and schedules up to `4,096` slots keep full replay, preserving the final assigned-slot assertion and preventing timeouts on `GOARCH=386`.
