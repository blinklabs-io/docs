## v0.213.7

**Title:** Strengthen authenticated message submission and 32-bit conformance coverage

**Version:** v0.213.7

This release protects authenticated local message submission against replay and improves long schedule VRF conformance coverage on 32-bit targets.

### New Features

* Improved authenticated `LocalMessageSubmission` handling by reserving message IDs before invoking the submission callback, rejecting duplicate IDs with `pcommon.AlreadyReceivedReason`, pruning expired reservations, and bounding replay state with `MaxReplayEntries`, which defaults to `10,000`. Invalid capacities are rejected, and connections share replay state only when they reuse the same `Config`.

### Additional Changes

* Expanded VRF replay conformance coverage on 32-bit targets by sampling every assigned slot and every 64th offset for schedules longer than `4,096` slots. 64-bit targets and schedules of `4,096` slots or fewer retain full replay, preserving the final assigned-slot assertion and avoiding `GOARCH=386` timeouts.
