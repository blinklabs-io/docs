## v0.213.7

**Title:** Protect authenticated message submission and improve 32-bit conformance coverage

**Version:** v0.213.7

This release protects authenticated local message submission from replay and expands long schedule VRF conformance coverage on 32-bit targets.

### New Features

* Improved authenticated `LocalMessageSubmission` by reserving each message ID before it calls the submission callback, rejecting duplicates with `pcommon.AlreadyReceivedReason`, pruning expired reservations, and bounding replay state with `MaxReplayEntries`, which defaults to `10,000`. Invalid capacities fail validation, and connections share replay state only when they reuse one `Config`.

### Additional Changes

* Expanded VRF replay conformance checks for 32-bit targets by sampling every assigned slot and each 64th offset when schedules exceed `4,096` slots. 64-bit targets and schedules up to `4,096` slots keep full replay, preserving the final assigned-slot assertion and preventing `GOARCH=386` timeouts.
