## v0.212.0

**Title:** Improve evaluation control and ledger compatibility

**Version:** v0.212.0

**Date:** 2026-10-08

This release enables cancellable Plutus evaluation, improves Musashi genesis parsing and Dijkstra validity checks, removes standalone examples, and provides an opt-in cardano-node integration test harness.

### New Features

* Added context-aware Plutus evaluation for Plutus V1 through V4, allowing applications to cancel work before processing starts or during evaluation and receive `context.Canceled`; existing evaluation methods remain compatible.
* Introduced an opt-in cardano-node integration test harness that connects through a node socket, exercises ChainSync, decodes a block, checks the tip, and verifies stop and restart behavior.

### Improvements

* Improved Musashi Shelley genesis parsing by accepting `blsKey` values, validating the public key and possession proof lengths, and retaining the decoded key for initial pool registration.
* Corrected Dijkstra validity decoding so only CBOR boolean values are accepted; null, undefined, integers, and other values now fail instead of being interpreted as false.

### Breaking Changes

* Removed standalone protocol example programs, their build and release automation, and the `make build` and `make clean` example targets. Applications that relied on those examples or targets must use library packages with their own test or build workflows.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |
