## v0.210.0

**Title:** Strengthen protocol limits and expand ledger access

**Version:** v0.210.0

This release strengthens protocol input and connection resource limits, expands Plutus script evaluation access, and improves Babbage datum handling and documentation.

### Improvements
* Improved protocol safety by limiting KES decoding depth to `MaxDepth` 63, KeyGen depth to `MaxKeyGenDepth` 12, handshake Propose and Confirm pending messages to `5,760` bytes, and keep-alive active state to `65,535` bytes; the release also documents these limits and tests boundary and oversized inputs.
