## v0.212.3

**Title:** Improve CBOR decoding and update Plutigo

**Version:** v0.212.3

This release improves in-memory and nested ledger CBOR decoding efficiency, clarifies input slice handling and error count behavior, and updates Plutigo to v0.9.1.

### Improvements

* Improved CBOR decoding for in-memory and nested ledger values by reading directly from the caller's byte slice, reducing allocations and CPU overhead. Destinations whose `UnmarshalCBOR` methods retain raw CBOR no longer receive a copied input, so applications must keep the input slice unchanged while the decoded value is in use; `cbor.Value` still keeps its own copy. Decoding now reports `n == 0` on errors, so applications must check `err` before using the consumed-byte count. The release documents `Decode`, `DecodeStrict`, `DecodeLenient`, `DecodeLedgerMap`, and ledger `New*FromCbor` constructors.
