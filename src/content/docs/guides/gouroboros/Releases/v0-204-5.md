## v0.204.5

**Title:** Normalize script data and improve protocol decoding

**Version:** v0.204.5

This release improves canonical script data handling across Plutus evaluation paths, strengthens UTxO-RPC and LocalStateQuery decoding, and stabilizes project maintenance and test fixtures.

### 🐛 Bug Fixes

* Fixed **script-visible PlutusData handling:** Script contexts and script inputs now normalize datums, redeemers, inline datums, and Dijkstra required guard datums to canonical CBOR using `serialiseData` behavior.

* Corrected **UTxO-RPC protocol conversions:** Zero-based cost-model mapping retains Plutus V1, Conway governance fields remain available in protocol parameters, and rational and committee conversions handle nil values and out-of-range values safely.
