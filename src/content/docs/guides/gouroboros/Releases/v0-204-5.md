## v0.204.5

**Title:** Normalize script data and improve protocol decoding

**Version:** v0.204.5

This release improves canonical script data handling across Plutus evaluation paths, strengthens UTxO-RPC and LocalStateQuery decoding, and stabilizes project maintenance and test fixtures.

### 🐛 Bug Fixes

* Fixed **script-visible PlutusData handling:** Script contexts and script inputs now normalize datums, redeemers, inline datums, and Dijkstra required guard datums to canonical CBOR using `serialiseData` behavior.

* Corrected **UTxO-RPC protocol conversions:** Zero-based cost-model mapping retains Plutus V1, Conway governance fields remain available in protocol parameters, and rational and committee conversions handle nil values and out-of-range values safely.

* Improved **script evaluation normalization:** V1 and V2 evaluation and V3 `ScriptContext` construction now normalize script-visible datums and redeemers consistently for definite and indefinite CBOR encodings, with regression coverage.

* Stabilized **Dijkstra test formatting:** A missing trailing newline no longer causes `gofmt` and `make format` checks to report unnecessary changes.

* Clarified **commenting guidance:** `AGENTS.md` now documents when to explain invariants, non-obvious algorithms, gotchas, exported identifiers, and `NOTE` comments.

* Added **LocalStateQuery block number decoding:** `GetChainBlockNo` handles the origin response `[0]` and non-origin response `[1, blockNo]`, while rejecting malformed CBOR and values outside int64.

* Refined **validity range fixtures:** Test comments now explain the validity range cases without changing runtime behavior.
