## v0.218.1

**Title:** Strengthen protocol decoding and transaction validation

**Version:** v0.218.1

This release improves Byron compatibility and overflow handling, enforces canonical VRF encodings, limits native script decoding work, and validates Dijkstra transaction fields more consistently.

### Bug Fixes

* Fixed Byron bootstrap witness address root hashing for chain codes of any length. Decoder version 12 and later still enforces 32-byte witness lengths.
* Ensured Byron header `SlotNumber` uses `math.MaxUint64` instead of wrapping when overflow occurs. Checked conversion still returns an overflow error.
* Hardened VRF decoding so non-canonical public key and proof gamma point encodings return `ErrNonCanonicalEncoding`, while key length errors remain unchanged.
* Optimized native script CBOR decoding so its work grows linearly with nesting depth, limits allocation and nesting depth, and rejects tagged child lists and scripts.
* Corrected Alonzo fuzz seed data and added deterministic seed decoding coverage while leaving production APIs unchanged.

### Additional Changes

* Added validation for Dijkstra treasury values and reference script sizes for each transaction even when phase 2 validation fails. Conway keeps this behavior gated.
