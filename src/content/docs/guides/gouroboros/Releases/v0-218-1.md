## v0.218.1

**Title:** Strengthen protocol decoding and transaction validation

**Version:** v0.218.1

This release improves Byron compatibility and overflow handling, enforces canonical VRF encodings, limits native script decoding work, and validates Dijkstra transaction fields more consistently.

### Bug Fixes

* Fixed Byron bootstrap witness address root hashing for chain codes of any length while decoder version 12 and later continues to enforce 32-byte witness lengths.
* Ensured Byron header `SlotNumber` saturates at `math.MaxUint64` when overflow occurs, while checked conversion still returns an overflow error.
* Hardened VRF decoding to reject non-canonical public key and proof gamma point encodings with `ErrNonCanonicalEncoding` while preserving key length errors.
* Optimized native script CBOR decoding to run in linear time relative to nesting depth, bound allocation and nesting depth, and reject tagged child lists and scripts.
* Corrected Alonzo fuzz seed data and added deterministic seed decode coverage without changing production APIs.
