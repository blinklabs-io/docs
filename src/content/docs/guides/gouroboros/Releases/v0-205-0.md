## v0.205.0

**Title:** Improve authentication, protocol reliability, and ledger validation

**Version:** v0.205.0

This release strengthens message authentication, protocol shutdown, metadata handling, ledger validation, UTxO-RPC conversions, and connection lifecycle controls.

### ⚠️ Breaking Changes

* Hardened **message authentication:** `MessageAuthenticator` now requires a `StakeAuthority`, derives the 28-byte Blake2b-224 `PoolKeyHash`, verifies KES signatures in process, rejects zero stake, and guards against KES period overflow. DMQ packages now fail closed when authentication is absent, so integrations that construct `MessageAuthenticator` must provide the required stake authority.

### 🐛 Bug Fixes

* Improved **shutdown delivery:** Context-aware delivery now lets `BlockFetch` and `ChainSync` `Stop` wait up to 250 ms for shutdown message delivery. Delivery errors, including `context.DeadlineExceeded`, return to the caller.

* Preserved **nested metadata keys:** Nested metadata maps now retain duplicate keys while outer auxiliary-data label maps continue to reject duplicate labels.
