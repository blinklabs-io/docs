## v0.214.0

**Title:** Add Tachys leader selection and strengthen protocol validation

**Version:** v0.214.0

This release adds a new Tachys method for selecting block leaders and checking headers, aligns DMQ signature checks with network behavior, and updates supported Go toolchains and test scheduling.

### New Features

* Added CIP-0177 Tachys leader selection to block production and header validation. The selector uses deterministic BLAKE2b-256 sampling from the epoch nonce and slot, selects leaders by cumulative stake, and confirms issuer authorization. Tachys builders and validators retain CPraos cryptographic checks without applying the finite E34 predicate.

### Bug Fixes

* Corrected DMQ KES signature verification to use the raw payload array bytes instead of an extra CBOR byte string wrapper. This matches dmq-node behavior and rejects signatures made for the old wrapped representation.

### Additional Changes

* Updated Go toolchain support for Cardano node integration testing with Go 1.26.x and 1.27.x, pinned NilAway to Go 1.26.x, and moved the module and tools requirement from Go 1.26.8 to 1.26.10.

* Refined test scheduling by limiting nightly fuzz runs to four parallel jobs without fail fast, running Cardano node integration tests daily and for pull requests instead of on every main branch push, and cancelling superseded runs in the same concurrency group.
