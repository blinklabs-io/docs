## v0.214.0

**Title:** Add Tachys leader selection and strengthen protocol validation

**Version:** v0.214.0

This release adds CIP-0177 Tachys leader selection for block production and header validation, improves DMQ KES signature verification, and updates the supported Go toolchains and CI scheduling.

### New Features

* Added CIP-0177 Tachys leader selection to block production and header validation. The selector samples deterministically from the epoch nonce and slot, selects leaders by cumulative stake, and authorizes the selected issuer. Tachys builders and validators preserve CPraos cryptographic checks while skipping the finite E34 predicate.

### Bug Fixes

* Corrected DMQ KES signature verification to use the raw payload array's CBOR bytes instead of an additional CBOR byte string wrapper. This matches dmq-node behavior and rejects signatures that use the obsolete wrapped representation.

### Additional Changes

* Updated the supported Go toolchains to test Cardano node integration with Go 1.26.x and 1.27.x, pin NilAway to Go 1.26.x, and raise the module and toolchain requirement from Go 1.26.8 to 1.26.10.

* Refined CI scheduling by limiting nightly fuzz runs to four parallel jobs without fail fast, running Cardano node integration tests daily and for pull requests instead of on every main branch push, and cancelling superseded runs within the same concurrency group.
