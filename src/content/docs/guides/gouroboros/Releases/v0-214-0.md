## v0.214.0

**Title:** Add Tachys leader selection and strengthen protocol validation

**Version:** v0.214.0

This release introduces CIP-0177 Tachys leader selection, aligns DMQ signatures with the payload format used by dmq-node, and refreshes Go support and validation scheduling.

### New Features

* Added CIP-0177 Tachys leader selection to block production and header validation. The selector uses deterministic BLAKE2b-256 sampling from the epoch nonce and slot, selects leaders by cumulative stake, and confirms issuer authorization. Tachys builders and validators retain CPraos cryptographic checks without applying the finite E34 predicate.

### Bug Fixes

* Corrected DMQ KES signature verification to validate raw payload array bytes instead of an extra CBOR byte string wrapper. This matches dmq-node behavior and rejects signatures made for the old wrapped representation.

### Additional Changes

* Updated Go toolchain support so Cardano node integration tests cover Go 1.26.x and 1.27.x, NilAway uses Go 1.26.x, and the module and tools requirement moves from Go 1.26.8 to 1.26.10.

* Refined validation scheduling by limiting nightly fuzz runs to four parallel jobs while allowing other jobs to continue after a failure, running Cardano node integration tests daily and for pull requests instead of on every main branch push, and cancelling superseded runs so current validation work continues.
