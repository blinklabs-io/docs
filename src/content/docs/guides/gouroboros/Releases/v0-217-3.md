## v0.217.3

**Title:** Improve ledger verification and protocol reliability

**Version:** v0.217.3

This release improves Leios certificate verification, exposes transaction-scoped ledger state to external callers, strengthens ChainSync restart handling, and accepts empty collateral asset maps as ADA only during Alonzo validation.

### New Features

* Added a way for external callers to traverse layered transaction-scoped ledger state.

### Bug Fixes

* Corrected Dijkstra Leios certificate verification to use the BLS proof domain that ledger state selects and to preserve direct configuration errors.
* Improved Alonzo collateral validation to treat an explicitly encoded empty collateral asset map as ADA only.

### Additional Changes

* Refined ChainSync integration restart handling so the live client drains pipelined replies before it reports completion and restarts.
