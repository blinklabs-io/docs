## v0.216.2

**Title:** Improve decoding safety and protocol compatibility

**Version:** v0.216.2

This release strengthens decoding safeguards, bounds resource use for untrusted data, improves message replay handling, and preserves compatibility for selected Shelley and Byron data.

### New Features

* Added a shared CBOR item budget and a per composite map key limit of `65536` items. The decoder now rejects keys that exceed the budget before processing them.

* Improved diagnostic output limits by weighting the allowance according to node structure, separating structural bytes from byte and text payloads, and using saturating arithmetic.

* Added per connection message submission replay protection through `Config.MaxReplayEntries`. The connection now filters message IDs that it has already delivered.

* Improved governance result parsing by growing arrays and maps as data arrives. The decoder now rejects duplicate map keys without preallocating from a declared count.

### Bug Fixes

* Fixed DRep duplicate detection so declared CBOR map counts no longer determine the initial size of the tracking map. This limits allocation from attacker controlled declarations.

* Added validation for Byron extra body data and definite list lengths before decoding. Invalid declared lengths no longer cause avoidable allocations.

* Improved `cbor.ListLength` so it counts list items without retaining the raw message for each item.

* Updated Byron raw array and map entry capacity sizing to use the declared item count instead of the encoded byte length.

* Strengthened rational and pool margin parsing by checking definite array lengths before decoding, including tagged rationals.

* Validated local message rejection reason arrays before decoding. The decoder now accepts type values from `0` through `3`, permits an optional text or null message, and rejects extra elements.

* Restored deprecated Shelley local state queries `4` and `21` after their former negotiated version upper bounds.

* Preserved Shelley genesis pool reward account credentials, network identity, and tagged relay shapes for byte exact certificate round trips.
