## v0.212.1

**Title:** Serialize concurrent peersharing exchanges

**Version:** v0.212.1

This release keeps concurrent peersharing requests paired with their matching replies and maximum response lengths.

### Improvements

* Fixed concurrent `Client.GetPeers` exchanges so each caller receives the `SharePeers` reply and maximum response length for its own request, preventing one request from receiving another request's reply or limit; added concurrent regression coverage for reply ownership and individual request limits.

**Release:** [v0.212.1](https://github.com/blinklabs-io/gouroboros/releases/tag/v0.212.1)
