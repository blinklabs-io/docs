## v0.212.1

**Title:** Serialize concurrent peersharing exchanges

**Version:** v0.212.1

This release serializes concurrent peersharing client exchanges so each request receives its own response and response-length limit.

### Improvements

* Fixed concurrent `Client.GetPeers` exchanges so each caller receives the `SharePeers` response and response-length limit for its own request, preventing cross-delivery and later requests from widening an earlier request's limit; added concurrent regression coverage for reply ownership and per-request limits.

**Release:** [v0.212.1](https://github.com/blinklabs-io/gouroboros/releases/tag/v0.212.1)
