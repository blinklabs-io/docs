## v0.208.4

**Title:** Improve protocol range delivery and muxer responsiveness

**Version:** v0.208.4

This release improves BlockFetch and ChainSync range delivery across same-slot Byron boundaries and keeps the muxer responsive when one protocol consumer falls behind.

### Bug Fixes
* Fixed BlockFetch ranges that cross a Byron epoch boundary from an EBB to the first main block in the same slot. Validation still requires the requested slot bounds, the correct endpoint identity, and the previous-hash chain, and it rejects later blocks after the requested end even when they share its slot.
