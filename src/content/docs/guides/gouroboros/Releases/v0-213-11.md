## v0.213.11

**Title:** Admit pipelined messages after replies return peer agency

**Version:** v0.213.11

This release keeps declared ChainSync pipelined requests admitted after a reply driven state transition returns agency to the peer, including when the declaring state and snapshot generations are equal.

### Bug Fixes

* Fixed ChainSync session failures when a pipelined request remained in flight during a local reply driven transition. The session now admits declared pipelined requests after the reply returns agency to the peer, no longer treats undeclared message types as matching a zero value generation, and keeps a `RequestNext` declared as pipelined in `CanAwait` admitted after `RollForward` returns the server to `Idle`.
