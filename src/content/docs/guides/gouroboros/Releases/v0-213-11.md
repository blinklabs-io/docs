## v0.213.11

**Title:** Keep pipelined ChainSync requests active across replies

**Version:** v0.213.11

This release prevents ChainSync request failures during reply driven state transitions.

### Bug Fixes

* Fixed ChainSync sessions that could reject a pipelined request while a local reply driven transition was in flight. Declared requests now remain admitted after the reply returns control to the peer, including when the declaring and saved state generations are equal. Undeclared message types no longer match an empty generation, and a `RequestNext` declared as pipelined in `CanAwait` remains admitted after `RollForward` returns the server to `Idle`, avoiding errors such as `received message type 0 without peer agency`.
