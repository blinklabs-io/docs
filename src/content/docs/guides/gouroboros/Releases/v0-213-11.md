## v0.213.11

**Title:** Keep pipelined ChainSync requests active across replies

**Version:** v0.213.11

This release prevents ChainSync request failures during reply driven state transitions.

### Bug Fixes

* Fixed ChainSync sessions that could reject a pipelined request while a local reply driven transition was in flight. Declared pipelined requests now remain admitted after the reply returns control to the peer, including when the declaring state generation is equal to or newer than the snapshot generation. Undeclared message types no longer match a zero value generation, and `RequestNext` remains admitted after `RollForward` returns the server to `Idle` when `CanAwait` declares it pipelined, avoiding errors such as `received message type 0 without peer agency`.
