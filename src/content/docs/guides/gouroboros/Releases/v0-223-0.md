## v0.223.0

**Title:** Add BlockFetch transport-write observation

**Release date:** 2026-11-28

**Version:** v0.223.0

This release lets BlockFetch operators opt in to bounded measurements of transport writes for each range request, including timing, outcomes, transport errors, and recording loss, while disabled observation leaves existing behavior unchanged.

### New Features

* Added opt-in, bounded BlockFetch connection write observation through `WithWriteRecorder`, enabling transport timing and outcome measurements for each range request while keeping observation disabled by default.

* Connected each BlockFetch request to its connection writes through internal queues, including batched, fragmented, and coalesced messages.

* Recorded when each observed request entered and left a queue, started writing, completed its final protocol data unit, or failed.

### Bug Fixes

* Exposed recorder loss through bounded `Rejected()` and `Lost()` counters so applications can identify recording pressure and loss.

* Rejected short transport writes with `io.ErrShortWrite`.

* Preserved accepted final SDU completion during connection retirement races.

### Additional Changes

* Clarified BlockFetch request semantics documentation.

* Updated pinned `ouroboros-mock` to v0.22.0 and `plutigo` to v0.13.1.

* Expanded test coverage for request correlation, write outcomes, bounded recording, and retirement races.
