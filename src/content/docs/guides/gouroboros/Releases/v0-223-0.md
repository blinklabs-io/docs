## v0.223.0

**Title:** Add BlockFetch transport-write observation

**Release date:** 2026-11-28

**Version:** v0.223.0

This release gives BlockFetch operators opt-in, bounded measurements for per-range-request transport writes, including timing, outcomes, transport errors, and recording loss, without changing behavior when observation remains disabled.

### New Features

* Added opt-in, bounded BlockFetch connection-write observation through `WithWriteRecorder`, enabling per-range request transport timing and outcome measurements while keeping observation disabled by default.

* Connected BlockFetch request traces across protocol queues and transport writes, including batching, fragmentation, and coalescing.

* Recorded enqueue, dequeue, write start, final SDU completion, and failure lifecycle data for each observed request.

### Bug Fixes

* Exposed recorder loss through bounded `Rejected()` and `Lost()` counters so applications can identify recording pressure and loss.

* Rejected short transport writes with `io.ErrShortWrite`.

* Preserved accepted final SDU completion during connection retirement races.

### Additional Changes

* Clarified BlockFetch request semantics documentation.

* Updated pinned `ouroboros-mock` to v0.22.0 and `plutigo` to v0.13.1.

* Expanded test coverage for request correlation, write outcomes, bounded recording, and retirement races.
