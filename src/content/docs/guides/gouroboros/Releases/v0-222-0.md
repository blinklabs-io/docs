## v0.222.0

**Title:** Align ledger behavior and protocol interoperability

**Release date:** 2026-11-28

**Version:** v0.222.0

This release aligns ledger calculations and protocol behavior with the reference implementations, strengthens malformed input handling, improves protocol interoperability, and expands reference-model coverage.

### New Features

* Expanded Conway and Dijkstra reference-model coverage for ledger behavior.

* Added exhaustive Dijkstra sub-transaction rule-cell tests.

* Enabled handshakes that span multiple mux segments.

* Added `PerasVotes` await and server-idle handling with reference timeouts.

* Restarted six protocol servers after client done messages.

### Breaking Changes

* Changed Mary `MinCoinTxOut` to accept a `TransactionOutput`; callers must update the argument passed to this API.

* Required `VerifyConfig.TPraosOverlay` for verification scenarios that use a TPraos overlay schedule.

* Changed `LeiosVote` to the CIP-0164 three-element form; applications that handle older full-vote offers must use `LeiosLegacyVote`.

* Changed pipeline draining and result delivery through `LosslessResults` and `ResultsDropped`; result delivery can drop results unless lossless mode is enabled.

* Corrected `CalculateRollingNonce` to expect a pre-derived 32-byte contribution before combining it into the rolling nonce.

* Changed constructor encoding to Plutus-compatible CBOR, which changes serialized bytes and hashes.
