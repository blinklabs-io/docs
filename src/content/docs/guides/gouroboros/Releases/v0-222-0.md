## v0.222.0

**Title:** Align ledger behavior and protocol interoperability

**Release date:** 2026-11-28

**Version:** v0.222.0

This release aligns ledger calculations and protocol behavior with the reference implementations, strengthens malformed input handling, improves protocol interoperability, and expands reference-model coverage.

### New Features

* Expanded Conway and Dijkstra `cardano-ledger` reference-model coverage.

* Added exhaustive Dijkstra sub-transaction rule-cell tests.

* Enabled handshakes that span multiple mux segments.

* Introduced `PerasVotes` await and server-idle handling with reference timeouts.

* Restarted six protocol servers after client done messages.

* Broadened account-state access across every Shelley-based era through Dijkstra while retaining Byron rejection.

* Decoded Local State Query `GetFuturePParams` query type `33` for Conway and Dijkstra.

### Breaking Changes

* Aligned fee, size, and minimum-coin calculations with `cardano-ledger`; changed Mary `MinCoinTxOut` to accept a `TransactionOutput`, so callers must update the argument passed to this API.

* Required `VerifyConfig.TPraosOverlay` for verification scenarios that use a TPraos overlay schedule.

* Reshaped `LeiosVote` to the CIP-0164 three-element form; applications that handle older full-vote offers must use `LeiosLegacyVote`.

* Revised pipeline draining and result delivery through `LosslessResults` and `ResultsDropped`; result delivery can drop results unless lossless mode is enabled.

* Corrected `CalculateRollingNonce` to expect a pre-derived 32-byte contribution before combining it into the rolling nonce.

* Adopted Plutus-compatible CBOR for constructor encoding, which changes serialized bytes and hashes.

* Expanded `cbor.Value` decoding limits so `MaxArrayElements` and `MaxMapPairs` apply throughout nested values, including tagged content, preventing oversized retained allocations.

* Made protocol lifecycle operations safe across Stop and restart, queued `SendMessage` calls made before Start, exposed restart-safe server access through `ProtocolInstance`, and improved `PerasVotes` context, reentrancy, and panic handling. Applications that rely on embedded or promoted `*protocol.Protocol` methods must migrate to the updated API.

* Rejected empty or null Local State Query era histories and stopped Byron slot-to-epoch conversion at the Byron boundary.

* Transmitted negotiated handshake data, validated ordering of recognized version keys, and aligned server agreement data with reference behavior.

* Updated node-to-node ChainSync `MustReply` timeouts to `[601, 911)` seconds and separated the 65,535-byte message limit from the 462,000-byte receive budget.

* Set non-positive KeepAlive `Period` and `Timeout` values to defaults; configure `Period` below `ClientTimeout`.

* Changed Local State Query filter encoding per era, used CBOR tag `258` from Conway onward, and encoded nil filters as empty sets.

* Accepted 32-bit protocol minor values and supported minor-version wraparound during parameter updates and Conway hard-fork following.

* Required `ValidateHeaderInput` to receive `Envelope` and, where applicable, `TPraos Overlay`; aligned consensus header validation order, envelope limits, and TPraos overlay checks with reference behavior.

* Checked collateral and reference inputs in `BadInputsUTxO` and changed the first reported missing-input error; callers that match prior error types must adapt.

* Specified exactly one CBOR tag `30` for ledger rationals while preserving plain rational decoding for Local State Query results.

* Measured Shelley-family transaction size from transaction parts instead of outer CBOR framing to stabilize fee and maximum-size behavior.

* Bounded ChainSync pipelining near the server tip, returned the carried tip from `GetCurrentTip` during sync, and improved callback and context shutdown behavior.

* Rejected ChainSync `Start` permanently on a connection when `Stop` cannot send `MsgDone` while a reply remains owed; returned `ErrStoppedWithoutDone` and closed the muxer.

* Enforced Dijkstra governance rules that reject `eMax=0` and pledge leverage below `1` while still allowing cap removal.

* Coordinated handshake setup with concurrent `Close` calls and made `Dial` wait for teardown to finish.

* Prevented concurrent ChainSync operations from receiving mismatched results by making `GetCurrentTip` wait for its own intersect response.

* Reported `ErrProtocolShuttingDown` from `LeiosVotes` and `LeiosNotify` `Sync` when `RunLoop` cannot start, without leaving stale running state.

* Clarified txsubmission request-style rules before callbacks or wire sends; invalid blocking and non-blocking styles now return protocol violations.

* Introduced distinct peer-sharing timeout behavior: client `WithTimeout` waits for `Busy`, while the server retains `BusyTimeout` and `Idle` has no timeout.

* Incrementally decoded protocol-parameter update maps and proposals across Shelley through Conway, rejecting invalid entries before large allocations.

* Aligned Local State Query acquire, release, and restart behavior: idle `Release` returns `ErrNotAcquired`, `AcquireImmutableTip` requires node-to-client v16 or later, implicit state releases after calls, and servers restart after `MsgDone`.

* Validated Local Tx Monitor lifecycle errors: idle `Release` returns `ErrNotAcquired` without sending, and `GetMeasures` returns `ErrProtocolShuttingDown` without sending during shutdown.

* Required constructor fields in `ConstructorDecoder` and `cbor.Value` to use CBOR lists.

* Accepted correctly sized PlutusV2 cost models in Alonzo parameter updates.

* Exposed `DijkstraLeiosKeyAgeContext`, `KeyAge`, `KeyRegisteredIn`, and a state-interface method; Dijkstra Leios certificates signed with aged-out voting keys now fail validation, so direct callers and state implementations must provide the new API requirements.

* Enforced `MaxKesEvolutions` before pipeline `ApplyFunc` and rejected `SkipKesEvolutionsValidation` bypasses in normal mode; pipeline startup behavior is now stricter.

* Rejected leading CBOR tags in `GetEraHistory` replies.

* Constrained CBOR tags on pre-Conway set-shaped fields and accepted Conway and later pool-owner sets only when untagged or carrying exactly one tag `258`.

* Rejected `null` and undefined child lists in native scripts while continuing to accept empty child arrays.

* Changed BlockFetch Stop and Start behavior after an owed range, suppressed `RangeDoneFunc` for failed unsent ranges, and set the default batch and block timeouts to 60 seconds.

* Preflighted Praos operational-certificate counters and rejected malformed or oversized maps before allocating memory.

* Decoded Local State Query result maps incrementally and bounded genesis rationals to reduce allocation risk from malformed replies.

* Accepted Leios certificates when the seated committee is smaller than the configured parameter and validated signer bitfields against the actual seated count.

* Streamed `DecodeArrayItems` callbacks before decoding later items, bounded declared array counts, and exposed raw slices that alias the input to callbacks.

* Limited LeiosFetch block replies to the reference maximum of 600,010 bytes.

* Aligned Origin and Byron EBB header envelope validation and exposed `PrevIsOrigin` and `PrevIsEBB` inputs.

* Reworked reward and pledge calculations to match `cardano-ledger`; the breaking `RewardParameters`, `RewardSnapshot`, and `RewardCalculationResult` fields now define the calculation inputs and results.

### Bug Fixes

* Reduced local transaction monitor cache memory use and handled transaction ID collisions safely.

* Removed the default `Busy` timeout from local transaction submission, so submissions no longer apply that timeout automatically.

* Validated Conway mainnet header protocol versions.

* Hardened raw CBOR map decoding against oversized malformed declarations.

* Strengthened general constructor decoding by rejecting malformed input before large allocation.

* Aligned DMQ message expiry bounds with `dmq-node` behavior.

* Matched message-submission request timeouts with `dmq-node` behavior.

* Resolved handshake negotiation, simultaneous open, and agreed-version data handling.

* Corrected Dijkstra committee proposals that originate from earlier levels.

* Clamped node-to-node transaction ID requests for protocol version 16 and later.

* Hashed transaction-body encodings when stored CBOR is absent to derive transaction IDs.

* Refined PPUP and MIR edge-case validation.

* Deferred DMQ operational-certificate counter and rate recording until commit, preventing refused messages from leaving stale counter state.

* Returned an empty peer list when `NoPeerSharing` is negotiated locally or remotely and avoided calling `ShareRequestFunc` in those cases.

* Pinned `BuildHeader` output to ouroboros-consensus header golden files.

* Counted bootstrap witness roots when checking genesis-delegate witnesses and expanded witness-rule model coverage.

* Decoded tag-258 sets through `cbor.Value`, supported composite map keys, and applied whole-tree decoding budgets to these values.

* Retried transaction-scoped memo builds after a panic so waiters do not receive a nil/nil success result.

* Verified Byron PBFT delegation-certificate signatures in both PBFT header validators.

* Aligned ledger/common decoding with `cardano-ledger`, including rejection of bignum multiasset quantities and Mary coin bignums.

* Waited for receiver cleanup when stopping the muxer and stopped replaced live senders and receivers during re-registration.

* Stabilized the KeepAlive server by restarting it after `MsgDone` and handling Stop and restart races.

* Corrected epoch-aware `PoolRegistered` logic, slot-aware block state, and Dijkstra cross-level views so reaped pools are not treated as registered and same-block re-registration is classified correctly.

* Protected governance model evaluation from nil Conway voters and required purpose-root state for non-proposed hard-fork predecessors.

* Shared transaction-offset extraction between combined and streaming block decoders and rejected transaction and offset count mismatches.

* Ensured BlockFetch `Start` waits for prior-instance goroutines and terminal range callbacks before returning.

* Coordinated connection teardown during `Dial`, joined protocol loops, added `CloseContext` for callback-owned shutdown, and prevented late sends on `ErrorChan`.

* Preserved exact DMQ payload CBOR bytes for message-ID hashing, KES verification, and relaying messages in their current shape.

* Made `LeiosNotify` `Server.Stop` wait for retired protocol instances while keeping callback-context shutdown non-blocking.

* Released BlockFetch fetches' own busy locks across Stop and Start and prevented hangs for fetches that never started.

* Calculated Genesis window block counts with exact integer arithmetic to improve selection precision for large values.

### Additional Changes

* Restricted protocol timers to receiver-only operation and removed the default Local State Query and Local Tx Monitor timeouts.

* Added CIP-0177 Tachys schedule conformance tests.

* Removed a duplicate DMQ message-size-check declaration so the package builds successfully.

* Covered admission generation-drift regression testing.

* Updated Tachys model tests for required `Envelope` input and reference validation order.

* Stabilized protocol read-loop tests.
