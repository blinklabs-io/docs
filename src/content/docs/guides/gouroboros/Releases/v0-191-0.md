## v0.191.0 (August 1, 2026)

**Title:** Strengthen validation and add node-to-client v21 support

**Date:** August 1, 2026

**Version:** v0.191.0

This release tightens address, redeemer, and delegation validation, preserves unknown ledger errors for Dijkstra-era handling, returns clearer errors for unknown protocol messages, and adds node-to-client protocol version 21 support.

### 💪 Improvements

* Fixed **raw address validation:** raw address decoding now rejects reserved CIP-0019 address types and invalid network IDs.

* Improved **protocol error reporting:** unknown CBOR message types now return explicit errors across blockfetch, chainsync, handshake, keepalive, leiosfetch, localstatequery, localtxmonitor, localtxsubmission, peersharing, and txsubmission.

* Expanded **ledger error handling:** unknown ledger error constructors now stay visible instead of defaulting to an era, Dijkstra-era cases receive dedicated handling, and marshal validation now rejects malformed ledger failures.

* Corrected **redeemer validation:** unmatched redeemer purposes now fail validation instead of being dropped.

* Updated **block classification:** block types now follow their declared protocol ranges.

* Refined **genesis validation:** CBOR marshal now rejects unknown genesis network IDs.

* Added **node-to-client v21 support:** local-state/query version 21 now uses the updated wire shape, and `GenesisConfigResult` now uses the renamed fields.

* Tightened **delegation validation:** delegation checks now reject unknown DRep types.
