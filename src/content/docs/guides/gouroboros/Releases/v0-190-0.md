## v0.190.0 (July 28, 2026)

**Title:** Validate Byron block body proofs during decode

**Date:** July 28, 2026

**Version:** v0.190.0

This release makes Byron block decoding validate the body proof during CBOR decode and keeps the `common.VerifyConfig{SkipBodyHashValidation}` escape hatch.

### 💪 Improvements

* Fixed **Byron block decoding:** Byron blocks now reject substituted or tampered bodies with `ErrBodyProofMismatch` during CBOR decode unless `common.VerifyConfig{SkipBodyHashValidation}` is set.

Thank you for following gOuroboros releases.
