## v0.212.2

**Title:** Expand transaction projections and protocol safety

**Version:** v0.212.2

This release expands transaction data available through UTxO-RPC, adds current Dijkstra protocol parameters, and makes protocol and payload validation more predictable and secure.

### Improvements

* Added complete transaction projections from Shelley through Dijkstra, including minting, withdrawals, collateral, explicit total collateral, validity intervals, an explicit zero time to live, governance and proposal data, parameter updates, witnesses, auxiliary data, redeemers, and transaction success. The projection applies canonical ordering and indexing, rejects malformed governance, script, redeemer, and execution cost data, and correctly encodes negative large integers and wide rational values.

### Breaking Changes

* Configured Leios fetch, notification, and voting protocols to start only when the corresponding version-compatible `WithLeios...Config` value is supplied. Unconfigured accessors can now be nil, and peer protocol IDs without configuration fail instead of dispatching; applications that use Leios must provide matching configuration values.

* Enabled Byron block payload authentication by default by verifying SSC proof hashes and delegation or update payload signatures during decoding and body proof validation. The `EnableByronSscProofHashValidation` and `EnableByronPayloadValidation` options and the old `VerifyConfig` parameters are no longer available; `SkipBodyHashValidation` remains the explicit parse-only bypass, and malformed or trailing `ssc_proof` data is rejected.
