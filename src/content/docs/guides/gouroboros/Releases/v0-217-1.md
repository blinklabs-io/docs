## v0.217.1

**Title:** Improve proof verification and script validation performance

**Version:** v0.217.1

This release improves proof verification, committee validation, script evaluation, transaction validation, and multi asset size calculation while preserving established verification behavior and ExUnits.

### Performance

* Enhanced VRF proof generation and verification with variable-time scalar multiplication for public inputs, shared canonical point encodings, and batched inversion. `VerifyAndHash` now derives its output consistently, while torsion and legacy differential tests preserve existing verification behavior.
* Accelerated Leios committee proof-of-possession verification by caching successful results in a bounded 8,192-entry cache, excluding failures from the cache, and aggregating public keys with Jacobian mixed addition. Large-committee verification now completes in milliseconds rather than seconds.
* Updated `plutigo` to v0.11.2 and shared `PlutusData` normalization across script evaluation to avoid redundant deep copies while preserving `ExUnits`.
* Reduced phase-1 validation work and allocations by replacing repeated `TransactionInput.String` formatting with comparable typed keys and memoizing language-view parameters in a bounded 16-entry cache.
* Optimized multi-asset size calculation by avoiding repeated CBOR encoding and memoized successful Plutus script well-formedness checks in a bounded 16,384-entry cache keyed by the script and protocol context. Combined with the phase-1 validation optimization, warm revalidation improves from about 586 microseconds to about 340 microseconds with bounded memory overhead.
