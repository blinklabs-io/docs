## v0.213.8

**Title:** Improve query safety and protocol reliability

**Version:** v0.213.8

This release bounds peer-controlled Shelley queries before decoding, improves local submission and pipelining behavior, validates LeiosFetch responses, and updates cryptographic dependencies.

### New Features
* Added replay reservation cleanup for rejected local message submissions, including `SubmitRefusedFunc` and `WithSubmitRefusedFunc`; token-safe cleanup prevents one reservation from releasing another.

* Improved pipelined message handling by tracking local-agency generations for declared message types, keeping requests admissible across a round trip while continuing to reject undeclared messages.

### Bug Fixes
* Strengthened LeiosFetch reply validation by correlating block, vote, and range replies with active requests; mismatches return `ErrUnexpectedResponse`, duplicate and range inconsistencies are detected, and abandoned-request draining remains available.

* Refined Shelley filtered local-state query handling by bounding peer-controlled sets and lists before typed CBOR decoding and enforcing `maxLocalStateQuerySetItems=10000` for multiple Shelley filters, non-myopic rewards, and pool filters.

### Additional Changes
* Updated `golang.org/x/crypto` from `0.57.0` to `0.58.0` and indirect `x/sys` from `0.48.0` to `0.49.0`.
