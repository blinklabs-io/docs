## v0.208.1

**Title:** Strengthen protocol validation and compatibility

**Version:** v0.208.1

This release hardens protocol handling, separates proposal validation concerns, improves transaction submission checks, expands era compatibility, and standardizes gOuroboros branding.

### Features
* Improved protocol ingress reliability by reading messages incrementally, enforcing byte limits for each protocol state, admitting peer initiated and pipelined messages only when allowed, and validating message submission request counts and windows. `MaxUnacknowledgedMessageIDs` controls the outstanding message ID limit and defaults to `100`.
* Refined proposal validation so generic validation and decoding do not reject protocol-only proposals for system tag length or ASCII content; ledger-state-dependent system tag checks remain available through `ValidateSystemTags`.
