## v0.206.0

**Title:** Add vote diffusion reservation and allow bootstrap parameter changes

**Version:** v0.206.0

This release reserves the Peras vote diffusion protocol number and allows broader parameter changes during Conway and Dijkstra bootstrap validation.

### New Features
* Added **the Peras vote diffusion protocol reservation:** `protocol/perasvotes` registers `peras-vote-diffusion` with protocol number `17` for CIP-0140. The reservation does not implement handlers, a state machine, messages, or a wire format.

### Breaking Changes
* Relaxed **bootstrap parameter validation:** Conway and Dijkstra `ParameterChange` actions no longer require field-level validation of the protocol parameter fields they update during bootstrap, while governance action type checks remain in place. During Conway bootstrap at PV9, canonical `DRepDeposit` updates can replay without stalling. Consumers of the removed `bootstrap-parameter-groups` rule and related exported helpers and error identifiers must migrate to the remaining bootstrap validation.
