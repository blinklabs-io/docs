## v0.192.1 (August 6, 2026)

**Title:** Tighten protocol and ledger validation

**Date:** August 6, 2026

**Version:** v0.192.1

This release tightens protocol and ledger validation so explicit `KES` slot zero values remain intact and invalid or unsupported inputs are rejected before they reach processing.

### 💪 Improvements

* Retained explicit `KES` slot zero values so a zero slot now remains intact during protocol handling.

* Rejected invalid reward parameters so reward validation now stops values outside the allowed range before they reach ledger processing.

* Blocked unknown `DMQ` reasons from reaching downstream processing.

* Prevented unknown governance actions from reaching ledger processing.

* Stopped malformed fallback data from reaching ledger processing.

Thank you for following gOuroboros releases.
