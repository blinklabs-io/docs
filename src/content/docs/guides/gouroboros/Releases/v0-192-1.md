## v0.192.1 (August 6, 2026)

**Title:** Tighten protocol and ledger validation

**Date:** August 6, 2026

**Version:** v0.192.1

This release tightens protocol and ledger validation so explicit `KES` slot zero values remain intact and invalid or unsupported inputs fail fast.

### 💪 Improvements

* Preserved explicit `KES` slot zero values so a zero slot now remains intact during protocol handling.

* Rejected invalid reward parameters so reward validation now stops out of range values before they reach ledger processing.

* Blocked unknown `DMQ` reasons so protocol handling now stops unsupported reasons before they continue downstream.

* Prevented unknown governance actions so ledger validation now stops unsupported actions before they are applied.

* Refused malformed fallback data so ledger validation now rejects invalid fallback payloads before they are used.

Thank you for following gOuroboros releases.
