## v0.189.5 (July 28, 2026)

**Title:** Update CI checkout and chainsync validation

**Date:** July 28, 2026

**Version:** v0.189.5

This release updates the checkout action used in CI workflows and tightens node-to-node chainsync validation for unknown eras and block types.

### 💪 Improvements

* Updated **CI workflow checkout action:** Seven workflows now use `actions/checkout` v7.0.1, which includes upstream fixes for unsafe pull request checks, ASCII whitespace trimming, and `--unset` escaping.

* Fixed **node-to-node chainsync validation:** Client rollforward handling now checks the era before continuing, and server rollforward handling now rejects unknown block types with clear errors.

Thank you for following gOuroboros releases.
