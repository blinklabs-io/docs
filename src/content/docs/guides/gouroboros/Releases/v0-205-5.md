## v0.205.5

**Title:** Improve ledger validation and decoding reliability

**Version:** v0.205.5

This release improves transaction metadata access, collateral validation, Byron signature verification, and decoding consistency while aligning native script thresholds with Conway CDDL.

### New Features

* Added **invalid transaction indexes to transaction offsets:** callers can retrieve invalid transaction indexes during the same block offset extraction for Shelley and legacy Dijkstra layouts. Absent or empty lists return `nil`.
