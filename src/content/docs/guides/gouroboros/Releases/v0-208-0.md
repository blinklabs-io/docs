## v0.208.0

**Title:** Expand protocol validation and compatibility

**Version:** v0.208.0

This release expands protocol support, strengthens validation, and improves compatibility across consensus, ledger, network, and application integrations.

### Features
* Introduced Peras vote diffusion when nodes negotiate node-to-node v16 support, aligned Leios wire tags with strict tag and type decoding, returned protocol errors for unavailable data, and bounded BlockRange responses to 1,000 responses or 64 MiB by default with a 5-second stall timeout.
* Added Dijkstra `MaxPledgeLeverage` and PV13-gated `MinPoolMargin` reward constraints with parameter range validation while preserving behavior before Dijkstra.

### Compatibility and Breaking Changes
* Enforced full consensus header validation to require a matching registered VRF key hash and limited DMQ KES authentication to a configurable maximum KES evolution window, defaulting to 62 and honoring explicit slot overrides.
* Registered MIR genesis-delegate quorum validation for the Shelley through Babbage eras and made UTxO-RPC MIR source-pot conversion preserve reserves versus treasury while rejecting invalid encodings.
* Synchronized configured Byron epoch lengths across BlockFetch and ChainSync and made slot conversion safe for large values.
* Resolved committee hot keys through typed authorizations, preserved key and script identity, handled multiple cold authorizations for shared hot credentials, and applied seated-member checks from protocol major version 11.
* Matched the NtC v19 and v20 ledger-peer-snapshot wire format with request `[34]`, outer snapshot wire version 1, and typed errors for unsupported peer kinds or versions.

### Bug Fixes
* Fixed ledger map handling by adding `DecodeLedgerMap`, rejecting duplicate keys at ledger transaction boundaries, retaining last-wins generic `cbor.Value` decoding, and preserving lenient Byron SSC payload handling.
* Accepted valid empty ledger peer snapshots during integration validation instead of treating empty pool lists as failures.

### Dependency Updates
* Upgraded `github.com/blinklabs-io/ouroboros-mock` from 0.20.2 to 0.20.3, including upstream certificate-builder and pipe-cleanup fixes.
* Refined `github.com/blinklabs-io/plutigo` integration at version 0.7.2 across root and example modules and made malformed-script coverage independent of UPLC version gating.
