## v0.205.3

**Title:** Improve consensus selection, decoding controls, and query efficiency

**Version:** v0.205.3

This release makes mixed candidate selection deterministic, adds configurable CBOR nesting limits, updates the Plutigo dependency, and reduces repeated current-era queries during an acquired snapshot.

### ✨ New Features

* Configured **CBOR nesting limits:** `cbor.MaxNestedLevels` and `cbor.MaxUntrustedNestedLevels` are now package variables with a default of `16384`. Set these values before the first `Decode` call because decoder modes cache lazily; `ParseDiagnostic` also enforces the configured `MaxNestedLevels` value.
