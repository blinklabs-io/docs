## v0.212.5

**Title:** Improve protocol decoding and validation

**Version:** v0.212.5

This release improves era history and ledger decoding compatibility, strengthens validation of encoded data, and makes artifact workflow retries more reliable during rate limiting.

### Breaking Changes

* Improved local state queries so era histories accept standard and indefinite safe zones, distinguish CBOR null unbounded ends from bounded ends, preserve optional Peras fields, and reject invalid counters, array lengths, and trailing bytes. New protocol-accurate nested `EraHistoryResult` types and field names require callers to update references to previous API or type definitions.

* Strengthened ledger decoding so fixed-arity tuples reject indefinite CBOR arrays and trailing bytes, Dijkstra variants validate their lengths, and `cbor.Decode` reads directly from the provided bytes with predictable byte counts. Updated Plutigo to `v0.9.1` as part of this decoding correction.

### Additional Changes

* Enhanced benchmark artifact downloads with `actions/download-artifact` `v8.0.2`, improving retry behavior when GitHub returns HTTP `429` rate limit responses.

* Updated benchmark and fuzz artifact uploads to `actions/upload-artifact` `v7.0.2`, improving retry behavior when GitHub returns HTTP `429` rate limit responses.

**Release:** [v0.212.5](https://github.com/blinklabs-io/gouroboros/releases/tag/v0.212.5)
