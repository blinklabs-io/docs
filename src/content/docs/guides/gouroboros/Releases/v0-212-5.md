## v0.212.5

**Title:** Improve protocol decoding and validation

**Version:** v0.212.5

This release improves era history and ledger decoding compatibility, strengthens validation of encoded data, and makes artifact workflow retries more reliable during rate limiting.

### Breaking Changes

* Improved local state query era history decoding to support standard and indefinite safe zones, distinguish CBOR null unbounded ends from bounded ends, preserve optional Peras fields, and validate counters, array lengths, and trailing bytes. The release also exposes protocol accurate nested `EraHistoryResult` types and field names, so callers must update references that use the previous API or type definitions.
