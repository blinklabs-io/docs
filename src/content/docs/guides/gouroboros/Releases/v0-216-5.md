## v0.216.5

**Title:** Improve cached script evaluation and Dijkstra header handling

**Version:** v0.216.5

This release improves repeated script evaluation and adds support for 10-field Dijkstra header bodies while retaining validation for unsupported layouts.

### Performance

* Improved cached script evaluation by upgrading `plutigo` from v0.10.0 to v0.11.0, caching each decoded Plutus program as a `cek.PreparedProgram`, and routing cached Plutus V1 through V4 scripts through a pooled evaluator for prepared programs. The PlutusV3 PV11 benchmark recorded 19.7% faster evaluation and 67.7% fewer allocated bytes for cached corpus scripts.

### Bug Fixes

* Fixed decoding of Dijkstra headers that carry the 10-field Babbage-era Praos body, as produced by cardano-node 11.2.0 on DijkstraNet after the PV12 hard fork. A 10-field body leaves the Leios extension `nil` and re-encodes to the same 10-field bytes, 12-field Leios bodies are still validated, and other field counts such as 11 are still rejected. A header built with a `nil` extension now encodes the 10-field body.
