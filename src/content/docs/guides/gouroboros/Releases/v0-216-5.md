## v0.216.5

**Title:** Improve cached script evaluation and Dijkstra header handling

**Version:** v0.216.5

This release improves repeated script evaluation and adds support for 10-field Dijkstra header bodies while retaining validation for unsupported layouts.

### Performance

* Improved cached script evaluation by upgrading `plutigo` from v0.10.0 to v0.11.0, caching decoded Plutus programs and `cek.PreparedProgram` objects, and routing cached Plutus V1 through V4 scripts through a pooled evaluator for prepared programs. The PlutusV3 PV11 benchmark recorded 19.7% faster evaluation and 67.7% fewer allocated bytes for cached corpus scripts.

### Bug Fixes

* Fixed Dijkstra header processing for 10-field Praos and Babbage bodies by encoding the extension as `nil`, while validating 12-field Leios bodies and rejecting unsupported field counts such as 11. Re-encoding preserves the 10-field byte layout, and post-DijkstraNet PV12 headers now decode successfully.
