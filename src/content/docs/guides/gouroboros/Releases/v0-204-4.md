## v0.204.4

**Title:** Normalize script-visible transaction data

**Version:** v0.204.4

This release normalizes datum and redeemer data before scripts receive it, aligning `serialiseData` output with cardano-ledger canonical encoding. The correction prevents execution failures caused by definite and indefinite length encoding mismatches while keeping `DatumHash` keys based on the original bytes.

### 🐛 Bug Fixes

* Fixed **script-visible datum and redeemer encoding:** Common script contexts and script purpose data now use canonical encoding before scripts receive them.

* Corrected **inline datum rendering:** V1 and V2 resolved inputs and Babbage inline datum payloads now expose normalized data.

* Improved **Conway script evaluation:** Evaluation paths and ScriptContextV3 redeemers now use canonical script-visible encoding.

* Corrected **Dijkstra script data handling:** V4 inline and guard datums and evaluation paths now normalize data before script execution.

* Preserved **datum hash identity:** `DatumHash` keys continue to use the original datum bytes, even when script-visible data is normalized.

* Expanded **normalization coverage:** Tests and the Voting CBOR fixture now verify canonical script-visible data handling.
