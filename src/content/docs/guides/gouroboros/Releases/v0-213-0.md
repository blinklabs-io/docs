## v0.213.0

**Title:** Expand protocol compatibility and validation safeguards

**Version:** v0.213.0

This release expands node to client compatibility, adds query and transaction monitoring capabilities, aligns Dijkstra and Leios behavior with the 2026w41 release candidate, and strengthens validation, resource bounds, message handling, and CI output safety.

### New Features

* Added node to client protocol versions `22` and `23`, gated Shelley local state queries on the negotiated version, exposed new query APIs and types, added wire versions for `LedgerPeerSnapshot` and peer kind requests, aligned codec behavior, and bounded nested `GetCBOR` decoding.

* Correlated MessageSubmission requests with replies, validated request IDs, counts, and windows, preserved pending requests when sending failed, and documented request and reply rules.

* Matched LocalTxMonitor replies to active queries, required `HasTx` IDs to contain exactly 32 bytes, and unblocked waiting calls safely during shutdown.

* Accepted pipelined TxSubmission2 `RequestTxIds` and `RequestTxs` while non blocking replies remained in flight and preserved reply ordering.
