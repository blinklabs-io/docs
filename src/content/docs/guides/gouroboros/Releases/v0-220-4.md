## v0.220.4

**Title:** Improve consensus performance and protocol validation

**Release date:** 2026-11-18

**Version:** v0.220.4

This release improves consensus performance, validates active leader assignments and Conway transaction data more precisely, strengthens chain selection and peer sharing behavior, and clarifies ledger parameter compatibility.

### Performance

* Improved Byron PBFT state updates by sharing an append-only log and advancing the newest state in constant time without copying or recounting the issuer window. Branch and rollback behavior remains unchanged. At `k=2160`, the stated benchmark improved from about 12,500 ns, 65,536 B, and 1 allocation to about 105 ns, 153 B, and 0 allocations.

### Breaking Changes

* Corrected non-Byron block issuer validation to use the active leader distribution snapshot through `VerifyConfig.LeaderPoolVrfKeyHash`. Issuer validation callers must provide this callback; retired or not yet active VRF rotated pools still validate when the slot snapshot includes them.

* Updated Praos chain selection to compare operational certificate issue numbers when the slot and cold issuer match, choosing the higher number before comparing VRF output. `ChainTip` implementations must now provide `IssuerVkey()` and `OpCertSequenceNumber()`.
