## v0.217.2

**Title:** Improve transaction validation and native script interoperability

**Version:** v0.217.2

This release improves transaction validation efficiency, aligns constructed native script encoding with Haskell serialization, and standardizes repository formatting for reliable checks.

### Performance

* Improved transaction validation efficiency by reusing each transaction's script view, including in-flight builds, errors, and partial results, across repeated requests. External validation loops can use `NewTransactionScopedLedgerState` and `IsTransactionScopedLedgerState` to preserve this reuse.

### Bug Fixes

* Corrected constructed native script encoding to match Haskell serialization rules: empty child lists use `0x80`, lists with up to 23 children use definite arrays, and lists with 24 or more children use indefinite lists for `all`, `any`, and `n-of-k` scripts. Imported scripts preserve their original bytes and hashes, while newly constructed scripts at the 23/24 child boundary can produce different hashes and derived addresses.

### Additional Changes

* Standardized repository formatting with `golines` and restored `gosec` suppression placement after reflow, keeping lint and test checks reliable without changing runtime or API behavior.
