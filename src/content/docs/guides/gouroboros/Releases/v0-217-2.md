## v0.217.2

**Title:** Improve transaction validation and native script interoperability

**Version:** v0.217.2

This release improves transaction validation efficiency, aligns constructed native script encoding with Haskell serialization, and standardizes repository formatting for reliable checks.

### Performance

* Improved transaction validation efficiency by reusing each transaction's prepared script view, including work in progress and earlier errors or partial results, so repeated requests avoid rebuilding the same data. External validation loops can use `NewTransactionScopedLedgerState` and `IsTransactionScopedLedgerState` to keep this shared state available.

### Bug Fixes

* Corrected constructed native script encoding to match Haskell serialization rules. Empty child lists use `0x80`; lists with 0–23 children use definite arrays; and lists with 24 or more use indefinite lists for `all`, `any`, and `n-of-k` scripts. Imported scripts retain their original bytes and hashes, while newly constructed scripts at the 23/24 boundary can produce different hashes and derived addresses.

### Additional Changes

* Standardized repository formatting with `golines` and kept `gosec` suppression annotations in recognized positions after reformatting. Lint and test checks remain reliable without changing runtime or API behavior.
