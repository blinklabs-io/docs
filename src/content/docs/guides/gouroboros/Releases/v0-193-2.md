## v0.193.2 (August 17, 2026)

**Title:** Strengthen consensus threshold precision and Byron proof validation

**Date:** August 17, 2026

**Version:** v0.193.2

This release tightens consensus threshold precision and strengthens Byron SSC body proof validation so the node handles both code paths more reliably.

### 💪 Improvements

* Fixed **consensus threshold precision:** range reduction now keeps `ln` and `exp` inputs within a safer range, preserving the leader threshold calculation.

* Updated **Byron SSC body proof validation:** body proof checks now verify the expected Byron structure and hash handling before acceptance.

Thank you for following gOuroboros releases.
