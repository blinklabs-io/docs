## v0.193.2 (August 17, 2026)

**Title:** Improve consensus threshold precision and Byron proof validation

**Date:** August 17, 2026

**Version:** v0.193.2

This release improves consensus threshold precision and Byron SSC body proof validation so leader threshold calculations and proof checks stay aligned with chain data.

### 💪 Improvements

* Fixed **consensus threshold precision:** range reduction keeps `ln` and `exp` inputs within a safer range, preserving leader threshold calculation accuracy.

* Updated **Byron SSC body proof validation:** proof checks now verify the expected Byron body structure and hash handling before acceptance.
