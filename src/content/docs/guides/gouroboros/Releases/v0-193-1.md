## v0.193.1 (August 16, 2026)

**Title:** Tighten governance validation and deep fork selection

**Date:** August 16, 2026

**Version:** v0.193.1

This release tightens governance validation, improves deep fork selection, and normalizes chain-state query output so consensus and ledger behavior stay aligned with live network data.

### 💪 Improvements

* Fixed **governance proposal and voting validation:** incomplete proposals and ballots now fail validation before processing.

* Improved **deep fork selection:** Genesis now chooses the denser branch first when it evaluates deep forks.

* Updated **chain-state query output:** `DebugChainDepState` now returns the current query result without an extra array wrapper.

### 🙏 Thank You

Thank you for following gOuroboros releases.
