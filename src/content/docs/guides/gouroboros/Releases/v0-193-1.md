## v0.193.1 (August 16, 2026)

**Title:** Strengthen governance checks and fork choice

**Date:** August 16, 2026

**Version:** v0.193.1

This release strengthens governance checks, improves fork choice for deep forks, and aligns chain state query output with the expected format.

### 💪 Improvements

* Fixed **governance proposal and voting checks:** incomplete proposals and votes now fail before processing.

* Improved **fork choice for deep forks:** Genesis now selects the denser branch first when it compares competing branches.

* Updated **chain state query output:** `DebugChainDepState` now returns the current result in the expected format, without an extra array wrapper.

### 🙏 Thank You

Thank you for following gOuroboros releases.
