## v0.213.10

**Title:** Expand query compatibility and protocol reliability

**Version:** v0.213.10

**Date:** 2026-10-21

This release improves receiver compatibility, expands local state query decoding for `cardano-cli` 11.3.1.0, and keeps pipelined protocol reservations aligned with state transitions.

### New Features

* Improved receiver consistency across CBOR, consensus, ledger, and protocol packages by enabling `recvcheck` linting. Block `Type` methods now use pointer receivers, so downstream code that calls them on value-typed blocks may need to pass pointers.

* Expanded local state query decoding for `cardano-cli` 11.3.1.0 layouts. Node-to-client versions 21 through 23 now support the `GenesisConfig` layout without extra configuration, while version 23 adds Shelley stake-pool state query 40, `Client.GetStakePoolState`, canonical pool-filter encoding, and Leios Praos2 `DebugChainDepState` and endorser announcement decoding.

### Bug Fixes

* Restored pipelined reply reservations as part of consuming state transitions, preventing stale admission reservations that can stall sessions.
