## v0.220.0

**Title:** Improve security and ledger compatibility

**Version:** v0.220.0

This release addresses Go and crypto vulnerabilities, improves Dijkstra minimum fee calculation, corrects IPv6 relay handling, and tightens Leios certificate and ledger validation.

### Security

* Updated the Go toolchain requirement from `1.26.10` to `1.26.11` in the root and tools modules, resolving a standard library vulnerability reported by `govulncheck`.
* Resolved the module level `govulncheck` finding by updating `golang.org/x/crypto` from `v0.58.0` to `v0.58.1-0.20261009181718-2f1f834330b2` in the root and tools modules and checksums; build and test behavior remains unchanged.

### Bug Fixes

* Corrected Dijkstra minimum fee calculation to include reference scripts consumed by top level and subtransactions, preventing undercalculated or zero minimum fees.

### Breaking Changes

* Standardized `PoolRelay.Ipv6` storage on standard network byte order while preserving ledger wire order for CBOR, genesis, and UTxO RPC serialization. Invalid IPv6 conversion now returns a UTxO RPC error; consumers that persist previous wire order values may need migration.
* Configured Leios certificate verification to use the raw 32 byte announcing block hash by default. Ledger capability configuration can select CBOR framed prototype encoding, while unsupported values now return configuration errors.
* Enforced missing Shelley `DELEG` and relay `dns_name` checks across stake registration and deregistration, MIR timing and pot validation, genesis delegation, and protocol version specific relay validation. Ledger state now requires the related capabilities and returns errors when they are unavailable.
