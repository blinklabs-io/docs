## v0.220.3

**Title:** Improve protocol compatibility and ledger validation

**Version:** v0.220.3

This release improves protocol compatibility across node-to-node and node-to-client connections, strengthens era-specific transaction and ledger validation, and improves chainsync and reference-script handling.

### Bug Fixes

* Updated `ouroboros-mock` to v0.21.2 and routed embedded consensus fixtures through a test hook, preserving fixture coverage without an import cycle.
* Enforced era-specific duplicate transaction-metadata label rules: Conway and Dijkstra reject duplicate top-level labels, while pre-Conway eras retain the last value and preserve the original CBOR.
* Simplified `GetConstitution` and `GetRatifyState` results by unwrapping their single era wrapper.
