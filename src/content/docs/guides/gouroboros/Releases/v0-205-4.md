## v0.205.4

**Title:** Improve transaction input matching performance

**Version:** v0.205.4

This release improves ledger validation performance by comparing transaction inputs directly as `(TxId, Index)` pairs instead of formatting them as strings. The optimization reduces repeated hex encoding and `Sprintf` allocation work during nested input matching while preserving matching behavior.

### Additional Changes

* Improved **transaction input matching:** `ResolvedInput.Equals` compares inputs directly by transaction ID and index, and `expandInputs` plus spend-redeemer resolution use the helper to reduce repeated allocation work during ledger validation while preserving matching behavior.
