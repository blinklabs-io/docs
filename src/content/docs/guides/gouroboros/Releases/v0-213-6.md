## v0.213.6

**Title:** Improve protocol handling and transaction fetching

**Version:** v0.213.6

This release improves protocol message admission, corrects filtered Shelley queries, updates transaction fetching for the Leios wire format, and upgrades the Plutigo dependency.

### Breaking Changes

* Changed `MsgBlockTxs` to carry only transactions. The `Point` and `Bitmaps` fields are removed, and `NewMsgBlockTxs` now accepts only transactions. The wire payload is `[4, [* tx]]`, with each transaction wrapped as tag 24 over a definite bytestring containing one `block_transaction`. The LeiosFetch client validates the returned transaction count against the requested bitmap count and rejects malformed wrappers or empty transactions. The protocol README references Leios release candidate `2026w42`.

### Bug Fixes

* Improved inbound message admission by binding it to the peer agency generation, reserving pipelined reply capacity against outstanding requests, and resnapshotting deferred state before admitting later messages. The protocol now rejects surplus coalesced replies deterministically while preserving legitimate pipelined ordering.
