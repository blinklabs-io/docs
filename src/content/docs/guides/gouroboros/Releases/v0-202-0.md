## v0.202.0 (August 26, 2026)

**Title:** Improve ledger compatibility and validation

**Date:** August 26, 2026

**Version:** v0.202.0

This release improves ledger compatibility with released Plutigo behavior, enforces transaction validity boundaries, preserves legacy cost model data, and decodes origin block headers correctly.

### 💪 Improvements

* Improved **Plutigo compatibility:** The ledger now uses released constructor tags, while examples and tests use compatible dependency versions so builds and tests align with the released Plutigo API.

* Enforced **validity interval upper bounds:** Transactions whose upper bound equals or precedes the current slot now receive a typed validation error, matching exclusive upper-bound behavior across supported eras.
