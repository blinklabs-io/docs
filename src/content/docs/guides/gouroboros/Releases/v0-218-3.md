## v0.218.3

**Title:** Improve protocol compatibility and transaction validation

**Version:** v0.218.3

This release improves ChainSync throughput, protocol decoding, ledger validation, Plutus compatibility, native-script signatures, and Leios endorser-block handling.

### Bug Fixes

* Updated the Plutigo dependency from `v0.11.4` to `v0.12.0` and switched Plutus data access to read-only methods. The reference decoder now accepts at most 32 constant tags and 1024 constructor fields.
* Improved ChainSync throughput on high latency connections by maintaining a sliding `RequestNext` window and refilling it to `PipelineLimit` while preserving callback backpressure. Fixed a shutdown race during reintersect.
