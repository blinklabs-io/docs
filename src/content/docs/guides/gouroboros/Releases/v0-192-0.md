## v0.192.0 (August 6, 2026)

**Title:** Standardize script-context mint rendering and key erasure

**Date:** August 6, 2026

**Version:** v0.192.0

This release keeps ledger output consistent across protocol versions and clears spent key material after use.

### 💪 Improvements

* Fixed **script-context mint rendering:** Plutus V1 and V2 script contexts now always include the zero-ADA mint entry in `txInfoMint`, so output stays consistent across protocol versions.

* Improved **key erasure behavior:** spent evolution keys are now cleared from memory after use, and sign or update requests using erased keys now fail immediately.

### 🙏 Thank You

Thank you for following gOuroboros releases.
