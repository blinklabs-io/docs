## v0.192.0 (August 6, 2026)

**Title:** Standardize script-context mint rendering and key erasure

**Date:** August 6, 2026

**Version:** v0.192.0

This release keeps script-context serialization consistent across protocol versions and clears spent key material after update.

### 💪 Improvements

* Fixed **script-context mint rendering:** Plutus V1 and V2 script contexts now include the zero-ADA mint entry in `txInfoMint` across every supported protocol version, so CBOR output stays consistent and no longer depends on protocol-major settings.

* Improved **key erasure behavior:** spent evolution keys are now cleared from memory after update, and sign or update requests using erased keys now fail immediately.

Thank you for following gOuroboros releases.
