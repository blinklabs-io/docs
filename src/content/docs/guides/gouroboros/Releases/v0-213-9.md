## v0.213.9

**Title:** Decode Alonzo genesis cost model overrides

**Version:** v0.213.9

This release adds Alonzo genesis cost model overrides for Plutus V1, V2, and V3 and makes stopped pipeline operations return consistent errors.

### New Features

* Added optional top-level `extraConfig.costModels` support for Alonzo genesis data. The decoder validates model lengths, skips unknown Plutus versions, leaves supplied model data unchanged, applies overrides during `UpdateFromGenesis`, and exposes `ApplyExtraConfigCostModels` for reapplying them across era transitions.

### Bug Fixes

* Improved pipeline stop handling so `Submit` after `Stop` and `Start` after `Stop` consistently return `ErrPipelineStopped` instead of an unrelated validation error.
