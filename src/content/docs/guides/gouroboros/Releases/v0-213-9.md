## v0.213.9

**Title:** Decode Alonzo genesis cost model overrides

**Version:** v0.213.9

This release adds Alonzo genesis cost model overrides for Plutus V1, V2, and V3 and improves the consistency of pipeline lifecycle errors.

### New Features

* Added optional top-level `extraConfig.costModels` support for Alonzo genesis data. The decoder validates model lengths, skips unknown Plutus versions, avoids modifying injected model slices, applies overrides during `UpdateFromGenesis`, and exposes `ApplyExtraConfigCostModels` for reapplying them across era transitions.
