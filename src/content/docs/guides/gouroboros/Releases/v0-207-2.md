## v0.207.2

**Title:** Improve validation, serialization, and fee calculation across supported eras

**Version:** v0.207.2

This release strengthens validation, serialization, fee calculation, and compatibility across the Byron, Shelley, Alonzo, Babbage, Conway, and Dijkstra eras.

### Bug Fixes
* Improved Dijkstra subtransaction validation by rejecting explicitly empty key-23 sets and duplicate child body hashes, including cases where witnesses or auxiliary data differ.
* Enhanced Byron AVVM redeem address handling by deriving network magic attributes when required and rejecting duplicate AVVM and non-AVVM genesis outpoints.
* Hardened Byron v1 wire decoding with definite framing, typed update proposal fields, strict address and attribute decoding, and structural validation of Byron update payloads.
* Restricted Byron transaction outputs to the 45,000,000,000,000,000 Lovelace maximum during decoding.
* Aligned Byron epoch boundary block and extra data CBOR shapes with reference behavior and exposed Genesis tag detection.
* Validated Conway `UpdateCommittee` quorum and duplicate removal rules, canonicalized governance serialization, and corrected collateral return, total collateral, Byron genesis configuration, and nested tag 24 decoding.
* Enforced the 128-byte UTF-8 pool metadata URL limit when local state query results are encoded and decoded.
* Removed the retired Go Report Card badge from the README.
* Included execution unit fees in Alonzo, Babbage, and Dijkstra minimum fee calculations and unified fee aggregation and rounding.
* Accepted signed Shelley native script M-of thresholds while enforcing era-specific native script constructor domains.
* Preserved DRep deregistration tombstones during Conway and Dijkstra transaction-local validation.
* Allowed child governance proposals to reference ancestors whose RATIFY period expired but that remain live until epoch removal.
* Applied the 128-byte UTF-8 governance anchor URL bound during construction and CBOR encoding and decoding.
* Expanded Dijkstra PV12 batch account state validation with direct deposit and account balance interval support, updated reward account keyed body fields, nested subtransaction validation, and related CBOR and witness invariants.
* Corrected Conway committee expiry, voting restrictions, elected member checks, and sequential committee certificate state validation.
