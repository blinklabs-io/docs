## v0.202.7

**Title:** Strengthen validation and request reliability

**Version:** v0.202.7

This release strengthens certificate and transaction validation, improves leiosfetch request handling, and adds Shelley stake pool certificate validation across supported eras.

### 💪 Improvements

* Strengthened **certificate and governance validation:** Certificate and governance voter authorization now require the appropriate witnesses. Unified credential traversal improves key and script validation, while tighter Plutus redeemer pointer and native script checks and corrected mixed withdrawal redeemer ordering improve transaction validation. Exported MIR genesis delegate quorum validation APIs give applications direct access to this validation.

* Hardened **transaction and redeemer index validation:** Alonzo and Dijkstra now reject invalid indices consistently, including values that overflow their wire representation or fall outside the valid range on 32 bit builds.
