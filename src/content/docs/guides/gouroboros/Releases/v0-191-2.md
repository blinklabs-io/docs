## v0.191.2 (August 2, 2026)

**Title:** Reject malformed certificate decoding and tighten fuzz targeting

**Date:** August 2, 2026

**Version:** v0.191.2

This release rejects malformed pool registration certificate JSON, tightens ledger decoding checks, and keeps fuzz runs focused on exact target names.

### 💪 Improvements

* Fixed **pool registration certificate decoding:** JSON unmarshalling now rejects operator keys with the wrong length and returns a clear validation error.

* Enhanced **ledger decode checks:** Byron null-header handling and legacy reply message decoding now assert the expected failure paths before the tests continue.

* Refined **fuzz CI targeting:** fuzz jobs now match exact target names and avoid persisting checkout credentials during execution.

Thank you for following gOuroboros releases.
