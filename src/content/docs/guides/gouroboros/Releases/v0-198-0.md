## v0.198.0

**Title:** Strengthen ledger validation and transaction encoding

**Version:** v0.198.0

This release improves ledger validation and keeps rebuilt transactions aligned with the data originally submitted.

### Improvements

* Fixed **Conway data validation:** Ledger decoding now rejects null or undefined values, values outside the allowed categories, empty governance records, missing keys, and certificate types that Conway and Dijkstra do not support.

* Preserved **Shelley and Allegra transaction data:** Rebuilt transaction bodies and shared witness sets keep their original encoded data, preventing inflated data sizes that can produce incorrect fees and maximum transaction size checks before Alonzo.

* Strengthened **Plutus script validation:** V3 and V4 wrappers now reject any data after a complete wrapper. V1 and V2 retain their existing behavior.
