## v0.198.0

**Title:** Strengthen ledger validation and transaction encoding

**Version:** v0.198.0

This release strengthens ledger validation and preserves original transaction encoding so accepted data remains faithful to its submitted form.

### Improvements

* Fixed **Conway value validation:** Ledger decoding now rejects null and undefined values, invalid enumerated values, empty governance records, missing keys, and certificate types that Conway and Dijkstra do not support.

* Preserved **Shelley and Allegra transaction encoding:** Rebuilding transaction bodies and shared witness sets now retains their original encoded data, preventing size inflation that can lead to incorrect pre-Alonzo fee and maximum-size validation.
