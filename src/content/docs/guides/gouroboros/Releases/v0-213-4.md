## v0.213.4

**Title:** Align Conway and ledger CBOR encoding and bound diagnostic output

**Version:** v0.213.4

This release aligns consensus-critical Conway and ledger CBOR encodings with Cardano, bounds diagnostic output, and improves reproducibility for tooling and integration tests.

### New Features

* Added bounded diagnostic rendering through `DiagnosticOptions.MaxOutputBytes`, a shared output cap for all diagnostic formats, a truncation marker, and linear path lookup.

### Bug Fixes

* Improved Conway and ledger CBOR compatibility by aligning ledger ordering, supporting indefinite-length maps and sets above 23 and tag-258 sets, omitting empty voting procedures, encoding Conway treasury values as unsigned, and updating validation.

* Stabilized tooling and integration tests by pinning `nilaway` and `benchstat` in `tools/go.mod`, invoking them with `go tool -modfile=tools/go.mod`, pinning Cardano node images by digest, and fixing checkout and tool resolution for comment-triggered benchmark runs.
