## v0.207.3

**Title:** Improve era validation, network protocol handling, and transaction compatibility

**Version:** v0.207.3

This release strengthens protocol decoding and encoding, transaction validation, era compatibility, and shutdown behavior across the Byron, Alonzo, Babbage, Conway, and Dijkstra eras.

### Bug Fixes
* Improved LeiosNotify vote offer handling by limiting each message to 1,000 votes and 256 KiB, rejecting malformed or trailing CBOR, and documenting these limits.
* Refined minimum UTxO calculation for Babbage, Conway, and Dijkstra by measuring preserved wire CBOR and aligning Alonzo empty policy sizing.
* Aligned Byron PBFT admission, genesis delegation, historical Ed25519 behavior, transaction wire and identity values, and witness validation with protocol rules.
* Verified TPraos nonce VRFs and changed operation certificate extraction to report errors for nil or unsupported headers.
