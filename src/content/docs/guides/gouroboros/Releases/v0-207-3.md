## v0.207.3

**Title:** Improve era validation, network protocol handling, and transaction compatibility

**Version:** v0.207.3

This release strengthens protocol decoding and encoding, transaction validation, era compatibility, and shutdown behavior across the Byron, Alonzo, Babbage, Conway, and Dijkstra eras.

### Bug Fixes
* Improved LeiosNotify vote offer handling by limiting each message to 1,000 votes and 256 KiB, rejecting malformed or trailing CBOR, and documenting these limits.
* Refined minimum UTxO calculation for Babbage, Conway, and Dijkstra by measuring preserved wire CBOR and aligning Alonzo empty policy sizing.
* Aligned Byron PBFT admission, genesis delegation, historical Ed25519 behavior, transaction wire and identity values, and witness validation with protocol rules.
* Verified TPraos nonce VRFs and changed operation certificate extraction to report errors for nil or unsupported headers.
* Strengthened Plutus context and UTXOW validation for Byron outputs, datum and redeemer rules, collateral, forecast handling, Dijkstra subtransaction indexes, and execution unit decoding.
* Enforced reliable shutdown by joining ChainSync operations, propagating connection shutdown to LeiosVotes callbacks, and preventing duplicate BlockFetch completion.
* Corrected Byron historical canonical JSON escaping and stopped JSON parsing after the first complete value instead of waiting for EOF.
* Rejected Dijkstra genesis-only Leios update fields without partially applying an update while retaining on-ledger keys 43 and 44.
* Preserved ordered and duplicate `invalid_transactions` behavior where required, rejected out-of-range auxiliary-data indexes, and retained legacy Dijkstra duplicate rejection.
* Validated Conway and Dijkstra parameter update domains, nullability, integer widths, bounded ratios, cost model language IDs, `MaxPledgeLeverage` tri-state values, and PV12 security group classification.
* Added Dijkstra golden coverage to verify encoding and decoding behavior without changing runtime behavior.
* Checked Conway and Dijkstra committee transitions, applied PV10 action restrictions, added PV11+ checks for unelected voters, and required the optional `CommitteeVotingState` capability.
