## v0.189.4 (July 25, 2026)

**Title:** Improve Leios certificate compatibility and stake address query support

**Date:** July 25, 2026

**Version:** v0.189.4

This release updates the release history, expands PoolRegistrationCertificate compatibility for Leios layouts, and adds stake address query support in LocalStateQuery.

### 💪 Improvements

* Improved **PoolRegistrationCertificate compatibility:** the certificate now accepts both the legacy 10-field and extended 11-field CBOR layouts, validates `LeiosKey` values with strict byte-length checks, and preserves original CBOR bytes for round trips.

* Fixed **stake address info queries:** LocalStateQuery now recognizes query type `22`, exposes `Client.GetStakeDelegDeposits`, decodes single-item CBOR wrappers correctly, uses the expected `ShelleyGetProposalsQuery` wire shape, and marshals `DRep` values consistently.

* Updated **release history:** v0.189.3 now appears at the top of the latest release list.

Thank you for following gOuroboros releases.
