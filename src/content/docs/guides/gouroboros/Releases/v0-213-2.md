## v0.213.2

**Title:** Improve ledger validation and runtime reliability

**Version:** v0.213.2

This release improves ledger size accounting and phase two validation across supported eras, makes network shutdown and callback handling more reliable, clarifies DMQ expiry checks, and tightens CBOR identifier decoding.

### Bug Fixes

* Refined ledger output value measurement to count indefinite map headers in Mary, Alonzo, Babbage, Conway, and Dijkstra, keeping value size checks aligned across supported eras.

* Stabilized muxer lifecycle handling by stopping the read loop after read deadline failures, containing panics from Metrics and EgressMetrics callbacks, preserving queue depth order, and preventing new shutdown registrations after shutdown begins.

* Limited `cbor.DecodeIdFromList` to the array header and first item while retaining the errors that identify malformed input.

* Normalized DMQ configuration so TTL validation runs by default; an explicitly supplied no-op validator remains the opt-out, and expired entries now receive clearer rejection errors.

* Restored pipeline race coverage with a matching Shelley block fixture, ensuring the test exercises the intended block processing path.

* Aligned phase two validation with ledger reference behavior by rejecting non-unit Plutus V3 and V4 results, accepting Byron bootstrap collateral witnesses, applying Conway and Dijkstra committee governance rules, and handling hard fork purpose roots correctly.
