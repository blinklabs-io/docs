## v0.213.2

**Title:** Improve ledger validation and runtime reliability

**Version:** v0.213.2

This release improves ledger size accounting and phase two validation across supported eras, makes network shutdown and callback handling more reliable, clarifies DMQ expiry checks, and tightens CBOR identifier decoding.

### Bug Fixes

* Refined ledger output value size measurement to count indefinite map headers in Mary, Alonzo, Babbage, Conway, and Dijkstra, so value size checks stay aligned across supported eras.

* Stabilized muxer lifecycle handling by stopping the read loop when read deadline failures occur, containing panics from Metrics and EgressMetrics callbacks, preserving queue depth order, and blocking shutdown registrations once shutdown begins.

* Limited `cbor.DecodeIdFromList` to the array header and first item while preserving the errors that identify malformed input.

* Normalized DMQ configuration so TTL validation runs by default unless an explicit no-op validator is supplied, and expired entries now return clearer rejection errors.

* Restored pipeline race coverage with a matching Shelley block fixture, so the test exercises the intended block processing path.

* Aligned phase two validation with ledger reference behavior by rejecting non-unit Plutus V3 and V4 results, accepting Byron bootstrap collateral witnesses, applying Conway and Dijkstra committee governance rules, and handling hard fork purpose roots correctly.
