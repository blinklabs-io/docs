## v0.213.2

**Title:** Improve ledger validation and runtime reliability

**Version:** v0.213.2

This release improves ledger size accounting and phase two validation across supported eras, makes network shutdown and callback handling more reliable, clarifies DMQ expiry checks, and tightens CBOR identifier decoding.
