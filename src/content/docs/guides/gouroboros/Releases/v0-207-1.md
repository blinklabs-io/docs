## v0.207.1

**Title:** Fix ledger vote parsing and DRep registration validation

**Version:** v0.207.1

This release corrects Byron update vote handling and Conway DRep certificate validation.

### Bug Fixes
* Fixed Byron update vote processing to accept both CBOR `false` and `true` decision bytes, reject nonboolean encodings, store the decision as `true`, and verify signatures against CBOR `true`; mismatched signatures continue to return `ErrInvalidSignature`.
* Enforced Conway DRep registration requirements by accepting an `UpdateDrepCertificate` only when the DRep is actively registered at that certificate's position. A later registration in the same transaction no longer qualifies, while updates for already registered DReps remain accepted and invalid updates return `DRepNotRegisteredError`.
