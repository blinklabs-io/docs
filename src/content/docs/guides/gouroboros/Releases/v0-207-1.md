## v0.207.1

**Title:** Fix ledger vote parsing and DRep registration validation

**Version:** v0.207.1

This release corrects Byron update vote handling and Conway DRep certificate validation.

### Bug Fixes
* Fixed Byron update vote handling by accepting CBOR `false` and `true` decision bytes, rejecting nonboolean encodings, storing every accepted decision as `true`, and verifying signatures against CBOR `true`; mismatched signatures still return `ErrInvalidSignature`.
* Enforced Conway DRep registration requirements by accepting an `UpdateDrepCertificate` only when the referenced DRep is actively registered in the transaction-local sequential state at the certificate's validation position. A registration later in the same transaction no longer qualifies, while updates for already registered DReps remain accepted and missing registration returns `DRepNotRegisteredError`.
