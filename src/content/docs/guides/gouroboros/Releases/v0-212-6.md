## v0.212.6

**Title:** Improve ledger decoding and dependency reliability

**Version:** v0.212.6

This release aligns bootstrap witness validation with network eras and updates cryptographic and CBOR libraries to incorporate upstream corrections and stricter decoding behavior.

### Breaking Changes

* Improved bootstrap witness decoding so the 32-byte chain code requirement applies according to the network era. Dijkstra transactions now reject 31-byte and 33-byte chain codes with `bootstrap witness chain code must be 32 bytes`, while public keys remain 32 bytes and signatures remain 64 bytes. This keeps transaction decoding and consensus behavior aligned.

### Additional Changes

* Updated `github.com/consensys/gnark-crypto` from `0.21.0` to `0.22.0`, along with `bitset` and the Go version directive from `1.26.5` to `1.26.8`. The update includes upstream cryptographic parameter and generator corrections, artifact compatibility changes, and validation and security fixes.

* Refined `github.com/fxamacker/cbor/v2` from `2.9.4` to `2.9.6` in `go.mod` and `go.sum`. The update clears stale Go map entries for CBOR null keys and values, sets interfaces to `nil` for CBOR null and undefined values, and can surface stricter decoding errors.
