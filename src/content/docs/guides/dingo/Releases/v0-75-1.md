## v0.75.1

**Title:** Improve evaluation performance and operational resilience

**Date:** 2026-10-01

**Version:** v0.75.1

**Release:** [v0.75.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.75.1)

Dingo v0.75.1 improves shared Plutus evaluation performance, startup replay resilience, catch-up metrics, and database availability during concurrent reads.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Evaluation and startup improvements

* Improved shared Plutus evaluation by reusing compiled CEK machines across compatible evaluation contexts. ExUnits remain stable while repeated evaluation performs fewer allocations.

* Prevented startup replay from dereferencing unavailable networking state. Endorser block processing now reports that networking is unavailable and retries until networking starts.

### Monitoring and database improvements

* Updated tip gap and epoch length gauges during catch-up when the node is behind the available horizon. Readiness behavior remains unchanged while operators receive current synchronization metrics.

* Reduced SQLite writer stalls during WAL checkpointing by allowing readers to finish before truncation and retrying truncation later when needed. This preserves database availability during concurrent reads.
