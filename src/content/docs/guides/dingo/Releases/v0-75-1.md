## v0.75.1

**Title:** Improve evaluation efficiency and operational resilience

**Date:** 2026-10-01

**Version:** v0.75.1

**Release:** [v0.75.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.75.1)

Dingo v0.75.1 brings more efficient shared Plutus evaluation, more resilient startup replay, current catch-up metrics, and fewer database write interruptions during concurrent reads.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Evaluation and startup improvements

* Improved shared Plutus evaluation by reusing pooled CEK machines across compatible evaluation contexts. ExUnits remain stable, and repeated evaluations use fewer allocations.

* Protected startup replay from unavailable networking state. Endorser block processing reports networking unavailability and retries until networking starts.

### Monitoring and database improvements

* Updated tip gap and epoch length gauges as the node catches up from behind the available horizon. Readiness behavior remains unchanged, and operators receive current synchronization metrics.

* Reduced SQLite writer stalls during WAL checkpointing by using a nonblocking checkpoint connection, checking whether readers allow truncation, and retrying truncation later when needed. Concurrent reads no longer hold the writer indefinitely.
