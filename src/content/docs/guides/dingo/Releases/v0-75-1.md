## v0.75.1

**Title:** Improve Plutus evaluation and node resilience

**Date:** 2026-10-01

**Version:** v0.75.1

**Release:** [v0.75.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.75.1)

Dingo v0.75.1 improves shared Plutus evaluation efficiency, startup replay resilience, catch-up monitoring, and database availability during concurrent reads.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Evaluation and startup improvements

* Improved shared Plutus evaluation by reusing pooled CEK machines across compatible evaluation contexts. ExUnits remain stable, and repeated evaluations use fewer allocations.

* Prevented startup replay from accessing unavailable networking state. Endorser block processing now reports that networking is unavailable and retries until networking starts.

### Monitoring and database improvements

* Updated tip gap and epoch length gauges while the node catches up from behind the available horizon. Readiness behavior remains unchanged, and operators receive current synchronization metrics.

* Reduced SQLite writer stalls during WAL checkpointing by giving readers time to finish before truncation and retrying truncation when readers still prevent it. Database availability continues during concurrent reads.
