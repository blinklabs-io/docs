## v0.79.0

**Title:** Improve API access, synchronization, state queries, and ledger validation

**Date:** 2026-10-06

**Version:** v0.79.0

**Release:** [v0.79.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.79.0)

Dingo v0.79.0 improves paginated API access, peer selection and recovery, state query isolation, Mithril backfill integrity, parity checks, and ledger validation. It also introduces the Peras package and conformance scaffold.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### API access
* Added paginated transaction retrieval to `GET /api/v0/blocks/latest/txs`. The endpoint validates `count`, `page`, and `order`, returns pagination headers, preserves the requested ordering, and returns an empty page when the requested page falls outside the available results.
