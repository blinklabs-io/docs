## v0.79.0

**Title:** Improve API access, synchronization, state queries, and ledger validation

**Date:** 2026-10-06

**Version:** v0.79.0

**Release:** [v0.79.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.79.0)

Dingo v0.79.0 improves paginated API access, peer selection and recovery, state query isolation, Mithril backfill integrity, parity checks, and ledger validation. It also introduces the Peras package and conformance scaffold.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### API access
* Added page by page transaction retrieval to `GET /api/v0/blocks/latest/txs`. The endpoint checks `count`, `page`, and `order`, returns pagination headers, preserves the requested ordering, and returns an empty page when a request falls outside the available results.

### Synchronization and peer governance
* Improved ChainSync and peer governance by measuring blockfetch peer performance, prioritizing configured roots, backing off stalled peers, recovering after a resynchronization, and cooling down inbound connections by host.

### State queries
* Isolated LocalStateQuery sessions with snapshots, a configurable maximum session lifetime, and explicit errors when a required dependency is unavailable.

### Mithril recovery
* Hardened Mithril backfills by correcting anchor selection, enforcing archive and proof checks, applying configurable download limits, and rejecting invalid artifacts.

### Peras
* Introduced the Peras package and conformance scaffold.

### Parity checks
* Enhanced `koios-parity` retries and significant mismatch reporting so transient failures receive additional attempts and material differences become visible.

### Ledger validation
* Corrected ledger validation for era-specific rules, fee and deposit accounting, malformed hashes, Byron replay behavior, and overflow handling.
