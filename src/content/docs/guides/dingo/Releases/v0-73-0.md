## v0.73.0

**Title:** Improve validation, recovery, and node resilience

**Date:** 2026-09-25

**Version:** v0.73.0

**Release:** [v0.73.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.0)

Dingo provides a Cardano blockchain node and API surface for direct use, and a Go library documented through [`go doc`](https://pkg.go.dev/cmd/go#hdr-Show_documentation_for_package_or_symbol) and [pkg.go.dev](https://pkg.go.dev/github.com/blinklabs-io/dingo). This release improves ledger and governance validation, protects synchronization and recovery workflows, and adds clearer controls for node operations.

### Validation and governance improvements

* Improved invalid and empty input handling with NilAway safeguards, so Dingo fails safely instead of dereferencing missing values. ([Change details](https://github.com/blinklabs-io/dingo/pull/4707))

* Strengthened sequential Conway committee certificate validation, preventing a transaction from repeating a resignation or resigning and then authorizing the same member. ([Change details](https://github.com/blinklabs-io/dingo/pull/4711))

* Stabilized node parity reconnect tests with gated listeners, improving confidence in reconnect behavior. ([Change details](https://github.com/blinklabs-io/dingo/pull/4693))

* Aligned Byron transaction and end of bootstrap block validation with cardano-ledger behavior, including serialized size and unknown attribute limits, positional witnesses, repeated input set semantics, fee and Lovelace bounds, canonical address roots, end of bootstrap block ordering, and deterministic replay recovery. ([Change details](https://github.com/blinklabs-io/dingo/pull/4710))

* Prevented Conway and Dijkstra parameter changes from accepting protocol version key `14`, and removed that key during enactment. ([Change details](https://github.com/blinklabs-io/dingo/pull/4699))
