## v0.79.1

**Title:** Improve ledger correctness, state queries, installation, and operational resilience

**Date:** 2026-10-07

**Version:** v0.79.1

**Release:** [v0.79.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.79.1)

Dingo v0.79.1 improves ledger validation, historical state queries, network peer selection, database recovery, Mithril imports, and release installation. It also strengthens API error responses, governance integrity checks, and operational observability.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Metadata and interoperability
* Strengthened metadata decoding consistency across CBOR key orders, preserving reliable Blockfrost pagination and raw-CBOR or JSON-unavailable behavior.
* Expanded validation for deeply nested PlutusData round trips through CBOR mapping and protobuf binary and JSON representations.
* Improved MCP schema discovery by enforcing a five-second minimum startup timeout, while expanding coverage for deeply nested Conway redeemer persistence.

### Ledger and state queries
* Corrected Dijkstra transaction validation so governance, certificate, and entity rules apply only to declared-valid transactions while structural and collateral checks continue to apply to declared-invalid transactions.
* Updated Dijkstra reward and stake reconstruction, prototype closure context, genesis pool deposit recording, and reward stake calculation version 3. Existing databases with stale computed state require replay or a trusted ledger-state import.

### Installation
* Introduced platform-native release installation for `@blinklabs/dingo` with SHA-256 verification, atomic installation, Node wrapper argument, signal, and exit forwarding, a Node `>=22` requirement, supported OS and CPU metadata, and npm publishing support.

### Database operations
* Reduced SQLite writer contention during Mithril bulk imports by serializing metadata-writing phases and suppressing or retrying scheduled checkpoints.
