## v0.70.5

**Title:** Improve governance, synchronization, and node reliability

**Date:** Not provided

**Version:** v0.70.5

**Release:** [v0.70.5](https://github.com/blinklabs-io/dingo/releases/tag/v0.70.5)

This release improves governance data accuracy, event handling, synchronization safety, network request handling, and Koios based account updates for Dingo nodes and library consumers.

### ✨ Highlights

* Improved committee credential handling so ledger validation, governance resolution, certificate state imports, and SQL metadata preserve credential tags and explicit membership terms. Required metadata migrations now keep tagged committee certificates and voters resolvable.

* Added strict event subscriptions that expose rollback handler and evaluation panics as events, while selector recovery prevents a panic from leaving subscriptions deadlocked.

* Corrected minted block counts by excluding operational certificate counters imported from Mithril, and reports malformed Mithril boundaries clearly instead of accepting invalid limits.

* Strengthened Leios fetch safety by checking response bitmap size and range before expansion, rejecting oversized or out of range responses without processing them.
