## v0.93.0

**Title:** Improve storage efficiency, signing operations, chain selection, and test reliability

**Version:** v0.93.0

**Release:** [v0.93.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.93.0)

**Comparison:** [v0.92.4...v0.93.0](https://github.com/blinklabs-io/dingo/compare/v0.92.4...v0.93.0)

Dingo v0.93.0 reduces database write churn, expands remote signing operations, improves pagination and chain selection, and strengthens time conversion, era handling, credential management, and validation workflows.

### Recommended Network Compatibility ⚠️

| preview-testnet     | ✅         |
| musashi             | ✅         |

#### Database and storage
* Improved SQLite stake and reward index updates with migration v59, narrower live stake and certificate upserts, prepared statements for changed columns, and overlay keep pool updates. These changes reduce unnecessary database writes during ledger processing.

#### Remote signing
* Added remote Bursa KES agent signing with selectable TLS or plain transport. Nonce bound admission, session reuse, signature validation, resend handling, preconnection, and configuration validation make remote signing more reliable while keeping transport choices explicit for operators.

#### Governance and pagination
* Streamlined non empty DRep pagination by deriving the total count with each returned page, allowing delegation aggregation to run once. The node keeps a separate count query only for pages outside the available range.

#### Chain selection
* Anchored observed chain selection frontiers at chainsync session intersections with parent and boundary safeguards, improving decisions at synchronization boundaries.
