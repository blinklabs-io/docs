## v0.78.0

**Title:** Expand API access and strengthen node reliability

**Date:** 2026-10-04

**Version:** v0.78.0

**Release:** [v0.78.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.78.0)

Dingo v0.78.0 expands opt-in API access, makes node shutdown and provider cleanup more predictable, corrects Conway and Mithril-anchored accounting, and strengthens deferred header verification and peer resynchronization.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### API access
* Added an opt-in Model Context Protocol (MCP) API plugin with Streamable HTTP at `/mcp` and SSE at `/sse`. Dingo exposes health checks at `/health` and `/healthz`, while read-only SQLite and Cardano tools and resumable UTxO queries support safer data access. Authentication, rate limiting, and origin validation protect requests, and non-loopback bindings require authentication and TLS.

### Node lifecycle and interface changes
* Improved node teardown with context-bounded shutdown, deterministic connection completion, bounded EventBus shutdown with reports for stuck handlers, coordinated provider cleanup, and metric registration that rolls back without panics when registration fails. Mempool completion channels now use `<-chan struct{}` instead of `<-chan error`, so consumers must update the channel type they handle.

### Ledger and governance corrections
* Corrected Conway snapshot classification for DState and DRep records, renamed `GetCommitteeActiveCount` to `GetCommitteeAuthorizedCount`, and fixed Mithril-anchored reward and API block counts. Genesis delegation now applies only after the Shelley stability window, and validation rejects duplicate and invalid delegations.

### Header verification and synchronization
* Hardened deferred header handling by fully verifying each header before changing the ledger, capping and persisting deferred markers, and rejecting oversized headers during verification. Resynchronization now records peer-specific attribution, and replay skips redundant cryptographic work only when both the slot and hash match exactly.
