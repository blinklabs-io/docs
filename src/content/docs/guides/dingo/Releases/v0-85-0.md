## v0.85.0

**Title:** Improve synchronization, APIs, storage, and operational reliability

**Version:** v0.85.0

**Release:** [v0.85.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.85.0)

Dingo v0.85.0 improves chain recovery, Blockfrost coverage, ledger persistence, resource admission, conformance tooling, and operational reliability.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Synchronization and ledger state
* Improved peer selection by withholding deferred producer authorization headers from chain selection and canonical rollback, then retrying those peers after ledger advancement.
* Extended operational certificate counter storage across the full `uint64` range with SQL migration v49 and encoding that preserves order.
* Tightened Midnight registration validation by requiring `authTokenPolicyId` and `authTokenAssetName` together, matching the exact policy and asset name pair, and rebuilding registration state after policy changes.
* Expanded Blockfrost history with epoch, account, pool, and governance queries, deterministic `404` responses when Dingo does not retain data, and complete governance vote history.

### Storage and resource management
* Tracked retained Leios cache allocations and improved shutdown and cleanup error reporting.
* Streamlined deferred SQLite UTxO imports by batching them without changing the inputs callers provide.
* Reduced Core Mithril storage work by skipping unused UTxO offset writes until a later API backfill.
* Isolated transaction evaluation admission with global and per host limits, while separating Mithril signature admission.
* Broadened UPLC Turbo report coverage, used corpus inputs tied to each shard, increased defaults and timeouts, and updated conformance tooling.
* Eliminated a database test cleanup race for more dependable test execution.
* Stabilized Badger and DMQ tests and surfaced selected cleanup errors.
* Batched Linux race tests and skipped selected expensive tests during race runs.

### APIs and integrations
* Added Blockfrost wallet and dApp query operations with API migrations v45 and v46.
* Updated the `plutigo` integration to v0.9.7.

### Security and operations
* Protected credentials by redacting secrets from container startup logs, including logs emitted with `DINGO_DEBUG` enabled.
* Aligned conformance reports with the pinned corpora that each test uses for consistent results.
* Configured Core synchronization to use a 1 KiB Badger threshold, honored an explicit `valueThreshold: 0`, and documented the behavior.
