## v0.87.0

**Title:** Improve resource safety, networking, and consensus compatibility

**Version:** v0.87.0

**Release:** [v0.87.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.87.0)

**Comparison:** [v0.86.0...v0.87.0](https://github.com/blinklabs-io/dingo/compare/v0.86.0...v0.87.0)

Dingo v0.87.0 improves resource controls, peer networking, synchronization safety, API behavior, configuration security, and consensus compatibility.

### Breaking changes
* Limited UTxO RPC `FollowTip` historical replay with process and per client concurrency limits, pacing, and history budgets. The service now returns `ResourceExhausted` when a configured limit is reached.
* Added DMQ peer listener, topology, and minimum and maximum peer settings through YAML, environment variables, and CLI options. Dingo validates these settings before startup.
* Returned retriable HTTP `503` from Mesh mempool listings when a pool exceeds its configured capacity instead of returning an incomplete prefix; listings now return transaction hashes only and enforce bounded concurrency.
* Changed Blockfrost address summaries to honor cancellation, limit enrichment, and return HTTP `400` for over budget requests or HTTP `429` when capacity is unavailable.
* Bound generated devnet APIs to loopback and blocked state, key, and file operations from following symlink redirection.
