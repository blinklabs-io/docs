## v0.87.0

**Title:** Improve resource safety, networking, and consensus compatibility

**Version:** v0.87.0

**Release:** [v0.87.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.87.0)

**Comparison:** [v0.86.0...v0.87.0](https://github.com/blinklabs-io/dingo/compare/v0.86.0...v0.87.0)

Dingo v0.87.0 improves resource controls, peer networking, synchronization safety, API behavior, configuration security, and consensus compatibility.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Breaking changes
* Limited UTxO RPC `FollowTip` historical replay with process and per-client concurrency limits, pacing, and history budgets. The service now returns `ResourceExhausted` when demand reaches a configured limit.
* Added DMQ peer listener, topology, and minimum and maximum peer settings through YAML, environment variables, and CLI options. Dingo validates these settings before startup.
* Returned retriable HTTP `503` from Mesh mempool listings when a pool exceeds its configured capacity instead of returning an incomplete prefix; listings now return transaction hashes only and enforce bounded concurrency.
* Changed Blockfrost address summaries to honor cancellation, limit enrichment, and return HTTP `400` when requests exceed their budget or HTTP `429` when demand reaches capacity.
* Bound generated devnet APIs to loopback and blocked state, key, and file operations from following symlink redirection.

### Security and reliability
* Authenticated token registry archive size and digest before Dingo parses gzip and tar contents.
* Validated local ImmutableDB block body hashes before importing blocks.
* Restricted decompressed Mithril tar stream consumption and honored cancellation during processing.
* Refused MCP reads while the metadata SQLite write-ahead log exceeded `128 MiB`, then resumed reads after recovery.
* Normalized Leios announcement headers for deduplication and semantic validation while preserving the bytes used for relay.

### APIs, synchronization, and integrations
* Updated `google.golang.org/api` to `v0.304.0` and refreshed related dependencies.
* Corrected future epoch genesis overlay parameter forecasting during from-genesis synchronization.
* Required one Byron witness for every transaction input.
* Refreshed the AWS SDK configuration and related modules.
* Expanded Bark `ArchiveService` with configurable global and per-caller lookup budgets; the service returns `RESOURCE_EXHAUSTED` before a cloud lookup would exceed a budget.

### Storage, consensus, and security
* Rebuilt SQLite and PostgreSQL UTXO spender indexes as non-null partial indexes while leaving MySQL unchanged.
* Introduced a selectable consensus provider with Praos as the default, persisted the provider identity, and rejected schedules that do not match that identity.
* Moved ledger waits outside locks and bounded deferred header verification with revalidation when Dingo applies the header.
* Pinned Go to `1.26.10` for the `crypto/x509` security fix.
* Verified competing fork headers with fork-derived candidate nonces and withheld unauthenticated ancestry without recycling peers.

### Additional changes
* Updated the Go build image to `ghcr.io/blinklabs-io/go:1.27.3-1`, refreshed runtime images and Debian snapshot pins, and updated the devnet and ERA `cardano-node` pins.
* Corrected `GetPoolDistr2` and `GetStakeDistribution2` CBOR tag `24` encoding to use the bare `PoolDistr` layout; decoders must use that layout for these responses.
* Added file-backed secret values through `_FILE` CLI and environment inputs, with validation, precedence, and conflict rules for Koios and node parity inputs; invalid or conflicting configuration now fails closed.
* Queued deferred headers that extend the local chain and waited for unapplied local work before admitting blocks within the forecast horizon.
* Waited for unapplied ancestors before forged block self-validation and dropped unjudged blocks when Dingo could not reach the parent.
* Improved ChainSync, LocalStateQuery, and `GetUTxOWhole` availability under synchronization load. `GetUTxOWhole` now returns a complete UTxO result through paged as-of reads, rollback retries, and snapshot detach and reattach; node-to-client roll-forwards wait for ledger application, tip snapshots defer during epoch boundary work, and chain selection records refused advertised tips for corroboration.
* Resynchronized without penalizing peers when forecast horizon admission finds no local work to process.
* Authenticated local Bark snapshot manifests with the configured trust key, used an authenticated cloud mirror when needed, and failed closed when neither source passed verification.
* Preserved Alonzo `extraConfig` cost models across Conway and Dijkstra, refreshed Musashi `rc-2026w42` configurations, enabled node-managed Mithril v2 synchronization through `mithril.enabled`, applied Dijkstra `block_transaction` and `is_valid` handling to Leios, optimized rollback stake lookup, and refreshed gouroboros integration.
* Sanitized tracing endpoint errors by removing credentials from userinfo, query, and fragment components.
* Added regression coverage for DRep pending deregistration so the node preserves correct registration state during that transition.
* Exposed validated certified Leios endorser block transactions consistently through Blockfrost and UTxO RPC, returning validation errors for missing or inconsistent data and honoring context cancellation.
* Hardened node parity from-genesis preprod validation with epoch oracle lookup, session and reconnect handling, retries, LocalStateQuery ingress backpressure, a single-message ChainSync pipeline, and Koios timeouts.
* Removed Mithril v1 backend support, rejected v1 configuration and pins, made bootstrap v2 only, and failed closed when verified ancillary state or digests were missing.
* Redacted credentials from remote ImmutableDB load URLs in query strings, fragments, userinfo, wrapped errors, and `errors.As` results.
* Validated DMQ topology JSON at startup, logged distinct peers, warned when no peers were configured, and warned while ignoring unsupported fields.
* Ignored unverified advertised fork heights when breaking chain-selection ties.
* Expanded bounded stale-reference corroboration to include peer references ahead of the local tip within twice the security parameter.
* Enabled ledger signature validation ahead by default and added `ledgerValidateAheadEnabled` control through YAML, environment variables, and CLI options.
* Moved downstream Homebrew, Ansible, cardano-up, and Helm consumer updates from `publish.yml` to `release-fanout` so release propagation follows the dedicated fanout workflow.
* Bounded MCP `get_mempool_info` with a default limit of `10`, a maximum of `50`, and retained-byte accounting.
* Honored Cardano `ConsensusMode` `PraosMode` by disabling Genesis chain selection for Musashi.
* Prevented same-block batched live stake from being counted more than once.
* Constrained LeiosVotes `RequestNext` values to the inclusive range `1` through `1000`.
* Introduced bounded and cancellable Mesh `/account/coins` reads with optional cursor pagination. Unpaged incomplete results now return HTTP `400`, while concurrency exhaustion returns HTTP `503`.
* Corrected Byron version-triggered boundary handling so it cannot skip Shelley.
* Limited MCP `get_asset_info` scans to `50,000` rows and shared a four-slot read budget across requests.
