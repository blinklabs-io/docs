## v0.73.3

**Title:** Improve dashboard health, governance boundaries, and block monitoring

**Date:** 2026-09-27

**Version:** v0.73.3

**Release:** [v0.73.3](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.3)

This release improves dashboard health visibility, Conway governance boundary handling, and recent block delay monitoring.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |

| musashi             | ✅         |

### Dashboard, governance, and monitoring improvements

* Improved [dashboard health status](https://github.com/blinklabs-io/dingo/pull/4744) by basing sync classifications on tip gap and recent slot advance rate, evaluating status across the selected time range, and showing `UNKNOWN` when metrics are unavailable. The dashboard skips startup samples and preserves earlier status signals in tooltips, reducing false `SYNCED` and `STALLED` states during genesis sync.

* Corrected [Conway governance expiry handling](https://github.com/blinklabs-io/dingo/pull/4676) so ratification runs at the final epoch boundary before expiration, already ratified proposals remain excluded from expiry processing, DReps remain active through the expiry epoch, and descendant and orphan handling uses the correct prior epoch proposal set.

* Added [recent block delay metrics](https://github.com/blinklabs-io/dingo/pull/4742) for the last 16 blocks at the chain tip. The history keeps each delay paired with its block number and ignores empty, repeated, or out of order deliveries, so operators can chart delay spikes without mismatched data.

* Refined [Grafana dashboards](https://github.com/blinklabs-io/dingo/pull/4740) with corrected metric queries, units, legends, filters, and alert thresholds. The dashboards now include forge gap and recent blockfetch views, a 20-signal status strip, worst state aggregation across selected instances, and links that preserve the selected time range and instance.
