## v0.77.1

**Title:** Improve storage, synchronization, Mithril recovery, and Dijkstra support

**Date:** 2026-10-03

**Version:** v0.77.1

**Release:** [v0.77.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.77.1)

Dingo v0.77.1 improves SQLite recovery space management, blockfetch delivery, Mithril state repair, Dijkstra script fee calculation, reward-credit queries, and network data validation. It also updates `gouroboros` to v0.209.0 and expands regression coverage for Dijkstra and Conway behavior.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Storage and data handling
* Limited retained SQLite write-ahead log space to 64 MiB after a reset, while active writes and readers can exceed that limit and idle truncation can reduce the log to zero.

* Aligned Byron balance, fee subtraction, and created-UTxO metrics with outputs 0 through 65,535 in the `Produced()` view while continuing to validate later outputs, and updated `gouroboros` to v0.209.0.

### Synchronization and recovery
* Streamlined blockfetch ledger publishing with bounded per-connection FIFO forwarding that preserves order and reports overflow, backpressure, and keep-alive timeout metrics.

* Repaired legacy Mithril reward state when the certified tip is an ancestor of the local tip by preserving verified tail blocks, rebuilding derived metadata, and refusing states older than the stable anchor.
