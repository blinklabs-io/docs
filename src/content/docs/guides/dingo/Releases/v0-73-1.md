## v0.73.1

**Title:** Improve transaction safety, reward accounting, and protocol validation

**Date:** 2026-09-25

**Version:** v0.73.1

**Release:** [v0.73.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.1)

This release compares with v0.73.0 and improves transaction decoding safety, reward accounting for Mithril snapshots, and validation across supported protocol eras.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Stability, accounting, and validation improvements

* Improved transaction safety across Blockfrost, Mesh, UTxO RPC, mempool, and Ouroboros transaction submission. Dingo now treats malformed or malicious transaction bytes as decode errors rather than allowing them to crash the node, and rejects an entire transaction submission reply when its decoding panics.

* Corrected reward pots for Mithril snapshots anchored mid epoch by including imported pre-anchor fees in reward accounting. Dingo repairs legacy imported databases during Mithril reconciliation before serving them, preventing reward and withdrawal values from diverging.

* Updated protocol validation with gouroboros `v0.207.5`. Dingo now supports classic PPUP and MIR state rules, PV11 Plutus V3 reference input disjointness checks, Dijkstra subtransaction committee and voter validation, protocol major aware script contexts, and correct conformance DRep deposits.
