## v0.73.4

**Title:** Improve protocol compatibility, resilience, and operational safety

**Date:** 2026-09-28

**Version:** v0.73.4

**Release:** [v0.73.4](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.4)

This release improves protocol compatibility, validation, storage efficiency, network safety, and operational resilience across the Dingo node and its examples.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Protocol and consensus improvements

* Updated protocol support for shared committee hot key authorization, Leios backfill failover, correct Bark archive era handling, and MIR quorum coverage.

* Added Dijkstra Leios committee selection with key age filtering, semantic endorser block validation, certificate checks, and prompt vote cancellation.

* Improved database and chain synchronization by making SQLite `VACUUM` opt in, releasing ChainSync locks during deferred persistence, using prepared UTxO lookups, and expanding metrics.

* Deferred S3 and GCS blob listings until the first read while preserving bounded seek behavior.

* Aligned classic protocol parameter update windows and quorum selection with the reference behavior, including storage for epoch 0 proposals.

* Enforced zero baselines for the first operational certificate and stopped safely after incomplete Mithril restores.

* Corrected Byron initialization to accept empty genesis setup while rejecting Byron era regressions and typed nil headers.

* Refined Conway Plutus context and cost model behavior to match the reference behavior.

* Blocked private and special use Koios destinations by default, with an explicit opt in for deployments that require them.

### Dependency and example updates

* Refreshed database telemetry integration so current database instrumentation remains available.

* Upgraded the SQLite driver dependency to the current `modernc.org/sqlite` release.

* Modernized the Blockfrost example's Node.js type definitions.

* Revised the Sundae example's Node.js type definitions.

* Expanded SundaeSwap core and math support for v4 stableswap quoting.

* Preserved required EventBus subscribers as back pressure builds, keeping required event consumers available.

* Accelerated the Blockfrost example's development tooling with the current Vite release.

* Introduced the current Vite release in the Sundae example's development tooling.

* Expanded the documentation with dedicated development, DevNet, and benchmark guides, and placed benchmark results alongside the benchmark documentation.

### Reliability and operations

* Scoped Dijkstra reference input overlap checks to executed Plutus contexts.

* Replaced AWS SDK credential modules with their current implementations.

* Strengthened forging recovery with improved retry handling and an empty block fallback.

* Restored Conway committee voting and state enforcement to the required protocol rules.

* Registered block producer cleanup before startup can fail, preserving cleanup during early startup errors.

* Applied the canonical Byron clock skew tolerance.

* Bounded Leios endorser block transaction selection by the slot deadline.

* Stabilized token registry snapshot synchronization by applying each snapshot atomically.

* Safeguarded ChainManager metric reuse so the node avoids conflicting registrations.

* Shifted reward crediting away from the epoch boundary and added resumable precomputation with metrics.

* Simplified the README and configuration defaults.
