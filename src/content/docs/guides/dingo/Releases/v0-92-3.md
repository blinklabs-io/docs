## v0.92.3

**Title:** Improve indexing, protocol reliability, and operational controls

**Version:** v0.92.3

**Release:** [v0.92.3](https://github.com/blinklabs-io/dingo/releases/tag/v0.92.3)

**Comparison:** [v0.92.2...v0.92.3](https://github.com/blinklabs-io/dingo/compare/v0.92.2...v0.92.3)

Dingo v0.92.3 improves transaction indexing, protocol validation, Leios delivery, database efficiency, operational controls, and release tooling.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### API, indexing, and data services
* Improved Blockfrost metadata label transaction pagination with an index-friendly query and a schema v58 index. Shared admission limits now govern requests, each page has a 15-second deadline, and overload responses return `429` or `503` with `Retry-After`.
* Added `LedgerState.BlockTransactions` as the source for Midnight transaction indexing, so Leios endorser-block transactions remain indexed through tracking, backfill, rebuild, and rollback.
* Expanded sampled Koios parity checks to compare inputs, collateral and reference inputs, outputs, and validity, with bounded retries and cache support.
* Reduced Genesis staging memory copying and allocation growth by sharing observed-point history between frontiers.
* Optimized SQLite write connections by keeping statement journals in memory with `temp_store=MEMORY`.

#### Protocol and peer reliability
* Preserved header verdict context across rollback when reloaded protocol parameters have equivalent values.
* Validated and bounded Leios offers before recording them, with per-host budgets and per-connection cache and source limits.
* Corrected Byron witness validation to follow zip semantics: validation skips unpaired trailing inputs or witnesses, and empty witness sets validate without a protocol magic lookup.
* Limited cumulative peer rollbacks with a persisted rollback anchor and high water mark.
* Introduced configurable per-pool DMQ message announcement pacing. The default interval is 60 seconds, held messages remain bounded, and CLI, YAML, and environment configuration are available.

#### Storage, delivery, and test reliability
* Reshaped `reward_account_output` indexes in migration v57 to reduce write amplification and updated readers.
* Deferred unread Leios announcement prefetch to notify offers instead of ledger-side by-point prefetch.
* Refined block nonce indexing with slot-leading indexes in migration v56 and updated latest nonce access paths.
* Bounded Leios devnet fork waits by the scenario deadline.
* Synchronized ChainSync test waiting with applied-tip publication to remove a timing race.

#### Validation and operations
* Improved Leios closure handling by avoiding waits for expired missing announcements while retaining validation for complete closures.
* Clarified writable ancestor sticky-bit diagnostics and documented fsGroup sticky bit requirements.
* Configured the trusted local NtC idle timeout: zero disables it, positive values enable it, Dingo rejects negative values, and the default is now no limit instead of two minutes.
* Corrected PBFT delegation and authorization to use network-relative Byron certificate slots.
* Retained header verdicts across tip-only publications and retried expired admission verification up to three times.

#### Dependencies and tooling
* Upgraded `ouroboros-mock` to `v0.21.2`.
* Refreshed `docker/login-action` to `v4.8.0`.
* Updated `google.golang.org/api` to `v0.311.0` and updated related modules.
* Advanced the AWS SDK S3 client to `v1.114.8` and updated companion modules.
