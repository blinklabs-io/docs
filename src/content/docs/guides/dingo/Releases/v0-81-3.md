## v0.81.3

**Title:** Improve peer reliability, conformance, and query recovery

**Version:** v0.81.3

**Release:** [v0.81.3](https://github.com/blinklabs-io/dingo/releases/tag/v0.81.3)

Dingo v0.81.3 improves peer connection handling, Conway conformance reporting, certified block processing, object storage integrations, and local state query recovery.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Peer connectivity
* Improved inbound peer connection stability by tracking flap history per normalized transport identity, adding bounded protection against repeated short sessions, canonicalizing scoped IPv6 addresses into `/64` groups, retaining active cooldowns beyond the observation window, and preventing unrelated NAT peers from sharing cooldowns.

### Conformance and validation
* Added a Conway CBOR conformance command that validates and normalizes CBOR, emits a `cardano-cbor-dataset` shaped JSON report, publishes a dated report with tagged releases, and allows release publishing to require exactly one report. The release also strengthens Byron validation, transaction output index bounds, governance cost model language ID validation, Byron epoch 0 EBB handling, block fetch low watermark configuration, and related validation and recovery behavior.

### Certified block processing
* Corrected certified apply test fixtures by supplying the required VRF and operational certificate data, keeping Leios validation scenarios aligned with certified blocks.

### Storage and observability
* Updated the AWS SDK S3 manager to `v1.23.13`, the S3 service to `v1.114.2`, and related indirect modules, keeping object storage integrations current.

* Enhanced OpenTelemetry Go and the OTLP HTTP trace exporter to `v1.47.0`, including upstream logs modules and an exporter response size option.

### Release automation
* Hardened optional conformance report uploads to handle releases without a report on Bash 3.2.

### Query recovery
* Restored LocalStateQuery continuity by reopening expired views at the acquired point or snapshotted tip, retrying queries, preserving pruning pins, and canceling reopen waits on disconnect. Nonreopenable rollback and pruning cases continue to fail.
