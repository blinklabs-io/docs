## v0.70.14

**Title:** Improve import performance, chain selection resilience, and operational visibility

**Date:** Not provided

**Version:** v0.70.14

**Release:** [v0.70.14](https://github.com/blinklabs-io/dingo/releases/tag/v0.70.14)

This release improves import performance, block and chain handling, ledger and database observability, governance processing, and startup recovery. It also updates protocol compatibility and strengthens test coverage for blockfetch, forging, genesis, socket, and nonce behavior.

### Recommended Network Compatibility ⚠️

| preview-testnet     | ✅         |
| musashi             | ✅         |

### Runtime and operational improvements

* Upgraded `gouroboros` to `v0.205.4` and restored Plutus conformance.

* Reused importer UTxO statements so repeated imports can avoid preparing the same database operation.

* Cached imported asset statements to reduce repeated database preparation during imports.

* Used positional `ReadAt` access for immutable block reads, keeping reads tied to their requested offsets.

* Persisted certificate rows and era-derived deposits while Mithril ingests gap blocks.

* Recycled peers after post-intersect rollback and added metrics for chain selection stalls and rollback registration.

* Hardened equal-slot alternative block forging to fail closed, adopted valid sibling blocks, and invalidated stale blockfetch state.

* Exposed read and write connection-pool contention metrics for the SQL store.

* Reconstructed nonces for blocks removed by truncation from surviving canonical checkpoints.

* Freed the shared `readDB` connection from `DiskSize` measurement and corrected WAL checkpoint guidance.

* Added per-block ledger composition metrics.

* Queued in-progress epoch stake-reward precomputation during startup.

* Decoded Conway committee authorization sum types, preserved resignations, failed closed on malformed committee data, and handled transactions with nil fees.

* Bound LeiosNotify cursor cleanup to connection ownership and connection lifecycle.

* Preserved VRF-key reservations across epoch boundaries by pinning `epochStartSlot`.

* Rate limited discretionary chain-selection switches across the node.

* Deferred expired governance proposal deposit refunds by one epoch and made `DROP` state safe during migration.

### Test and validation improvements

* Corrected blockfetch endpoint tests to parse complete protocol messages instead of muxer segments.

* Expanded apply-path coverage for operational certificate persistable-counter rejection.

* Pinned embedded genesis hashes and bounded Unix socket test paths.

* Standardized sibling nonce fixtures on 32-byte values.
