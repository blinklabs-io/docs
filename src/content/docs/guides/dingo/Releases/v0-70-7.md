## v0.70.7

**Title:** Improve network resilience, synchronization, storage, and validation

**Date:** Not provided

**Version:** v0.70.7

**Release:** [v0.70.7](https://github.com/blinklabs-io/dingo/releases/tag/v0.70.7)

This release improves peer safety, request handling, chain synchronization, archival queries, ledger validation, and Leios reliability for Dingo nodes and library consumers.

### ✨ Highlights

* Improved learned peer validation by rejecting RFC 5737 TEST-NET and RFC 3849 documentation-only ranges while preserving topology-private and established-inbound exceptions.

* Added a 30-second deadline for Mesh request-body reads and a 60-second listener backstop to prevent stalled requests from holding resources indefinitely.

* Strengthened live primary-chain rewinds by bounding them by K, publishing rollback signals, classifying over-K and Mithril cases for resynchronization, preserving durable undo ordering, and guarding buffered headers.

* Refined Leios resource use by bounding the persistence queue at 256 MiB and coalescing committee computations with a 16-epoch in-flight limit.

* Updated forging contests so equal-slot cases reach leader selection when appropriate, and added warnings for scheduled leader skips.

* Enhanced protocol compatibility by adopting gOuroboros v0.202.10 and ouroboros-mock v0.19.0, and corrected conformance committee-resignation cleanup.

* Preserved `LedgerState.Close` results and bounded replay waits at 10 seconds.

* Expanded ArchiveService block references to support hash, slot, and height lookups, return `not_found` for each missing reference, use metadata for height lookup, decode compact metadata, and seek through S3 data within bounded limits.
