## v0.86.0

**Title:** Improve validation, security, and synchronization reliability

**Version:** v0.86.0

**Release:** [v0.86.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.86.0)

Dingo v0.86.0 improves ledger validation, synchronization safety, API protection, storage recovery, conformance reporting, and operational performance compared with v0.85.0.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Breaking changes
* Changed Genesis corroboration to run by default. An explicit opt out is now required to disable it.
* Enforced Leios certification timing and epoch boundaries, and required a forger timing checker for certification.
* Limited block ExUnits during historical synchronization so the node rejects blocks that exceed the permitted resource budget.
* Required verified TLS for remote PostgreSQL and MySQL metadata connections, and rejected `tls=skip-verify` for snapshot and restore operations.
* Required token authentication for remote Blockfrost mutation routes, while local access uses loopback defaults and remote authenticated access requires TLS.

### Security and reliability
* Hardened remote block ingestion with rewind on failure, block span validation, body hash verification, and panic safe decoding.
* Restricted Mithril and npm download destinations, verified ancillary manifests before extraction, and enforced download and extraction budgets.
* Protected snapshot trust key loading with no follow behavior, ownership and permission checks, and a 1 KiB size limit.
* Verified Praos headers during ImmutableDB replay and load, failed closed when verification inputs were missing, safely rewound rejected blocks, preserved manual recovery causes, and avoided unnecessary marker cleanup.
* Overlapped replay header verification with bounded workers while preserving cancellation errors.
* Bounded rollback intent recovery input and added a bounded metadata store read.
