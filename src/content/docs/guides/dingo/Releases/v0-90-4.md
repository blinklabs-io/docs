## v0.90.4

**Title:** Improve networking, synchronization, APIs, and configuration

**Version:** v0.90.4

**Release:** [v0.90.4](https://github.com/blinklabs-io/dingo/releases/tag/v0.90.4)

**Comparison:** [v0.90.3...v0.90.4](https://github.com/blinklabs-io/dingo/compare/v0.90.3...v0.90.4)

Dingo v0.90.4 improves scoped address handling, Leios validation and timing, historical API backfill, Blockfrost history retention, configuration compatibility, and Plutus processing.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### Networking and consensus
* Fixed scoped IPv6 literal handling by preserving zone identifiers, avoiding DNS lookups for literal addresses, and excluding zoned literals from gossip admission.
* Updated AWS S3 support from v1.114.5 to v1.114.6.
* Improved Plutus processing with plutigo v0.10.2, which adds faster FLAT decoding and evaluation and uses the standard library SHA-256 implementation.
* Validated Leios endorser blocks when announcing blocks commit, and preserved retries when validation capacity is active or full so votes and certificates remain within the intended window.

#### API and database
* Strengthened historical API backfill by following the canonical block index, stopping on missing or invalid canonical bodies, persisting and validating checkpoint identity, propagating cancellation, and bounding blob reads. Database migration v52 supports the change.
* Upgraded CBOR processing from fxamacker/cbor v2.9.6 to v2.10.0.

#### Leios timing
* Scheduled local Leios votes from Dijkstra protocol-parameter wall-clock windows, deferred early announcements, dropped late votes, and revalidated vote lifecycle and deadlines.
