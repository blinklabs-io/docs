## v0.90.4

**Title:** Improve networking, synchronization, APIs, and configuration

**Version:** v0.90.4

**Release:** [v0.90.4](https://github.com/blinklabs-io/dingo/releases/tag/v0.90.4)

**Comparison:** [v0.90.3...v0.90.4](https://github.com/blinklabs-io/dingo/compare/v0.90.3...v0.90.4)

Dingo v0.90.4 improves scoped address handling, Leios validation and timing, historical API backfill, Blockfrost history retention, configuration compatibility, and Plutus processing.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### Networking and consensus
* Fixed scoped IPv6 literals by preserving zone identifiers, avoiding DNS lookups for literal addresses, and excluding zoned literals from gossip admission.
* Updated AWS S3 support to v1.114.6 from v1.114.5.
* Improved Plutus processing with plutigo v0.10.2 through faster FLAT decoding and evaluation and use of standard library SHA-256.
* Validated Leios endorser blocks when the announcing block commits, and preserved retries when validation capacity is active or full so votes and certificates remain within the intended window.

#### API and database
* Strengthened historical API backfill by following the canonical block index, stopping on missing or invalid canonical bodies, persisting and validating checkpoint identity, propagating cancellation, and bounding blob reads. Database migration v52 supports this behavior.
* Upgraded CBOR processing from fxamacker/cbor v2.9.6 to v2.10.0.

#### Leios timing
* Scheduled local Leios votes within Dijkstra protocol-parameter wall-clock windows, deferred early announcements, dropped late votes, and revalidated vote lifecycle and deadlines.

#### Operations and dependencies
* Corrected `DINGO_LOG_FILE` error reporting so failed log file creation includes the underlying errno instead of always reporting that the file already exists.
* Expanded Bursa support from v0.17.1 to v0.21.1.
* Refined AWS support by updating the version 2 SDK to v1.47.5 from v1.47.4 and smithy-go to v1.28.7 from v1.28.6.
* Enhanced Plutus evaluation with plutigo v0.11.0 and gouroboros v0.216.5. Dingo now checks cancellation in 200-step batches, enforces Musashi Dijkstra Leios header extensions, and accepts ten-field Dijkstra headers on other networks.
* Refreshed the Debian bookworm-slim image digest.

#### API and configuration compatibility
* Preserved Blockfrost epoch and pool block history after API mode backfill by writing block nonces and refining retention checks.
* Accepted cardano-node Version 2 envelope configurations with nested `Protocol`, `Testing`, `Consensus`, and `Network` sections, peer target mapping, duplicate key validation, and version validation while retaining flat format support.
* Upgraded the stdouttrace exporter to v1.47.0.

#### Test reliability
* Stabilized LSQ tests by releasing an in-process session before assertions, preventing SQLite acquisition failures during races.
* Coordinated DMQ peer teardown before sent counter assertions, making test results reflect completed peer shutdown.
