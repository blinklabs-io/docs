## v0.92.0

**Title:** Improve synchronization, consensus reliability, and ledger performance

**Version:** v0.92.0

**Release:** [v0.92.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.92.0)

**Comparison:** [v0.91.0...v0.92.0](https://github.com/blinklabs-io/dingo/compare/v0.91.0...v0.92.0)

Dingo v0.92.0 improves synchronization, consensus validation, ledger processing, Mithril imports, and operational visibility.

#### Breaking changes
* Updated metadata APIs to require a context, so callers must provide one when pruning reward state. Bounded adaptive batches now check for cancellation between batches.

#### Synchronization and storage
* Expanded default Leios timing windows from one second by the configured Shelley genesis slot duration, rounding up to preserve the intended wall clock duration. Explicit timing overrides remain unchanged, including on networks with subsecond slots.
* Increased single pass verified immutable entry reads from 16 MiB to 128 MiB, reducing double reads during Mithril imports while retaining bounded fallback verification.
* Improved peer continuity by revalidating retained fork ancestry after consensus context changes, sharing transaction scoped ledger state, and advertising peer addresses only after verified outbound connectivity.
* Tuned Mithril synchronization to use Badger's 1 KiB value threshold in Core and API modes. Larger API mode block bodies now use the value log, while explicit thresholds continue to override the default.
