## v0.88.1

**Title:** Improve peer synchronization and ledger processing

**Version:** v0.88.1

**Release:** [v0.88.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.88.1)

**Comparison:** [v0.87.1...v0.88.1](https://github.com/blinklabs-io/dingo/compare/v0.87.1...v0.88.1)

Dingo v0.88.1 improves peer retention during deferred header recovery and makes eligible trusted batch ledger updates more efficient while preserving the resulting persisted state.

### Recommended Network Compatibility ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Peer synchronization
* Improved deferred header recovery so the node keeps a peer connected when another peer applies the withheld header canonically, aligns the peer cursor without reconnecting or resynchronizing, preserves delivery accounting, and invalidates the resolution when a rollback could otherwise move the cursor backward.

### Ledger processing
* Accelerated eligible trusted batch updates in SQLite core storage by reading UTxOs in bulk, staging changes in memory, and writing only the net differences while preserving the same persisted state as the standard path; uniqueness conflicts return to standard processing and increment `dingo_ledger_trusted_batch_overlay_fallbacks_total` for operational visibility.
