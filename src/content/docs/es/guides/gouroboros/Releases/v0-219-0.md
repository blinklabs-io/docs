## v0.219.0

**Título:** Añadir una intersección de cadena de una sola operación y mejorar el rendimiento de validación

**Versión:** v0.219.0

Esta versión añade una intersección de cadena de una sola operación para clientes ChainSync inactivos, mejora el manejo de testigos bootstrap y acelera la validación Plutus de fase 2.

### Nuevas funciones

* Añadió `Client.Jump(points []pcommon.Point)` para ejecutar `FindIntersect` una sola vez sin sincronizar. El método devuelve el punto de intersección, el tip del servidor, un estado de encontrado y un error. Devuelve `ErrSyncInProgress` mientras se ejecuta un bucle de sincronización o `MsgRequestNext` permanece sin respuesta, serializa las operaciones simultáneas, drena las señales listas obsoletas y permite llamar a `Sync` después de `Jump`.

### Correcciones de errores

* Corrigió la validación de testigos al contar las raíces de dirección calculables de `BootstrapWitness` como hashes de clave proporcionados para los firmantes requeridos, las entradas de hash de clave Shelley y las garantías bloqueadas por clave. Los errores de bootstrap faltante de Byron siguen siendo distintos.

### Rendimiento

* Redujo un 6,3 % el tiempo de validación de fase 2 por transacción en la medición proporcionada de 532 transacciones al indexar la caché de programas Plutus con una clave `maphash` inicializada por proceso. La caché clona los bytes de los scripts para comprobar colisiones, compara los bytes de forma segura, reduce la contención de mutex y trata las colisiones como fallos de caché sin reemplazar las entradas existentes.
