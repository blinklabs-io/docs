## v0.205.0

**Título:** Reforzar la autenticación y la interoperabilidad del ledger

**Versión:** v0.205.0

La versión v0.205.0 refuerza la autenticación, el cierre de protocolos, la validación de datos y las conversiones UTxO-RPC en las eras de Cardano.

### 🔐 Seguridad y autenticación

* Fortaleció **la autenticación de mensajes:** `MessageAuthenticator` ahora exige `StakeAuthority`, deriva el `PoolKeyHash` de 28 bytes con Blake2b-224 y verifica KES durante el procesamiento. También rechaza el stake cero, controla el desbordamiento del período KES y hace que los paquetes DMQ relacionados fallen de forma segura cuando falta autenticación.

### 🔧 Correcciones

* Mejoró **la entrega durante el cierre de protocolos:** las esperas de entrega con contexto hacen que `BlockFetch` y `ChainSync` esperen hasta 250 ms para entregar el mensaje de cierre y devuelvan los errores de entrega.

* Conservó **las claves duplicadas en metadatos anidados:** los mapas de metadatos internos mantienen las claves duplicadas, mientras que los mapas de etiquetas de datos auxiliares externos siguen rechazando duplicados.
