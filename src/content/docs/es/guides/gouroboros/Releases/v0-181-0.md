## v0.181.0

**Título:** Red Leios y metadatos del ledger

**Versión:** v0.181.0

**Fecha:** 7 de junio de 2026

- `NetworkCardanoLeios` incorpora el magic y el par de arranque de la testnet Leios al registro estándar de redes.
- Las APIs tipadas `LeiosEndorserBlock` y `LeiosTransactionReference` rechazan referencias duplicadas, tamaños cero o excesivos, envolturas incorrectas y bytes sobrantes mediante validación CBOR estricta.
- Los procedimientos de votación usan semántica de valores en `AddOrReplace`, búsquedas, clonado e igualdad para evitar votos lógicos duplicados por comparar direcciones de memoria. La codificación CBOR se conserva.
- Se analiza JSON de metadatos cardano-cli sin esquema y con esquema detallado, se emite CBOR canónico determinista y se crean datos auxiliares Shelley que solo contienen metadatos.
- El código que use el alias exportado mal escrito `LeiosEndorderBlock` debe migrar a `LeiosEndorserBlock`. Se actualiza también el historial de versiones.
