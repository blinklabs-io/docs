## v0.208.0

**Título:** Ampliar la validación y compatibilidad del protocolo

**Versión:** v0.208.0

Esta versión amplía la compatibilidad con protocolos, refuerza la validación y mejora la compatibilidad entre el consenso, el ledger, la red y las integraciones de aplicaciones.

### Funcionalidades
* Incorporó la difusión de votos de Peras cuando los nodos negocian compatibilidad nodo a nodo v16, alineó las etiquetas de cableado de Leios con una decodificación estricta de etiquetas y tipos, devolvió errores de protocolo cuando los datos no están disponibles y limitó de forma predeterminada las respuestas de BlockRange a 1,000 respuestas o 64 MiB, con un tiempo de espera por estancamiento de 5 segundos.
* Añadió las restricciones de recompensas de Dijkstra `MaxPledgeLeverage` y `MinPoolMargin`, esta última condicionada por `PV13`, con validación del rango de parámetros y sin cambiar el comportamiento anterior a Dijkstra.
