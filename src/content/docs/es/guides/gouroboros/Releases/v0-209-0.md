## v0.209.0

**Título:** Mejorar la seguridad del protocolo, la validación de transacciones y la visibilidad de los tiempos

**Versión:** v0.209.0

Esta versión refuerza el manejo de entradas del protocolo, valida las transacciones contra los efectos de bloques anteriores, expone datos de tiempo de las etapas y corrige el comportamiento de Plutus, los modelos de costes y las transacciones de Byron.

### Cambios incompatibles
* Añadió datos de tiempo agregados para las etapas correctas de decodificación, validación y aplicación mediante `PipelineStats` y `StageTimings`; el código que crea `PipelineStats` con literales sin claves debe añadir los nuevos campos o cambiar a literales con claves.
