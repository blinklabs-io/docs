## v0.179.0

**Título:** Protocolo LeiosVotes y ejemplos independientes

**Versión:** v0.179.0

**Fecha:** 27 de mayo de 2026

- El protocolo node-to-node LeiosVotes permite recibir y servir votos `CIP-0164` mediante un flujo específico.
- Las conexiones y sus opciones de configuración exponen ese flujo junto con el resto de protocolos Leios.
- Los comandos de ejemplo se organizan como módulos independientes bajo `examples/` para compilación, pruebas, lint y ejecución local.
- El historial aclara que no se publicaron versiones entre `v0.171.0` y `v0.178.0` por un error de etiquetado, e incorpora la entrada estructurada `v0.178.0` antes de v0.179.0.
