## v0.213.11

**Título:** Mantener activas las solicitudes canalizadas de ChainSync durante las respuestas

**Versión:** v0.213.11

Esta versión evita que fallen las solicitudes de ChainSync durante las transiciones de estado impulsadas por respuestas.

### Correcciones de errores

* Resolvió el problema que podía hacer que las sesiones de ChainSync rechazaran una solicitud canalizada durante una transición local impulsada por una respuesta. Las solicitudes declaradas como canalizadas ahora siguen admitidas después de que la respuesta devuelve el control al par, incluso cuando la generación del estado que las declara es igual o posterior a la generación de la instantánea. Los tipos de mensaje no declarados ya no coinciden con una generación de valor cero, y `RequestNext` sigue admitido después de que `RollForward` devuelve el servidor a `Idle` cuando `CanAwait` lo declara como canalizado, evitando errores como `received message type 0 without peer agency`.
