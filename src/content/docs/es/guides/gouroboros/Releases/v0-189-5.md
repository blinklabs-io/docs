## v0.189.5

**Título:** Checkout de CI y validación chainsync más estricta

**Versión:** v0.189.5

**Fecha:** 28 de julio de 2026

- Siete flujos usan `actions/checkout` v7.0.1, con correcciones para comprobaciones inseguras de pull requests, recorte de espacios ASCII y escape de `--unset`.
- El cliente node-to-node chainsync rechaza eras desconocidas antes de continuar con rollforward; el servidor devuelve errores claros para tipos de bloque desconocidos.
