## v0.221.0

**Título:** Mejorar el orden y añadir compresión optativa de BlockFetch

**Fecha de lanzamiento:** 2026-11-22

**Versión:** v0.221.0

Esta versión estabiliza el orden de los destinos MIR UTxO-RPC, refuerza la validación de UPLC, añade compresión experimental y optativa de BlockFetch desactivada de forma predeterminada para versiones compatibles de Dijkstra del protocolo nodo a nodo, y actualiza las dependencias auxiliares y las acciones de CI.

### Nuevas funciones

* Añadió compresión experimental y optativa de CIP-0150 BlockFetch, desactivada de forma predeterminada, para versiones compatibles de Dijkstra del protocolo nodo a nodo. Las aplicaciones pueden optar por mensajes de bloques sin comprimir o comprimidos con Zstandard; el protocolo limita la descompresión, aplica un presupuesto de bytes a cada rango y admite el procesamiento tanto en el cliente como en el servidor.
