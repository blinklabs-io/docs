## v0.201.0 (26 de agosto de 2026)

**Título:** Aplica las reglas de gobernanza en Dijkstra

**Fecha:** 26 de agosto de 2026

**Versión:** v0.201.0

Esta versión aplica las reglas de gobernanza necesarias durante la era Dijkstra para que el procesamiento del ledger siga el comportamiento de gobernanza actual del protocolo.

### 💪 Mejoras

* Corrigió **el procesamiento de gobernanza de Dijkstra:** El procesamiento del ledger ahora aplica las reglas de gobernanza necesarias para Dijkstra.
