## v0.218.0

**Título:** Mejorar la evaluación de Plutus y el acceso a los comités Leios

**Versión:** v0.218.0

Esta versión mejora la eficiencia de evaluación de Plutus, amplía el acceso a los comités Leios y alinea la decodificación de consultas de estado local con el comportamiento del libro mayor.

### Nuevas funciones

* Añadió la consulta 41 de `localstatequery` de Shelley y `Client.GetLeiosCommittee()` para recuperar los comités de votación Leios actual y siguiente opcional. El decodificador limita el número de puestos y acepta una clave BLS opcional solo cuando tiene exactamente 96 bytes.
