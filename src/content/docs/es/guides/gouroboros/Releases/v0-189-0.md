## v0.189.0

**Título:** Decodificación Byron EBB y contadores de certificados operativos

**Versión:** v0.189.0

**Fecha:** 22 de julio de 2026

- `ByronEpochBoundaryBlock.UnmarshalCBOR` devuelve un error si la cabecera decodificada es `nil`, evitando crear bloques que provoquen un panic después.
- LocalStateQuery convierte `DebugChainDepState` en contadores de certificados operativos y los devuelve mediante la API tipada `GetOpCertCounters`.
- Se moderniza la implementación CBOR sin cambiar el comportamiento visible y se eliminan los archivos de automatización para cerrar incidencias.
