## v0.178.0

**Título:** Ejemplos propios y API pública de diagnóstico CBOR

**Versión:** v0.178.0

**Fecha:** 26 de mayo de 2026

- Se incorporan ejemplos de obtención de bloques, chainsync, tip, intercambio de pares, ping, consulta de estado, monitorización y envío de transacciones.
- Los ejemplos son módulos independientes bajo `examples/`; las ejecuciones locales deben partir de allí, no de la antigua ruta `cmd/`.
- El diagnóstico admite transacciones, bloques, datos Plutus y scripts nativos, con etiquetas Cardano y anotaciones de direcciones legibles.
- La API pública de diagnóstico cubre CBOR genérico, transacciones y bloques Cardano, con árboles de análisis, offsets, advertencias y estadísticas.
- Esta versión reúne los cambios desde v0.171.0. Los ejemplos ya no deben describirse como procedentes del antiguo repositorio de starter kit; la ubicación definitiva es `examples/`.
