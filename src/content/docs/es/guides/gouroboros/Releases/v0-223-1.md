## v0.223.1

**Título:** Mejorar la correlación de solicitudes y la finalización del apagado

**Fecha de lanzamiento:** 2026-11-28

**Versión:** v0.223.1

Esta versión mejora la correlación entre las solicitudes de las devoluciones de llamada y los registros de datos enviados por el transporte entre reinicios del protocolo, y garantiza que el apagado espere a la publicación de finalización. No incorpora cambios incompatibles y no modifica la CLI, la configuración ni los requisitos de instalación.

### Nuevas funciones

* Añadió `Client.WriteObservationSession()`, que devuelve un identificador de sesión para los registros de datos enviados por el transporte. El identificador permanece estable entre reinicios del protocolo y es cero cuando el registro está desactivado.

### Correcciones de errores

* Mejoró el seguimiento de las solicitudes de las devoluciones de llamada al permitir que los ID de solicitud coincidan con los registros de datos enviados por el transporte, incluso cuando se reutilizan las direcciones de conexión o se reinician los protocolos.

* Corrigió el apagado del protocolo para que espere a que terminen todos sus bucles y a que se publique la finalización antes de devolver el control. La finalización publicada tiene prioridad sobre la cancelación del contexto.

* Alineó el apagado y `StopForRestart` con este orden de finalización, reduciendo las condiciones de carrera durante el apagado y evitando que `DoneChan` permanezca abierto.
