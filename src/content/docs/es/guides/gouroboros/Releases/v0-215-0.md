## v0.215.0

**Título:** Configuración de la red de pruebas Dijkstra

**Versión:** v0.215.0

**Fecha de publicación:** 2026-10-24

Esta versión registra la red de pruebas Dijkstra de Cardano. Los clientes pueden seleccionarla por nombre (`dijkstra`) o magic de red (`6`), y descubrir pares mediante su relay de arranque.

### Nuevas funciones

- Se añade la red de pruebas Dijkstra con el nombre `dijkstra`, magic de red `6` y el par de arranque `dijkstra-node.play.dev.cardano.org:3001`. Los clientes pueden seleccionar la red por nombre o magic de red.
