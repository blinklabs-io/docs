# Usando Adder en Windows

Esta guia te mostrara como usar Adder en Windows. En las siguientes secciones te mostraremos ejemplos de como usar Adder. Recuerda que estos son ejemplos para familiarizarte con el tipo de cosas que Adder es capaz de hacer. El verdadero poder de Adder puede ser desbloqueado por tu imaginacion.

> Nota: esta guia asume que has descargado el instalador MSI de Adder desde <a href="https://blinklabs.io/projects-open-source" target="_blank">blinklabs.io</a>. Si no has descargado el instalador, por favor consulta nuestro [Inicio Rapido](../002-quick-start-overview)

## Paso 1 - Descargar e instalar Adder

La forma mas sencilla de instalar Adder en Windows es usar el instalador MSI disponible en <a href="https://blinklabs.io/projects-open-source" target="_blank">https://blinklabs.io/projects-open-source</a>.

![adder-windows-release-download](/adder-windows-release-download.webp)

Selecciona la version adecuada para el sistema: Windows x64 o Windows arm64.

### Paso 1.1 - Abrir el instalador MSI

Cuando termine la descarga, haz clic en `Open` para abrir el archivo `.msi`.

![adder-windows-open-msi](/adder-windows-open-msi.webp)

### Paso 1.2 - Ejecutar el instalador

Haz clic en `Run` para iniciar la instalacion.

![adder-windows-run-msi](/adder-windows-run-msi.webp)

## Paso 2 - Iniciar Adder

Abre el menu Inicio de Windows.

![adder-windows-start-menu](/adder-windows-start-menu.webp)

Busca la aplicacion `Adder` y abrela.

![adder-windows-search-adder-app](/adder-windows-search-adder-app.webp)

> Si no aparece la pantalla de configuracion **Welcome**, abre la bandeja del sistema, haz clic derecho en la aplicacion Adder y selecciona **Configure** para abrir el asistente de configuracion.
