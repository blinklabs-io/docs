## v0.43.0 (25 de junio de 2026)

**Título:** Editor de reglas de notificación, instaladores firmados, migración de API y publicaciones más fiables

**Fecha:** 25 de junio de 2026

**Versión:** v0.43.0

Esta versión renueva las notificaciones de bandeja, añade un editor integrado y amplía la observación de varios objetivos. Incluye un instalador macOS `.pkg` firmado y notarizado, firma Windows más fiable con Java 21, migración de la API a `net/http`, correcciones de prioridad de configuración y mejoras de los flujos de publicación y CI.

### ✨ Aspectos destacados

- **Notificaciones sin reiniciar:** Desde la bandeja se editan los cinco grupos de objetivos y las categorías de notificación. Se mantiene la opción Monitor Everything y los cambios recargan el motor de notificaciones en caliente.

- **Instalador macOS:** La CLI y la aplicación de bandeja se empaquetan en `Adder.app`. Cuando hay credenciales, el instalador se firma, se notariza y recibe el comprobante de notarización. Se publican paquetes verificados con scripts de preinstalación y posinstalación.

- **Firma Windows:** El flujo utiliza Java 21 y evita los fallos de firma de Java 17.

- **Servidor API:** Se migra a `net/http` sin modificar las rutas documentadas. Incluye registros de acceso estructurados, recuperación de pánicos, streaming en `/events`, rutas FCM y QR actualizadas, rutas Swagger ajustadas y tiempos de espera coherentes con el servicio.

- **Configuración y guardado:** Se conservan las opciones CLI y se aplica `CLI > YAML > env`. YAML tiene prioridad sobre el entorno; el guardado se serializa por ruta y refuerza las escrituras atómicas.

- **Fallos por plataforma:** Se desactiva `adder-tray` en la matriz FreeBSD para evitar fallos de compilación, la firma macOS deja de bloquear y la publicación final continúa aunque fallen algunos trabajos de la matriz.

### 💪 Mejoras

- **Datos Cardano:** Las nuevas versiones de `gouroboros` mejoran la verificación de certificados operativos, la decodificación de redeemers Dijkstra y los modelos de costes de parámetros de protocolo durante la conversión determinista.

- **Duplicados Cardano:** Se gestionan con mayor fiabilidad las claves MultiAsset duplicadas anteriores a Conway y las entradas duplicadas de conjuntos etiquetados de testigos Conway.

- **Evaluación y criptografía:** Las nuevas versiones de `plutigo` y `x/crypto` refuerzan la decodificación y evaluación y añaden seguridad y rendimiento.

- **Imágenes y fuentes:** La actualización de `golang.org/x/image` refuerza las fuentes, comprueba la decodificación WebP y corrige el relleno TIFF.

- **Telegram:** Se actualiza `github.com/go-telegram/bot` para mantener la salida alineada con las dependencias actuales.

- **Plataformas Go:** Se actualiza `golang.org/x/sys` para mantener las compilaciones compatibles con el soporte actual de ejecución.

- **Mantenimiento Go:** Una actualización posterior de `golang.org/x/sys` incorpora correcciones de ejecución y compatibilidad del proyecto original.

### 🧪 Pruebas, CI, documentación y publicación

- Se actualiza la acción `golangci-lint` del flujo de lint.

- Se elimina la acción que actualizaba la fecha de cierre de issues durante las comprobaciones.

- Los filtros Cardano utilizan fixtures `TransactionOutputBuilder` de `ouroboros-mock` para direcciones, identificadores de política, huellas de activo y DRep. Se refuerzan las aserciones CIP-0129 y se limpia el entorno de lint y pruebas Go.

- Se actualiza `actions/setup-java` en el paso de firma Windows para mantener el entorno Java.

- Se actualiza `actions/setup-go` en los flujos Go sin cambiar las versiones Go configuradas.

- Se actualiza `actions/checkout` en varios flujos.

- Se actualiza `docker/metadata-action` en CI y publicación Docker.

- Se actualiza `actions/setup-java` en publicación y MSI para mejorar diagnósticos, caché y gestión de herramientas Maven y Java.

- Se actualiza `docker/build-push-action` en CI y publicación Docker.

- Se actualiza `docker/login-action` en el flujo de publicación de contenedores.

- Se actualiza `actions/attest` para reforzar la verificación de artefactos publicados.

- Se incorpora otra actualización de `actions/checkout` con correcciones de seguridad y checkout para PR de forks y otros desencadenantes.

- Se actualiza `actions/upload-artifact` en las pruebas MSI. Los runners propios requieren Actions Runner 2.327.1 o posterior.
