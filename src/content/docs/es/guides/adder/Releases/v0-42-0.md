## v0.42.0 (25 de junio de 2026)

**Título:** Notificaciones de bandeja para varios objetivos, prioridad de configuración predecible, ejemplos y publicaciones más fiables

**Fecha:** 25 de junio de 2026

**Versión:** v0.42.0

Esta versión mejora las notificaciones, la configuración y la fiabilidad de las publicaciones de Adder.

### ✨ Aspectos destacados

- **Varios objetivos desde la bandeja:** Adder envía notificaciones de escritorio nativas para varias billeteras, DRep y pools a la vez. Incluye un modo para observarlo todo, aplica cambios de reglas sin reiniciar y migra los ajustes antiguos al nuevo formato.

- **Prioridad de configuración:** Se aplica `CLI > YAML > env > defaults`. YAML tiene prioridad sobre las variables de entorno; las instalaciones que dependían de la prioridad contraria deben ajustar su configuración.

- **Ejemplos de biblioteca:** Se incluyen `adder-publisher`, `poolid-filter` y `event-address-filter` para comprender y adaptar patrones habituales de publicación y filtrado.

- **Publicaciones por plataforma:** Las compilaciones macOS se fijan a `macos-15`, el empaquetado se separa de la firma y la notarización, el fallo de una plataforma no detiene todas las compilaciones y la publicación continúa tras crear correctamente el borrador de la versión.

### 💪 Mejoras

- **Red Cardano:** La validación más segura y las nuevas capacidades de red permiten procesar con mayor fiabilidad la actividad actual.

- **Imágenes y fuentes:** La decodificación más segura refuerza la resistencia al cargar los recursos visuales incluidos.

- **Sistemas operativos:** Se actualiza el soporte de sistemas y llamadas de sistema para conservar la estabilidad y compatibilidad de los entornos actuales.

### 🧪 Pruebas, CI, documentación y publicación

- Se actualizan las herramientas de publicación de las compilaciones automatizadas para mantener una preparación fiable.

- Se actualizan las herramientas de firma y publicación para mantener fiables las firmas automatizadas.
