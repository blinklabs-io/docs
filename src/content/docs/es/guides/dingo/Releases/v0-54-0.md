## v0.54.0

**Título:** Mithril v2 predeterminado y recuperación Leios y chainsync

**Versión:** v0.54.0

**Fecha:** 12 de junio de 2026

- Mithril v2 es el backend predeterminado. Para usar el comportamiento anterior se debe seleccionar v1 explícitamente.
- Se permite obtener metadatos Mithril sin una sesión activa en línea, para examinarlos antes de una descarga completa.
- Se mejoran la temporización y la progresión de etapas de los flujos experimentales Leios y Dijkstra, y se integra la producción de bloques endorser Leios en el líder de slot Praos de Dijkstra.
- Se detectan antes los pares chainsync obsoletos y se mejora la reconexión y recuperación cuando los pares caen o rotan.
- Se incorpora la definición Acropolis `midnight_state.proto` y la generación de código gRPC para Midnight.
- Las rutas de importación de paquetes de API pasan al espacio `api/`; los endpoints de ejecución conservan sus rutas.
- Se rechazan bloques endorser Leios experimentales cuyos slots no coinciden con la temporización esperada.
- Se publican las notas finalizadas de v0.53.0.
