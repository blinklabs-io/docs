## v0.46.4

**Título:** Arranque desde génesis y seguimiento de Mithril más completos

**Versión:** v0.46.4

**Fecha:** 18 de mayo de 2026

- El arranque inicial desde génesis funciona con MySQL y Postgres, además de SQLite, y mantiene un estado inicial coherente entre los backends admitidos.
- La monitorización de Mithril muestra las etapas y el progreso de sincronización y recuperación.
- SQLite usa búsquedas más eficientes para cargas con muchas salidas y maneja etiquetas de transacciones de gran valor sin desbordamientos.
- Se actualizan las bibliotecas de AWS S3, Google API y `btcutil`, y se añaden las notas de v0.46.3.
- Se aplican los procedimientos habituales de actualización de versiones de corrección.
