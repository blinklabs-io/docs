## v0.46.3

**Título:** Recuperación ChainSync y consultas de base de datos más rápidas

**Versión:** v0.46.3

**Fecha:** 17 de mayo de 2026

Esta versión de corrección se centra en fiabilidad, rendimiento y pruebas.

- `ouroboros-mock` v0.11.0 amplía las pruebas de conformidad de rollbacks sintéticos.
- Nuevos índices aceleran las consultas de gobernanza sobre cuentas y UTxO, y las búsquedas de stake por pool en los datos de cuentas.
- La recuperación tras una meseta de sincronización usa una conexión nueva cuando los pares pierden la alineación.
- Se publican las notas v0.46.2 y se aclara el mapeo de métricas de ejecución, eliminando una referencia obsoleta a un archivo local.
- Se aplican los procedimientos habituales de actualización de versiones de corrección.
