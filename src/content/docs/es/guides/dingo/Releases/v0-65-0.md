## v0.65.0

**Título:** Seguimiento de recompensas y recuperación Leios con pares lentos

**Versión:** v0.65.0

**Fecha:** 15 de julio de 2026

- Al actualizar, el arranque puede reconstruir datos de stake de recompensas ausentes. Se conserva más historial y se mantiene la continuidad tras reinicios. Esta versión todavía no introduce el cálculo de recompensas.
- Las instantáneas de stake de pools incluyen los saldos de cuentas de recompensas de cada slot y conservan delegadores que solo tienen recompensas, evitando falsos fallos del umbral de liderazgo.
- La recuperación Leios cambia a pares saludables cuando un par responde lentamente o permanece ocupado.
- Sundae Preview y Blockfrost Explorer usan TypeScript 7.0.2 y requieren Node 16.20.0 o posterior para desarrollo local.
