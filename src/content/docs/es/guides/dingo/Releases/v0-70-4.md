## v0.70.4

**Título:** Mejorar el procesamiento de Leios, la fiabilidad de la API y las operaciones del nodo

**Fecha:** Not provided

**Versión:** v0.70.4

Esta versión mejora el procesamiento de Leios, el descubrimiento de pares, el manejo de bases de datos, las respuestas de la API, el estado de gobernanza y la fiabilidad operativa de los nodos Dingo y los consumidores de la biblioteca.

### Compatibilidad de red recomendada ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Aspectos destacados

* Mejoró la validación automatizada para que los pushes independientes de la línea principal ya no se cancelen entre sí, mientras las comprobaciones de pull requests conservan su comportamiento de cancelación actual.

* Añadió cobertura de extremo a extremo para el doble consumo en cierres de Leios. El cierre conforme a Musashi y Haskell ahora tolera una salida ya consumida, mientras las rutas de CIP y de bloques de ranking siguen devolviendo `ErrUtxoConflict`.

* Actualizó las referencias de bloques endosadores de Leios para usar el resumen Blake2b256 y el tamaño codificado completo de los datos íntegros de la transacción.

* Amplió la verificación de migraciones de bases de datos para cubrir la inicialización de metadatos, la memoización, el aislamiento de artefactos y los directorios temporales delimitados por proceso.
