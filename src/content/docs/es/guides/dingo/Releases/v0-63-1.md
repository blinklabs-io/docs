## v0.63.1

**Título:** Menos errores espurios y dependencias actualizadas

**Versión:** v0.63.1

**Fecha:** 14 de julio de 2026

- Los cierres esperados de conexiones duplicadas se registran como información, no como errores.
- Se actualizan las configuraciones de registro y la red Musashi incluidas.
- Los valores internos no válidos de los controles de concurrencia provocan un fallo inmediato para evitar corrupción de estado.
- Se actualizan dependencias de salud de servicios sin cambiar sus comprobaciones, bibliotecas del sistema operativo, seguridad, terminal y texto.
- Se actualizan las dependencias web de Blockfrost Explorer y Sundae Preview, incluida la biblioteca principal de SundaeSwap.
