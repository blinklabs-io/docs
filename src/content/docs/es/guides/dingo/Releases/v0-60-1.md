## v0.60.1

**Título:** Recuperación Mithril y cálculo del nonce Dijkstra

**Versión:** v0.60.1

**Fecha:** 29 de junio de 2026

- Las descargas de instantáneas y archivos Mithril se recuperan mejor de interrupciones temporales.
- Se actualizan el acceso a instantáneas y archivos en Google Cloud Storage, las integraciones de servicios incluidas, la capa de base de datos y la imagen nview de los recursos de despliegue.
- Se corrige el cálculo del nonce en el tip para la producción Dijkstra.
- Se actualizan las herramientas de atestación, configuración de Go y caché de los flujos de compilación y publicación.
- Se actualizan los paquetes de tipos Node.js y Vite de dos ejemplos web para mantener sus entornos alineados.
- Se actualiza el registro de notas de v0.60.0.
