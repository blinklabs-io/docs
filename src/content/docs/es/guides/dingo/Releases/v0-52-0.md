## v0.52.0

**Título:** Caducidad histórica independiente y validación de comisiones Conway

**Versión:** v0.52.0

**Fecha:** 8 de junio de 2026

- El historial local de bloques puede caducar sin recurrir a un archivo. El acceso al archivo Bark sigue disponible como opción de despliegue independiente.
- Se corrigen las comisiones mínimas Conway, incluidos los costes de scripts de referencia y los redeemers necesarios, evitando rechazos de validación innecesarios.
- Se actualizan `github.com/aws/smithy-go` a v1.27.2, `google.golang.org/api` a v0.283.0, `github.com/aws/aws-sdk-go-v2` a v1.42.0 y `github.com/aws/aws-sdk-go-v2/credentials` a v1.19.23.
- Se publican las notas de v0.51.0.
