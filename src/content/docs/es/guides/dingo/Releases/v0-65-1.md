## v0.65.1

**Título:** Formación de comités Leios y recuperación estable de relays

**Versión:** v0.65.1

**Fecha:** 16 de julio de 2026

- En Musashi y otras redes Leios basadas en Dijkstra se restaura la formación de comités cuando faltan ajustes necesarios, sin modificar una configuración de red fijada. Los ajustes no válidos siguen rechazándose.
- El envío de transacciones maneja datos inesperados de forma segura sin interrumpir el procesamiento de solicitudes.
- Se corrige la recuperación chainsync con un solo relay para que los rollbacks avancen sin repetir el mismo bucle.
- Las conexiones a relays de pools usan la dirección resuelta cuando falla la conexión mediante el nombre descubierto.
- Se refuerzan las imágenes de pruebas de resiliencia y la validación de datos de recompensas entre los almacenes admitidos.
