## v0.62.0

**Título:** Recuperación Mithril, certificados y consultas de base de datos

**Versión:** v0.62.0

**Fecha:** 9 de julio de 2026

- La recuperación Mithril v2 en modo core conserva los marcadores inmutables, detecta antes las divergencias y reconcilia el ledger obsoleto sin resincronizar todo cuando la cadena aún coincide.
- Se verifican los certificados operativos en cabeceras y aplicación de bloques, rechazando pronto datos falsificados, caducados, obsoletos o con huecos.
- Las consultas de transacciones MySQL y Postgres requieren menos intercambios, y los nombres de bases de datos MySQL se validan antes de crearlas.
- Blockfrost añade búsquedas de direcciones que poseen un activo.
- Se refuerzan las pruebas directas de aplicación del estado del ledger y se actualiza `gouroboros` para alinear Dijkstra y Leios con los cambios de origen.
