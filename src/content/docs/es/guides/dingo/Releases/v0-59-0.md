## v0.59.0

**Título:** Indexación Midnight y selección de cadena más estable

**Versión:** v0.59.0

**Fecha:** 26 de junio de 2026

- El modo de almacenamiento API indexa actividad cNIGHT y registros de Midnight, completa el historial y restaura el estado tras reiniciar. La coincidencia de tokens de autenticación Midnight puede limitarse a una política concreta.
- Se mantiene un par conectado saludable cuando comparte el tip o existen bifurcaciones pequeñas cerca de él, reduciendo cambios innecesarios de par.
- Los endpoints Blockfrost de cuentas de staking amplían estado, saldos, delegación, historial de registro y delegación de gobernanza según sus definiciones publicadas.
- Las descargas Mithril de instantáneas y archivos inmutables reintentan fallos transitorios de conexión, límites de solicitudes y errores del servidor. El límite de reintentos es configurable.
- La validación restrictiva acepta transacciones válidas que superan temporalmente el presupuesto declarado durante la contabilidad interna del script.
- ChainSync usa transiciones de estado e instantáneas seguras frente a concurrencia.
- Las consultas de estado de representantes de gobernanza usan el formato esperado de cuatro elementos.
- Las pruebas de cabeceras se verifican contra sus bytes originales para evitar rechazos por campos decodificados obsoletos.
- Se actualizan las notas internas de v0.58.0.
