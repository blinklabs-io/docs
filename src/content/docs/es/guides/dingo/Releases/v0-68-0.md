## v0.68.0

**Título:** APIs Blockfrost, recuperación y dependencias

**Versión:** v0.68.0

**Fecha:** 28 de julio de 2026

- Se conserva el índice de stake activo durante la indexación histórica de la API y se corrige el manejo de UTxO de instantáneas con punteros.
- La lista y las respuestas DRep se alinean con Blockfrost. Se añade `GET /addresses/{address}` y las consultas LSQ `stake-address-info`.
- Se restaura la actividad DRep a partir de certificados y las consultas de UTxO por dirección exacta devuelven las mismas salidas en Blockfrost y UTxO-RPC.
- Se reorganizan los plugins conservando la migración de configuraciones existentes.
- Ouroboros observa el rollback antes de avanzar la barrera de aplicación.
- Se refuerzan la recuperación tras cambios del estado de génesis y la seguridad de propiedad de bases de datos abiertas.
- Las instantáneas mark usan la vista `reward_live_stake` y el bucle de reproducción puede reiniciarse tras fallos sin bloquear el nodo.
- Se interpretan correctamente las cuentas de recompensas de pools Leios.
- El procesamiento de eventos aplica contrapresión para conservarlos bajo carga.
- Se actualizan `bark`, `@blaze-cardano/sdk`, AWS SDK for Go v2 y sus módulos de credenciales y configuración, y `cloud.google.com/go/storage`.
- Se añade la entrada de v0.67.1 y se da la bienvenida a @mmahut como colaborador.
