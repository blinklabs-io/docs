## v0.66.0

**Título:** Procesamiento de recompensas y valores de servicio más seguros

**Versión:** v0.66.0

**Fecha:** 19 de julio de 2026

- Se calculan y aplican recompensas en las transiciones de época, manteniendo el arranque alineado con los datos de recompensas. La primera aplicación espera hasta que esos datos estén disponibles.
- El cálculo previo asíncrono prepara recompensas con antelación para aplicarlas en el punto requerido.
- Se amplían las instantáneas de stake de recompensas y las APIs de metadatos relacionadas.
- Las rutas Blockfrost no reconocidas devuelven `404`.
- Los servidores UTxORPC y Bark requieren como mínimo TLS 1.2; los clientes antiguos deben actualizarse.
- Se añade cobertura de conformidad PostgreSQL para recompensas y se alinea Leios con el prototipo Musashi w29.
