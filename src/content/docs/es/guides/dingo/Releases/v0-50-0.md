## v0.50.0

**Título:** APIs para navegadores, Gov Lens e importación Mithril más resistente

**Versión:** v0.50.0

**Fecha:** 1 de junio de 2026

- Las APIs Bark, Blockfrost, Mesh y UTXORPC aceptan solicitudes de navegadores para facilitar integraciones web directas.
- El ejemplo Gov Lens añade un panel de gobernanza y recursos de despliegue. Su arranque espera a que termine la sincronización Mithril.
- Las importaciones masivas Mithril aplazan algunas consultas de metadatos y las recuperan de forma segura después de reiniciar. Se informa con más detalle del progreso y los tiempos de indexación histórica.
- Se amplía la documentación sobre modos de archivo y poda.
- Se refuerza la recuperación de Badger y el manejo de lecturas que se cierran inesperadamente.
- Se mejoran los diagnósticos cuando falla una nueva decodificación de un bloque producido.
- Se mantienen alineados los resultados de validación Plutus y las comprobaciones de reproducción.
- Se aplazan consultas de políticas de activos durante importaciones masivas sin debilitar la protección contra importaciones duplicadas.
- Se actualizan las dependencias del ejemplo Dingo Sundae Preview y se elimina la publicación de paquetes npm del flujo de versiones.
- Se actualizan `blinklabs-io/nview` a v0.14.0 y `blinklabs-io/go` a 1.26.3-1, además de AWS SDK, `smithy-go`, `google.golang.org/api` y los exportadores de trazas OpenTelemetry HTTP y stdout.
