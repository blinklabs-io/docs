## v0.60.0

**Título:** Métricas de pares y producción Dijkstra más fiable

**Versión:** v0.60.0

**Fecha:** 28 de junio de 2026

- Se informa de la latencia BlockFetch de cada par.
- Las compilaciones predeterminadas no incluyen los plugins de blobs S3 y GCS. Para incluirlos se debe compilar con `-tags dingo_extra_plugins`.
- Los errores de arranque de listeners de métricas o depuración se registran, pero el nodo sigue funcionando si existe un conflicto de puertos.
- Se corrigen la codificación y el hash de los bloques producidos Dijkstra para que superen la validación.
- Se actualiza el registro de notas de v0.59.1.
