## v0.51.0

**Título:** Ajustes de almacenamiento, instantáneas de pares y preparación Leios

**Versión:** v0.51.0

**Fecha:** 7 de junio de 2026

- Se pueden configurar la compresión del almacenamiento y sus niveles.
- Las consultas locales devuelven instantáneas de pares del ledger.
- Se agilizan las escrituras durante la indexación histórica de la API y se separa la reconstrucción urgente de índices de la diferida para reducir el trabajo posterior.
- Se pueden elegir registros de texto o JSON y su nivel de detalle. El texto sigue siendo el valor predeterminado; JSON requiere configuración explícita.
- Se añade preparación para Dijkstra y la votación Leios, incluido el intercambio y servicio de votos. La versión incorpora la configuración de la testnet Leios.
- Las respuestas de época incluyen los ajustes de protocolo Conway.
- Se actualizan el arranque Genesis mediante instantáneas y los datos de instantáneas y topología incluidos.
- La devnet incluida usa la versión mínima admitida 11.
- Se corrigen bloqueos de sincronización y arranque cerca del tip de la cadena.
- Se añade un ejemplo de explorador conectado a una API local y se publican las notas de v0.50.2.
