## v0.74.1

**Título:** Limitar los recursos de entrada y fortalecer la validación del libro mayor

**Fecha:** 2026-09-30

**Versión:** v0.74.1

**Versión publicada:** [v0.74.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.74.1)

Esta versión limita la exposición de recursos durante la entrada, mejora la información de metadatos de la base de datos y fortalece la validación de datos del libro mayor y la cobertura de regresión.

### Compatibilidad de red recomendada ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Mejoras de entrada y base de datos

* Mejoró el control de recursos de entrada al limitar por bytes las cachés de decodificación y el historial de encabezados de pares, eliminar de la caché los bloques rechazados, limitar y combinar la verificación de votos y anuncios de Leios en ventanas fijas y separar la admisión de Node-to-Client local de confianza de las cuotas remotas. Se puede configurar `--max-trusted-local-ntc-conns` o `DINGO_MAX_TRUSTED_LOCAL_NTC_CONNS`; los valores no positivos usan el valor predeterminado `100`. Las métricas de bytes almacenados distinguen entre clientes locales de confianza y remotos.

* Actualizó las respuestas de Bark `GetDatabaseInfo` para informar el nivel de almacenamiento configurado de la base de datos en el campo `Tier`, con valores como `core` y `api`.
