## v0.92.0

**Título:** Mejorar la sincronización, la fiabilidad del consenso y el rendimiento del ledger

**Versión:** v0.92.0

**Versión publicada:** [v0.92.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.92.0)

**Comparación:** [v0.91.0...v0.92.0](https://github.com/blinklabs-io/dingo/compare/v0.91.0...v0.92.0)

Dingo v0.92.0 mejora la sincronización, la validación del consenso, el procesamiento del ledger, las importaciones de Mithril y la visibilidad operativa.

### Compatibilidad de red recomendada ⚠️

| Red                 | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### Cambios incompatibles
* Actualizó las API de metadatos para requerir un contexto. Las llamadas deben proporcionar uno al podar el estado de recompensas, y los lotes adaptativos acotados ahora comprueban la cancelación entre lotes.
