## v0.56.0

**Título:** Compatibilidad Leios y Musashi y validación mediante checkpoints

**Versión:** v0.56.0

**Fecha:** 23 de junio de 2026

- Se actualizan el comportamiento Leios y el procesamiento de endorsements durante la sincronización para ajustarlos a la red Preview actual.
- La cadena se valida contra los checkpoints configurados y se comprueba la coherencia de las horas de inicio de red.
- Se unifica el nombre Musashi y se muestra con más claridad el progreso de recuperación mediante Mithril.
- Se reducen los registros repetidos de pares omitidos durante actualizaciones de gobernanza y se prepara el soporte de compilación de almacenamiento opcional.
- No se retrocede innecesariamente durante la recuperación Mithril si el tip del ledger ya está en la cadena principal; se conserva la reproducción hacia delante.
- Se omiten esperas por endorsements Leios obsoletos.
- Se actualizan los tipos Node.js de Sundae Preview y TypeScript de Blockfrost Explorer y Sundae Preview.
- Las comprobaciones de arquitectura verifican los límites entre paquetes. Se publican y aclaran las notas de v0.55.0.
