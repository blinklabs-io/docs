## v0.78.0

**Título:** Ampliar el acceso a la API y fortalecer la fiabilidad del nodo

**Fecha:** 2026-10-04

**Versión:** v0.78.0

**Versión publicada:** [v0.78.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.78.0)

Dingo v0.78.0 amplía el acceso opcional a la API, hace más predecibles el apagado del nodo y la limpieza de proveedores, corrige el recuento basado en Conway y Mithril, y fortalece la verificación diferida de encabezados y la resincronización de pares.

### Acceso a la API
* Añadió un complemento de API de Model Context Protocol (MCP) opcional con HTTP Streamable en `/mcp` y SSE en `/sse`. Dingo expone comprobaciones de estado en `/health` y `/healthz`, mientras que las herramientas de solo lectura de SQLite y Cardano y las consultas UTxO reanudables permiten un acceso más seguro a los datos. La autenticación, la limitación de velocidad y la validación del origen protegen las solicitudes, y las vinculaciones que no sean de bucle invertido requieren autenticación y TLS.
