## v0.48.0

**Título:** Descargas Mithril e importación histórica más resistentes

**Versión:** v0.48.0

**Fecha:** 26 de mayo de 2026

- Se puede exponer un endpoint de depuración en un puerto separado durante la sincronización Mithril.
- El tamaño de lote de indexación histórica se configura mediante ajustes o flags para adaptarlo al almacenamiento y la carga local.
- Se detectan las descargas de instantáneas detenidas, se validan pronto los ajustes de reintento y se reanudan las transferencias parciales sin comenzar desde cero.
- Durante importaciones intensivas, los datos históricos acumulados se escriben antes para reducir la presión de memoria.
- Se corrige una condición de temporización al alcanzar el último bloque conocido, evitando que la sincronización quede esperando una actualización posterior.
- Se aplican los procedimientos habituales de actualización de versiones de corrección.
