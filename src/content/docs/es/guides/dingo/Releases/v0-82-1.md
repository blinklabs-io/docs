## v0.82.1

**Título:** Evitar transacciones demasiado grandes durante la recuperación de la base de datos

**Versión:** v0.82.1

**Versión publicada:** [v0.82.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.82.1)

Dingo v0.82.1 mejora la recuperación de bases de datos antiguas al reconstruir el inventario de bloques retenidos en lotes con límites. Esta versión de corrección no requiere cambios en las aplicaciones.

### Compatibilidad de red recomendada ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Recuperación de la base de datos
* Mejoró la recuperación durante el arranque y la recuperación de marcas de tiempo de confirmación para bases de datos antiguas que preceden al inventario de bloques retenidos, ya que Dingo construye la información de búsqueda de bloques retenidos en lotes con límites. Esto evita los errores por superar el tamaño de una transacción cuando una sola transacción no puede contener toda la información de búsqueda, mantiene correctos los recuentos del inventario, las ranuras más antiguas, las relaciones con los sucesores y las búsquedas en conjuntos de datos grandes, y elimina la información de búsqueda obsoleta durante la inicialización.
