## v0.16.0 - generación de certificados y derivación de claves

- **Fecha:** 2026-02-28
- **Versión:** 0.16.0

### Resumen

Esta versión añade comandos para generar certificados de staking y gobernanza Conway, y adapta la derivación de claves raíz de wallets a Cardano `CIP-3` Icarus. También actualiza dependencias y componentes de seguridad.

### ✨ Nuevas funciones

- Se añaden comandos para generar certificados de staking y gobernanza Conway.

### ⛓️‍💥 Cambios incompatibles

- La derivación de claves raíz de wallets sigue ahora Cardano `CIP-3` Icarus (PBKDF2). Es necesario regenerar las claves derivadas y actualizar los vectores de prueba almacenados.

### 🔐 Seguridad

- Se actualizan las dependencias criptográficas y de gestión de secretos: `filippo.io/edwards25519` a `v1.2.0`, `github.com/cloudflare/circl` a `v1.6.3`, `github.com/ethereum/go-ethereum` a `v1.17.0` y `sops` a `v3.12.1`.

### Otros cambios

- Se actualizan módulos Go como `gouroboros`, `plutigo` y `grpc`, la acción `docker/build-push-action` a `v6.19.2` y la imagen base Docker `blinklabs-io/go` a `1.25.7-1`.
- Se actualizan las anotaciones de supresión del linter para algunas comprobaciones de seguridad y se excluye `.worktrees/` en `.gitignore`.
