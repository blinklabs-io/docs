## v0.28.0 - Atestación de claves preparadas con agentes KES de confianza

**Versión:** v0.28.0

### Resumen

Esta versión permite que los operadores que usan un agente KES TLS atestado autoricen la emisión de certificados operativos para claves preparadas sin modificar `opcerts[].kes_vkeys` ni reiniciar Bursa para cada clave.

| preview-testnet     | ✅         |
