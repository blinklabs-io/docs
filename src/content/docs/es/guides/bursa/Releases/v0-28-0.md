## v0.28.0 - Atestación de claves preparadas con agentes KES de confianza

**Versión:** v0.28.0

### Resumen

Esta versión permite que los operadores que usan un agente KES TLS atestado autoricen la emisión de certificados operativos para claves preparadas sin modificar `opcerts[].kes_vkeys` ni reiniciar Bursa para cada clave.

### Compatibilidad de red recomendada ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ Funciones nuevas
* Incorporó `--attestation-out` a `gen-staged-key`, para que un agente KES TLS atestado genere y guarde una atestación firmada de clave preparada.

* Autorizó la emisión de certificados operativos para claves preparadas cuando una atestación válida coincide con un agente de confianza en `opcerts[].kes_agents`.

* Configuró agentes KES de confianza con un pin `spki_sha256` y un `profile` opcional en `opcerts[].kes_agents`.

* Validó la configuración de los agentes KES de confianza al iniciar Bursa para rechazar los pins de autorización no válidos antes de comenzar la operación.

* Rechazó las atestaciones no válidas de claves preparadas durante la emisión de certificados operativos.

* Conservó la ruta de autorización existente mediante `opcerts[].kes_vkeys` para las solicitudes sin atestaciones.
