## v0.24.0 - Comprobaciones de disponibilidad más fiables, perfiles KES seguros y dependencias actualizadas

**Fecha:** 2026-11-12

**Versión:** v0.24.0

**Comparación:** [v0.23.0...v0.24.0](https://github.com/blinklabs-io/bursa/compare/v0.23.0...v0.24.0)

**Versión publicada:** [v0.24.0](https://github.com/blinklabs-io/bursa/releases/tag/v0.24.0)

### Resumen

Esta versión hace más fiables las comprobaciones de disponibilidad de PostgreSQL, añade la selección de perfiles a la atestación KES, actualiza la cadena de herramientas de Go y las imágenes de contenedor, y renueva las bibliotecas `gouroboros` y `plutigo`.

### Compatibilidad de red recomendada ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ Funciones nuevas

* Añadió selectores opcionales `kes_vkey` y de perfil a las solicitudes de atestación del agente KES. Bursa puede servir varios perfiles atestados, vincular cada sesión admitida con el perfil seleccionado, rechazar selectores ambiguos o que no coincidan y devolver `ErrProfileMismatch` cuando una sesión intenta firmar para otro perfil.

### 🔒 Seguridad

* Resolvió la contención entre las comprobaciones de disponibilidad de PostgreSQL al asignar a cada registro un sufijo hexadecimal aleatorio único de 8 bytes. Bursa usa esa clave para actualizar la disponibilidad y revierte la transacción de la base de datos, por lo que las comprobaciones no dejan filas; el comportamiento de SQLite no cambia.

* Fortaleció la seguridad y la coherencia de los flujos de trabajo al actualizar las directivas de Go en los módulos raíz, `armory`, `openapi` y `ui` de `1.26.10` a `1.26.11`; CI ahora usa `1.26.x` o los archivos de versión `go.mod`/`ui/go.mod`, y las imágenes de Go para Docker ahora usan `ghcr.io/blinklabs-io/go:1.27.4-1` en lugar de `ghcr.io/blinklabs-io/go:1.27.3-1`. Esto corrige la vulnerabilidad notificada de `net/http` en `govulncheck` y reduce las diferencias entre los flujos de trabajo.

### Cambios adicionales

* Actualizó `github.com/blinklabs-io/gouroboros` de `v0.218.0` a `v0.219.0` y `github.com/blinklabs-io/plutigo` de `v0.11.5` a `v0.12.1`, para mantener Bursa alineado con estas versiones de biblioteca.
