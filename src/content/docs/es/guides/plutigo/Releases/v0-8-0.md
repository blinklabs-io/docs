## v0.8.0

**Título:** Completar el modelo de costes de Plutus V4 y actualizar la API

**Versión:** v0.8.0

**URL de la versión:** [https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**Comparación:** v0.7.2...v0.8.0

Esta versión completa el modelo de costes publicado de Plutus V4, incorpora herramientas para construir y serializar contextos V4, reorganiza la API de V4 y actualiza el enrutamiento de revisiones y notificaciones del repositorio.

### ✨ Nuevas funciones

* Completó **el modelo de costes publicado de Plutus V4:** Plutigo ahora utiliza el modelo de costes V4 publicado y actualiza los presupuestos CEK correspondientes. La tabla `Policies` usa `AssetCount` con 361 parámetros en lugar de 357, y los nombres `policies-*` coinciden con el modelo publicado.

* Incorporó **constructores y serializadores para contextos V4:** Plutigo ahora puede construir y serializar estos contextos, incluido `NoOutputDatum`, para representar salidas sin datum.

### ⚠️ Cambios incompatibles

* Trasladó **la API de V4 de `plutus/v4` a `lang`:** Los símbolos de `plutus/v4` ahora pertenecen a `lang`. La migración requiere actualizar las importaciones y los nombres de tipo, además de migrar los alias auxiliares `*V4`.

### 📦 Cambios adicionales

* Actualizó **el enrutamiento de revisión y notificaciones:** `.github/CODEOWNERS` ahora dirige las solicitudes de revisión y las notificaciones a `@agaffney` y `@wolf31o2`, sin cambiar el comportamiento en tiempo de ejecución.

### 🙏 Gracias

Gracias por usar Plutigo.
