## v0.8.0

**Título:** Completar el modelo de costes de Plutus V4 y actualizar la API

**Versión:** v0.8.0

**URL de la versión:** [https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**Comparación:** v0.7.2...v0.8.0

Esta versión completa el modelo de costes publicado de Plutus V4, añade herramientas para trabajar con contextos V4, reorganiza la API de V4 y actualiza el enrutamiento de revisiones y notificaciones del repositorio.

### ✨ Nuevas funciones

* Completó **el modelo de costes publicado de Plutus V4:** Plutigo ahora usa el modelo de costes V4 publicado y actualiza los presupuestos CEK asociados. La tabla `Policies` usa `AssetCount` con 361 parámetros en lugar de 357, y los nombres `policies-*` coinciden con el modelo publicado.

* Incorporó **los constructores y serializadores de contexto V4:** Plutigo ahora permite construir y serializar contextos V4, incluido `NoOutputDatum`, para representar salidas sin datum.
