## v0.8.0

**Título:** Completar el modelo de costes de Plutus V4 y actualizar la API

**Versión:** v0.8.0

**URL de la versión:** [https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**Comparación:** v0.7.2...v0.8.0

Esta versión completa el modelo de costes publicado de Plutus V4, incorpora constructores y serializadores de contextos V4, reorganiza la API de V4 y actualiza el enrutamiento de revisiones y notificaciones del repositorio.

### ✨ Nuevas funciones

* Completó **el modelo de costes publicado de Plutus V4 para `Policies` y `AssetCount`:** el vector de parámetros V4 ahora contiene 361 entradas, frente a las 357 anteriores, e incluye los cuatro nombres `policies-*`. Las evaluaciones V4 afectadas ahora generan resultados diferentes en el presupuesto CEK.

* Incorporó **constructores y serializadores para contextos V4:** Plutigo ahora puede construir y serializar contextos V4, y admite `NoOutputDatum` para representar salidas sin datum.

### ⚠️ Cambios incompatibles

* Trasladó **la API de V4 de `plutus/v4` a `lang`:** Los símbolos de `plutus/v4` ahora forman parte de `lang`. La migración requiere actualizar las importaciones y los nombres de tipo con sufijo `V4`, además de sustituir el alias `Data` y las utilidades auxiliares `List`, `Map` y `MapEntry`.

### 📦 Cambios adicionales

* Actualizó **el enrutamiento de revisión y notificaciones:** `.github/CODEOWNERS` elimina a `@agaffney` y deja a `@wolf31o2` como único propietario de las rutas afectadas; este ajuste cambia el enrutamiento de las revisiones y las notificaciones, pero no el comportamiento en tiempo de ejecución.

### 🙏 Gracias

Gracias por usar Plutigo.
