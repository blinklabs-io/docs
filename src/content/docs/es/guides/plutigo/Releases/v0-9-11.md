## v0.9.11

**Título:** Actualizar la cadena de herramientas de Go de Plutigo

**Versión:** v0.9.11

**URL de la versión:** [v0.9.11](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.11)

**Comparación:** [v0.9.10...v0.9.11](https://github.com/blinklabs-io/plutigo/compare/v0.9.10...v0.9.11)

### Compatibilidad de red recomendada ⚠️

| Red | Compatible |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

Esta versión actualiza Go y mejora la fiabilidad al decodificar JSON de PlutusData profundamente anidado, sin modificar los límites de seguridad configurados.

### Cadena de herramientas

* Actualiza la versión de Go de `1.26.8` a `1.26.10`.
* Alinea el análisis automatizado con la versión `1.26.x` de Go.

### Decodificación de JSON

* Mejora la decodificación de JSON de PlutusData válido y profundamente anidado mediante una ruta de decodificación alternativa cuando el decodificador predeterminado alcanza su límite interno de anidamiento, sin dejar de respetar los límites configurados de profundidad máxima y de nodos.
* Estandariza los errores de la decodificación alternativa para que las entradas incompletas produzcan resultados coherentes entre versiones de Go.
* Mantiene estables los errores de `DecodeJSON` cuando el JSON comienza con un valor distinto de un objeto.

### Validación

* Amplía la cobertura de pruebas para errores de decodificación, entradas incompletas, límites de profundidad, valores profundamente anidados y errores estables para entradas profundamente incompletas.
