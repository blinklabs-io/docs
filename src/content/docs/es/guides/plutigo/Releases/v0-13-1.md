## v0.13.1

**Título:** Rechazar de forma coherente las constantes de datos Value

**Versión:** v0.13.1

**Fecha de lanzamiento:** 2026-11-19

**URL de la versión:** [v0.13.1](https://github.com/blinklabs-io/plutigo/releases/tag/v0.13.1)

**Comparación:** [v0.13.0...v0.13.1](https://github.com/blinklabs-io/plutigo/compare/v0.13.0...v0.13.1)

### Compatibilidad de red recomendada ⚠️

| Red                 | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

Esta versión rechaza de forma coherente los datos PlutusData en forma de Value, representados por la etiqueta CBOR `1401` o `V [...]`, durante el análisis, la validación de programas y la codificación FLAT. También detecta ciclos en grafos `ProtoPair` construidos por quien llama durante la validación.

### Rechazar datos Value durante el análisis

* Corrigió el análisis para rechazar los datos PlutusData en forma de Value.

### Rechazar datos Value durante la validación del programa

* Mejoró `ValidateProgram` para los lenguajes de ledger V1–V4, de modo que rechace los datos PlutusData en forma de Value con `errValueData`.

### Rechazar datos Value antes de la codificación FLAT

* Impidió que la codificación FLAT serialice constantes `Data` que contienen datos PlutusData en forma de Value, para que no produzca bytes que no puedan volver a convertirse correctamente.

### Detectar ciclos en grafos ProtoPair

* Añadió la detección de ciclos en la ruta activa para grafos `ProtoPair` construidos por quien llama; la validación devuelve `errCyclicPair` para los grafos cíclicos.

### Cambio incompatible para los flujos de trabajo con datos Value

* Cambió el tratamiento de los datos en forma de Value: los flujos de trabajo que utilizan estas constantes deben reemplazarlas por formas de PlutusData compatibles antes del análisis, la validación del programa o la codificación FLAT.
