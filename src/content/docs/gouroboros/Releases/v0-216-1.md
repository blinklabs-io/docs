## v0.216.1

**Title:** Improve connection setup and transaction validation

**Version:** v0.216.1

This release adds a connection setup deadline, strengthens CBOR decoding, and expands Dijkstra transaction support and validation.

### New Features

* Added a configurable initial handshake setup deadline through `ouroboros.WithHandshakeTimeout`, defaulting to 30 seconds for node to node and node to client connections. A stalled setup now closes the connection and returns an error, while the new deadline remains separate from protocol state timeouts.
* Enabled Dijkstra witness sets to accept, marshal, round trip, and validate PlutusV4 scripts stored at key `8`.

### Bug Fixes

* Hardened CBOR block array decoding to accept only 2 to 5 components, preserve raw component bytes, and use exact header widths for offsets. Streaming offsets, transaction offsets, and block body size helpers now reject malformed or trailing encodings deterministically.
* Included auxiliary native scripts when `MaryTransaction.Cbor` calculates transaction fees and maximum transaction sizes.
* Restricted indefinite length fixed size CBOR array validation to the expected number of elements. Malformed counts, break markers, truncated data, and trailing bytes now produce deterministic errors.
* Corrected Dijkstra pool certificate and certificate deposit state across transaction levels. Validation now preserves VRF ownership, includes earlier effects when checking deposits, skips the relevant checks for phase 2 invalid transactions, and maintains the correct order for nested stake deposits.
