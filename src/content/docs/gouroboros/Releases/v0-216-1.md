## v0.216.1

**Title:** Improve connection setup and transaction validation

**Version:** v0.216.1

This release improves connection setup controls, strengthens CBOR decoding, and expands Dijkstra transaction support and validation.

### New Features

* Added a configurable initial handshake setup deadline through `ouroboros.WithHandshakeTimeout`, with a default of 30 seconds for node to node and node to client connections. A stalled setup now closes the connection and returns an error, while the new deadline remains separate from protocol state timeouts.
* Enabled Dijkstra witness sets to accept, marshal, round trip, and validate PlutusV4 scripts at key `8`.

### Bug Fixes

* Hardened CBOR block array decoding to accept only 2 to 5 components, preserve raw component bytes, and use exact header widths for offsets. Streaming offsets, transaction offsets, and block body size helpers now reject malformed or trailing encodings deterministically.
* Included auxiliary native scripts when `MaryTransaction.Cbor` calculates transaction fees and maximum transaction sizes.
