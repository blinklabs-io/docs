## v0.202.2（2026年8月27日）

**タイトル:** 台帳のデコードとコンセンサス検証を改善

**日付:** 2026年8月27日

**バージョン:** v0.202.2

このリリースでは、不正なトランザクションデータと origin ブロックの台帳デコードを改善し、Byron の信頼性および時間設定の検証を強化します。

### 💪 改善

* 改善 **不正なトランザクションデータの処理:** `ApplyTxError.UnmarshalCBOR` は短い `UtxowFailure` 配列を検証し、`OutsideValidityIntervalUtxo.Error` はデコードした値の型と長さを検証します。また、`ledger.GetTxBodies` はインデックス参照前に空のトランザクション行を拒否します。これらのチェックはパニックの代わりに説明的なエラーを返し、不正な形状に対する回帰テストも追加されています。

* 修正 **origin ヘッダーのデコード:** Shelley、Allegra、Mary、Alonzo のヘッダー本体デコーダーは、origin ブロックの `prev_hash` に CBOR の `null` を指定した場合に、ゼロ値の `Blake2b256` として受け入れます。一方、null 以外のハッシュと不正なエンコードに対する厳密な検証は維持されます。

* 強化 **Byron の信頼性および時間設定の検証:** `ComputeGenesisWindow` と `NewGenesisSelector` はエラーを返すようになりました。ネットワーク設定では security、coefficient、slot duration、epoch、KES などの範囲を検証し、Byron の検証では空の genesis trust root を `ErrGenesisIssuerSetEmpty` として拒否します。また、`cbor.Rat` の JSON デコードでは分母が 0 の値を拒否します。呼び出し側は変更された API シグネチャのエラーを処理する必要があります。
