## v0.221.0

**タイトル:** 順序を改善し、オプトイン方式の BlockFetch 圧縮を追加

**リリース日:** 2026-11-22

**バージョン:** v0.221.0

このリリースでは、MIR UTxO-RPC の target 順序を安定させ、UPLC の検証を強化し、互換性のある Dijkstra node-to-node protocol version 向けに、実験的でデフォルトでは無効なオプトイン方式の BlockFetch 圧縮を追加します。また、補助依存関係と CI action を更新します。

### 新機能

* 追加: 互換性のある Dijkstra node-to-node protocol version 向けに、実験的でデフォルトでは無効なオプトイン方式の CIP-0150 BlockFetch 圧縮を追加します。アプリケーションは raw または Zstandard 圧縮 block message をオプトインできます。protocol は decompression の範囲を制限し、各 range に byte budget を適用し、client と server の両方で処理できます。
