## v0.221.0

**タイトル:** 順序を改善し、オプトイン方式の BlockFetch 圧縮を追加

**リリース日:** 2026-11-23

**バージョン:** v0.221.0

このリリースでは、MIR UTxO-RPC の target 順序を安定させ、UPLC の検証を強化し、互換性のある Dijkstra node-to-node protocol version 向けに、実験的でデフォルトでは無効なオプトイン方式の BlockFetch 圧縮を追加します。また、補助依存関係と CI action を更新します。

### 新機能

* 追加: 互換性のある Dijkstra の node-to-node protocol version 向けに、実験的でデフォルトでは無効なオプトイン方式の CIP-0150 BlockFetch 圧縮を追加します。アプリケーションはオプトインして raw または Zstandard 圧縮の block message を利用できます。protocol は decompression に上限を設け、各 range に byte budget を適用し、client と server の双方で処理できます。

### バグ修正

* 安定化: ledger credential の順序で target を sort することで MIR UTxO-RPC reward target の順序を安定させます。script target は key target より前になり、hash は昇順に並びます。

* 拡張: `plutigo` を v0.13.0 に更新し、未対応 UPLC version の coverage を強化します。また、canonical cost-model alias と parameter count を検証し、従来の legacy boundary を維持します。

### その他の変更

* 更新: `ouroboros-mock` を v0.21.3 に、間接依存の `go.yaml.in/yaml/v3` を v3.0.6 に更新します。

* 改良: `github.com/klauspost/compress` を v1.20.3 から v1.20.4 に更新します。

* 最新化: CI workflow で固定している `actions/setup-go` の version を v7.0.0 から v7.1.0 に更新します。設定済みの Go version は変更しません。
