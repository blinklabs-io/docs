## v0.186.3

**タイトル:** Conway witness の重複許容と lint 更新

**日付:** 2026年7月6日

**バージョン:** v0.186.3

過去の Conway ブロックで許容される witness の重複に対応し、GitHub Actions の lint を更新します。

### 改善

- `ConwayTransactionWitnessSet.UnmarshalCBOR` は Conway プロトコルバージョン 9～11 の tag-258 フィールドについて、vkey witness、bootstrap witness、ネイティブスクリプト、Plutus データの重複を許容します。これらで過去のブロックが `duplicate member in set` により失敗することを防ぎます。Plutus V1/V2/V3 スクリプト集合の重複は引き続き拒否します。
- `golangci/golangci-lint-action` を `9.2.1` から `9.3.0` に更新しました。影響は CI の lint 出力と動作に限られます。

gOuroboros のリリースをフォローしていただきありがとうございます。
