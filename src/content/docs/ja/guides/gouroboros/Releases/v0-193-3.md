## v0.193.3（2026年8月17日）

**タイトル:** 依存関係とメインネットのブートストラップ処理を更新

**日付:** 2026年8月17日

**バージョン:** v0.193.3

このリリースでは、主要な依存関係を更新し、Cardano メインネットから emurgo のブートストラップピアを削除し、Shelley および Conway の genesis データに対する Leios genesis の解析を強化します。

### 改善

* 更新 **コア依存関係:** `github.com/blinklabs-io/ouroboros-mock` を `v0.15.1` から `v0.16.0` に、`golang.org/x/crypto` を `v0.54.0` から `v0.55.0` に、`github.com/stretchr/testify` を `v1.11.1` から `v1.12.0` に更新しました。`examples/ping` モジュールも更新しました。

* 削除 **Cardano メインネットの emurgo ブートストラップピア:** デフォルトのメインネットピアセットから削除しました。

* 修正 **Leios genesis の extraConfig 解析:** Shelley および Conway の genesis 処理で、初期化前に安全でない extraConfig 値を拒否するようになりました。

### 感謝

gOuroboros のリリースを確認いただきありがとうございます。
