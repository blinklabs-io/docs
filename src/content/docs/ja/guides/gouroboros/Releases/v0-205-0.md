## v0.205.0

**タイトル:** 認証、終了処理、デコードを改善

**バージョン:** v0.205.0

v0.205.0 では、メッセージ認証、プロトコルの終了処理、メタデータと台帳データの検証、UTxO-RPC 変換、接続ライフサイクルを改善します。

### 🐛 バグ修正

* 改善 **メッセージ認証:** `MessageAuthenticator` は `StakeAuthority` を必須とし、28 バイトの Blake2b-224 `PoolKeyHash` を導出して処理中に KES を検証します。ゼロの stake を拒否し、KES period のオーバーフローを防ぎ、認証情報がない場合は関連する DMQ パッケージを fail closed にします。

* 修正 **終了メッセージの配信:** コンテキスト対応の配信待機により、`BlockFetch` と `ChainSync` の `Stop` は終了メッセージの配信を最大 250 ミリ秒待機し、配信エラーを返します。

* 保持 **メタデータの重複キー:** ネストしたメタデータマップは重複キーを保持し、外側の auxiliary data のラベルマップは引き続き重複を拒否します。
