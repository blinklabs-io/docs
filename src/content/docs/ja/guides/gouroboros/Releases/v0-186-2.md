## v0.186.2

**タイトル:** Conway と Dijkstra の厳格な検証を保ち、古いデータの互換性を改善

**日付:** 2026年7月5日

**バージョン:** v0.186.2

Conway より前のデータとの互換性を改善し、不正な Conway と Dijkstra データへの厳格な検証を維持します。

### 新機能と改善

- Conway と Dijkstra の対象となる witness、body、サブトランザクション、guard のタグ付き集合で、重複要素をデコード時に拒否します。
- Conway より前の MultiAsset CBOR の重複マップキーは、最後の値を優先して受け入れ、古いチェーンの同期とデコードの互換性を改善します。
- Conway と Dijkstra のトランザクションでは、引き続きデコード後に重複 MultiAsset キーを拒否し、曖昧な状態を生成しません。
