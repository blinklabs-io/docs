## v0.209.1

**タイトル:** 台帳検証、Plutus 対応、依存関係の一貫性を改善

**バージョン:** v0.209.1

このリリースでは、Dijkstra のトランザクションと証明書の検証を強化し、MIR の転送ルールを適用し、Plutus V4 の対応を拡張し、ネイティブスクリプトの処理を改善しました。また、例の依存関係管理をルートモジュールと統一しました。

### バグ修正
* 修正: Dijkstra ブロックのトランザクションデコードで末尾の `is_valid` 値を読み取り、無効なトランザクションを報告し、値がない場合やブール値でない場合を拒否するようにしました。
* 是正: MIR 証明書のエンコードとデコードで 2 要素の source と target の配列形式を使用し、source ポットと target を検証し、形式が不正な報酬マップと重複する credential キーを拒否し、credential の判別値を安全に処理するようにしました。
* 強化: MIR の保留報酬と転送ルールを適用し、Alonzo より前のポット転送と負の差分を拒否するとともに、Alonzo 以降の負の差分を以前のブロック、同一トランザクション、同一ブロック内の変更による保留報酬の範囲内に制限しました。
* 改善: ネイティブ評価中に不要な witness ネイティブスクリプトをスキップして witness 検証へ送るようにしました。Byron の出力インデックスは構築時と CBOR デコード時に `0` から `65,535` の範囲に収まります。

### 追加変更
* 拡充: rewarding、spending、guarding、プロトコルバージョン、サブトランザクションレベルにまたがる Plutus V3 の通常入力と参照入力の重複について、Dijkstra の回帰テスト範囲を拡張しました。
* 更新: モック台帳のフィクスチャとプロトコルモデリング依存関係を、互換性のある最新バージョンに更新しました。
* 導入: Plutus V4 のスクリプトコンテキストビルダーを更新し、Plutus V4 の CEK コストテーブルを完成させました。
* 統一: 例のビルドでルートモジュールを使用するようにし、ルートの依存関係更新をすべての例へ自動的に適用し、ルートのビルド、テスト、lint の対象に例を含めました。
