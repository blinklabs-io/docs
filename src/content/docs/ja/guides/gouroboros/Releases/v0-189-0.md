## v0.189.0

**タイトル:** Byron EBB デコードと運用証明書カウンター

**日付:** 2026年7月22日

**バージョン:** v0.189.0

不正な Byron EBB のデコードを修正し、LocalStateQuery に型付きの運用証明書カウンターアクセスを追加します。

### 改善

- `ByronEpochBoundaryBlock.UnmarshalCBOR` は、デコードしたヘッダーが `nil` ならエラーを返します。後からパニックするブロックを作らず、早期に拒否します。
- `DebugChainDepState` を運用証明書カウンターにデコードし、型付き API `GetOpCertCounters` で取得できます。
- 利用者向けの動作を変えずに CBOR 実装を更新しました。
- リポジトリから issue-closed ワークフローの自動化ファイルを削除しました。

gOuroboros のリリースをフォローしていただきありがとうございます。
