## v0.206.0

**タイトル:** 投票拡散の予約を追加し、ブートストラップのパラメーター変更を許可

**バージョン:** v0.206.0

このリリースは、Peras 投票拡散プロトコル番号を予約し、Conway と Dijkstra のブートストラップ検証で、より広いパラメーター変更を許可します。

### 新機能
* 追加 **Peras 投票拡散プロトコル番号の予約:** `protocol/perasvotes` は CIP-0140 用に `peras-vote-diffusion` とプロトコル番号 `17` を登録します。この予約は番号だけを登録し、ハンドラー、ステートマシン、メッセージ、ワイヤーフォーマットを提供しません。

### 破壊的変更
* 緩和 **ブートストラップのパラメーター検証:** Conway と Dijkstra の `ParameterChange` アクションは、ブートストラップ中に更新するプロトコルパラメーター項目のフィールド単位の検証を必要としなくなりました。一方、実装はガバナンスアクション種別のチェックを維持します。Conway ブートストラップの PV9 では、正規の `DRepDeposit` 更新をリプレイしても処理は停止しません。削除された `bootstrap-parameter-groups` ルールと関連するエクスポート済みヘルパーおよびエラー識別子の利用者は、残るブートストラップ検証へ移行する必要があります。
