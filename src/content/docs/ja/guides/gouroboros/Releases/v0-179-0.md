## v0.179.0

**タイトル:** LeiosVotes 対応とリリース履歴の明確化

**日付:** 2026年5月27日

**バージョン:** v0.179.0

v0.179.0 の変更点です。

### 新機能と改善

- Node-to-Node で `CIP-0164` 投票を処理する専用の LeiosVotes フローを追加し、投票の受信と配信に対応しました。
- 接続単位のアクセスと設定オプションで投票フローを利用でき、他の Leios プロトコルと併せて有効にできます。
- サンプルコマンドを `examples/` の独立したモジュールに配置し、ビルド、テスト、lint、ローカル実行を管理しやすくしました。

### 確認事項

- タグ付けの誤りにより `v0.171.0` と `v0.178.0` の間のバージョンは公開されなかったことを、公開履歴で明記しました。
- ソースの履歴で、構造化した `v0.178.0` の項目を `v0.179.0` の直前に追加しました。
