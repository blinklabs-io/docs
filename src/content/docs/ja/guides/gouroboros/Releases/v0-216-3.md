## v0.216.3

**タイトル:** プロトコルの信頼性とデコードの安全性を改善

**バージョン:** v0.216.3

このリリースでは、ローカルプロトコル処理、ブロックデコード時のメモリ使用量、クエリの正規エンコード、チェーン検証、再起動からの復旧、Dijkstraのデータム検証、信頼できない入力への防御を改善しました。

### 新機能

* 改善: LocalTxMonitorのメンプール確認で、トランザクションの解析を`HasTx`まで遅延し、トランザクションIDをキャッシュします。スナップショット間で不要なIDを削除し、`Release`でキャッシュを消去し、生のIDバイト列を比較し、解析エラーにトランザクションのインデックスとEraを含めます。

* 削減: Shelley系ブロックヘッダーのデコードで、ヘッダー本体とバイト列フィールドがCBORのバッキングストレージを共有するようにし、保持されるメモリを減らしました。共有されるバイト列は不変として扱い、変更する場合は事前にコピーしてください。

* 正規化: local state queryのプールID集合を、ソート済みの一意なIDによるtag `258`の確定長配列としてエンコードします。`10,000`個を超える集合を拒否し、空の`GetStakePoolParams`のエンコードも更新しました。

### バグ修正

* 検証: ブロック単位の検証でByronのメインチェーンおよびエポック境界のボディプルーフを検証し、ByronではETA0の検索をスキップします。

* 保持: chainsync、blockfetch、txsubmission、peersharing、leiosnotify、leiosfetch、leiosvotesの各サーバーミニプロトコルが再起動したとき、クライアントが最初に送信したメッセージを保持します。

* 拡張: top-level Dijkstra supplemental datumの正当性確認で、サブトランザクションの出力、collateral return、reference inputのUTxOを根拠として使用できるようにしました。サブトランザクションの分離と従来モードの動作は維持します。

* 制限: 認識されたpredicate failureのフィールドリストを割り当て前に`16`個までに制限し、未知のコンストラクターは生のCBORとして保持します。

* 修正: TPraosの`DebugChainDepState`を実際のレイアウトに従ってデコードし、epoch、previous epoch、lab nonceを返すようにし、不正なフィールドを拒否します。

* 効率化: metadata JSON変換でエラーパスを遅延して生成し、変換に成功した場合の割り当てを減らしながら、エラーのテキストとラッピングを維持します。

* 強化: `cbor.Rat`のdistribution replyデコードを2要素に制限し、整数形式とbignum形式を検証して、大きな割り当ての前に不正な有理数入力を拒否します。
