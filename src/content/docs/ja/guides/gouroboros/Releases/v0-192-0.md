## v0.192.0

**タイトル:** スクリプトコンテキストの一貫性と使用済み鍵の消去

**日付:** 2026年8月6日

**バージョン:** v0.192.0

プロトコルバージョン間で台帳出力を一貫させ、使用済みの鍵を消去します。

### 改善

- Plutus V1/V2 の `txInfoMint` に、常に 0 ADA の mint 項目を含めます。
- 使用済みの進化鍵をメモリから消去し、消去済みの鍵による署名や更新要求は直ちに拒否します。
