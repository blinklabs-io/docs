## v0.212.6

**タイトル:** レジャーのデコードと依存関係の互換性を改善

**バージョン:** v0.212.6

このリリースでは、ブートストラップ・ウィットネスの検証をネットワーク Era に合わせ、暗号および CBOR ライブラリを更新して、上流の修正とより厳格なデコード動作を取り込みます。

### 破壊的変更
* 改善しました。ブートストラップ・ウィットネスのデコードで、32 バイトのチェーンコード要件がネットワーク Era に応じて適用されるようになりました。Dijkstra トランザクションは、31 バイトおよび 33 バイトのチェーンコードを `bootstrap witness chain code must be 32 bytes` というエラーで拒否します。一方、公開鍵は 32 バイト、署名は 64 バイトのままです。これにより、トランザクションのデコードとコンセンサス動作が一致します。

### 追加変更
* 更新しました。`github.com/consensys/gnark-crypto` を `0.21.0` から `0.22.0` に更新し、`bitset` と Go のバージョン設定も `1.26.5` から `1.26.8` に更新しました。この更新には、上流の暗号パラメーターおよびジェネレーターの修正、生成アーティファクトに影響する互換性変更、検証およびセキュリティ修正が含まれます。

* 改訂しました。`go.mod` と `go.sum` の `github.com/fxamacker/cbor/v2` を `2.9.4` から `2.9.6` に更新しました。この更新により、CBOR の null キーおよび値に対する古い Go map エントリを解消し、CBOR の null および undefined 値に対してインターフェースを `nil` に設定し、より厳格なデコードエラーを返すようになります。
