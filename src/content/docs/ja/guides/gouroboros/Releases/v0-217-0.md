## v0.217.0

**タイトル:** chainsync のライフサイクル制御を追加し、台帳処理を改善

**バージョン:** v0.217.0

このリリースでは、chainsync の明示的なライフサイクル制御を追加し、Shelley メタデータ検証のネスト制限を緩和し、台帳のプルーフ選択と Plutus 処理を改善し、DMQ エンコーディングを dmq-node 0.7.2.1 に合わせます。

### 新機能

* `Client.Reintersect(points)` と `Client.StopAfterDrain(ctx)` を公開し、同一接続でライフサイクルを安全に切り替えられるようにしました。どちらも未処理の `MsgRequestNext` 応答を排出してから、それぞれ `MsgFindIntersect` または `MsgDone` を送信します。

### バグ修正

* Shelley UTxO メタデータ検証から 64 レベルのネスト制限を削除し、テキストとバイト列のリーフに対する 64 バイト制限は維持しました。
* プールプルーフのドメイン選択を台帳状態に基づくように修正しました。
* DMQ のローカル応答と拒否理由の CBOR エンコーディングを、dmq-node 0.7.2.1 のデコード要件に合わせました。
