## v0.205.4

**タイトル:** トランザクション入力の比較性能を改善

**バージョン:** v0.205.4

このリリースは、照合動作を変えずに、ネストした入力照合での台帳検証を効率化します。

### その他の変更

* 改善 **トランザクション入力の照合:** `ResolvedInput.Equals` はトランザクション ID とインデックスで入力を直接比較し、`expandInputs` と spend-redeemer の解決処理がこのヘルパーを使用することで、台帳検証中の繰り返しアロケーションを削減します。照合動作は変わりません。
