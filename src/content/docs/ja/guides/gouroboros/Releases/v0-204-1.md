## v0.204.1

**タイトル:** 接続終了、プール識別、メタデータ検証を改善

**バージョン:** v0.204.1

このリリースでは、接続終了の動作、プール証明書の識別、ChainSync コールバックからの接続完了確認、プールメタデータハッシュのデコード、BlockPipeline の信頼性テスト、メタデータ JSON のネスト制限を改善しました。
