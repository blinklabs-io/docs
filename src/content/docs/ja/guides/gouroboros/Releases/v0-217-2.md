## v0.217.2

**タイトル:** トランザクション検証とネイティブスクリプトの相互運用性を改善

**バージョン:** v0.217.2

このリリースでは、トランザクション検証の効率を高め、構築したネイティブスクリプトのエンコーディングを Haskell のシリアライズに合わせ、リポジトリのフォーマットを標準化してチェックの信頼性を高めます。

### パフォーマンス

* 改善しました。各トランザクションの準備済みスクリプトビューを再利用し、処理中の作業、以前のエラー、部分結果も含めて、同じデータの再構築を避けることでトランザクション検証の効率を高めました。外部の検証ループでは `NewTransactionScopedLedgerState` と `IsTransactionScopedLedgerState` を使用して、この共有状態を利用できます。

### バグ修正

* 修正しました。構築したネイティブスクリプトのエンコーディングを Haskell のシリアライズ規則に合わせました。空の子リストは `0x80` を使用し、子が 0～23 個のリストは確定長配列を、24 個以上のリストは不定長リストを `all`、`any`、`n-of-k` スクリプトで使用します。インポートしたスクリプトは元のバイト列とハッシュを保持しますが、新しく構築したスクリプトでは 23/24 の境界によって異なるハッシュや派生アドレスになる可能性があります。

### 追加変更

* 標準化しました。`golines` でリポジトリのフォーマットを整え、再フォーマット後も `gosec` の抑制アノテーションを `gosec` が認識できる位置に戻しました。ランタイムや API の動作は変更せず、lint と test のチェックの信頼性を維持します。
