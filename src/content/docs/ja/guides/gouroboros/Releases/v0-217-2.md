## v0.217.2

**タイトル:** トランザクション検証とネイティブスクリプトの相互運用性を改善

**バージョン:** v0.217.2

このリリースでは、トランザクション検証の効率を高め、構築したネイティブスクリプトのエンコーディングを Haskell のシリアライズに合わせ、リポジトリのフォーマットを標準化してチェックの信頼性を高めます。

### パフォーマンス

* 改善しました。各トランザクションの検証で準備済みスクリプトビューを再利用し、処理中の作業や以前のエラー、部分結果を含む共有状態を保持して、同じデータを再構築せずに済むようにしました。外部の検証ループでは `NewTransactionScopedLedgerState` と `IsTransactionScopedLedgerState` を使用して、この共有状態を利用できます。

### バグ修正

* 修正しました。構築したネイティブスクリプトのエンコーディングを Haskell のシリアライズ規則に合わせました。空の子リストは `0x80` を使用し、子が 0～23 個のリストには確定長配列を、24 個以上のリストには不定長リストを `all`、`any`、`n-of-k` スクリプトで使用します。インポートしたスクリプトは元のバイト列とハッシュを保持しますが、新しく構築したスクリプトでは 23/24 の境界によって異なるハッシュや派生アドレスになる可能性があります。

### 追加変更

* 標準化しました。`golines` でリポジトリのフォーマットを整え、再フォーマット後も `gosec` の抑制アノテーションを認識可能な位置に戻しました。ランタイムや API の動作は変更せず、lint と test のチェックの信頼性を維持します。
