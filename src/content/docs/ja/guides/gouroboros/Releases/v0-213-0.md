## v0.213.0

**タイトル:** プロトコル互換性と検証保護の拡張

**バージョン:** v0.213.0

Node-to-Client 互換性、クエリ、トランザクション監視を拡張し、Dijkstra/Leios を 2026w41 リリース候補に合わせ、検証、リソース制限、メッセージ処理、CI 出力の安全性を強化します。

### 新機能

- Node-to-Client `22`/`23` を追加し、交渉したバージョンに応じて Shelley LocalStateQuery を許可します。新しいクエリ API と型、`LedgerPeerSnapshot` とピア種別要求のワイヤーバージョンを追加し、コーデックを整合させ、入れ子の `GetCBOR` デコードを制限します。
- MessageSubmission の要求と返信を対応付け、ID、件数、ウィンドウを検証します。送信失敗時も保留要求を保持し、要求/返信の規則を文書化しました。
- LocalTxMonitor の返信をアクティブなクエリに対応付け、`HasTx` ID を 32 バイトちょうどに制限し、終了時に待機中の呼び出しを安全に解除します。
- ノンブロッキングの返信が進行中でも、TxSubmission2 の `RequestTxIds` と `RequestTxs` をパイプライン処理し、返信順序を保持します。

### 互換性に影響する変更

- コンセンサスヘッダー検証には、正規の運用証明書カウンター状態が必要です。ロールバックと CPraos の省略を拒否し、完全な検証後にのみ次のカウンターを返します。コンセンサス状態を提供するアプリは、この正規のカウンター状態も渡す必要があります。
- パイプラインに正規のブロック型の結び付けと、順序に従う状態付き検証を必須にしました。曖昧または未検証のピアブロック経路を拒否し、ChainSync/BlockFetch が不正なデータを越えて進まないよう、終了とエラー動作を変更しました。
- エンドーサーブロックのエンコード、厳格な認証と所有証明、Plutus V4 リスト、`TopTxInfo`、CDDL とベクターを含め、Dijkstra/Leios を 2026w41 リリース候補に合わせました。
- 正規のエポック、ガバナンス、将来のプール、プロトコルパラメーター状態がない場合、コンセンサス検証は拒否します。各状態不足に型付きエラーを追加しました。
- ビルドと実行には Go 1.26.6 以降が必要です。

### セキュリティ

- LeiosVotes の `Vote` を 256 バイト、受信保留データを 16 KiB に制限し、バックプレッシャーを適用して生 CBOR の重複保持を避けます。
- プロトコルデコーダーでコレクション数と入れ子の事前上限、および要求ごとの応答予算を適用します。LeiosFetch/LeiosNotify に終了とキャンセルメッセージを追加し、割り当て回帰テストを拡充しました。
- Cardano 診断フォーマッターで `MaxDepth` と `MaxArrayItems` を強制し、深すぎるデータや要素数の多すぎるデータを無制限に描画せず省略します。

### その他

- DMQ とローカルメッセージ通知を認証し、重複排除します。デコードを制限し、キューのメッセージを複製して、接続とプロトコルの終了を改善しました。
- CI ベンチマークコメントを安全にエスケープし、メンションを無効化して、サイズ上限と切り詰めを適用します。
