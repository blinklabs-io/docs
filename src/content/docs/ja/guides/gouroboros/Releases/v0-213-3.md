## v0.213.3

**タイトル:** Cardano の有限 E34 述語にコンセンサスのリーダー適格性を一致

**バージョン:** v0.213.3

このリリースでは、コンセンサスのリーダー選出とヘッダー検証を Cardano の固定された有限 E34 算術に一致させ、CPraos と TPraos に対応した評価を追加し、従来のしきい値 API を削除しました。

### 新機能

* 導入しました。`NewLeaderEligibility(poolStake, totalStake, f, mode)` に CPraos と TPraos のモードを追加し、リーダー適格性の評価を準備できるようにしました。

* 一致させました。リーダー選出を従来の理想的な実数のしきい値ではなく Cardano の有限 E34 述語に基づくようにし、限定された比較器と BELOW の場合だけ選出する判定によって固定された有限算術に従うようにしました。

* 提供しました。不変の準備済み評価器と `CheckCertifiedNatural` および `CheckVRFOutput` を追加しました。リーダー選出とヘッダー検証はこの評価器とモード固有の VRF natural 導出を使用します。

* 改善しました。準備済み評価器の状態を、上限 4096 件のミューテックス保護された LRU キャッシュに保存して、繰り返し行う適格性評価を効率化しました。

### バグ修正

* 検証しました。active-slot coefficient の値域を検証し、`poolStake` が `totalStake` を超える場合は上限を `totalStake` に設定し、ステークがゼロの場合は適格でないゼロ値の結果を返すようにしました。
