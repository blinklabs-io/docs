## v0.182.0

**タイトル:** Conway ガバナンス、クエリ文書、32 ビット互換性

**日付:** 2026年6月9日

**バージョン:** v0.182.0

v0.182.0 は、32 ビットビルドを復旧し、主要な依存関係、ガバナンスクエリのサンプルと説明、および Conway ガバナンスデータの作成を改善します。

### 新機能

- Conway のガバナンスアクションと提案手続きのヘルパーは、正しいアクション型を自動選択し、不正な入力を早期に拒否します。
- Conway ガバナンスクエリのサンプルと説明を拡充しました。

### 改善とその他

- 32 ビット向けのビルドを復旧しました。
- 主モジュールとサンプルの `plutigo` を v0.1.15 に揃えました。
- テストとモックの `ouroboros-mock` を v0.12.0 に更新しました。
- ビルドワークフローの actions/checkout を v6.0.3 に更新しました。
- 以前の v0.181.0 のリリースノートを公開履歴に追加しました。
