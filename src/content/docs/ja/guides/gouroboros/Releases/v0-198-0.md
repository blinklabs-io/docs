## v0.198.0（2026年8月25日）

**タイトル:** 台帳検証とトランザクションエンコーディングを強化

**日付:** 2026年8月25日

**バージョン:** v0.198.0

このリリースでは、台帳の検証を改善し、再構築されたトランザクションが元々送信されたデータと一致するようにします。

### 💪 改善

* 修正 **Conway データ検証:** 台帳のデコードで、null または undefined の値、許可されたカテゴリ外の値、空のガバナンスレコード、キーの欠落、Conway および Dijkstra でサポートされない証明書タイプを拒否するようになりました。

* 保持 **Shelley と Allegra のトランザクションデータ:** 再構築されたトランザクション本体と共有ウィットネスセットは元のエンコードデータを保持するため、Alonzo より前の不正確な手数料や最大トランザクションサイズの検査につながるデータサイズの増大を防ぎます。

* 強化 **Plutus スクリプト検証:** V3 と V4 のラッパーは完全なラッパーの後にあるデータを拒否するようになりました。V1 と V2 の動作は従来どおりです。
