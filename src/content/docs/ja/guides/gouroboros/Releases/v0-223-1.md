## v0.223.1

**タイトル:** リクエスト相関とシャットダウン完了を改善

**リリース日:** 2026-11-28

**バージョン:** v0.223.1

このリリースでは、protocol の再起動をまたいだ transport write の相関を改善し、シャットダウン時に完了通知の公開を待機するようにします。破壊的変更はなく、CLI、設定、インストール要件にも変更はありません。

### 新機能

* 追加: `Client.WriteObservationSession()` を追加しました。transport write record の識別子を返し、その識別子は protocol の再起動後も維持されます。recording が無効な場合はゼロになります。

### バグ修正

* 改善: callback の request ID と transport write record を対応付けられるようにし、connection address の再利用時や protocol の再起動後もリクエストを相関できるようにしました。

* 修正: protocol のシャットダウンが、戻る前に protocol loop と完了通知の公開の両方を待機するようにしました。公開された完了通知を context cancellation より優先します。

* 防止: シャットダウンと `StopForRestart` が完了通知の公開前に戻らないようにし、シャットダウン競合を減らして `DoneChan` が開いたままになることを防ぎます。
