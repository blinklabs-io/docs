## v0.202.0（2026年8月26日）

**タイトル:** 台帳の互換性と検証を改善

**日付:** 2026年8月26日

**バージョン:** v0.202.0

このリリースでは、リリース済みの Plutigo の動作との互換性を高め、トランザクションの有効期間境界を適用し、従来のコストモデルデータを保持し、origin ブロックヘッダーを正しくデコードします。

### 💪 改善

* 改善 **Plutigo 互換性:** 台帳はリリース済みの Plutigo API に準拠し、例とテストも互換性のある依存関係のバージョンを使用して、ビルドとテストの一貫性を保ちます。

* 強化 **有効期間の上限の適用:** 台帳は、トランザクションの上限が現在のスロット以下の場合、そのトランザクションを拒否し、サポート対象のすべての台帳時代で排他的な上限を適用します。

* 保持 **従来のコストモデルマップ:** Alonzo genesis 設定は従来のパラメータの順序と名前を維持し、両方の形式がある場合は現行の値を優先し、短い有効な定義も受け入れます。

* 修正 **origin ブロックヘッダーのデコード:** Babbage family の origin ヘッダーでは、null の previous hash を zero hash として扱い、デコーダーは不正な null 以外のハッシュを引き続き拒否します。
