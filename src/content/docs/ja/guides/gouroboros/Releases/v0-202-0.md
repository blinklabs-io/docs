## v0.202.0（2026年8月26日）

**タイトル:** 台帳の互換性と検証を改善

**日付:** 2026年8月26日

**バージョン:** v0.202.0

このリリースでは、リリース済みの Plutigo の動作に合わせて台帳の互換性を改善し、トランザクションの有効期間境界を適用し、従来のコストモデルデータを保持し、origin ブロックヘッダーを正しくデコードします。

### 💪 改善

* 改善 **Plutigo 互換性:** 台帳はリリース済みの Plutigo API に従い、例およびテストでは互換性のある依存関係のバージョンを使用することで、ビルドとテストの一貫性を保ちます。

* 強化 **有効期間の上限の適用:** トランザクションは、上限が現在のスロットと等しいかそれより前の場合に検証に失敗し、サポート対象のすべての台帳時代で排他的な上限の動作に従います。

* 保持 **従来のコストモデルマップ:** Alonzo genesis 設定は従来のパラメータの順序と名前を保持し、両方の形式が存在する場合は現行の値を優先し、より短い有効な定義も受け入れます。
