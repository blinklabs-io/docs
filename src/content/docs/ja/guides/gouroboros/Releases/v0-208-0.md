## v0.208.0

**タイトル:** プロトコル検証と互換性を拡張

**バージョン:** v0.208.0

このリリースでは、コンセンサス、台帳、ネットワーク、アプリケーション統合におけるプロトコル対応を拡張し、検証を強化して互換性を改善しました。

### 機能
* 導入 Peras 投票の拡散を、ノードがノード間 v16 サポートをネゴシエートした場合に有効にし、Leios ワイヤータグを厳格なタグおよび型デコードに合わせました。また、利用できないデータにはプロトコルエラーを返し、BlockRange の応答を既定で 1,000 件または 64 MiB に制限し、5 秒の停止タイムアウトを設定しました。
* 拡張 Dijkstra の `MaxPledgeLeverage` と PV13 で有効になる `MinPoolMargin` の報酬制約を追加し、パラメータ範囲を検証しながら、Dijkstra より前の動作を維持しました。
