## v0.208.0

**タイトル:** プロトコル検証と互換性を拡張

**バージョン:** v0.208.0

このリリースでは、コンセンサス、台帳、ネットワーク、アプリケーション統合におけるプロトコル対応を拡張し、検証を強化して互換性を改善しました。

### 機能
* 導入 Peras 投票の拡散を、ノードがノード間 v16 サポートをネゴシエートした場合に有効にし、Leios ワイヤータグを厳格なタグと型のデコードに合わせました。利用できないデータにはプロトコルエラーを返し、BlockRange の応答を既定で 1,000 件または 64 MiB に制限し、5 秒の停止タイムアウトを設定しました。
* 拡張 Dijkstra の `MaxPledgeLeverage` と PV13 で有効になる `MinPoolMargin` の報酬制約を追加し、パラメータ範囲を検証しながら、Dijkstra より前の動作を維持しました。

### 互換性と破壊的変更
* 強化 完全なコンセンサスヘッダー検証を適用し、各ヘッダーを登録済み VRF キーハッシュと照合するとともに、DMQ KES 認証を設定可能な最大 KES 進化ウィンドウ内に制限しました。既定値は 62 で、明示的なスロット上書きも適用します。
* 登録 Shelley、Allegra、Mary、Alonzo、Babbage の各時代に MIR genesis-delegate クォーラム検証を組み込み、UTxO-RPC MIR の source-pot 変換でリザーブとトレジャリーを区別して保持するとともに、無効なエンコーディングを拒否しました。
* 同期 設定された Byron エポック長を BlockFetch と ChainSync で同期し、オーバーフローに安全なスロット変換を適用しました。
* 解決 型付き認証で委員会のホットキーを解決し、キーとスクリプトの識別情報を保持しました。共有ホット認証情報に複数のコールド認証がある場合も処理し、プロトコルメジャーバージョン 11 以降では着席メンバーをチェックしました。
* 対応 NtC v19/v20 の ledger-peer-snapshot ワイヤーフォーマットに合わせ、リクエスト `[34]`、外側のスナップショットワイヤーバージョン 1、未対応のピア種別またはバージョンに対する型付きエラーを含めました。

### バグ修正
* 修正 台帳マップを処理するために `DecodeLedgerMap` を追加しました。台帳トランザクション境界では重複キーを拒否し、汎用の `cbor.Value` デコードでは最後に出現した値を採用する動作を維持し、Byron SSC ペイロードの寛容な処理を保持しました。
* 許容 統合テストで有効な空の台帳ピアスナップショットを受け入れ、空のプールリストを失敗と判定しないようにしました。

### 依存関係の更新
* 更新 `github.com/blinklabs-io/ouroboros-mock` を 0.20.2 から 0.20.3 にアップグレードし、上流の証明書ビルダーとパイプクリーンアップの修正を取り込みました。
* 改訂 `github.com/blinklabs-io/plutigo` をバージョン 0.7.2 に更新し、ルートモジュールとサンプルモジュールに適用しました。形式不正なスクリプトのカバレッジも UPLC バージョンのゲーティングから独立させました。
