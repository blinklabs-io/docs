## v0.189.1

**タイトル:** GetCBOR クエリとステークスナップショットのプールフィルター

**日付:** 2026年7月23日

**バージョン:** v0.189.1

GetCBOR で包まれた Shelley クエリを修正し、プールフィルターを cardano-node のワイヤー形式に合わせます。

### 修正

- `cardano-cli query stake-snapshot` などの LocalStateQuery で Shelley クエリをデコードでき、失敗して Node-to-Client 接続を閉じることを防ぎます。
- ステークスナップショットのプールフィルターを正しい形式でエンコード、デコードし、全プールと特定プールの要求を正しく処理します。

gOuroboros のリリースをフォローしていただきありがとうございます。
