## v0.213.6

**タイトル:** プロトコルの受け入れ、クエリ処理、トランザクション取得を改善

**バージョン:** v0.213.6

このリリースでは、プロトコルメッセージの受け入れを改善し、Shelley のフィルタリングされたクエリ処理を修正し、Leios のワイヤーフォーマットに合わせてトランザクション取得を更新し、Plutigo の依存関係をアップグレードしました。

### 破壊的変更

* 変更しました。`MsgBlockTxs` がトランザクションのみを保持するようにしました。API から `Point` と `Bitmaps` フィールドを削除し、`NewMsgBlockTxs` はトランザクションのみを受け取るようにしました。ワイヤーペイロードは `[4, [* tx]]` を使用し、各トランザクションを 1 つの `block_transaction` を含む確定バイト文字列のタグ 24 でラップします。LeiosFetch クライアントは、返されたトランザクション数を要求されたビットマップ数と照合し、形式が不正なラッパーまたは空のトランザクションを拒否します。プロトコル README は Leios リリース候補 `2026w42` を参照します。

### バグ修正

* 改善しました。インバウンドメッセージの受け入れをピアのエージェンシー世代に関連付け、未処理のリクエストに対してパイプライン化された返信の容量を予約し、後続メッセージを受け入れる前に遅延状態を再スナップショットするようにしました。プロトコルはまとめて送信された余分な返信を決定的に拒否し、正当なパイプライン順序を維持します。

* 修正しました。明示的なワイヤーレイアウトと型付きの pool set を使用して、Shelley のフィルタリングされたクエリのデコードを修正しました。クエリデコーダーは複数の pool set を含む不正なフィルターを拒否し、`Client.GetPoolState` と `Client.GetPoolDistr` はすべてのプールおよび選択したプールに対して `StrictMaybe (Set PoolId)` 引数を正しくエンコードします。

### 追加変更

* 更新しました。Plutigo の依存関係を `v0.9.6` から `v0.9.7` に更新し、ビルド、台帳テスト、コンフォーマンステストが更新されたバージョンで実行されるようにしました。
