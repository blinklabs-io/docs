## v0.212.0

**タイトル:** 評価制御と台帳互換性を改善

**バージョン:** v0.212.0

**日付:** 2026-10-08

このリリースでは、キャンセル可能な Plutus 評価、Musashi genesis の解析、Dijkstra の validity 検証を改善し、スタンドアロンのサンプルを削除し、任意で実行できる cardano-node 統合テストハーネスを追加します。

### 新機能

* 追加: Plutus V1 から V4 までのコンテキスト対応 Plutus 評価により、処理開始前または評価中に処理をキャンセルして `context.Canceled` を受け取れるようにしました。既存の評価メソッドとの互換性も維持します。
* 導入: cardano-node のソケットに接続し、ChainSync を実行してブロックをデコードし、tip を確認し、停止と再起動を検証する任意実行の統合テストハーネスを追加しました。
