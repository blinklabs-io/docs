## v0.204.5

**タイトル:** スクリプトデータを正規化し、プロトコルのデコードを強化

**バージョン:** v0.204.5

このリリースでは、Plutus の評価経路全体でスクリプトデータを正規化し、UTxO-RPC と LocalStateQuery のデコードを強化するとともに、プロジェクトの保守とテスト fixture を安定化します。

### 🐛 バグ修正

* 修正 **スクリプト境界のデータ:** スクリプトコンテキストとスクリプト入力が、datum、redeemer、inline datum、および Dijkstra で必要な guard datum を、`serialiseData` が生成する正規 CBOR 形式でスクリプトに渡します。

* 改善 **UTxO-RPC プロトコル変換:** ゼロベースのコストモデルマッピングで Plutus V1 を保持し、プロトコルパラメータで Conway ガバナンスフィールドを保持するとともに、有理数と委員会の変換で nil 値および範囲外の値を安全に処理します。

* 強化 **評価時のエンコーディング互換性:** V1 と V2 の評価、および V3 の `ScriptContext` 構築で、入力 CBOR が確定長または不定長を使用する場合でも、スクリプトから見える datum と redeemer を一貫して渡します。両方の形式を回帰テストで検証します。

* 安定化 **Dijkstra テストのフォーマット:** 末尾の改行がない場合でも、`gofmt` と `make format` のチェックが不要な変更を報告しなくなります。

* 明確化 **コメントの記述ガイダンス:** `AGENTS.md` が、不変条件、分かりにくいアルゴリズム、注意点、エクスポートされた識別子、および `NOTE` コメントについて説明すべき場面を文書化します。
