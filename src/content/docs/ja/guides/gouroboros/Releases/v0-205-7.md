## v0.205.7

**タイトル:** 検証、互換性、リソース安全性を改善

**バージョン:** v0.205.7

このリリースは、台帳の検証、時代互換性、暗号処理、公開 API のエラー報告、保留中のネットワークデータの上限を改善します。

### バグ修正
* 強化 **Leios と Dijkstra の検証:** signer bitfield は最大 `8,192` バイトを受け入れ、Dijkstra body は CIP-0164 に従い、トランザクションが同時に存在する場合に Leios 証明書を拒否します。

* 安定化 **ChainSync Stop テストのアサーション:** テストは競合状態のあるタイミングの前提に依存しなくなり、本番の動作は変わりません。

* 改善 **不正な台帳入力の予測可能な失敗:** 不正な Byron 入力、nil の Byron ヘッダー、範囲外のガバナンス ID、不正な検証用 hex は、エラーまたは決定的なセンチネル出力を返します。公開関数 `ledger.NewByronTransactionInput` は `(value, error)` を返すようになりました。
