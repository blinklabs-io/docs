## v0.178.0

**タイトル:** 使用例の移行と Cardano 対応の公開 CBOR 診断 API

**日付:** 2026年5月26日

**バージョン:** v0.178.0

v0.171.0 から v0.178.0 までの変更点です。

### 新機能

- block fetch、chain sync、chain tip、peer sharing、ping、state query、tx monitor、tx submission の公式サンプルアプリを追加しました。
- サンプルは独立したモジュールとして `examples/` に配置します。ローカル実行も以前の `cmd/` ではなく、ここから行います。
- トランザクション、ブロック、Plutus データ、ネイティブスクリプトに対応する診断フォーマットを追加しました。
- 診断出力に Cardano のラベルと、人が読めるアドレス注釈を含められます。
- 汎用 CBOR と Cardano のトランザクション、ブロック向けの公開診断 API を追加しました。解析ツリー、オフセット、警告、統計を提供します。

### 確認事項

ドキュメントとローカル作業では、廃止したスターターキットリポジトリではなく、最終的な `examples/` パスを使用してください。
