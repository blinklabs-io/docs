## v0.183.0

**タイトル:** アカウント状態クエリ、時代モデル、パイプライン検証の改善

**日付:** 2026年6月12日

**バージョン:** v0.183.0

v0.183.0 は Conway の `GetAccountState` を追加し、Dijkstra と Leios の関係を明確化して、検証中の未確認ブロックがチェーン状態に影響することを防ぎます。

### 新機能

Conway の `GetAccountState` で国庫と準備金のアカウント状態を取得できます。gOuroboros ベースのノードに対する `cardano-cli transaction build` などを、未対応クエリエラーなしに実行できます。Conway より前のチェーンでは、未対応クエリを送らず明確なエラーを返します。

### 改善

- Dijkstra を台帳の時代、Leios をその対応の中で導入された重ね合わせプロトコルとして扱い、Leios を独立した時代と記述しないよう説明を更新しました。
- 検証が有効な場合、未確認ブロックがチェーン状態に影響する前に停止し、明確なエラーを返します。
