## v0.207.3

**タイトル:** 各時代の検証、ネットワークプロトコル処理、トランザクション互換性を改善

**バージョン:** v0.207.3

このリリースでは、Byron、Alonzo、Babbage、Conway、Dijkstra 各時代のプロトコルのデコードとエンコード、トランザクション検証、互換性、終了処理を強化します。

### バグ修正
* 改善 LeiosNotify の VotesOffer 処理に各メッセージ 1,000 票と 256 KiB の制限を適用しました。不正な CBOR や末尾データを拒否し、これらの制限を文書化しました。
* 調整 Babbage、Conway、Dijkstra の最小 UTxO 計算で保持したワイヤー CBOR を測定し、Alonzo の空ポリシーサイズを整合させました。
* 整合 Byron の PBFT 参加判定、ジェネシス委任、過去の Ed25519 の動作、トランザクションの `WireId` と `Id` の動作、証人検証をプロトコル規則に合わせました。
* 検証 TPraos の nonce VRF を検証し、nil または非対応ヘッダーの場合に運用証明書の抽出処理がエラーを返すようにしました。
* 強化 Plutus コンテキストと UTXOW 検証を強化し、Byron の出力、datum と redeemer の規則、担保、OutsideForecast、Dijkstra のサブトランザクションインデックス、実行単位のデコードを整合させました。
* 安定化 終了処理を安定させ、ChainSync 操作の完了を待機し、接続終了を LeiosVotes コールバックへ伝播し、BlockFetch の二重完了を防止しました。
* 修正 Byron の過去互換の canonical JSON エスケープを適用し、最初の完全な JSON 値の後に EOF を待たず解析を終了するようにしました。
* 拒否 Dijkstra のジェネシス専用 Leios 更新フィールドを部分適用せず拒否し、オンレジャーキー 43 と 44 は保持しました。
* 維持 必要な場合は `invalid_transactions` の順序と重複を保持し、範囲外の補助データインデックスを拒否し、従来の Dijkstra の重複拒否も維持しました。
* 検証 Conway と Dijkstra のパラメータ更新について、ドメイン、null 許容性、整数幅、上限付き比率、コストモデルの言語 ID、`MaxPledgeLeverage` の 3 状態値、PV12 のセキュリティグループ分類を検証しました。
* 追加 実行時の動作を変更せず、エンコードとデコードを検証する Dijkstra のゴールデンテストを追加しました。
* 確認 Conway と Dijkstra の委員会遷移を検証し、PV10 のアクション制限を適用し、PV11 以降で未選出投票者を確認し、オプションの `CommitteeVotingState` 機能を必須にしました。
