## v0.191.0

**タイトル:** 検証強化と Node-to-Client v21 対応

**日付:** 2026年8月1日

**バージョン:** v0.191.0

アドレス、redeemer、委任の検証、Dijkstra の台帳エラー、プロトコルエラー、および Node-to-Client v21 対応を改善します。

### 改善

- 生アドレスのデコードで、CIP-0019 の予約済みアドレス型と不正なネットワーク ID を拒否します。
- blockfetch、chainsync、handshake、keepalive、leiosfetch、localstatequery、localtxmonitor、localtxsubmission、peersharing、txsubmission の未知の CBOR メッセージ型に明示的なエラーを返します。
- 未知の台帳エラーコンストラクターを、既定の時代に置き換えず保持します。Dijkstra を専用に処理し、マーシャル時に不正な台帳失敗を拒否します。
- 対応する目的のない redeemer は、捨てずに検証で拒否します。
- ブロック型を宣言されたプロトコル範囲に従って分類します。
- CBOR マーシャルで未知のジェネシスネットワーク ID を拒否します。
- LocalStateQuery v21 の新しいワイヤー形式と、`GenesisConfigResult` の改名後のフィールドに対応します。
- 委任の検査で未知の DRep 型を拒否します。
