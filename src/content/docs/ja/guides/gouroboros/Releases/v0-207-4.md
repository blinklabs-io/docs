## v0.207.4

**タイトル:** プロトコルパイプライン処理と証人検証を改善

**バージョン:** v0.207.4

このリリースでは、プロトコルパイプライン処理を改善し、不正な Conway と Byron の証人を早期に拒否し、ベンチマークチェックの実行タイミングを見直します。

### バグ修正
* 改善 プロトコルパイプライン処理中のメッセージ順序を改善し、接続状態を準備完了シグナルと同期させ、遅延した状態遷移の完了後にキュー内のメッセージを再確認し、保留中のメッセージを保持してバッチ内のすべてのメッセージを検証するようにしました。正当な状態の進行によって接続が致命的に終了することがなくなり、ChainSync の `MsgRequestNext` リクエストを返信の到着前に連続して送信できるようになりました。
* 拒否 CBOR のデコード時に witness set のフィールド 0 から 7 が明示的に存在して空の場合、Conway トランザクションを拒否するようにしました。一方、フィールドが存在しない場合とゼロ値の witness set エンコードは有効なまま維持されるため、不正なトランザクションを早期に失敗させます。
* 更新 ベンチマークチェックを公開リリース、手動リクエスト、承認済みの `/benchmark` コメントで実行するようにし、`main` へのすべての push では実行しないようにしました。
* 強化 Byron の証人検証で、コンストラクタ 3 を含む未対応のコンストラクタを拒否し、コンストラクタ 0 と 2 にはキーと署名の正確な長さを要求するようにしました。これにより、不正なトランザクションおよびブロックの証人を検証時に拒否します。
