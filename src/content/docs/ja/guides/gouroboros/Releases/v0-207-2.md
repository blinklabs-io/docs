## v0.207.2

**タイトル:** 対応する各時代の検証、シリアライズ、手数料計算を改善

**バージョン:** v0.207.2

このリリースでは、Byron、Shelley、Alonzo、Babbage、Conway、Dijkstra の各時代で検証、シリアライズ、手数料計算、互換性を強化します。

### バグ修正
* 改善 **Dijkstra サブトランザクション検証:** 明示的に空の key-23 セットと、証人や補助データが異なる場合でも重複する子サブトランザクション本文ハッシュを拒否します。
* 強化 **Byron AVVM redeem address 処理:** 必要な場合に network magic 属性を導出し、重複する AVVM および非 AVVM の genesis outpoint を拒否します。
* 厳格化 **Byron v1 ワイヤーデコード:** definite framing、型付き update proposal フィールド、厳格なアドレスと属性のデコード、Byron update payload の構造検証を適用します。
* 制限 **Byron トランザクション出力:** デコード時に 45,000,000,000,000,000 Lovelace の上限を適用します。
* 整合 **Byron エポック境界ブロックと追加データの CBOR 形状:** 参照実装と互換性のある形状にそろえ、Genesis タグの検出を公開します。
* 検証 **Conway `UpdateCommittee` の規則:** クォーラムと重複削除を検証し、ガバナンスシリアライズを正規化します。さらに、collateral return、total collateral、Byron genesis configuration、ネストした tag 24 のデコードを修正します。
* 適用 **プールメタデータ URL の上限:** ローカル状態クエリ結果のエンコードとデコードで、128-byte UTF-8 の上限を適用します。
* 削除 **README のバッジ:** 廃止された Go Report Card バッジを削除します。
* 反映 **最小手数料計算:** Alonzo、Babbage、Dijkstra で実行ユニット手数料を含め、手数料の集計と丸めを統一します。
* 受け入れ **Shelley native script の M-of 閾値:** 符号付きの閾値を受け入れながら、時代ごとの native script コンストラクター領域を適用します。
* 保持 **DRep 登録解除の tombstone:** Conway と Dijkstra のトランザクション内検証で保持します。
* 許可 **子ガバナンス提案の参照:** RATIFY 期間が終了していてもエポックから削除されるまで存続する祖先を参照できるようにします。
* 適用 **ガバナンスアンカー URL の上限:** 構築時と CBOR のエンコードおよびデコード時に、128-byte UTF-8 の上限を適用します。
* 拡張 **Dijkstra PV12 のバッチアカウント状態検証:** direct deposit と account balance の期間サポート、更新された reward account keyed body fields、ネストしたサブトランザクション検証、関連する CBOR と witness の不変条件を追加します。
* 修正 **Conway 委員会状態の検証:** 失効、投票制限、選出メンバーの確認、連続する委員会証明書の状態を検証します。
