## v0.189.5

**タイトル:** CI checkout と ChainSync 検証の更新

**日付:** 2026年7月28日

**バージョン:** v0.189.5

CI の checkout を更新し、未知の時代とブロック型に対する Node-to-Node ChainSync の rollforward 検証を厳格化します。

### 改善

- 7 つのワークフローで `actions/checkout` v7.0.1 を使用します。危険な PR チェック、ASCII 空白の除去、`--unset` のエスケープに関する上流修正を取り込みます。
- クライアントは継続前に未知の時代を拒否し、サーバーは未知のブロック型に明確なエラーを返します。
