## v0.192.1

**タイトル:** プロトコルと台帳の検証強化

**日付:** 2026年8月6日

**バージョン:** v0.192.1

明示的な `KES` スロット 0 を保持し、不正または未対応の入力を処理前に拒否します。

### 改善

- 明示的に指定した `KES` スロット 0 を、プロトコル処理でもそのまま保持します。
- 許容範囲外の報酬パラメーターを台帳処理前に拒否します。
- 未知の `DMQ` 理由を後続処理に渡しません。
- 未知のガバナンスアクションを台帳処理に渡しません。
- 不正な代替データを台帳処理に渡しません。
