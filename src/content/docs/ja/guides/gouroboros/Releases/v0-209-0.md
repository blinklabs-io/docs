## v0.209.0

**タイトル:** プロトコルの安全性、トランザクション検証、タイミングの可視性を改善

**バージョン:** v0.209.0

このリリースでは、プロトコル入力の処理を強化し、以前のブロックの効果に対してトランザクションを検証し、ステージのタイミングデータを公開し、Plutus、コストモデル、Byron トランザクションの動作を修正します。

### 破壊的変更
* 成功した decode、validate、apply ステージの集約タイミングデータを `PipelineStats` と `StageTimings` で追加しました。キーなしリテラルで `PipelineStats` を作成するコードは、新しいフィールドを追加するか、キー付きリテラルに切り替える必要があります。
