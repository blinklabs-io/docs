## v0.213.11

**タイトル:** 返信をまたいでパイプライン化された ChainSync リクエストを維持

**バージョン:** v0.213.11

このリリースでは、返信による状態遷移中に ChainSync リクエストが失敗する問題を防ぎます。

### バグ修正

* 修正しました。ローカルの返信駆動の状態遷移中に、パイプライン化されたリクエストを拒否する可能性があった ChainSync セッションを修正しました。パイプライン化すると宣言されたリクエストは、返信によってピアに制御が戻った後も、宣言した状態の世代がスナップショットの世代以上である場合を含め、引き続き許可されます。宣言されていないメッセージタイプがゼロ値の世代に一致することはなくなり、`CanAwait` が `RequestNext` をパイプライン化すると宣言している場合、`RollForward` によってサーバーが `Idle` に戻った後も `RequestNext` が許可されるため、`received message type 0 without peer agency` などのエラーを回避できます。
