## v0.205.3

**タイトル:** コンセンサス選択、デコード制御、クエリ効率を改善

**バージョン:** v0.205.3

このリリースでは、混在する候補の選択を決定的にし、設定可能な CBOR ネスト制限を追加し、Plutigo 依存関係を更新します。また、取得済みスナップショット中の現在の era クエリをキャッシュします。

### ✨ 新機能

* 設定 **CBOR ネスト制限:** `cbor.MaxNestedLevels` と `cbor.MaxUntrustedNestedLevels` が、デフォルト値 `16384` のパッケージ変数になりました。デコーダーモードは遅延してキャッシュされるため、最初の `Decode` 呼び出しの前に両方の値を設定してください。`ParseDiagnostic` も設定された `MaxNestedLevels` の値を適用します。

### 🐛 バグ修正

* 改善 **コンセンサス候補の選択:** `PraosChainSelector` が、`GenesisWindowSlots` で選択された同一のスケール上ですべての候補を比較するようになりました。設定済みセレクターはウィンドウ内のブロック数を使用し、従来の `ChainTip.Density` はそのウィンドウに投影されて `uint64` の上限で飽和します。未設定のセレクターは正規化された従来の密度を使用します。`NaN` や `uint64` の境界値を含め、候補の到着順に関係なく混在候補の選択が決定的になりました。セレクターは再び `go vet` でコピー可能になり、エクスポートされたコメントは API を正確に説明します。

* 最適化 **現在の era クエリ:** 成功した `LocalStateQuery.GetCurrentEra` の結果が、取得済みスナップショットの間キャッシュされるようになりました。解放または再取得するとキャッシュが無効になり、再取得やクエリに失敗した場合はキャッシュに登録されません。シャットダウン後の呼び出しは、キャッシュされた結果が存在する場合でも `ErrProtocolShuttingDown` を返します。

### 追加変更

* 更新 **Plutigo 依存関係:** ルートモジュールとすべての example モジュールが、チェックサムを同期した `github.com/blinklabs-io/plutigo` `v0.7.1` を使用するようになりました。
