## v0.202.10

**タイトル:** トランザクション検証、会計、プロトコル互換性を改善

**バージョン:** v0.202.10

このリリースでは、Byron、Conway、Dijkstra 全体の台帳検証、トランザクションと報酬の会計の一貫性、プロトコルパラメータおよび CBOR の処理を改善しました。

### 💪 改善

* 改善 **Byron 軽量委任の検証:** エポック範囲の両端を含めるようになりました。署名生成では wire encoded certificate index を正確に保持し、正しい light および heavy wire tag を使用し、heavy omega を制約しません。

* 整理 **withdrawal の順序とインデックス:** withdrawal は credential でソートされ、script credential が key credential より先になります。`TxInfo` と redeemer のインデックスは一貫して保たれ、nil 値も安全に処理されます。

* 修正 **CBOR 境界テスト:** 配列ヘッダーの境界テストが 32 ビットと 64 ビットの両方のシステムで正しい結果を返すようになりました。

* 防止 **pool deposit の重複請求:** すでに retired になった pool の登録時には deposit を請求し、同じトランザクション内では台帳 era をまたいでも同じ deposit を複数回請求しません。

* 強化 **無効なトランザクションの依存関係:** トランザクションが無効でも、required script witness と reference input の解決を必須にしました。
