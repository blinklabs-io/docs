## v0.213.4

**タイトル:** Conway と ledger の CBOR エンコードを整合させ、診断出力を制限

**バージョン:** v0.213.4

このリリースでは、コンセンサスに関わる Conway と ledger の CBOR エンコードを Cardano に合わせ、診断出力を制限し、ツールと統合テストの再現性を高めました。

### 新機能

* 追加しました。`DiagnosticOptions.MaxOutputBytes` による診断レンダリングの出力上限、すべての診断形式で共有する出力上限、切り捨てマーカー、線形パス検索を実現しました。

### 破壊的変更

* 更新しました。`ConwayTransactionBody.TxCurrentTreasuryValue` の型を `int64` から `uint64` に変更しました。このフィールドを使用する Go コードは `uint64` に更新する必要があります。

* 強化しました。`ExUnitPrice.UnmarshalCBOR` の検証で、長さが未定義の実行価格配列を拒否し、実行価格をちょうど 2 つ含む長さが明示された配列を必須にしました。

* 制限しました。深くネストされた診断のレンダリングを既定の `DiagnosticOptions.MaxOutputBytes` の動作に従って制限し、レンダラーは出力が上限に達すると `... (output truncated)` を追加します。

### バグ修正

* 改善しました。ledger の順序を合わせ、23 を超える indefinite-length のマップとセットおよび tag-258 のセットに対応し、空の voting-procedure を省略し、Conway の treasury 値を unsigned としてエンコードし、検証を更新して Conway と ledger の CBOR 互換性を高めました。

* 安定化しました。`tools/go.mod` で `nilaway` と `benchstat` を固定し、`go tool -modfile=tools/go.mod` で実行できるようにし、Cardano ノードのイメージをダイジェストで固定し、コメントで起動するベンチマークのチェックアウトとツール解決を修正しました。
