## v0.213.4

**タイトル:** Conway と ledger の CBOR エンコードを整合させ、診断出力を制限

**バージョン:** v0.213.4

このリリースでは、コンセンサスに重要な Conway と ledger の CBOR エンコードを Cardano に合わせ、診断出力を制限し、ツールと統合テストの再現性を高めました。

### 新機能

* 追加しました。`DiagnosticOptions.MaxOutputBytes` による診断レンダリングの上限、各診断形式で共有する出力上限、切り捨てマーカー、線形パス検索を追加しました。

### バグ修正

* 改善しました。ledger の順序を整合させ、23 を超える indefinite-length のマップとセットおよび tag-258 のセットに対応し、空の voting-procedure を省略し、Conway の treasury 値を unsigned としてエンコードし、検証を更新して Conway と ledger の CBOR 互換性を高めました。

* 安定化しました。`tools/go.mod` と `go tool -modfile=tools/go.mod` によって `nilaway` と `benchstat` を固定し、Cardano ノードのイメージをダイジェストで固定し、コメントで起動するベンチマークのチェックアウトとツール解決を修正しました。
