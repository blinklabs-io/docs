## v0.180.1

**タイトル:** Conway 以降の検証に対応する mint エンコード

**日付:** 2026年6月3日

**バージョン:** v0.180.1

v0.180.1 は新機能を追加せず、検証の修正とリリース履歴の更新を行います。

### 修正

Plutus V1/V2 のスクリプトコンテキストにおける mint エンコードを cardano-ledger に合わせ、Conway の PV10 以降では 0 ADA の mint 項目を含めます。PV10 より前の動作を維持しつつ、検証時の CBOR 不一致を防ぎます。

### その他

同じ期間に上流が `v0.180.0` のリリースノートを公開しました。これは履歴の文書更新で、実行時の動作は変わりません。
