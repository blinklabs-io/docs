## v0.222.0

**タイトル:** ledger の動作と protocol interoperability を整合

**リリース日:** 2026-11-28

**バージョン:** v0.222.0

このリリースでは、reference implementation に合わせて ledger の計算と protocol の動作を整合し、malformed input の処理を強化し、protocol interoperability を改善します。また、reference model の coverage を拡張します。

### 新機能

* Conway と Dijkstra の ledger 動作について reference model の coverage を拡張します。

* Dijkstra の sub-transaction rule-cell test を網羅的に追加します。

* 複数の mux segment にまたがる handshake を有効にします。

* `PerasVotes` の await と server-idle 処理に reference timeout を追加します。

* client の done message 後に 6 つの protocol server を再起動します。

### 破壊的変更

* Mary の `MinCoinTxOut` が `TransactionOutput` を受け取るように変更されました。呼び出し側はこの API に渡す引数を更新する必要があります。

* TPraos overlay schedule を使用する verification では `VerifyConfig.TPraosOverlay` が必須になりました。

* `LeiosVote` message が CIP-0164 の 3 要素形式に変更されました。以前の full-vote offer を処理するアプリケーションでは `LeiosLegacyVote` を使用する必要があります。

* pipeline の drain と result delivery が `LosslessResults` と `ResultsDropped` を使用する形に変更されました。lossless mode を有効にしない場合、result delivery で結果が失われる可能性があります。

* `CalculateRollingNonce` は、rolling nonce に組み合わせる前に導出済みの 32 byte contribution を受け取るように修正されました。

* constructor encoding が Plutus-compatible CBOR に変更され、serialized byte と hash が変わります。

### バグ修正

* local transaction monitor の cache memory 使用量を削減し、transaction ID の collision を安全に処理します。

* local transaction submission の default `Busy` timeout を削除し、submission にこの timeout を自動適用しないようにします。

* Conway mainnet header の protocol version を検証します。

* raw CBOR map decoding を強化し、過大な malformed declaration を処理する際の問題を防ぎます。

* large allocation の前に malformed input を拒否することで、general constructor decoding を強化します。

* DMQ message expiry の範囲を `dmq-node` の動作に合わせます。

* message-submission request timeout を `dmq-node` の動作に合わせます。

* handshake negotiation、simultaneous open、agreed-version data の処理を修正します。

* earlier level に由来する Dijkstra committee proposal を修正します。

* protocol version 16 以降の node-to-node transaction ID request を制限します。

* stored CBOR がない場合に transaction-body encoding を hash して transaction ID を導出します。

* PPUP と MIR の edge case validation を改善します。

### その他の変更

* protocol timer を receiver-only operation に限定し、Local State Query と Local Tx Monitor の default timeout を削除します。
