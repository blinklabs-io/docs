## v0.193.0

**タイトル:** Byron 委任検証とトランザクション有効期間の強化

**日付:** 2026年8月10日

**バージョン:** v0.193.0

Byron 委任証明書の検証を強化し、明示的な 0 を含むトランザクションの有効期間を保持して、コンセンサスと台帳をチェーンデータに一致させます。

### 改善

- 発行者、委任先、署名のサイズが不正な証明書を拒否し、Cardano Byron の署名ペイロード配置を正しく検証します。既定で、検証できなければ拒否します。実際の mainnet ベクターと、決定的な正常/異常ケースをテストします。
- トランザクション CBOR のデコードで、明示的な 0 を含む上下限を保持します。Plutus の有効期間を `cardano-ledger` の上限の意味に合わせました。`ouroboros-mock` の有効期間フィクスチャでテストを拡充し、`ouroboros-mock` を `v0.15.1`、`plutigo` を `v0.3.0` に更新しました。
