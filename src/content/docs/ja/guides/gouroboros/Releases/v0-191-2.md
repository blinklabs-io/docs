## v0.191.2

**タイトル:** 不正な証明書デコードの拒否と fuzz 対象の限定

**日付:** 2026年8月2日

**バージョン:** v0.191.2

プール登録証明書 JSON と台帳デコードの検査を強化し、fuzz 対象を正確な名前に限定します。

### 改善

- JSON のプール登録証明書で、長さの不正なオペレーター鍵を拒否し、明確な検証エラーを返します。
- Byron の null ヘッダーと従来の返信メッセージのデコードテストで、期待する失敗経路を確認してから先に進みます。
- fuzz CI は対象名に完全一致させ、checkout の認証情報を実行中に永続化しません。
