## v0.187.4

**タイトル:** トランザクション送信の終了処理と Leios 投票の相互運用

**日付:** 2026年7月14日

**バージョン:** v0.187.4

トランザクション送信の信頼性、Leios 投票の相互運用、ビルドとサンプルの暗号依存関係を改善します。

### 改善

- 送信成功後にセッションを正常終了でき、プロトコル状態エラーでノードクライアントのセッションが切断されることを防ぎます。
- 現行のプロトタイプ投票形式を送るピアに対応し、古い投票識別子と完全な投票形式も引き続き受け入れます。署名が不正なプロトタイプ投票はデコード時に拒否します。
- ビルドと同梱サンプルの `golang.org/x/crypto` を v0.54.0 に更新し、`golang.org/x/sys` も揃えました。公開 API を変えずに上流の修正と強化を取り込みます。
