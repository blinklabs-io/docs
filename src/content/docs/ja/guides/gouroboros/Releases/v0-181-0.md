## v0.181.0

**タイトル:** Leios 対応と台帳メタデータ処理の拡張

**日付:** 2026年6月7日

**バージョン:** v0.181.0

v0.181.0 の変更点です。

### 新機能

- Leios テストネットのネットワークマジックとブートストラップピアを持つ `NetworkCardanoLeios` を追加しました。設定を手で構築せず、標準ネットワークレジストリ API から解決して接続できます。
- 型付きの `LeiosEndorserBlock` と `LeiosTransactionReference` API を追加しました。厳格な CBOR 検証で、参照の重複、サイズ 0、過大なサイズ、不正なエンベロープ形式、末尾バイトを拒否します。

### 改善

- `AddOrReplace`、検索、複製、同等性比較などの投票手続きヘルパーを値の意味に基づく処理にし、メモリアドレスによる追跡で生じる論理的な投票の重複を防ぎます。CBOR エンコードは維持します。
- cardano-cli の no-schema と detailed-schema の両形式のメタデータ JSON を解析し、決定的な正規 CBOR への書き出しと、メタデータのみの Shelley auxiliary data の作成に対応しました。

### 確認事項

- 公開済み変更に合わせて上流のリリース履歴を更新しました。
- 古い誤記の公開別名 `LeiosEndorderBlock` を使うコードは、`LeiosEndorserBlock` に変更してください。
