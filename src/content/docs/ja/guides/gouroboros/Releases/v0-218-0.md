## v0.218.0

**タイトル:** Plutus 評価と Leios 委員会へのアクセスを改善

**バージョン:** v0.218.0

このリリースでは、Plutus 評価の効率、Leios 委員会へのアクセス、台帳の動作に合わせたローカル状態クエリのデコードを改善しました。

### 新機能

* 新たに Shelley の `localstatequery` クエリ 41 と `Client.GetLeiosCommittee()` を追加し、現在の Leios 投票委員会と、オプションで次の委員会を取得できるようにしました。デコーダーは座席数を制限し、オプションの BLS キーは長さが正確に 96 バイトの場合のみ受け入れます。

### パフォーマンス

* 改善として、`github.com/blinklabs-io/plutigo` を v0.11.2 から v0.11.3 に更新し、評価結果を変えずに Plutus 評価の速度とメモリ使用量を高めました。

* 拡張した Plutus マシンの再利用では、言語バージョンと `EvalContext` ごとにミューテックスで保護された LIFO の空きリストを使用します。再利用はガベージコレクション中も継続し、アイドル状態で保持する数を `GOMAXPROCS` 以下に制限し、プールは nil ポインターを安全に処理します。

* 制限として、`github.com/blinklabs-io/plutigo` を v0.11.4 に更新し、Plutus のメモリ保持を改善しました。値アリーナの保持メモリを 32 MiB に制限し、マシン再利用の改善を補完します。

### バグ修正

* 修正した `localstatequery` の UTxO 結果デコードでは、台帳の lenient アドレスルールを使用します。
