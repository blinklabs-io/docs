## v0.47.0

**タイトル:** イベント配信、堅牢な運用、Cardano サポートの拡充

**バージョン:** v0.47.0

**比較:** [v0.46.0...v0.47.0](https://github.com/blinklabs-io/adder/compare/v0.46.0...v0.47.0)

このリリースでは、イベント配信と Cardano ネットワークのサポートを拡充し、可観測性、設定の安全性、通知制御、webhook の耐久性、デスクトップの信頼性を改善します。

### ✨ ハイライト

* **運用状況の可視性を改善:** 構造化ログフィールド、コンポーネント単位のロガー、メトリクス、一貫したログシステムにより、起動、同期、配信、webhook の動作を把握しやすくなりました。Adder はログに書き込む前に FCM トークンを短縮し、webhook URL をサニタイズします。

* **ガバナンスのデポジット全体を保持:** DRep と投票委任のデポジットが、符号付き整数に縮小されず、符号なし64ビット値を保持するようになりました。ガバナンスイベントは更新されたデポジットスキーマを使用するため、連携先は完全な範囲を処理できます。

* **ヘッドレス通知を追加:** `notify-json` 出力と通知検証コマンドにより、トレイなしで自動化できます。バージョン付き通知設定は厳格な検証を行い、UI に依存しないトレイ通知と投票メッセージ内のガバナンスアクション ID により、通知連携の予測可能性が向上します。

* **トレイプロセスの蓄積を防止:** トレイから起動したプログラムが正常に終了するため、フォルダー、URL、インストーラーの操作を繰り返しても子プロセスが実行中のまま残りません。

### 💪 改善

* **デスクトップ通知を更新:** 通知ライブラリが beeep 0.11.3 を使用し、現在のデスクトップ連携の動作に対応します。

* **システム互換性を更新:** システムインターフェースの依存関係が x/sys 0.46.0 を使用し、現在のオペレーティングシステムの動作への対応を改善します。

* **ライブラリ例をホスト型ドキュメントへ移行:** Adder の例がドキュメントサイトに掲載され、ライブラリ利用者がガイダンスを一つの保守された場所で確認できるようになりました。

* **Signal 配信を導入:** Signal 出力が signal-cli JSON-RPC と厳格なエンドポイントおよび受信者の検証を使用し、受信者ごとに成功を確認してリダイレクトを拒否します。新しい `docs/signal.md` ガイドで設定を説明します。

* **モックチェーンのサポートを更新:** ouroboros-mock 依存関係がバージョン 0.20.4 を使用し、ローカルおよび自動化されたチェーンテストに対応します。

* **リンティングの自動化を効率化:** Go の lint ワークフローが golangci-lint-action 9.3.0 を使用し、開発パイプラインで現在のチェックを実行します。

* **macOS 公開を強化:** ビルドが macos-15 ランナーを使用し、失敗後も独立したビルドを継続し、パッケージ化と署名を分離して、部分的なビルド失敗後にリリースを完了します。

* **コンテナ公開を保護:** Docker レジストリ認証が docker/login-action 4.5.1 を使用します。
