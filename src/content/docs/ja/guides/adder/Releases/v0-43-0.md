## v0.43.0（2026年6月25日）

**タイトル:** 通知ルールエディター、署名済みインストーラー、API 移行、リリースの信頼性向上

**日付:** 2026年6月25日

**バージョン:** v0.43.0

トレイ通知を刷新し、アプリ内ルールエディターと複数対象の監視を拡充します。署名・公証済み macOS `.pkg`、Java 21 による Windows 署名の安定化、`net/http` への API 移行、設定優先順位の修正、リリースと CI の改善を含みます。

### ✨ 主な変更点

- **再起動不要の通知管理:** トレイから 5 つの対象グループと通知カテゴリを編集できます。Monitor Everything 切り替えも利用でき、変更適用時には通知エンジンをホットリロードします。

- **macOS インストーラー:** CLI とトレイアプリを `Adder.app` にまとめます。認証情報がある場合はインストーラーを署名・公証し、公証チケットを添付します。インストール前後のスクリプトを含む検証済みパッケージを公開します。

- **Windows 署名:** Java 21 を使い、Java 17 で発生していた署名失敗を防ぎます。

- **API サーバー:** 文書化されたルートを維持したまま `net/http` に移行します。構造化アクセスログ、パニック回復、`/events` のストリーミング、FCM・QR ルート更新、Swagger パス調整、実際のサービスに合うリクエストタイムアウトを含みます。

- **設定と保存:** CLI フラグを保持し、`CLI > YAML > env` を適用します。YAML が環境変数より優先され、パスごとの保存を直列化してアトミック書き込みを強化します。

- **プラットフォーム別の失敗処理:** FreeBSD の公開マトリクスで `adder-tray` を無効にしてビルド失敗を防ぎます。macOS 署名を非ブロッキングにし、一部ジョブが失敗しても最終公開を継続します。

### 💪 改善

- **Cardano データ:** 新しい `gouroboros` により、運用証明書検証、Dijkstra redeemer のデコード、決定的変換時のプロトコルパラメーターのコストモデル処理を改善します。

- **重複データ:** Conway より前の MultiAsset の重複キーと、Conway witness のタグ付き集合の重複要素を安定して処理します。

- **評価と暗号:** 新しい `plutigo` と `x/crypto` により、デコード・評価・セキュリティ・性能を改善します。

- **画像とフォント:** `golang.org/x/image` を更新し、フォント処理、WebP デコード検査、TIFF パディングを改善します。

- **Telegram:** `github.com/go-telegram/bot` を更新します。

- **Go のプラットフォーム対応:** `golang.org/x/sys` を更新し、現在の実行環境との互換性を維持します。

- **Go の保守:** さらに新しい `golang.org/x/sys` を採用し、実行時の修正と互換性更新を取り込みます。

### 🧪 テスト、CI、ドキュメント、リリースツール

- lint ワークフローの `golangci-lint` アクションを更新します。

- 自動チェック中に issue のクローズ日付を更新するアクションを削除します。

- Cardano フィルターのテストに `ouroboros-mock` の `TransactionOutputBuilder` fixture を使い、アドレス、ポリシー ID、アセット fingerprint、DRep を検証します。CIP-0129 のアサーションと Go の lint・テスト環境も改善します。

- Windows 署名ステップの `actions/setup-java` を更新します。

- 設定済みの Go バージョンは変えずに `actions/setup-go` を更新します。

- 複数ワークフローで `actions/checkout` を更新します。

- Docker CI・公開ワークフローの `docker/metadata-action` を更新します。

- 公開・MSI ワークフローの `actions/setup-java` を更新し、Maven・Java の診断、キャッシュ、ツールチェーン処理を改善します。

- Docker CI・公開ワークフローの `docker/build-push-action` を更新します。

- コンテナー公開の `docker/login-action` を更新します。

- 公開ワークフローの `actions/attest` を更新し、成果物の証明処理を強化します。

- フォークからの PR やその他のトリガーに対するセキュリティ・checkout 修正を取り込むため、`actions/checkout` をさらに更新します。

- MSI テストの `actions/upload-artifact` を更新します。セルフホスト runner には Actions Runner 2.327.1 以降が必要です。
