## v0.43.1（2026年7月23日）

**タイトル:** API サーバー移行、パッケージ、トレイ操作、リリース処理の更新

**日付:** 2026年7月23日

**バージョン:** v0.43.1

Adder の公開 API を Go の `net/http` に移行し、macOS パッケージ、トレイ操作、公開処理、依存関係を改善します。

### ✨ 主な変更点

- **公開ルートの維持:** `/ping`、`/healthcheck`、`/events`、FCM・QR の `/v1` ルートを `net/http` で提供します。構造化ログ、パニック回復、より安全なストリーミングを備えます。

- **macOS インストーラー:** 署名・公証済み `.pkg` にインストール前後の処理を含め、成果物の公開と検証を安定させます。

- **アプリ内通知エディター:** トレイから監視対象と通知カテゴリを再起動せずに編集できます。適用・再読み込み時にはルールとレート制限を即座に更新します。

- **FreeBSD:** amd64・arm64 の公開ジョブで `adder-tray` を除外し、タグ付きリリースの失敗を防ぎます。

- **Cardano データ取り込み:** `gouroboros` v0.186.3 により、Conway より前の MultiAsset 重複キーと、Conway witness のタグ付き集合の重複を修正します。

- **Cardano 同期:** `gouroboros` v0.186.1 により、opcert 検証、Dijkstra redeemer デコード、決定的なプロトコルパラメーター変換の修正を取り込みます。

- **画像とフォント:** `golang.org/x/image` v0.44.0 でフォント処理を強化し、WebP・TIFF の保護を追加します。

### 💪 改善

- Go ワークフローのアクションとアップロード・証明ツールを更新し、公開と CI を安定させます。

- `go/sys`、`x/image`、`plutigo`、`gouroboros`、`x/sys` を更新し、デコードと実行時動作を強化します。

- アセット・ポリシーテストに `ouroboros-mock` fixture を使用し、CIP-0129 DRep アサーションと lint・テスト依存関係を更新します。

- Windows、macOS pkg、Linux バイナリ、Docker Hub、GHCR の証明に `actions/attest` v4.1.1 を使用します。

- 公開・MSI テストで `setup-java` v5.5.0 を使用し、Java 21 と Temurin は維持します。

- Docker CI・公開で `docker/build-push-action` v7.3.0 を使用します。

- ライブラリ用の入門サンプル、ドキュメント、ツールを `examples/` に追加します。

- Telegram bot の組み込みに `go-telegram/bot` v1.22.0 を使用します。

- GitHub Projects の Closed Date フィールドを更新していた GitHub Actions ワークフローを削除します。
