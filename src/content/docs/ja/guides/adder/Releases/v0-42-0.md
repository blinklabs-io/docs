## v0.42.0（2026年6月25日）

**タイトル:** 複数対象のトレイ通知、予測可能な設定の優先順位、ライブラリサンプル、リリースの信頼性向上

**日付:** 2026年6月25日

**バージョン:** v0.42.0

このリリースでは、Adder の通知、設定、リリース処理の信頼性を改善します。

### ✨ 主な変更点

- **トレイから複数対象を監視:** 複数のウォレット、DRep、プールに対してネイティブのデスクトップ通知を同時に送信できます。すべてを監視するモード、再起動不要の通知ルール更新、旧設定から新形式への移行にも対応します。

- **設定の優先順位:** `CLI > YAML > env > defaults` を適用します。YAML が環境変数より優先されるため、環境変数による YAML の上書きに依存していた構成は調整が必要です。

- **ライブラリサンプル:** `adder-publisher`、`poolid-filter`、`event-address-filter` を追加し、一般的なイベント発行・フィルタリングの組み込み方を理解しやすくします。

- **プラットフォーム別のリリース:** macOS ビルドを `macos-15` に固定し、パッケージ作成を署名・公証から分離します。単一プラットフォームの失敗で全ビルドが止まらず、ドラフトリリースの作成成功後も公開処理を継続します。

### 💪 改善

- **Cardano ネットワーク:** より安全な検証と新しいネットワーク機能により、現在のネットワーク動作を安定して処理します。

- **画像とフォント:** 同梱画像・フォントのデコードを安全にし、視覚リソース読み込み時の堅牢性を高めます。

- **OS 互換性:** 新しい OS とシステムコールのサポートに追従し、現在の環境での安定性と互換性を維持します。

### 🧪 テスト、CI、ドキュメント、リリースツール

- 自動ビルドで使うリリースツールを更新し、リリース準備の信頼性を維持します。

- 署名・公開ツールを更新し、自動リリース署名の信頼性を維持します。
