## v0.28.0 - 信頼されたKESエージェントでステージ済みキーをアテステーション

**バージョン:** v0.28.0

### 概要

このリリースでは、アテステーション付きTLS KESエージェントを使用する運用者が、ステージ済みキーごとに`opcerts[].kes_vkeys`を変更したり、Bursaを再起動したりせずに、オペレーショナル証明書の発行を承認できるようになりました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ 新機能

* `gen-staged-key --attestation-out`を追加し、アテステーション付きTLS KESエージェントが署名済みのステージ済みキーアテステーションを生成できるようにしました。

* 有効なアテステーションが`opcerts[].kes_agents`に設定された信頼済みエージェントと一致する場合、ステージ済みキーのオペレーショナル証明書発行を承認できるようにしました。

* `opcerts[].kes_agents`の下で、信頼するKESエージェントを`spki_sha256`ピンと任意の`profile`値で設定できるようにしました。

* 信頼済みKESエージェントの設定を起動時に検証し、無効な認証ピンを運用開始前に拒否するようにしました。

* オペレーショナル証明書の発行時に、無効なステージ済みキーアテステーションを拒否するようにしました。

* アテステーションを含まないリクエストでは、既存の`opcerts[].kes_vkeys`による承認経路を維持しました。
