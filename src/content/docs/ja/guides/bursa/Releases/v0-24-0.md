## v0.24.0

**タイトル:** より信頼性の高いレディネスチェック、安全なKESプロファイル、依存関係の更新

**日付:** 2026-11-12

**バージョン:** v0.24.0

**比較:** [v0.23.0...v0.24.0](https://github.com/blinklabs-io/bursa/compare/v0.23.0...v0.24.0)

**リリース:** [v0.24.0](https://github.com/blinklabs-io/bursa/releases/tag/v0.24.0)

### 概要

このリリースでは、PostgreSQLのレディネスチェックの信頼性を高め、KESアテステーションにプロファイル選択を追加し、Goツールチェーンとコンテナイメージを更新して、`gouroboros`と`plutigo`ライブラリを更新しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ 新機能

* 追加: KESエージェントのアテステーションリクエストに、任意の`kes_vkey`とプロファイルセレクターを追加しました。Bursaは複数のアテステーション済みプロファイルに対応し、許可された各セッションを選択したプロファイルに結び付け、あいまいなセレクターや一致しないセレクターを拒否します。セッションが別のプロファイルに対して署名しようとすると、`ErrProfileMismatch`を返します。

### 🔒 セキュリティ

* 解消: PostgreSQLのレディネスチェック間の競合を解消するため、各レコードに一意の8バイトのランダムな16進数サフィックスを付けました。Bursaはこのキーをレディネス更新に使用してデータベーストランザクションをロールバックするため、チェック後に行が残りません。SQLiteの動作は変更ありません。

* 強化: ルート、`armory`、`openapi`、`ui`モジュールのGoディレクティブを`1.26.10`から`1.26.11`に更新しました。CIは`1.26.x`または`go.mod`/`ui/go.mod`のバージョンファイルを使用し、Docker Goイメージは`ghcr.io/blinklabs-io/go:1.27.3-1`から`ghcr.io/blinklabs-io/go:1.27.4-1`に更新しました。これにより、報告されていた`govulncheck`の`net/http`脆弱性に対処し、ワークフロー間の差異を減らします。

### 追加の変更

* 更新: `github.com/blinklabs-io/gouroboros`を`v0.218.0`から`v0.219.0`に、`github.com/blinklabs-io/plutigo`を`v0.11.5`から`v0.12.1`に更新し、Bursaをこれらのライブラリバージョンに合わせました。
