## v0.17.0 - ハードウェア署名、ウォレットの信頼性、リリースの安全性

- **日付:** 2026-09-19
- **バージョン:** 0.17.0
- **リリース比較:** [v0.16.0...v0.17.0](https://github.com/blinklabs-io/bursa/compare/v0.16.0...v0.17.0)

### 概要

任意の HSM 署名を導入し、ウォレットとストレージの保護、Cardano ネットワーク互換性、リリース資産と公開ワークフローの予測可能性を改善します。

### ✨ 新機能

* `pkcs11` ビルドタグで任意の PKCS#11 Ed25519 HSM 署名バックエンドを追加しました。設定でモジュール、トークン、スロット、PIN、許可する鍵を選択します。署名はトークン上で行い、PKCS#11 鍵の CIP-8 は未対応です。
* アカウントのステーク鍵インデックスを `0` に統一し、支払い鍵のインデックスは変更可能なまま、一貫したアカウントアドレスを導出します。
* 読み取り専用の `GET /wallet/governance-actions` に、検索、ページング、ライフサイクル状態、投票集計、エクスプローラーリンク、明確な読込/エラー表示を追加しました。
* ノードでプールと DRep を検証し、トランザクションのプレビューと確認、報酬出金を行うステーキングとガバナンス委任を追加しました。
* エアギャップ QR、CBOR、スキャナー、モーダル、フィンガープリントの共通部品で、ハードウェアウォレット署名を一貫させました。
* Manifest V3 拡張で任意の CIP-30/CIP-95 dApp コネクターを追加しました。オリジンごとの許可、承認キュー、Server-Sent Events、`BURSA_CONNECTOR` 設定に対応します。
* xpub のみへのアクセスと端末上の署名を使う Ledger WebHID の初期設定を統合しました。
* `GET /wallet/settings/auto-lock` と `PUT /wallet/settings/auto-lock` で、無操作時の自動ロックを `0`、`1`、`5`、`15`、`30` 分から保存できます。代替値は 15 分です。
* デスクトップとモバイルで、コマンドパレットを常時利用できます。
* 任意の活動通知を `GET /wallet/activity` と `GET /wallet/settings/notifications` で提供し、`PUT /wallet/settings/notifications` で設定を更新します。
* Keystone の初期設定と署名にエアギャップ QR を使用し、UI 通信を QR のみに限定して、拡張フィンガープリントを検査します。
* 読み取り専用の `GET /wallet/pools` に検索、ページング、ライブ飽和度を追加しました。
* トランザクションの取り込み、デコード、共同署名、送信 API に、マルチシグのしきい値検査を追加し、不完全な承認を防ぎます。
* SeedSigner の QR 専用通信、拡張フィンガープリント復元、ステーキング署名で、エアギャップのハードウェアウォレット対応を拡張しました。
* `nftmedia` による任意の NFT メディアを追加し、設定の保存、IPFS 取得、上限付き画像検証、NFT エンドポイントを実装しました。
* `BURSA_LEAN` を初期値として、Lean Storage の履歴期限切れを永続化します。`GET /wallet/settings/history-expiry` と `PUT /wallet/settings/history-expiry` で管理し、変更は再起動後に反映します。
* 共通の運用証明書デコードとして `bursa.DecodeOpCert` を公開し、呼び出し元間で解析を一貫させました。
* `GET /wallet/mnemonic/generate` で 24 語の BIP39 ニーモニックを生成します。作成ガイドでは確認への同意と、復元フレーズの 3 語の再入力が必要です。
* `bursa kes-agent` デーモンに serve-key/sign モード、フレーム付き Unix ソケット、制御コマンド、保護メモリ内 KES 鍵、永続的な単調期間ガード、ソケット保護、`kes_agent` 設定を追加しました。権限は `service_socket_mode` と `control_socket_mode` を使用します。
* ブートストラップ中もローカル導出アドレスと `usage_known` で Receive を利用できます。不確かな分類を表示せず、CIP-30 の利用状況メソッドが使えなければ HTTP `503` を返します。
* ローカル連絡先に `GET /wallet/contacts`、`POST /wallet/contacts`、`DELETE /wallet/contacts` を追加しました。検証上限、破損ファイル時の代替処理、Contacts 画面、Send のアドレス選択に対応します。
* Receive で次の未使用アドレスと個別アドレスの QR を表示します。操作しやすい切り替えと完全なアドレスのエンコードに対応します。
* アーキテクチャ別のネイティブパッケージを公開します。公証済み macOS `.pkg`、任意の WebView2 導入付き署名済み Windows `.msi`、Linux/FreeBSD アーカイブに加え、検証、アテステーション、Make ターゲット、署名環境の要件を用意しました。
* CIP-26 レジストリのトークン名、ticker、`0`～`18` の小数桁を表示します。レジストリがオンチェーンの小数桁を上書きできない場合は、オンチェーンの値を維持します。
* Android/iOS シェルにフォアグラウンドサービス、ライフサイクルとネットワークの耐障害性、オフライン対応ポーリングと再試行、ビルドツール、OS 別要件を追加しました。
* Buffer がない場合の起動代替、Ledger WebHID の遅延読み込み、回復可能なエラー境界、Stake タブ統合、コピー操作、診断プロキシ、Activity と CSV 出力、委任下書きの保持を改善しました。
* 履歴に詳細フィールド、`GET /wallet/transactions/{hash}`、Activity フィルターと詳細、CSV 出力、保留/削除済みトランザクション処理、CSV 数式注入対策を追加しました。
* CIP-30/CIP-95 拡張の契約を広げ、`getCollateral` の null を受け入れ、HTTP(S) の端から端までのオリジンとアドレスエンコード動作を明記しました。
* Settings タブ、Portfolio の Send/Receive、従来ルートの互換性、9 項目のナビゲーションを追加しました。
* BIP44 複数アカウント導出、永続保存、アカウント API、切り替え UI を追加しました。
* ログを出力できる診断 API と画面を追加しました。
* CIP-1854 のネイティブマルチシグアカウント導出に対応しました。
* ステーキング、ガバナンス、マルチシグのハードウェア署名経路を用意しました。
* 運用者向けの 5 項目ナビゲーションと Pool Ops モードを追加し、ステーク資格情報がないスクリプトウォレットではステーキング操作を省略します。
* Ledger/Trezor の CIP-8 ハードウェアメッセージ署名と COSE 出力を有効にしました。
* 選択した支払い鍵とステーク鍵でアドレスを導出し、明示した `WithAddressID` を導出既定値より優先します。
* Ledger/Trezor を共通のハードウェア署名経路で扱い、端末選択、Trezor の同意確認、複数アセット、厳格なエンコード検証に対応しました。
* `POST /v1/sign` の `type=opcert` に KES フィールドとコールド署名応答を追加し、ポリシー/ACL とプール鍵制限を適用します。
* Receive、Activity、Staking、DRep、プール、トランザクション、アドレスに Cardanoscan リンクを追加しました。デスクトップは `https`/`http` を検証してから OS ブラウザーで開きます。
* モバイルのレスポンシブなドロワーと上部バーで、キーボードと支援技術のフォーカス/スクロールを保持します。
* デスクトップのトレイ最小化、状態ポーリング、ネイティブ close/最小化制御、組み込み webview に必要な Linux ランタイム依存を追加しました。
* 任意の TPM 2.0 による vault 鍵の結び付けを追加しました。PCR 固定モード、パスワード代替、vault 形式 2 への移行、状態/有効化/無効化 API に対応します。
* ブートストラップの各段階とダウンロード進捗を保持し、UI の同期状態を改善しました。
* プール運用ツール、`/wallet/pool/*`、Operate UI、メタデータと運用証明書の作業フローを追加しました。
* CIP-8 検証とエアギャップのトランザクション署名を有効にしました。このフローには署名 sidecar が必要で、vault によるウォレットのライフサイクルに対応します。
* `apiVersion` 1、`getExtensions`、任意の CIP-95、制限的 CSP での登録テストによる CIP-30 拡張交渉を実装しました。
* `GET /wallet/rewards` と Rewards UI を追加しました。履歴は暫定的に空です。

### ⛓️‍💥 互換性に影響する変更

* HD 由来の署名鍵を拡張 Ed25519-BIP32 エンベロープに変更し、プールのコールド鍵は非拡張のままにしました。識別子、移行、エンベロープ契約を説明します。
* 従来の testnet API 名を正規の `mainnet`、`preprod`、`preview` に置き換え、OpenAPI/Swagger を更新しました。
* Linux/FreeBSD CLI を `tar.gz`、macOS をアーキテクチャ別 `.pkg` にし、macOS runner を固定してアップロード資産を認証します。
* モバイルのタグによる自動実行を停止し、手動ビルドにしました。macOS 署名は `APPLE_CERTIFICATE_PASSWORD` に合わせます。
* 永続的な KES `guard_file` を必須にし、再起動後も巻き戻し防止の下限を保持します。
* ソースの最低 Go を `1.26.0`、Prometheus client を `1.24.1` に更新し、`golang.org/x/sync` を `0.22.0` から `0.23.0` にしました。
* プールのコールド検証鍵導出を修正し、正規の `StakePoolVerificationKey_ed25519` と `StakePoolSigningKey_ed25519` を出力します。従来の Shelley 接尾辞の型も読み込みます。
* `cert op-cert` は、コールド検証鍵を含む正規の `NodeOperationalCertificate` CBOR エンベロープを出力します。
* ネイティブスクリプトの Ed25519 witness を暗号学的に検証します。API の `message`/`public_keys`、CLI の `--public-keys` を追加し、`--message` と `--message-hex` を排他的にします。
* `POST /wallet` に不正なニーモニックを送ると HTTP `400` を返します。
* `ui/web` のテストとカバレッジを `3.x` から Vitest `5.0.0` に更新し、対応する Node.js/Vite のエンジン要件を必須にしました。
* UI 開発環境は Vite `8.1.5`、Vitest `4.1.10`、`coverage-v8` `4.1.10` が要求する Node.js に対応する必要があります。
* マルチシグを正式な vault ウォレットにし、従来の `multisig.json` を移行します。`POST /wallet/multisig` は `vault_password` が必須で `WalletView` を返します。削除は `DELETE /wallet/multisig/{id}` から `DELETE /wallet/{id}` に移し、Send に統合します。
* DRep 一覧をノードのページング API に移し、退任/期限切れ/定義済みの意味、メタデータ URL と表示、投票力、ID 検索、CIP-129 検証を追加して `/wallet/dreps` の行スキーマを変更しました。
* 鍵と運用証明書の末尾 CBOR を拒否します。拡張 Ed25519 と cardano-cli VRF は、埋め込み公開識別子と導出値を照合し、導出した識別子を返します。
* 非ループバックの従来 API に TLS と Bearer JWT/JWKS を必須にしました。既定は `127.0.0.1` で、YAML `api.address`/`API_LISTEN_ADDRESS`、`api.jwt_secret`/`api.jwks_url`、任意の issuer/audience、TLS 証明書/鍵を指定できます。機密ルート保護、秘密応答の no-cache、POST 専用 `/api/wallet/create`、要求サイズ上限、Swagger/OpenAPI 更新も含みます。
* 出力しない `TxSummary.kind` の union 値と、使われない `ImportTransaction` 警告処理を削除しました。
* CLI メタデータハッシュを JCS ではなくファイルの正確なバイト列で計算し、NaN、無限大、負、`1` より大きいプールマージンを拒否します。
* ニーモニック導出をバイト列に統一し、不正なら `ErrInvalidMnemonic` を返します。
* 運用証明書の発行カウンターを `off`、`warn`、`enforce` と永続 SQLite で単調増加に保護します。
* `gouroboros` `0.205.5` に対応し、`NativeScriptNofK.N` を `int64` に変更、`PoolMetadataHash` を公開して、UI を `modernc.org/sqlite` に移しました。
* `/status` からウォレットのネットワークを取得し、`AddWallet` の選択欄を削除しました。クライアントはノードのネットワークを使用します。
* エアギャップ運用証明書の署名ペイロードを `OpCertSignableBytes` に修正しました。

* `signer.caller_policies` と `signer.policy_hook_url` を実行時に適用します。不正な呼び出し元ポリシーは起動を停止し、フックエラーは署名を拒否します。
* 固定 SHA-256 キー、件数とバイト上限、呼び出し元と nonce の衝突耐性のある分離でリプレイキャッシュを制限し、満杯なら拒否します。
* 取り込んだネイティブマルチシグのしきい値が 0 または不明なら送信を拒否します。有効な送信には正のしきい値と `signed_count >= threshold` が必要です。
* UI の `google.golang.org/grpc` を `1.82.1` から `1.83.1` まで更新し、xDS RBAC とバッファーを修正しました。
* 取り込んだネイティブスクリプトの witness を、消費する支払い出力に照合します。未結合/おとりスクリプトを拒否し、共有の支払いと mint の場合は維持します。
* UI の `quic-go` を `0.59.0` から `0.59.1` に更新し、HTTP/3 trailer を厳格に検証します。
* `modernc.org/sqlite` `1.56.0` で巻き戻し破損を修正しました。
* UI 通信を `google.golang.org/grpc` `1.83.2` と `golang.org/x/net` `0.58.0` に揃えました。
* 認証鍵処理の `keyfunc` を更新しました。
* JSON Web Key Set 処理の `jwkset` を強化しました。
* `sops` `3.13.3` で秘密管理を保護します。
* ブートストラップ段階を読みやすく表示し、`NodeNotReady` 再試行インターフェイスを追加しました。
* `type=postgres` と DSN/DSNEnv 解決で、PostgreSQL を共有ウォーターマーク/カウンターストアに設定できます。`/readyz` は必要な依存の準備を待ちます。
* validator `10.30.4` に対して検証しました。
* KES 発行カウンターのオーバーフローを拒否し、VRF/KES とプール証明書の入力を検証します。不適切な権限、過大ファイル、シンボリックリンク、再解析ポイントから秘密鍵を読み込みません。
* Keystone/SeedSigner QR フローの要求 ID を照合し、`crypto.randomUUID` が使えない場合は拒否します。
* GCP に保存した従来ウォレットの操作を管理者 Bearer JWT で認可し、`API_JWT_ADMIN_SUBJECTS` を必須にしました。
* 並行するウォレット出力エラーを決定的に集約し、Bech32、CBOR、最低手数料を強化しました。従来のパスワード項目を API と OpenAPI から削除しました。
* `github.com/blinklabs-io/gouroboros` を `0.202.2` から `0.202.8` に更新し、互換性修正を取り込みました。
* close 後の `FakeEventSource` 配信を防ぎ、`useAsync` の処理状態の取り込みを明確にしました。
* `golang.org/x/crypto` を `0.55.0` から `0.57.0` に更新し、間接 `x/*` のセキュリティとプラットフォーム修正を取り込みました。
