## v0.20.0

**タイトル:** 安全なウォレットストレージ、ブラウザー対応、プロトコル改善

**日付:** 2026-10-20

**バージョン:** v0.20.0

**リリース:** [v0.20.0](https://github.com/blinklabs-io/bursa/releases/tag/v0.20.0)

Bursa v0.20.0では、安全なウォレットストレージとリモートキー管理を拡充し、コネクターのFirefox対応を追加しました。また、モバイルのノードデータをウォレットデータから分離し、Cardanoプロトコル、データベース、暗号処理、送信の信頼性を強化しました。

### 推奨ネットワーク互換性 ⚠️

|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ 新機能
* 追加: AWS Secrets Managerによるウォレットストレージ、AWS KMSおよび`age SOPS`キーのサポート、ストレージ暗号化と起動時検証を導入しました。すべてのバックエンドで認証済みのウォレットCRUD、一貫した`404`レスポンス、汎用的な永続化エラー、永続的なウォーターマーク適用、キャンセルの伝播、Vault境界のテスト範囲も追加しました。
* 有効化: コネクターのFirefox向けパッケージングと実行時サポートを追加しました。ターゲット固有のマニフェスト、決定論的なアーカイブ、Firefoxのオリジン処理、ブラウザー間のCIP-30エンドツーエンドテスト、自動パッケージングとLint、`moz-extension://`認証に対応しました。
* 導入: AWS Nitro EnclavesとGCP Confidential Space向けの認証済みリモートキー管理を追加しました。トランザクションハッシュ、運用証明書、CIP-8に対するnonceと用途に紐づいた署名に加え、プラットフォームのアテステーション検証、強化されたHTTPおよびUnixトランスポート、JWKSリダイレクト制御、型付きKES Praosヘッダー署名によってキー管理操作を保護します。
* 分離: モバイルのノードデータベースをウォレットデータから分離しました。従来の`<DataDir>/db`データを一度だけ移行し、iOSの一時ディレクトリフォールバックを削除し、iOSとAndroidのノードディレクトリにプラットフォームに適した保護とバックアップ設定を適用しました。

### 🔒 セキュリティ
* 修正: `2.9.4`から`2.9.6`への更新後のCBOR処理を修正し、nullとundefinedの値がインターフェースの値をnilにクリアし、古いマップエントリーが残らず、無効な入力にはより厳格なエラーを返すようにしました。
* 強化: `filippo.io/age`を`1.3.1`から`1.3.2`に更新してageとSOPSの処理を強化し、不正なrecipientや、サイズ超過または複数recipientの入力を拒否できる検証を追加しました。
* 改善: SQLiteを`1.59.0`から`1.60.1`に更新し、libcとツールの依存関係も更新しました。write-ahead loggingの障害復旧と大きなパラメーターのバインディングをサポートし、仮想ファイルシステムのクローズ処理とモジュールバージョン要件を厳格化しました。
* 拡張: `gouroboros`を`0.212.5`から`0.213.3`に更新し、Goを`1.26.8`に更新しました。ノードとクライアントのプロトコルバージョン22および23、より厳格なコンセンサスとパイプラインの検証、有限なE34リーダー適格性、台帳、CBOR、DMQの修正を追加しました。
* 改訂: `gouroboros` `0.212.5`の統合を`0.210.0`から更新し、より厳格な台帳とCBORのデコード、ローカル状態クエリ、プロトコルの修正を適用しました。
* 更新: `golang.org/x/crypto`を`0.57.0`から`0.58.0`に更新し、`x/sys`と`x/term`も更新しました。上流のSSHおよびACME機能と、暗号処理およびSSH解析の修正を取り込みました。
