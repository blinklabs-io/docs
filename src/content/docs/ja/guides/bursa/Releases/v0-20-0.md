## v0.20.0

**タイトル:** 安全なウォレットストレージ、ブラウザー対応、プロトコル改善

**日付:** 2026-10-20

**バージョン:** v0.20.0

**リリース:** [v0.20.0](https://github.com/blinklabs-io/bursa/releases/tag/v0.20.0)

Bursa v0.20.0では、安全なウォレットストレージとリモートキー管理を拡充し、コネクターのFirefox対応を追加しました。また、モバイルのノードデータをウォレットデータから分離し、Cardanoプロトコル、データベース、暗号処理、送信の信頼性を強化しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ 新機能
* 追加: AWS Secrets Managerによるウォレットストレージ、AWS KMSおよび`age SOPS`キーのサポート、ストレージ暗号化と起動時検証を導入しました。すべてのバックエンドで認証済みのウォレットCRUD、一貫した`404`レスポンス、汎用的な永続化エラー、永続的なウォーターマーク適用、キャンセルの伝播、Vault境界のテスト範囲も追加しました。
* 有効化: コネクターのFirefox向けパッケージングと実行時サポートを追加しました。ターゲット固有のマニフェスト、決定論的なアーカイブ、Firefoxのオリジン処理、ブラウザー間のCIP-30エンドツーエンドテスト、自動パッケージングとLint、`moz-extension://`認証に対応しました。
* 導入: AWS Nitro EnclavesとGCP Confidential Space向けの認証済みリモートキー管理を追加しました。トランザクションハッシュ、運用証明書、CIP-8に対するnonceと用途に紐づいた署名に加え、プラットフォームのアテステーション検証、強化されたHTTPおよびUnixトランスポート、JWKSリダイレクト制御、型付きKES Praosヘッダー署名によってキー管理操作を保護します。
* 分離: モバイルのノードデータベースをウォレットデータから分離しました。従来の`<DataDir>/db`データを一度だけ移行し、iOSの一時ディレクトリフォールバックを削除し、iOSとAndroidのノードディレクトリにプラットフォームに適した保護とバックアップ設定を適用しました。

### 🔒 セキュリティ
* 修正: `2.9.4`から`2.9.6`への更新後のCBOR処理を修正し、nullとundefinedの値がインターフェースの値をnilにクリアし、古いマップエントリーが残らず、無効な入力にはより厳格なエラーを返すようにしました。
* 強化: `filippo.io/age`を`1.3.1`から`1.3.2`に更新してageとSOPSの処理を強化し、不正なrecipientや、サイズ超過または複数recipientの入力を拒否できる検証を追加しました。
* 改善: SQLiteを`1.59.0`から`1.60.1`に更新し、libcとツールの依存関係も更新しました。write-ahead loggingの障害復旧と大きなパラメーターのバインディングをサポートし、仮想ファイルシステムのクローズ処理とモジュールバージョン要件を厳格化しました。
* 拡張: `gouroboros`を`0.212.5`から`0.213.3`に更新し、Goを`1.26.8`に更新しました。ノードとクライアントのプロトコルバージョン22および23、より厳格なコンセンサスとパイプラインの検証、有限なE34リーダー適格性、台帳、CBOR、DMQの修正を追加しました。
* 改訂: `gouroboros` `0.212.5`の統合を`0.210.0`から更新し、より厳格な台帳とCBORのデコード、ローカル状態クエリ、プロトコルの修正を適用しました。
* 更新: `golang.org/x/crypto`を`0.57.0`から`0.58.0`に更新し、`x/sys`と`x/term`も更新しました。上流のSSHおよびACME機能と、暗号処理およびSSH解析の修正を取り込みました。

### 🐛 バグ修正
* 解決: デスクトップ通知プロセスの処理を修正し、両方の再取得経路で`cmd.Wait`の結果を収集し、nilではないエラーをデバッグレベルで記録するようにしました。

### 追加の変更
* 現代化: 拡張機能のツールを更新し、`web-ext`を`10.7.0`から`10.8.0`に更新するとともに、`shell-quote`と`fx-runner`も更新しました。リロード、glob、署名の修正と、より安全なシェルクォートを取り込みました。
* 置換: スキップされていたウォレットクライアントのチェックを`httptest`によるリクエスト、レスポンス、エラーのデコードテストに置き換え、CLIハッシュ出力のアサーションを安定化し、OpenAPIコードの競合テストと拡張機能の継続的インテグレーションを追加しました。
* 強化: UIアーティファクトのアップロード処理で`actions/upload-artifact`を`7.0.1`から`7.0.2`に更新し、レート制限されたリクエストがサーバーの`Retry-After`の指示に従うようにしました。
* 補強: モバイル、公開、UIのアーティファクトアップロード処理で`actions/upload-artifact`を`7.0.1`から`7.0.2`に更新し、サービスがレート制限を適用した場合の再試行動作を改善しました。
* 明確化: Unicodeと双方向テキストの処理で`golang.org/x/text`を`0.42.0`から`0.43.0`に更新し、`x/sync`と`x/tools`も更新しました。双方向ルールの初期化をより安全にしました。
* 追加: メトリクス形式のネゴシエーションオプションを追加し、Prometheusクライアントのインターフェースを`1.24.1`から`1.25.0`に更新しました。関連する依存関係も更新され、Go`1.26`が必要になりました。
* 制限: 組み込みノードのUTxO RPCトランザクション送信に30秒のダイヤル、リクエスト、コンテキストの制限を設定し、トランザクション参照の長さを検証するようにしました。Firefoxの`web-ext` Lintを`addons-linter`に置き換え、`js-yaml`を更新して、UTxO RPC SDKを接続しました。
* 抑制: モバイルとUIのアーティファクトダウンロードで`actions/download-artifact`を`8.0.1`から`8.0.2`に更新し、HTTP 429レスポンスへの再試行とバックオフ処理を改善しました。
* 更新: AWSサービス統合でAWS SDK v2を`1.47.1`から`1.47.3`に、`smithy-go`を`1.28.1`から`1.28.5`に更新しました。
* 改善: Viteを`6.4.3`から`6.4.4`に更新し、HTML変換、変換識別子、安全なモジュールパス、エディター起動統合の修正を取り込みました。
* 検証: モバイル、公開、UIのワークフローでNode.jsのセットアップを検証するため、`actions/setup-node`を`7.0.0`から`7.1.0`に更新しました。Node 22を維持し、バージョンチェック、マニフェストの再試行、`mise.toml`、絶対パスの`node-version-file`に対応しました。
* 維持: UIワークフローでNode 22を維持しながら、`actions/setup-node`を`7.0.0`から`7.1.0`に更新しました。
* 簡素化: モバイルと公開のワークフローでTemurin Javaのセットアップを簡素化するため、`actions/setup-java`を`6.0.1`から`6.1.0`に更新しました。
