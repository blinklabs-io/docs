## v0.25.0

**タイトル:** KESエージェント制御の拡張と、より安全なトランザクション承認

**日付:** 2026-11-14

**バージョン:** v0.25.0

**比較:** [v0.24.0...v0.25.0](https://github.com/blinklabs-io/bursa/compare/v0.24.0...v0.25.0)

**リリース:** [v0.25.0](https://github.com/blinklabs-io/bursa/releases/tag/v0.25.0)

### 概要

このリリースでは、KESエージェントのコマンドライン制御、ガバナンス証明書の概要表示の改善、承認署名前の補助トランザクションデータ検証を追加しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi              | ✅         |

### ✨ 新機能

* `info`、`gen-staged-key`、`install-key`、`drop-key`操作を備えた`bursa kes-agent control`コマンドを追加しました。このコマンドは`kes_agent.control_socket`または明示的な`--socket`値から制御ソケットを検出し、プロファイルを選択できます。JSON形式の応答ではキーのフィールドを16進数で返し、リクエストを30秒に制限し、キャンセル時はソケットの入出力を直ちに停止します。エージェントがリクエストを拒否した場合は、0以外の終了ステータスを返します。キー生成ではKES検証キーのエンベロープファイルを上書きせず、インストールでは運用証明書のエンベロープを受け付け、キー削除では`staged`、`active`、`all`の対象を検証します。

* DRepの登録・更新証明書と、委員会コールドキーの辞任証明書の概要にアンカーURLとハッシュを表示するよう改善しました。アンカーのない更新では`anchor none`と表示します。

* 承認フローで検証済みの補助トランザクションメタデータを表示し、補助データがない場合、一致しない場合、ハッシュ化されていない場合、サポート対象外の場合、デコードできない場合、スクリプトを含む場合、または表示するには大きすぎる場合は署名を拒否するようにしました。
