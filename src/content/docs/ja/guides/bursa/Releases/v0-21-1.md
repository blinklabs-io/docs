## v0.21.1

**タイトル:** より安全な署名、強化されたセッション制御、Cardano互換性

**日付:** 2026-10-27

**バージョン:** v0.21.1

**リリース:** [v0.21.1](https://github.com/blinklabs-io/bursa/releases/tag/v0.21.1)

### 概要

このリリースでは、KESと外部署名者の制御を強化し、再読み込み後もVaultとセッションのセキュリティ状態を正しく維持します。また、リソース制限と障害処理を改善し、`cardano-cli` `11.0`およびConwayトランザクション機能との互換性を拡張します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ 新機能

* 改善: KESキーのプッシュで、正確なアクティブ期間に対する認証成功を必須にし、ガード状態の永続化に失敗した場合は再試行するようにしました。
* 更新: Google Cloud Secret Managerの統合を`1.22.0`から`1.23.0`に更新しました。
* 強化: アイドルロックが有効になる前にアクティビティリスナーを登録し、有効化処理中のアクティビティもロックタイマーで認識できるようにしました。
* 保護: 外部署名者のポリシーフックで認証済みHTTPSを必須にし、リダイレクトと末尾のレスポンスデータを拒否します。`OperationSummary`を拡張し、概要が不完全な場合は安全側に倒して失敗するようにしました。
* 精密化: 署名処理の開始前に、解決済みキーのハッシュを1個以上162個以下に制限し、監査失敗時に生の署名者データを減らしました。

### 🔒 セキュリティ

* 制限: 並行するスクリプト検証リクエストの本文に使用するメモリを制限し、本文の受け入れスロットが利用できない場合はHTTP `503`を返すようにしました。
* 最新化: コンテナーレジストリへのログイン処理で`docker/login-action`を`4.7.0`に更新しました。
* 設定: リリース署名ジョブを`release-signing` GitHub Environmentで保護し、`main`ブランチとバージョンタグだけに制限しました。
* 整合: VRFおよびKESキーのエンベロープとVRF署名キーの配置を`cardano-cli` `11.0`に合わせました。
* 適用: サーバーが管理するVaultの自動ロックをUIの再読み込み後も適用し、`POST /vault/activity`を追加して、UIのロック状態をサーバーと同期するようにしました。

### 追加の変更

* 拡張: 署名者の上限に、国庫寄付および証明書や提案のデポジットなど台帳の値の影響を含め、完全性メタデータを公開しました。
* 更新: ニーモニックのサポートで`go-bip39`を`0.2.1`に更新しました。
* 導入: KESエージェントフレームの完了に10秒の期限を追加し、再接続時の動作を文書化しました。
* 追加: プール登録の所有者フラグとリレーフラグを導入し、`cardano-cli`と互換性のあるエンコードに対応しました。
* 有効化: Conwayのステーク登録および登録解除で、任意のデポジットフラグを使用できるようにしました。
* 制限: GCPウォレットのSecret Managerアクセスで名前空間を検証し、許可された範囲に制限しました。
* 強化: ニーモニック生成で`POST`リクエストを使用し、`no-store`と`no-cache`の動作を適用しました。
* 改訂: `gax-go/v2`を`2.27.0`に更新し、推移的依存関係も更新しました。

* 修正: `fast-uri`を`3.1.9`に更新しました。
* 認証: 起動URLトークンと`HttpOnly` Cookieを使用して、ウォレット制御とコネクターの同意セッションを認証しました。
* 更新: `modernc.org/sqlite`を`1.61.0`に更新し、SQLiteのサポートを進めました。
* 変換: 棄権および信任なしのDRepターゲットをConway配列としてエンコードしました。
* 検証: 固定されていないWindowsバンドルでWebView2の発行元を検証しました。
* 検査: JWKSリダイレクトのトランスポートを検証し、リダイレクトチェーンを制限しました。
* 簡素化: Dingoを`0.88.1`に、Apolloを`2.2.0`に更新して、UIの保守を簡素化しました。
