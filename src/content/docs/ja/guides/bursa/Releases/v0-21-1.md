## v0.21.1

**タイトル:** より安全な署名、強化されたセッション制御、Cardano互換性

**日付:** 2026-10-27

**バージョン:** v0.21.1

**リリース:** [v0.21.1](https://github.com/blinklabs-io/bursa/releases/tag/v0.21.1)

### 概要

このリリースでは、KESと外部署名者の制御を強化し、Vaultとセッションのセキュリティ状態を再読み込み後も正しく適用します。また、リソース制限と障害処理を改善し、`cardano-cli` `11.0`およびConwayトランザクション機能との互換性を拡張します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ✨ 新機能

* 改善: KESキーのプッシュで、正確なアクティブ期間に対する認証成功を必須にし、ガード状態の永続化に失敗した場合は再試行するようにしました。
* 更新: Google Cloud Secret Managerの統合を`1.22.0`から`1.23.0`に更新しました。
* 強化: アイドルロックが有効になる前にアクティビティリスナーを登録し、有効化処理中のアクティビティもロックタイマーで認識できるようにしました。
* 保護: 外部署名者のポリシーフックで認証済みHTTPSを必須にし、リダイレクトと末尾のレスポンスデータを拒否します。`OperationSummary`を拡張し、概要が不完全な場合は安全側に倒して失敗するようにしました。
* 精密化: 署名処理の開始前に、解決済みキーのハッシュを1個以上162個以下に制限し、監査失敗時に生の署名者データを減らしました。

### 🔒 セキュリティ

* 制限: 並行するスクリプト検証リクエストの本文に使用するメモリを制限し、本文の受け入れスロットが利用できない場合はHTTP `503`を返すようにしました。
* 最新化: コンテナーレジストリへのログイン処理で`docker/login-action`を`4.7.0`に更新しました。
* 設定: リリース署名ジョブを`release-signing` GitHub Environmentで保護し、`main`ブランチとバージョンタグだけに制限しました。
* 整合: VRFおよびKESキーのエンベロープとVRF署名キーの配置を`cardano-cli` `11.0`に合わせました。
* 適用: サーバーが管理するVaultの自動ロックをUIの再読み込み後も適用し、`POST /vault/activity`を追加して、UIのロック状態をサーバーと同期するようにしました。
