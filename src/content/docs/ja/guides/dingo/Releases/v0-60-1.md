## v0.60.1

**タイトル:** Mithril 復旧の高速化、Dijkstra の先端 nonce、依存関係

**日付:** 2026年6月29日

**バージョン:** v0.60.1

### 主な変更と改善

- 一時的な失敗後に Mithril スナップショットとアーカイブのダウンロードを円滑に復旧します。
- Google Cloud Storage のスナップショットとアーカイブアクセス、同梱サービス、データベース層、nview イメージを現行の対応に更新しました。
- Dijkstra のチェーン先端での nonce 計算を修正し、ブロック生成を安定させます。

### ツールと文書

- リリースとビルドのアテステーションを更新しました。
- リリースとテストの Go セットアップおよびキャッシュを更新しました。
- 2 つのサンプルの Node 型定義をそれぞれ更新し、2 つの Web サンプルの Vite も更新しました。
- v0.60.0 のノートを履歴に揃えました。
