## v0.81.2

**タイトル:** スナップショットの完全性、同期、ストレージの信頼性を改善

**バージョン:** v0.81.2

**リリース:** [v0.81.2](https://github.com/blinklabs-io/dingo/releases/tag/v0.81.2)

Dingo v0.81.2では、スナップショットの検証、ストレージの信頼性、ピア同期を強化し、ブロックフェッチの復旧応答性を高める機能とオプトインのブロックフェッチ閾値を追加しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### スナップショットの完全性とストレージ
* 検証: マイグレーションロックを保持している間に報酬ステークスナップショットのプロヴェナンスを検証します。プロヴェナンスを検証できない場合、Dingoはスキーママイグレーション、バックフィル、その他のデータベースやジャーナルの変更を実行する前に起動を停止します。検証済みのgenesis、era、protocolパラメータを持ち、Leiosコンテキストを含まず、データベースを開くすべての経路でgenesis選択が一致するバージョン2スナップショットだけが計算バージョン3に進めます。

### ストレージ、トポロジー、リカバリ
* 最適化: Mithrilバックフィル中のSQLite委員会認証クリーンアップを最適化し、各バッチを置き換え対象のIDに限定して、整数主キーによって行を削除します。これにより、古い統計情報が原因の全テーブルスキャンを回避します。
