## v0.77.0

**タイトル:** ガバナンス、同期、APIの信頼性を強化

**日付:** 2026-10-02

**バージョン:** v0.77.0

**リリース:** [v0.77.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.77.0)

Dingo v0.77.0では、ガバナンス処理、フォージングの安全性、報酬処理、API互換性、同期、検証を改善します。また、運用メトリクスを追加し、ConwayおよびDijkstraの動作に対する回帰テスト範囲を拡大します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ガバナンスと報酬
* Conwayのガバナンス処理を修正し、エポック境界で両方が適用される場合に、`ENACT` アクションより先に `RATIFY` アクションを実行するようにしました。

* Conwayの投票権にアクティブな提案のデポジットを含め、ガバナンスの決定に意図したステークの表現を与えるよう拡張しました。

* Conwayの `UpdateCommittee` のしきい値処理を改良し、委員会の更新で正しい承認ルールとクォーラムルールを使用するようにしました。

* Dijkstraの子ガバナンスを回帰テストでカバーし、子提案が正しいガバナンス経路に従うことを検証するようにしました。

* 重複したガバナンス提案識別子に対するDijkstraの回帰テスト範囲を強化しました。
