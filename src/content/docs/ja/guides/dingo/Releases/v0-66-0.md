## v0.66.0

**タイトル:** エポック報酬処理とサービスの安全な既定値

**日付:** 2026年7月19日

**バージョン:** v0.66.0

報酬の計算から適用、非同期の事前計算、ブートストラップ復旧、メタデータ API、外部サービスの既定値を改善します。

### 主な変更

- エポック移行中に報酬更新を準備し、ブートストラップを現行の報酬データに合わせ、データが準備できるまで初回適用を待ちます。
- 報酬を非同期に事前計算し、処理が所定のポイントに到達したときに適用します。
- 報酬ステークスナップショットとメタデータ API を拡張し、外部から状態を確認し、将来必要なデータを保持できます。
- Blockfrost の未対応ルートは `404` を返します。
- UTxORPC と Bark の最低 TLS バージョンを 1.2 にしました。古いクライアントは更新が必要です。
- PostgreSQL の報酬適合性テストを追加しました。
- Leios を Musashi prototype w29 の同期動作に合わせました。
