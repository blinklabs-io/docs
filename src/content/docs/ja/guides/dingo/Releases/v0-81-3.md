## v0.81.3

**タイトル:** ピアの信頼性、適合性、クエリ復旧を改善

**バージョン:** v0.81.3

**リリース:** [v0.81.3](https://github.com/blinklabs-io/dingo/releases/tag/v0.81.3)

Dingo v0.81.3では、ピア接続、Conway適合性レポート、認証済みブロック処理、オブジェクトストレージ連携、ローカルステートクエリの復旧を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ピア接続

* 改善: 正規化したトランスポート識別子ごとにフラップ履歴を追跡してインバウンドピア接続の安定性を高め、ホストごとの短時間セッションの繰り返しを制限し、スコープ付きIPv6アドレスを`/64`単位でグループ化しました。観測期間の終了後も有効なクールダウンを維持し、同じNATの背後にある無関係なピアを分離します。
