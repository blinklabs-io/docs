## v0.81.3

**タイトル:** ピアの信頼性、適合性、クエリ復旧を改善

**バージョン:** v0.81.3

**リリース:** [v0.81.3](https://github.com/blinklabs-io/dingo/releases/tag/v0.81.3)

Dingo v0.81.3では、ピア接続、Conway適合性レポート、認証済みブロック処理、オブジェクトストレージ連携、ローカルステートクエリの復旧を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ピア接続

* 改善: 正規化したトランスポート識別子ごとに接続断続の履歴を追跡してインバウンドピア接続の安定性を高め、ホストごとの短時間セッションの繰り返しを制限し、スコープ付きIPv6アドレスを`/64`単位でグループ化しました。観測期間の終了後も有効なクールダウンを維持し、同じNATの背後にある無関係なピアを分離します。

### 適合性と検証

* 追加: Conway CBOR適合性コマンドでCBORを検証して正規化し、`cardano-cbor-dataset`形式のJSONレポートを出力して、日付付きレポートをタグリリースの成果物として公開します。リリース配信ではレポートをちょうど1件必須にできます。Byronチェック、トランザクション出力インデックスの上限、ガバナンスのコストモデル言語IDチェック、Byron epoch 0 EBB処理、BlockFetchの低水位設定、関連する復旧動作も改善しました。

### テスト

* 修正: 台帳テストのコンパイルとLeiosの認証済み適用テスト用データを修正し、有効なブロックメタデータに対するLeios認証チェックとの整合性を保ちました。実稼働時の動作は変更していません。

### ストレージ

* 更新: AWS SDKのS3マネージャーを`v1.23.13`に、S3サービスを`v1.114.2`に更新し、関連する間接モジュールも更新してオブジェクトストレージ連携を最新に保ちます。

### 認証済みブロック処理

* 強化: すべてのネットワークで、証明書を確認した後にのみエンドーサーブロックを適用します。認証済み依存関係が欠落または無効な場合は、未検証のブロックを適用せず、拒否または待機します。メトリクスに利用できない結果を含めません。

### 可観測性

* 拡張: OpenTelemetry GoとOTLP HTTPトレースエクスポーターを`v1.47.0`に揃え、上流のログモジュールとエクスポーターのレスポンスサイズオプションを追加します。

### リリース自動化

* 防止: 適合性レポートがない場合でも、Bash 3.2でリリースを実行するときにシェル変数エラーが発生しないようにします。

### クエリ復旧

* 復元: 期限切れの`LocalStateQuery`ビューを取得済みのポイントまたはスナップショットの先端で再オープンしてローカルステートクエリの継続性を復元し、クエリを再試行し、プルーニングのピンを維持し、切断時に再オープン待機をキャンセルします。再オープンできないロールバックとプルーニングのケースは引き続き失敗します。
