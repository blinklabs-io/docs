## v0.91.0

**タイトル:** トレーシング、可観測性、性能、運用を向上

**バージョン:** v0.91.0

**リリース:** [v0.91.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.91.0)

**比較:** [v0.90.5...v0.91.0](https://github.com/blinklabs-io/dingo/compare/v0.90.5...v0.91.0)

Dingo v0.91.0では、ノード間トレーシング、運用上の可視性、ノード同等性の設定、データベース性能、コンテナビルド、プロトコル検証、ドキュメント品質を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### トレーシングと可観測性
* 追加: 各ブロックハッシュから共通のトレース識別子を導出するブロックトレーシングを追加し、従来のスパン名をステージベースの分類に置き換え、ステージ、トランザクション受付、キャッチアップ、Mithril、データベースのライフサイクルスパンをノード間で結び付け、ログを相関させました。任意のOTLPログおよびメトリクス出力には`OTEL_LOGS_EXPORTER`と`OTEL_METRICS_EXPORTER`を使用し、`OTEL_RESOURCE_ATTRIBUTES`と`OTEL_SERVICE_NAME`でサービスリソースを設定できます。SQLスパンはサンプリングされたトレースだけに記録し、`DINGO_TRACING_ALWAYS_SAMPLE_POOLS`で常時サンプリングするプールの許可リストを解析するトレーシングダッシュボードにも対応しました。
* 除外: オブザーバーに降格されたピアをLimit on Eagernessの候補から除外し、可観測性専用のピアがチェーン選択を制約しないようにしました。

#### API、ノード同等性、データベース性能
* 投影: SQLが対応する場合にBlockfrostのブロック出力と手数料の合計をSQLから直接取得し、トランザクション全体を読み込まずに十進値の正確性とフォールバック動作を維持しました。
* 設定: `--koios-tx-info-batch-size`と`--koios-tx-info-concurrency`でKoios `/tx_info`のバッチ処理を設定できるようにしました。既定値はリクエストあたり40ハッシュ、同時リクエスト数8のままで、検証とリクエストスケジューリングも改善しました。
* 最適化: インデックスに適したスロット範囲選択でエポック出力合計を取得し、APIモードのクロージャアドレス行の延期とロールバックを一貫させ、識別子とキャンセルを維持しながらSQLiteの挿入結果処理のオーバーヘッドを削減しました。
* 再利用: SQLiteの正確なbigint合計でスクラッチ値を再利用し、64ビットの十進文字列を高速処理しながら、幅の広い十進値の正確な動作を維持しました。
* 維持: 取得したトランザクション挿入結果を使い、SQLiteのトランザクション識別子、競合処理、リプレイ動作、ロールバック、キャンセルを維持しました。
* 効率化: APIモードのLeiosクロージャアドレス行をフラッシュまでまとめ、SQLiteのUTxO挿入結果処理のオーバーヘッドを削減しながら修復動作を維持しました。

#### プロトコル検証とビルド運用
* 強化: MithrilのGenesis証明書検証で、アグリゲートキーとプロトコルパラメータハッシュを署名済みメッセージに結び付けました。
* 選択: canonical DijkstraNetには従来のBLS_SIG証明ドメインを使用し、その他のチェーンとプライベートチェーンにはBLS_POPを起動、リプレイ、検証で一貫して使用しました。
* 更新: `ca-certificates`と`libssl3`の固定バージョンおよびDebianスナップショット日付を更新し、ビルドで必要なパッケージを解決できるようにしました。
* 切り替え: DockerのランタイムとAntithesisステージでライブDebianリポジトリと固定しないパッケージを使用し、フィンガープリント検証後に署名済みのライブ`pgdg`リポジトリからPostgreSQLクライアント16をインストールするようにしました。
* 改善: プロキシの転送エラーが発生した場合に、CIとDockerのモジュール取得が`https://proxy.golang.org`から`direct`へフォールバックするようにしました。
