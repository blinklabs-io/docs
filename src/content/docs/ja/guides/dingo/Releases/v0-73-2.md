## v0.73.2

**タイトル:** ロールバック復旧、ガバナンスレポート、データベース効率を改善

**日付:** 2026-09-27

**バージョン:** v0.73.2

**リリース:** [v0.73.2](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.2)

このリリースでは、ロールバックからの復旧、台帳のリプレイ、VRFキーの予約、遅延メタデータの復元、ガバナンス投票力のレポート、UTxOの一括削除を改善します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 復旧、ガバナンス、データベースの改善
* 改善し、ロールバック後の報酬事前計算の復旧で、古い処理中の作業をクリアし、有効な置換作業を復元または再キューし、古い世代からの再試行を拒否するようにしました。Dingoは事前計算の書き込みとロールバックの切り詰めをシリアル化し、永続的なtip floorをコミットできない場合は `FatalErrorFunc` を呼び出します。報酬計算とスキーマは変更されません。

* 修正し、slotだけでなく、slot、hash、block ancestry、block numberを含む完全なchain pointを比較して台帳を復旧するようにしました。同じslotにある有効な先行ブロックも復旧に参加できるため、リプレイが停止することを防ぎます。

* 改善し、エポック内のVRFキー予約では各プールの最新登録だけがキーを予約するようにしました。Dingoは置き換えられた中間キーを解放し、台帳検証をリファレンスの動作に合わせます。
