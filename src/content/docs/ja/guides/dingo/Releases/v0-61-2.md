## v0.61.2

**タイトル:** ピア復旧、検証、Leios の信頼性

**日付:** 2026年7月6日

**バージョン:** v0.61.2

ピア復旧、着信と発信の接続、検証、アーカイブの安全性を改善します。

### 主な変更

- 発見したピアと公開ルートの切り替えを安全にし、一度も接続できない相手への無限再接続を避け、過去の接続を追跡して繰り返す失敗にバックオフを適用します。
- 選択ピアのカーソルがローカル先端を越えた場合、カーソルを整合させ再同期します。
- Mithril とエポック境界をまたぐ Praos nonce の組み立てを修正し、起動時に欠けた Mithril gap ブロック nonce を修復します。
- ジェネシスと先端のブロック番号検索で正しい起点を返します。
- 解決した複数の IP を順番に試し、DNS を更新して、接続先失敗時に安全に代替します。

### 改善

- Leios エンドーサーブロックを非同期で blob 保存し、書き込み経路を止めません。
- Leios バックフィルの連続失敗に、接続ごとの長いバックオフを適用します。
- Musashi の keep-alive タイムアウトを延長し、一時的な遅延で正常接続を閉じないようにしました。
- `gouroboros` を `v0.186.2`、`v0.186.3` に更新しました。
- 消費済み UTxO 検証を設定可能にし、厳格モードと Mithril 境界検査で必要時に制御します。

### 修正と検証

- 台帳の保留処理が解消、整合するまで、ChainSync ピアの再利用を待ちます。
- 復旧不能な巻き戻しループをメトリクスと運用者への警告で報告します。
- Mithril 境界より前への復旧を拒否します。
- 受け入れ前に、プール登録とブロック番号の整合を検査します。
- Bark ダウンロードに HTTPS、URL 検証、サイズ上限、ホスト許可リストを適用します。
- 長さ 0 の Leios エンドーサーブロックも、デコード前にポイントハッシュを検証します。
- `golangci-lint` とサンプルの Node 型定義を更新し、上流不足時の台帳ピア補充と委員会投票クエリを改善しました。
