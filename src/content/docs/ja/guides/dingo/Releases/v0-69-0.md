## v0.69.0

**タイトル:** メモリプール再検証、復旧、API 対応の拡張

**日付:** 2026年8月7日

**バージョン:** v0.69.0

メモリプールとコンセンサス、台帳復旧、Blockfrost/LocalStateQuery、データベース、設定、Leios、CI、サンプルを改善します。

### 主な変更

- 二重バッファー FIFO、安定した台帳検証セッション、設定可能な `revalidationDeltaCap`、低いロック競合とベンチマークで再検証を改善します。
- ハードフォーク予測範囲を強制します。範囲を越えて届いたヘッダーはピアを切り替えず拒否を遅延し、アダプター間で `ErrPastHorizon` を保持して、リーダー事前計算を制限します。
- `GetLatestBlockNonce` を永続化済み適用位置の基準とし、主チェーン所属を正とします。同じ先端/スロットの巻き戻し不一致を修復し、再実行復旧の基準を固定します。
- `SlotTimeConverter` を分離し、現在付近のスロット代替計算と `EndorserBlockWaitDuration` のオーバーフローを修正しました。
- Conway `TxInfo` にプロトコル主バージョンを含め、型付き nil を早期拒否します。予算不一致に構造化エラーを返し、制限付き予算の定数を時代間で共有します。
- `GetChainDepState` と `GetPoolDistr2` を追加し、現在の先端から取得するデータと上限付きのプールスナップショット読み取り、リーダースケジュールを改善しました。
- Blockfrost の退任予定プール、メタデータ、詳細、一覧、アカウント報酬履歴、ステークアカウントの UTxO/出金/トランザクションを拡張し、拡張プール応答も期待する API に合わせます。
- データベースのスナップショット、復元、切り詰めのライフサイクル、プロセス内のライブ復元/切り詰め、S3/GCS ミラー、自動エポックスナップショット、メモリ内 SQLite スキーマ再実行、プールとメタデータの保持/性能改善を追加しました。
- 厳格な既定値、Mithril とネットワーク不一致、ネットワークマジック同期、Leios 署名鍵レジストリ検証、重要な DB 設定の永続化、`utxorpc` v1beta を含む設定と信頼検査を強化しました。
- BLS 鍵の読み込み、キャッシュ済みエンドーサーブロックのトランザクション安定性、プロトタイプ投票の鍵導出と署名メッセージ、および生成ブロックの提供情報の拡散を修正しました。
- 文書、CI、サンプルのビルド契約検査、アーカイブ例のビルドフラグ、依存関係とイメージの固定、README/DevNet の説明を揃えました。

### アーカイブと安全性

- 破壊的な DB RPC に mTLS を適用します。
- アーカイブから取得したブロックを受け入れる前に、要求したスロットとハッシュの一致を確認します。
- ブロックをローカル検証してメタデータを導出し、デコードした時代と異なる型を拒否します。
- デコード不能、本体のハッシュ/スロット/メタデータ/型の不一致、完全に認証できない Byron main ブロックの読み取りを明確に拒否します。
- 上流の Byron SSC 証明検証が利用可能になるまで Byron main アーカイブを制限し、エポック境界ブロックは許可します。
- 差し替えブロック、デコード不能本体、各種不一致、時代違い、期限切れ履歴解決、Byron アーカイブのテストを拡充しました。
- Bark の信頼境界と検証をアーキテクチャ/DB 文書に記載しました。
- `gouroboros` を v0.190.0 に更新し、リーダースケジュールとヘッダー検証のエラー返却を一貫させました。
