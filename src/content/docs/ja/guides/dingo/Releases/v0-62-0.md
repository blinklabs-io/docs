## v0.62.0

**タイトル:** Mithril 追いつき処理、証明書検査、データベース検索

**日付:** 2026年7月9日

**バージョン:** v0.62.0

追いつき処理の安全性、証明書検証、検索性能、Blockfrost のアセット保有者検索を改善します。

### 主な変更

- core モードの Mithril v2 で immutable マーカーを保持し、分岐を早期検出します。チェーンが一致する場合、全再同期を強制せず古い台帳状態を整合させます。
- ヘッダーとブロック適用で運用証明書を検査し、偽造、期限切れ、古い値、欠落区間を早期に拒否します。
- MySQL/Postgres のトランザクション検索の往復回数を減らします。
- MySQL のデータベース名を作成前に検証します。
- Blockfrost にアセット保有アドレス検索を追加しました。

### テストと依存関係

台帳状態適用の直接テストを強化し、Dijkstra/Leios の上流変更に合わせて `gouroboros` を更新しました。
