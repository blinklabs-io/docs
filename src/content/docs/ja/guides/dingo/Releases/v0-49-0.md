## v0.49.0

**タイトル:** Leios N2C 配信、報酬状態の永続化、ChainSync の安定性

**日付:** 2026年5月27日

**バージョン:** v0.49.0

通常の更新手順で対応できます。DingoSwap、Leios データ配信、報酬処理、送信の信頼性を改善します。

### 新機能

- ローカルの Preview 用 DingoSwap サンプルは、外部のホスト型チェーン API を使わず、Dingo の UTxO RPC から SundaeSwap 注文を構築します。
- Node-to-Client で Leios のランキングとエンドーサーのデータを統合して配信し、下流側が完全な情報を取得できます。
- 報酬追跡状態を再起動と巻き戻し復旧をまたいで保持します。
- スナップショット時のステークプール報酬アカウントの委任を CIP-1694 に従わせ、プールの投票結果を報酬アカウントの意図と一致させます。

### 改善と修正

- v0.48.0 のノートを追加し、DingoSwap のフロントエンドツールを更新しました。
- トランザクション送信の拒否内容を、現行ツールが期待する構造で返します。
- ChainSync の進行に応じて古いヘッダー追跡状態を削除し、保持量を制限します。
- 非同期送信失敗を捨てず、直接報告して接続の問題を検出、復旧しやすくします。
