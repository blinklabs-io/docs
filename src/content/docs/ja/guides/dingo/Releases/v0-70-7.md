## v0.70.7

**タイトル:** ネットワーク、保存、検証の信頼性向上

**バージョン:** v0.70.7

**日付:** Not provided

### ネットワークと同期

- ピア学習でRFC 5737 TEST-NETとRFC 3849の文書用アドレスを拒否します。トポロジーのプライベートアドレスと確立済みの受信接続の例外は維持します。
- Meshのリクエスト本文の読み取りを30秒、リスナー側の最終上限を60秒に制限します。
- ライブrollback時のプライマリチェーン巻き戻しをKまでに制限し、rollback通知を発行します。K超過とMithrilのケースは再同期向けに分類し、永続undoの順序とバッファー済みヘッダーを保護します。
- `LedgerState.Close`の結果を保持し、再生待機を10秒に制限します。
- アクティブな同期では、ヘッダーを配信済みの適格な追跡対象ピアを選択します。選択済みピアからピアなしへの遷移を集約します。
- 正規チェーン上で遅れているピアをK超過の分岐として排除せず保持し、K位置の交差点と`dingo_chainsync_behind_peers_total`を追加しました。
- ピア共有の応答サイズを制限し、不正なアドレスやルーティングできないアドレスを除外します。遅れて届いたヘッダーのcallbackが観測済み履歴を再作成しないようにしました。
- 起動時にピアスナップショット設定を検証し、`allLedgerPools`を追加しました。
- トランザクション送信でラップされた送信サイズ広告を受け付けます。サイズが一致しないバッチを破棄してバックオフし、`dingo_txsubmission_reply_size_mismatch_total`を公開します。
- チェーン選択イベントを専用の経路で順序付けし、停止したhandlerをwatchdogで検出します。`event_subscriber_handler_stalled_total`を追加しました。

### Leios、ブロック生成、復旧

- Leiosの永続化キューを256 MiBに制限し、委員会計算を集約して同時処理を16エポックまでに制限します。
- 同一スロットの競合でも必要な場合はリーダー選択に進み、予定された生成機会を見送った場合は警告します。
- 同一スロットのrollback競合は争点のスロットより前で処理し、安全な経路がない場合は明示的に失敗します。
- Leiosのフェイルオーバーをコンテキストで制限し、切れた接続を再利用せず作り直します。認証済みendorserブロックの重複復旧を除き、バックオフを段階的に増やし、callbackのシグネチャを更新しました。
- rollback・巻き戻しではバッチのコミット完了後にインデックスを復元し、復元を省略した場合を記録して、復旧先がチェーンに属することを確認します。
- 復旧先をライブtipから導出し、再試行数を制限して非収束を検出します。拒否が続く場合は安全側に停止し、undoイベントの重複と並行するチェーン変更後の古いメモリ状態の復元を防ぎます。
- 上流の目標が不明でもローカルtipが最新ならブロック生成を許可します。ローカルtipが古い場合は引き続き待機し、関連メトリクスを修正しました。
- ヘッダーVRFキーを、選出に用いたスナップショットのエポックに対応する登録履歴で検証し、そのエポックのキャッシュを固定します。
- Praosリーダーしきい値の二重切り上げを除去し、PreviewとPraosの境界を修正しました。`ScheduleFormatVersion`を`3`から`4`に上げて古い計画を無効化し、再試行のバックオフを制限します。
- 各時代のブロック生成前に運用証明書カウンターを確認し、コールド署名には共通の検証器を使います。TPraosカウンターとKES periodは`uint64`幅を保ち、永続化の上限`MaxInt64`を超えるカウンターを拒否します。

### 台帳と報酬

- 証明書のデポジットには、公開済みの同じプロトコルパラメータスナップショットを使います。未知のステークデポジットは`NULL`で保持し、明示的に記録されたゼロを正とします。誤った`KeyDeposit`による代替返金を防ぎます。
- Alonzo、Babbage、Conway、DijkstraでExUnits合計のオーバーフローを拒否します。受信ブロック全体の`MaxBlockExUnits`を適用し、Dijkstraサブトランザクションのwitness予算を数え、無効トランザクションのoverlay動作を整合させます。
- 報酬計算の分母に除外プールのステークも含めます。`RewardStakeCalculationVersion`を1から2に変更し、旧バージョン1の報酬状態は再bootstrapを必要とします。
- Mithrilスナップショットのブロック数を報酬性能計算に取り込み、件数がない場合は報酬ラウンドを実行しません。期待ブロック数は切り捨て、結果がゼロになる期待値を拒否します。
- Conwayの出金をネットワーク、認証情報の種類、認証情報のバイト列で並べます。スクリプト認証情報がキー認証情報より先になります。
- 実際の出所が確認できるまで、Dingoの合成PlutusV2コストモデルを外部の現行プロトコルパラメータに返しません。マーカーは再起動、rollback、truncateをまたいで永続化します。
- スナップショット再取得後のsigma分子・分母の整合性を決定論的な回帰テストで確認します。Dijkstraではphase 2を省略しても必須redeemerの検証を続けます。
- 符号付きMIR差分をSQL、台帳集計、アカウント合計、Blockfrost出力まで保持します。負の値を許可し、台帳が付与できない場合は集計を破棄します。
- ビルド時に`LedgerView`が`StakeCredentialDepositState`を実装することを確認します。
- 複数時代のエポックキャッシュでプロトコルパラメータを予測し、台帳のmutex解放後に`chain.update`とrollbackを公開します。
- Plutus有効期間境界の予測変換は、適用ブロックの直前のブロックを基準にします。
- Conway genesis作成時に初期委員を登録し、負の有効期限エポックを拒否します。
- migration v10を追加し、インポートされた報酬初期化失敗の`reward_seed_failure`由来情報を永続化します。

### アーカイブ、検証、依存関係

- ArchiveServiceはハッシュ、スロット、高さで検索し、存在しない参照ごとに`not_found`を返します。高さ検索にはメタデータを使い、圧縮メタデータを解読し、上限付きでS3内を検索します。
- 無効なchunk offsetを、型付きの`immutable.ErrInvalidChunkOffset`で返します。
- キャッシュ済み境界バッチの適用後に読み取り結果を完了します。台帳の読み取り・反復エラーは`readChainResult`で伝播し、再試行とバックオフを維持します。
- 停止・キャンセル時にslot clock購読を閉じ、エポックnonceのキャッシュでは生のnonceバイト列を比較します。
- Koiosのプール離脱は退役証明書で確認します。片側だけゼロの報酬行は情報上の一致と分類し、Dingoが付与した報酬だけを比較して重大な不一致数を報告します。`koios_epoch_params`でエポック別パラメータ比較、バックフィル、結果分類を追加し、テストスキーマの重複エポックテーブルを除きました。
- 適合性トランザクションをDingoの時代別バリデーターで再生し、検証の迂回を検出します。Conwayルールはdescriptorの同一性で解決します。空の周期トランザクションfixtureはエラーを返し、`nilaway`と`modernize`の指摘を修正しました。
- 生成出力がゼロという警告は、宣言済み出力やcollateral returnが失われた場合に限定し、ケース別のログ属性を追加しました。DRep返金の`NULL`の説明は実行動作を変更しません。
- リリースCIでサービスを使うテストとraceテストを分離しました。
- gOuroborosをv0.202.10、ouroboros-mockをv0.19.0、Google Cloud Storageを`1.67.0`、両サンプルのNode.js型定義を`26.4.1`に更新しました。`cardano-cli`ビルドイメージは`11.0.0.0-1`から`11.2.3.1-1`です。
- S3用AWS SDKを`1.107.3`から`1.110.0`、`golang.org/x/crypto`を`0.55.0`から`0.56.0`、MySQLドライバーを`1.10.0`から`1.10.1`、`prometheus/client_model`を`0.6.2`から`0.6.3`に更新しました。gOuroboros v0.202.9の厳格なKES検証を取り込み、適合性テストの委員辞任の後処理を修正しました。
