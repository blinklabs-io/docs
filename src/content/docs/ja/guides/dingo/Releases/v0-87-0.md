## v0.87.0

**タイトル:** リソース安全性、ネットワーク、コンセンサス互換性を改善

**バージョン:** v0.87.0

**リリース:** [v0.87.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.87.0)

**比較:** [v0.86.0...v0.87.0](https://github.com/blinklabs-io/dingo/compare/v0.86.0...v0.87.0)

Dingo v0.87.0では、リソース制御、ピアネットワーク、同期の安全性、APIの動作、設定のセキュリティ、コンセンサス互換性を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 破壊的変更
* 制限: UTxO RPC `FollowTip`の履歴リプレイに、プロセス単位およびクライアント単位の同時実行数制限、ペーシング、履歴予算を適用しました。需要が設定済みの制限に達すると、サービスは`ResourceExhausted`を返します。
* 追加: YAML、環境変数、CLIオプションでDMQピアリスナー、トポロジー、最小および最大ピア数を設定できるようにしました。Dingoは起動前にこれらの設定を検証します。
* 変更: Meshのメンプール一覧で、プールが設定容量を超えた場合に不完全な先頭部分を返す代わりに、再試行可能なHTTP `503`を返すようにしました。一覧はトランザクションハッシュのみを返し、同時実行数にも上限を設けます。
* 修正: Blockfrostのアドレス概要でキャンセルを尊重し、エンリッチメントを制限するようにしました。リクエストが予算を超えるとHTTP `400`を返し、需要が容量に達するとHTTP `429`を返します。
* 保護: 生成されたdevnet APIをループバックにバインドし、状態、キー、ファイル操作がシンボリックリンクによるリダイレクトを追跡しないようにしました。

### セキュリティと信頼性
* 検証: 認証済みトークンレジストリのアーカイブサイズとダイジェストを、Dingoがgzipおよびtarの内容を解析する前に検証するようにしました。
* 確認: ローカルImmutableDBのブロック本文ハッシュを検証してからブロックをインポートするようにしました。
* 制限: 展開後のMithril tarストリームの消費量に上限を設け、処理中のキャンセルを尊重するようにしました。
* 拒否: メタデータSQLiteの書き込み先行ログが`128 MiB`を超えている間はMCPの読み取りを拒否し、復旧後に読み取りを再開するようにしました。
* 正規化: Leiosのアナウンスヘッダーを重複排除と意味検証のために正規化し、リレーに使用するバイト列は保持するようにしました。

### API、同期、統合
* 更新: `google.golang.org/api`を`v0.304.0`に更新し、関連する依存関係を刷新しました。
* 修正: ジェネシスからの同期中に、将来のエポックのジェネシスオーバーレイパラメーターを予測する処理を修正しました。
* 必須化: すべてのトランザクション入力に1つのByron witnessを必須にしました。
* 改訂: AWS SDKの設定と関連モジュールを刷新しました。
* 拡張: Bark `ArchiveService`に、設定可能なグローバルおよび呼び出し元単位の検索予算を追加しました。クラウドルックアップが予算を超える前に、サービスは`RESOURCE_EXHAUSTED`を返します。
