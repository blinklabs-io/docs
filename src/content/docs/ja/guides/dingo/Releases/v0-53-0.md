## v0.53.0

**タイトル:** Mithril 同期の再利用、実験的 Leios 投票、供給量の修正

**日付:** 2026年6月10日

**バージョン:** v0.53.0

### 主な変更

- CLI 以外の Dingo ベースの処理からも Mithril 同期を実行し、ダウンロード、インポート、バックフィル、完了の進捗を追跡できます。
- 実験的な Leios 委員会投票を追加しました。ステークから委員を選び、接続ノード間で投票を共有し、検証済みステークから定足数を確認して、設定した投票鍵を使用します。
- 新規 Mithril バックフィルでは入力復旧の重複検査を省略し、再開時の安全な復旧経路は維持します。

### 修正

- Blockfrost のロック済み/流通供給量を正確にし、`/network/eras` から余分な `era` フィールドを除きました。
- Leios エンドーサーブロックとランキングブロックを正しく扱い、投票と統合ブロック配信をネットワーク動作に合わせます。
- ストレージ、Mithril、台帳、プロトコルの重要経路のエラーと検証を強化しました。

### 検証と公開

- 主要な公開に不要な付属イメージのビルドを省略します。
- リリースタグ以外の公開では、アテステーション失敗が処理全体を止めないようにしました。
- txpump テストで、生成済みジェネシス設定から資金データを正しく読み込みます。
- 期限切れメモリプールトランザクション数の検査と nil 保護のテストを強化しました。
- v0.52.1 の公開ノートを履歴に記録しました。
