## v0.73.0

**タイトル:** ledger検証、recovery、ノードのresilienceを改善

**日付:** 2026-09-25

**バージョン:** v0.73.0

**リリース:** [v0.73.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.0)

Dingoは直接利用できるCardanoブロックチェーンノードおよびAPIプロバイダーであり、Goライブラリとしては [`go doc`](https://pkg.go.dev/cmd/go#hdr-Show_documentation_for_package_or_symbol) と [pkg.go.dev](https://pkg.go.dev/github.com/blinklabs-io/dingo) でドキュメント化されています。このリリースでは、ledgerとgovernanceの検証を改善し、同期とrecovery workflowを保護し、ノード運用の制御を明確にします。

| preview-testnet     | ✅         |

### 検証とガバナンスの改善

* 改善し、無効な入力や空の入力を安全に処理して、値が存在しない場合の参照を避けるようにしました。([Change details](https://github.com/blinklabs-io/dingo/pull/4707))

* 強化し、Conway committee certificateの連続した検証で、transactionが同じ辞任を繰り返したり、同じメンバーを辞任させた後に承認したりすることを防ぐようにしました。([Change details](https://github.com/blinklabs-io/dingo/pull/4711))

* 安定化し、gated listenerによってnode parity reconnect testを安定させ、reconnect behaviorへの信頼性を高めました。([Change details](https://github.com/blinklabs-io/dingo/pull/4693))

* 整合させ、Byron transactionとbootstrap block終了時の検証をcardano-ledgerの動作に合わせました。serialized sizeとunknown attribute limit、positional witness、repeated input setの意味、feeとLovelaceの上限、canonical address root、bootstrap block終了時の順序、deterministic replay recoveryを含みます。([Change details](https://github.com/blinklabs-io/dingo/pull/4710))

* 防止し、ConwayおよびDijkstraのparameter変更でprotocol version key `14`を受け入れないようにし、enactment時にそのkeyを削除しました。([Change details](https://github.com/blinklabs-io/dingo/pull/4699))

* 堅牢化し、Mithril backfill recoveryでmalformed blockとoffset failureをfail closedとして扱い、最後にcommitしたcheckpointを保持し、過去のwithdrawal accountが不足している場合にerrorを報告するようにしました。([Change details](https://github.com/blinklabs-io/dingo/pull/4473))
