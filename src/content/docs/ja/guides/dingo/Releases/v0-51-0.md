## v0.51.0

**タイトル:** ストレージ調整、台帳ピアスナップショット、Leios の基盤

**日付:** 2026年6月7日

**バージョン:** v0.51.0

### 改善

- 圧縮レベルを含むストレージ圧縮設定を調整できます。
- ローカルクエリで台帳ピアスナップショットを取得できます。
- API バックフィルのデータベース書き込みを一貫させ、効率を改善します。
- text/JSON ログとログレベルを選べます。JSON を明示しなければ text が既定です。
- Dijkstra 対応と投票処理の初期基盤を追加しました。
- Leios 投票の共有と配信に対応します。
- Leios テストネット設定を同梱しました。
- エポック応答に Conway のプロトコル設定を含めます。
- スナップショットを使う Genesis 初期ピアと、同梱のスナップショットおよびトポロジーを更新しました。

### 修正とその他

- API バックフィル後の索引再構築を、緊急と遅延の処理に分けて負荷と復旧時間を減らします。
- 同梱 devnet を最小対応バージョン 11 に合わせました。
- 同期とブートストラップで、先端付近に取り残される停止を防ぎます。
- ローカル API に接続するエクスプローラー例と、v0.50.2 のノートを追加しました。
