## v0.54.0

**タイトル:** Mithril v2 の既定化、オフラインメタデータ取得、Leios と同期の改善

**日付:** 2026年6月12日

**バージョン:** v0.54.0

### 主な変更

- Mithril 同期の既定バックエンドを v2 にしました。従来の動作が必要な場合は v1 を明示します。
- アクティブなオンラインセッションなしでメタデータを取得し、完全な取得を開始する前に同期メタデータを確認できます。
- 実験的 Leios/Dijkstra のパイプライン時刻と段階の進行を改善しました。
- Dijkstra の Praos スロットリーダーに、実験的 Leios エンドーサーブロック生成を統合しました。

### 改善と修正

- 古くなった ChainSync ピアを検出し、早期に復旧して停止を減らします。
- 再接続とピアの入れ替わり後の復旧を安全にしました。
- Acropolis の `midnight_state.proto` を同梱し、gRPC コード生成を追加して MidnightState 連携を揃えます。
- API ライブラリのインポート先を `api/` 名前空間に移し、実行時エンドポイントは維持します。
- 実験的 Leios エンドーサーブロックのスロットが期待時刻と一致しない場合は拒否します。
- 確定した v0.53.0 のノートを追加しました。
