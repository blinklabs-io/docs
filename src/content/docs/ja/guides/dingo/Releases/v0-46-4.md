## v0.46.4

**タイトル:** ジェネシス起動の拡張、Mithril の可視性、データベースの安定性

**日付:** 2026年5月18日

**バージョン:** v0.46.4

ジェネシス起動の選択肢と同期監視を拡張し、出力の多い処理とデータベースの正確性を改善します。

### 新機能

- SQLite に加え、MySQL と Postgres でもジェネシスから初期チェーンを起動できます。
- Mithril 同期の進捗と段階を監視に公開し、復旧中の各手順を把握できます。

### 改善と修正

- SQLite のトランザクション出力検索を効率化し、出力の多い処理を高速化します。
- AWS S3、Google API、`btcutil` の依存関係を更新しました。
- v0.46.3 のノートを履歴に追加しました。
- 対応するデータベース間で、ジェネシス起動の初期状態を一貫させました。
- SQLite で値の非常に大きいトランザクションメタデータラベルを正しく処理し、オーバーフローを防ぎます。
