## v0.77.1

**タイトル:** ストレージ、同期、Mithrilの復旧、Dijkstra対応を改善

**日付:** 2026-10-03

**バージョン:** v0.77.1

**リリース:** [v0.77.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.77.1)

Dingo v0.77.1では、SQLiteの復旧用領域管理、blockfetchの配信、Mithril状態の修復、Dijkstraのスクリプト手数料計算、報酬クレジットのクエリ、ネットワークデータの検証を改善します。また、`gouroboros` をv0.209.0に更新し、DijkstraとConwayの動作に対する回帰テスト範囲を拡大します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ストレージとデータ処理
* `journal_size_limit` により、リセット後に保持されるSQLiteのwrite-ahead log領域を64 MiBに制限し、アクティブな書き込みやリーダーはこの上限を超えられる一方、`TRUNCATE` でアイドル状態のログをゼロまで縮小できるようにしました。

* Byron残高、手数料値の減算、作成UTxOのメトリクスを、`Produced()` ビューの出力0から65,535に対応させ、後続の出力の検証を継続するようにしました。また、`gouroboros` をv0.209.0に更新しました。

### 同期と復旧
* blockfetchの台帳公開を受信処理から切り離し、接続ごとに上限付きFIFO転送を行うことで順序を維持し、オーバーフロー、バックプレッシャー、キープアライブタイムアウトのメトリクスを追加しました。

* 認証済み先端がローカル先端の祖先である場合に、検証済みの末尾ブロックを保持し、派生メタデータを再構築することで従来のMithril報酬状態を修復し、安定アンカーより古い状態を拒否するようにしました。

### Dijkstraとガバナンス
* DijkstraのPlutus V4コンテキストと`required_top_level_guards`の回帰テスト範囲を拡大し、既存の検証動作を確認できるようにしました。

* Dijkstraのリファレンススクリプト手数料をプロトコルのストライドと乗数で計算し、必要に応じてConwayのフォールバックを使用するようにしました。また、Plutus V4のコストモデル動作を対象にしました。

* インポートした認証済みの`UpdateCommittee`アクションが次のエポック境界で適用されることを、回帰テストで確認しました。

### 効率性と整合性
* 保留インデックスでIDを選択し、主キーで行を読み取ることで、報酬クレジット請求時のSQLiteスキャンを削減しました。

* Mithrilのダイジェストリーフを数値順に並べ、検証または展開に失敗した利用できない完全ダウンロード済みアーカイブを削除する一方、部分ダウンロードとキャンセルを保持し、集約署名の解析を厳格化しました。
