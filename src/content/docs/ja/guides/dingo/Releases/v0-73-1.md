## v0.73.1

**タイトル:** transaction safety、reward accounting、protocol validationを改善

**日付:** 2026-09-25

**バージョン:** v0.73.1

**リリース:** [v0.73.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.1)

このリリースはv0.73.0と比較して、transaction decodingの安全性、Mithril snapshotのreward accounting、およびサポート対象のprotocol era全体のvalidationを改善します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### Stability、accounting、validationの改善

* 改善し、Blockfrost、Mesh、UTxO RPC、mempool、Ouroboros transaction submission全体で、malformedまたはmaliciousなtransaction bytesをnode crashではなくdecode errorとして処理します。transaction submission replyのdecodingでpanicが発生した場合、Dingoはreply全体をrejectします。

* 修正し、epoch途中にanchorされたMithril snapshotのreward potにimport済みのpre anchor feeを含めるようにしました。Mithril reconciliation中にlegacyのimport済みdatabaseをservice前にrepairするため、rewardとwithdrawalの値が分岐することを防ぎます。

* 更新し、gouroboros `v0.207.5`を通じてprotocol validationを改善しました。classic PPUPおよびMIR state rule、PV11 Plutus V3 reference input disjointness check、Dijkstra subtransactionのcommitteeとvoter validation、protocol major aware script context、正しいconformance DRep depositに対応します。
