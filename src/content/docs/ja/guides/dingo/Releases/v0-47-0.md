## v0.47.0

**タイトル:** 逆向きチェーン走査、Mithril バックフィル、安全な同期復旧

**日付:** 2026年5月21日

**バージョン:** v0.47.0

通常の更新手順で対応でき、履歴走査と同期制御を追加し、Mithril と API バックフィルを安定させます。

### 新機能

- 選んだチェーンポイントから起点へ逆向きに走査でき、履歴の表示を手で構築する必要がありません。
- ChainSync が停止と判断されるまでの無通信時間を設定でき、遅いネットワークや密度の低いネットワークに合わせて調整できます。

### 改善

- 履歴 API バックフィルのアドレス鍵の解決処理を削減しました。
- API バックフィル前、および Mithril インポートや再開後に SQLite のクエリ計画情報を更新します。
- 国庫出金、提案の期限切れ、成立の処理に関するガバナンス検証を拡充しました。
- v0.46.4 のノートを追加しました。

### 修正

- 長時間進まない Mithril ダウンロードを検出し、到達済みの位置から再試行、再開します。
- 現れないトランザクションを待つ WaitForTx は、無期限に待たずサーバーの時間制限で終了します。
- 同期ポイントに Mithril 信頼境界を含め、復元ノードの安全な復旧基準にします。
- Mithril API バックフィルで既存のオフセットの重複書き込みを省略します。
- API モードは履歴検索に必要な消費済み出力を、後処理やプルーニング後も保持します。
- 順序が重要な ChainSync イベントは、バッファー更新を捨てず、バックプレッシャーをかけて順序通り配信します。
