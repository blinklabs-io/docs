## v0.83.1

**タイトル:** 台帳検証、復旧、ストレージの信頼性を改善

**バージョン:** v0.83.1

**リリース:** [v0.83.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.83.1)

Dingo v0.83.1では、v0.83.0と比較して、台帳検証、プロトコル対応、復旧処理、リモートストレージの安全性、データベース性能を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 台帳とプロトコルの検証
* 改善: ネットワークごとのKoios事前ステーキング境界を適用し、Preprodではエポック5まで、デフォルトではエポック1まで厳密なジェネシスからのPreprodパリティを処理します。これにより、active stakeがnullの場合も正しく処理します。
* 検証: 選出されたプールのVRFキーを適用済み台帳チップで検証し、主要レコードを利用できない場合はスナップショットまたは有効な登録情報を使用します。
* 更新: `gouroboros` v0.213.1の統合により、ブロックパイプラインとLeiosプロトコルの対応を更新しました。更新された検証動作、`GetStakeDistribution2`、現在のLeiosメッセージ形式、`uint32`サイズのトランザクション参照に対応します。
* 追加: 更新操作によって誤って記録された委員会任期の開始位置を修復するデータベースマイグレーションv44を追加しました。

### 同期と復旧
* 強化: Leiosの過去データのバックフィルで適切なソースを選択し、配信ログのエントリを安全に削除します。
* 整合: 台帳状態から境界時代を導出し、検証とブロック生成を一致させます。
* 再試行: 台帳の遷移をまたいで生成済みブロックの自己検証を再試行し、検証できないブロックを誤った検証失敗として報告せずにスキップします。
* 確認: 復旧をエスカレーションする前に、ロールバックポイントをローカルのプライマリチェーンで検証します。
* 復元: キャッチアップインポート中にアンカーポイント後のメタデータをロールバックし、台帳の整合性を復元します。

### ストレージと運用の信頼性
* 拡張: リモートImmutableDBの宛先をリダイレクトとDNS解決を含めて検証し、暗黙のプロキシを無効化します。転送、キャッシュ、空き容量、同時実行処理に対する合計制限も適用します。
* 最適化: Mithril APIの初回ブートストラップ分類を最適化し、プランナー統計を確実に確定します。
* 高速化: SQLiteの遅延インデックス再構築を、バルクロード設定とUTxOのバッチ処理によって高速化します。

### Mempoolとピア管理
* 保持: ブロックで確定したトランザクションをmempoolから削除し、ロールバックされたトランザクションは保持します。
* 拒否: ローカルチェーンから大きく遅れているロールバック登録済みピアを拒否します。
