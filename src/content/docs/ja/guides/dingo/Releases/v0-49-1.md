## v0.49.1

**タイトル:** Preview swap の説明、Leios 対応、データベースの信頼性

**日付:** 2026年5月28日

**バージョン:** v0.49.1

Preview サンプル、Leios、報酬、データベース、および同期の安定性を改善します。

### 新機能と改善

- SQL ガイドでストレージの動作と主要なクエリ経路を説明します。
- DingoSwap はプールの読み取り、アセット管理、swap 注文構築、ブラウザーウォレット接続による SundaeSwap V3 Preview 操作を示します。現行のブラウザービルドツールに合わせ、セットアップと接続を改善しました。
- Leios のランキングとエンドーサー情報を統合し、接続アプリやテストツールに返します。
- CIP-1694 の投票時の報酬アカウント委任ルールを自動適用します。
- 報酬状態を実行間で保持し、報酬追跡と国庫表示の連続性を改善します。
- ビルド、テスト、公開、モジュールのツールを対応する現行要素に揃えました。

### 修正

- 呼び出し元のキャンセル時にチェーン読み取りを速やかに停止します。
- データベース操作にアクティブなネットワーク設定を一貫して渡します。
- Postgres のエポック要約の準備状態を、データベース処理中も保持します。
- 復旧インポートで欠けていたトランザクション結果と担保返却を保持します。
- 有効な送信拒否の詳細を保持し、接続 close イベントで ChainSync 送信失敗を通知します。
- 通常の同期中に過剰なヘッダー履歴を削除します。
