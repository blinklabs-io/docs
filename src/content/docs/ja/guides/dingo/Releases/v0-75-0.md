## v0.75.0

**タイトル:** 同期、検証、ノード運用を改善

**日付:** 2026-10-01

**バージョン:** v0.75.0

**リリース:** [v0.75.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.75.0)

このリリースでは、ジェネシスからの同期、リプレイとロールバックの検証、台帳とデータベースの処理、ピア選択、Leiosのエポック境界処理、運用時の可観測性を改善します。また、テスト範囲を拡大し、状態移行とデータベースの動作を明確にします。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 同期と検証の改善
* Byronのジェネシスからの同期を修正し、最初のブロックをキュー内のヘッダーチェーンに対して検証するようにしました。時代の範囲を超えたヘッダーは、ピアの障害として扱わず延期します。

* フルスイートおよびrace実行中の遅い起動と終了に対応できるよう、エントリーポイントのシグナルテストを改善しました。

* ライブおよびリプレイによるブロック適用時の必須Plutus支出データムと、プロトコルバージョンを認識するConway V3 `TxInfo` のテスト範囲を拡大しました。これにより検証要件を保護しつつ、本番動作は変更しません。

* 言語、プロトコルバージョン、コストモデル、synthetic V2状態をキーとする有界LRU Plutus評価コンテキストキャッシュを追加しました。`LedgerState` と `LedgerView` は一致するコンテキストを再利用し、繰り返しの構築を避けます。

* リプレイ、ロールバック、フォーク後のByron検証で採用済みプロトコルパラメータを使用するよう更新しました。パラメータの採用状況を判断できない場合はサイズと手数料の検査を省略し、Byron時代のスナップショット復元を明示的に拒否します。

### データベース、ガバナンス、各時代の処理

* `pool_history` が未公開のエポックについて、12時間の猶予期間を適用し、不完全な `KoiosFault` 結果を1件返すことで、誤ったプール単位のKoiosステーク不一致を抑制します。

* アーキテクチャーとデータベースのドキュメントから課題およびトラッカーへの参照を削除し、ドキュメントの整合性を検査する仕組みを追加しました。

* ブロック入力UTxOの先読みを検証済みブロックごとに1回のクエリへまとめ、使用済みエントリを安全に削除し、バッチクエリが失敗した場合はポイント読み取りに戻すようにしました。

* ロールバック時のプール更新を影響を受けるプールに限定し、データベース方言ごとの結合更新を生成するとともに、クエリメトリクスを改善しました。

* 各時代でrawブロックUTxOオフセットの永続化とトランザクション検証を整合させ、Dijkstraの有効性および担保返却ルールと、無効なトランザクションインデックスの厳密な処理に対応しました。

### ガバナンス、ネットワーク、状態処理

* バックグラウンドジョブで古いクレジット済み報酬ラウンドを圧縮し、エポック境界コミット後のRATIFYおよびSNAP処理を延期し、削除されるまでガバナンス提案の所属を保持し、可観測性とクエリを改善しました。

* データベースドキュメントで、Leiosエンドーサーブロックのblobキー、書き込み条件、重複排除の動作、コミット境界、synthetic bpの処理を明確にしました。

* ピアゴバナーターの動作を安定させ、ゴシップの変動によるホットセットの枯渇を防ぎ、`MinHotPeers` 未満の場合に上限付きのコールド再接続を行い、ピア選択メトリクスを追加しました。

* 重複排除された空のアセット名に対するMemPackのデコードを修正し、すでにインポートされた状態への移行上の影響を文書化しました。

### テストと可観測性

* Goのテストファイルを1,299個から640個に統合し、関連するビルド制約、インポート、ライセンス、lintディレクティブ、参照を修正しました。

* コミット済みバッチごとのブロック適用レイテンシーとバッチサイズのメトリクス、およびGrafanaパネルを追加しました。

* 後続エポックが公開されるまで、エポック境界をまたぐLeios証明書の検査を延期します。
