## v0.71.0

**タイトル:** 台帳の復旧と運用の信頼性を改善

**日付:** 2026-09-21

**バージョン:** v0.71.0

**リリース:** [v0.71.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.71.0)

このリリースでは、Dingoをv0.70.16からv0.71.0に更新しました。台帳の復旧、ステーク履歴、トランザクション送信、運用証明書の検証、KESエージェント連携、リプレイ処理、開発時の信頼性を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 台帳および復旧の改善

* 改善し、`gouroboros`を`v0.205.7`へ更新しました。Alonzoプロトコルパラメータの出所を厳格に検証し、プロトコルパラメータ移行v20に対応し、リストアを保護し、eraごとの`coins_per_utxo_size`動作を一致させ、トランザクション送信の境界を適用し、復旧検証を統一しました。

* 追加し、`serve-key`および`sign`モード、新しいCLIと設定オプション、プロトコル処理の範囲制限、検証、メトリクスを備えたBursa KESエージェントクライアントに対応しました。

* 復元し、保持期間のプルーニングで削除された報酬ステーク入力を再構成して、過去の報酬計算に必要な入力を保持するようにしました。

* 安全化し、保持されたプロデューサーの親またはフォールバックアンカーがない場合に、不完全な状態から復旧しないようリプレイ復旧を変更しました。

* 延期し、一括台帳状態インポート中の`reward_live_stake`再構築をインポート完了後に実行するようにしました。

* 整合させ、txpumpのウォレット入力とノードスナップショットを一致させて、トランザクション送信をノードの現在の状態に合わせました。

* 除外し、履歴ステーク計算から古い`POOLREAP`後の委任を除外しました。

* 一致させ、運用証明書のコールド署名検証を台帳検証で使用する厳格な基準に合わせました。

### 信頼性および検証の改善

* 安定化し、SQLiteの`DiskSize`テストが`AsyncWait`の期限内で完了するまで再試行するようにしました。

* 強化し、信頼済みの不変ブロックデコードに対するキャンセル検証を拡充して、キャンセル時にデコードを安全に中断できるようにしました。

* まとめ、バルクリプレイ中の早すぎる台帳バッチフラッシュを集約し、リプレイを監視しやすくするコミットバッチメトリクスを追加しました。

* 統一し、`ledger/eras/mir_test.go`のフォーマットを標準化して、保守の一貫性を高めました。

### 依存関係およびサンプルの改善

* 更新し、Dingo Blockfrost Explorerサンプルの`@types/node`依存関係を`26.5.1`から`26.6.1`へ変更しました。

* 引き上げ、Dingo Sundae Previewサンプルの`@types/node`依存関係を`26.5.1`から`26.6.1`へ変更しました。

* 刷新し、AWS S3 Go SDKサービスを`1.110.0`から`1.113.1`へ変更し、関連するSDKモジュールも更新しました。

* 最新化し、`klauspost/compress`を`1.19.2`から`1.20.0`へ更新しました。

### ビルドおよび品質の改善

* 拡張し、`docker/build-push-action`を`7.3.0`から`7.4.0`へ更新して、CIのビルド対応を改善しました。

* 改良し、`docker/setup-buildx-action`を`4.3.0`から`4.4.1`へ更新して、CIのイメージビルドを改善しました。

* 限定し、`NILAWAY_FLAGS`を通じて`make lint`のnilaway解析を`blinklabs-io`パッケージに限定しました。
