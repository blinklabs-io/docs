## v0.68.0

**タイトル:** Blockfrost、復旧、依存関係の拡張

**日付:** 2026年7月28日

**バージョン:** v0.68.0

Blockfrost、UTxO とスナップショット、再起動と再実行の復旧を強化します。

### 主な変更

- v0.67.1 のノートを追加しました。
- API バックフィルでライブステーク索引を保持します。
- DRep 一覧と応答を Blockfrost の形に合わせ、`GET /addresses/{address}` を追加しました。
- `bark`、サンプルの `@blaze-cardano/sdk`、AWS SDK for Go v2 本体と credentials/config、`cloud.google.com/go/storage` を更新しました。
- ポインターを使うスナップショット UTxO の処理を修正しました。
- `stake-address-info` の LSQ クエリを有効にしました。
- 証明書から DRep の活動を復元します。
- Blockfrost と UTxO-RPC の完全一致アドレス検索が同じ出力を返します。
- プラグインシステムを整理し、既存設定の移行互換性を維持します。
- Ouroboros では apply gate を進める前に巻き戻しを観測します。
- ジェネシス変更後の再起動と、開いたデータベースの所有権変更を安全にしました。
- mark スナップショットで reward_live_stake のライブビューを使用します。
- 再実行ループの失敗後に停止せず復旧でき、Leios プールの報酬アカウントを正しく解析します。
- 負荷時のイベントを捨てず、バックプレッシャーを適用します。
- 新しい貢献者 @mmahut を迎えました。
