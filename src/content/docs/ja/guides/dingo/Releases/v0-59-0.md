## v0.59.0

**タイトル:** チェーン選択、Midnight インデックス、API と台帳互換性

**日付:** 2026年6月26日

**バージョン:** v0.59.0

### 主な変更

- API モードで Midnight cNIGHT と登録イベントを追跡し、過去のバックフィル、再起動後の状態復元に対応します。認証トークンの一致を特定ポリシーに制限することもできます。
- 同じ先端や小さな先端分岐では、正常な接続ピアを維持して頻繁な入れ替わりを減らし、追いつき処理と先端付近の同期を安定させます。
- Blockfrost 互換のステークアカウント応答に、状態、総残高、委任詳細、登録履歴、ガバナンス委任フィールドを含め、現行の公開定義に近づけました。

### 改善と修正

- Mithril スナップショットと immutable アーカイブで、一時的な接続、レート制限、サーバーの失敗を再試行します。上限は設定可能です。
- スクリプトの一時的な計上が実行中に宣言予算を越える場合でも、ネットワークが受け入れるトランザクションを制限付き検証で過剰拒否しないよう修正しました。
- 並行する ChainSync の状態遷移とスナップショットをスレッドセーフにしました。
- ガバナンス代表者状態を期待される 4 要素形式で返し、標準クエリとトランザクション構築を正しくデコードできます。
- 元のヘッダーバイト列で証明を検証し、古いデコード済みフィールドによる有効ヘッダーの拒否を防ぎます。
- 内部の v0.58.0 ノートを公開履歴と揃えました。
