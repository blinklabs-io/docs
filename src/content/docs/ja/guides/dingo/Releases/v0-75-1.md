## v0.75.1

**タイトル:** 評価性能と運用の回復性を改善

**日付:** 2026-10-01

**バージョン:** v0.75.1

**リリース:** [v0.75.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.75.1)

このリリースでは、共有Plutus評価の性能、起動時のリプレイの回復性、キャッチアップ中のメトリクス、同時読み取り時のデータベース可用性を改善します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 評価と起動の改善

* 改善: 互換性のある評価コンテキスト間でコンパイル済みCEKマシンを再利用し、共有Plutus評価の処理を効率化しました。ExUnitsの値を維持しながら、繰り返し評価で発生するアロケーションを減らします。

* 防止: 起動時のリプレイでネットワーク状態が利用できない場合の参照エラーを防ぎました。エンドーサーブロックの処理はネットワークが利用できないことを報告し、ネットワークの起動後に再試行します。

### 監視とデータベースの改善

* 更新: ノードが利用可能なホライズンより遅れている場合、キャッチアップ中もチップとの差分とエポック長のゲージを更新します。レディネスの動作は変えずに、現在の同期メトリクスを確認できます。

* 削減: 読み取り処理の完了を待ってからSQLiteのWALを切り詰め、必要な場合は後で再試行することで、書き込みの停止を減らしました。読み取りが同時に発生してもデータベースの可用性を維持します。
