## v0.63.0

**タイトル:** Midnight アクセスとブロック検証の強化

**日付:** 2026年7月10日

**バージョン:** v0.63.0

Midnight、Blockfrost、ステークとスロットの報告、着信ブロック検証を改善します。

### 主な変更

- Midnight の大きな未消費出力一覧をページごとに取得できます。
- Midnight のガバナンス、ネットワーク設定、ブロック、エポック、ステータスの取得を拡充しました。
- Blockfrost のブロック応答に概要とヘッダーを、アドレスとトランザクション出力応答に欠けていたデータと参照詳細を追加しました。
- プールクエリのライブステーク合計を修正しました。
- 保存データの巻き戻し後処理の失敗をログに記録します。
- Byron 履歴のスロットを正しく計算します。
- Leios のエポック移行効果をプールとガバナンスに適用します。
- Dijkstra のブロック生成をチェーン規則に合わせて復旧しました。
- 検証が有効な場合、不正または順序違反の着信ブロックを早期に拒否します。

### テストと文書

記録イベントがない Midnight 巻き戻しもテストし、以前のリリースを対応する公開言語で文書化しました。
