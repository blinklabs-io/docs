## v0.90.2

**タイトル:** 同期の信頼性、台帳の正確性、API性能を改善

**バージョン:** v0.90.2

**リリース:** [v0.90.2](https://github.com/blinklabs-io/dingo/releases/tag/v0.90.2)

**比較:** [v0.90.1...v0.90.2](https://github.com/blinklabs-io/dingo/compare/v0.90.1...v0.90.2)

Dingo v0.90.2では、ネットワーク同期の信頼性、台帳とAPIの正確性、リソース使用量、MCPとUTxOの動作、運用の可視性を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 同期とネットワーク
* 防止: 適用済みのポイントが存在するまで Genesis と Origin の ChainSync がブロック 0 を越えて進まないようにし、チェーンの欠落を防ぎました。
* 遅延: 台帳の確定までヘッダーの再検証を遅らせ、同期の応答性を保つため待機時間を制限しました。
* 制限: `Limit on Eagerness` を不変チップに制限し、制限時間付きの eagerness 待機後に再同期するようにしました。
* 保持: ローカル認証の復旧後もピアを保持し、再同期の理由を別に記録するようにしました。
* メモ化: 各コンセンサスコンテキストで成功したピアフォーク祖先の状態確認をメモ化しました。
* フォールバック: Dingo がピアを選択しない場合にヘッダーパイプライン接続へフォールバックするようにしました。

#### 台帳、API、性能
* 置換: オペレーション証明書の `COUNT(*)` 検索をインデックスに適した `MAX(sequence)` 検索へ置き換えました。
* 反映: `GetStakeDistribution2` がライブの委任済みステークと流通供給量の割合を使うようにし、`GetPoolDistr2` の動作は維持しました。
* 正確化: Blockfrost のエポック出力合計を任意精度で正確に返し、負の小計を拒否するようにしました。
* 直列化: 並行する `GetUTxOWhole` 要求を直列化し、完全な結果を維持するようにしました。
* キャッシュ: 各述語評価で繰り返される UTxO RPC の使用済み出力検索をキャッシュするようにしました。
