## v0.65.0

**タイトル:** 報酬追跡の信頼性と遅いピアからの Leios 復旧

**日付:** 2026年7月15日

**バージョン:** v0.65.0

報酬メタデータ、プールステーク、Leios 追いつき処理、サンプルの開発ツールを改善します。

### 主な変更

- 起動時に欠けた報酬ステークデータを再構築し、再起動後の追跡と将来の処理用履歴を保持します。このリリースで報酬計算を導入するわけではありません。
- 各スロットの報酬アカウント残高をステークスナップショットに含め、報酬残高だけを持つ委任者も保持します。リーダーしきい値の誤検証を減らします。
- 遅い、または処理中の Leios ピアを長時間待たず、正常なピアに移ります。
- Sundae Preview と Blockfrost エクスプローラーは、TypeScript 7.0.2 を使用し、ローカル開発に Node 16.20.0 以降を必要とします。
