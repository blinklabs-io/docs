## v0.79.1

**タイトル:** 台帳の正確性、状態クエリ、インストール、運用の信頼性を改善

**日付:** 2026-10-07

**バージョン:** v0.79.1

**リリース:** [v0.79.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.79.1)

Dingo v0.79.1では、台帳検証、過去の状態クエリ、ネットワークピアの選択、データベース復旧、Mithrilインポート、リリースのインストールを改善しました。APIエラー応答、ガバナンスの整合性チェック、運用メトリクスも強化しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### メタデータと相互運用性
* 強化しました: CBORキーの順序に左右されないメタデータデコードを検証し、Blockfrostのページネーションとraw-CBORまたはJSONが利用できない場合の動作を安定させました。
* 拡充しました: 深さのあるPlutusDataをCBORマッピング、protobufのバイナリ、JSON表現間で往復する検証を拡充しました。
* 改善しました: MCPスキーマ検出に5秒の最小起動タイムアウトを適用し、深くネストしたConway redeemerの永続化検証も拡充しました。

### 台帳と状態クエリ
* 修正しました: Dijkstraトランザクション検証で、ガバナンス、証明書、エンティティのルールを宣言上有効なトランザクションだけに適用し、宣言上無効なトランザクションには構造と担保のチェックを引き続き適用します。
* 更新しました: Dijkstraの報酬とステークの再構築、prototype closureコンテキスト、genesisプールデポジットの記録、報酬ステーク計算バージョン3を更新しました。計算済み状態が古い既存データベースでは、リプレイまたは信頼できる台帳状態のインポートが必要です。

### インストール
* 導入しました: `@blinklabs/dingo`のプラットフォームネイティブなリリースバイナリを、SHA-256検証、アトミックインストール、Nodeラッパーによる引数・シグナル・終了コードの転送、Node `>=22`要件、対応OSとCPUのメタデータ、npm公開に対応させました。

### データベース操作
* 削減しました: Mithrilの一括インポート中にメタデータ書き込みフェーズを直列化し、スケジュール済みチェックポイントを抑制または再試行することで、SQLiteの書き込み競合を削減しました。
