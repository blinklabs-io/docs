## v0.74.1

**タイトル:** イングレスのリソースを制限し、台帳検証を強化

**日付:** 2026-09-30

**バージョン:** v0.74.1

**リリース:** [v0.74.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.74.1)

このリリースでは、イングレス中のリソース使用を制御し、データベースメタデータの報告を改善し、台帳データの検証と回帰テストを強化します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### イングレスとデータベースの改善

* 改善しました。イングレスのリソース制御で、デコードキャッシュとピアヘッダー履歴をバイト単位で制限し、拒否されたブロックをキャッシュから削除します。Leiosの投票とアナウンスの検証を固定ウィンドウ内で制限および統合し、信頼されたローカルのNode-to-Client接続とリモート接続の割り当てを分離します。`--max-trusted-local-ntc-conns` または `DINGO_MAX_TRUSTED_LOCAL_NTC_CONNS` で設定でき、0以下の値にはデフォルトの `100` を使用します。バッファ済みバイト数のメトリクスで、信頼されたローカル接続とリモート接続を区別できます。

* 更新しました。Barkの `GetDatabaseInfo` レスポンスが、`Tier` フィールドで設定済みデータベースストレージ階層を報告します。`core` や `api` などの値を返します。

### 台帳検証とテストカバレッジ

* 修正しました。台帳状態のインポート時に、包括的な `[0,1]` の範囲外にある委員会クォーラム値を拒否し、ConwayとDijkstraの不正なデコードに対する回帰テストを追加しました。

* 拡充しました。ConwayとDijkstraの `ParameterChange` 値について、ゼロ値、整数幅、ドメインとタグの境界、コストモデルの言語ID制限を含む回帰テストを追加しました。

* 強化しました。ShelleyからConwayまでの補助データのデコードと検証について、インデックス境界、時代ごとの形式とPlutus言語、未知のフィールド、不正なPlutusスクリプトを含む回帰テストを強化しました。

* 検証しました。Leios永続化キューの予約解放について、パニックからの巻き戻し、マニフェストと完了済みインストールの競合、バイト予算への同時参加を検証しました。フックはデフォルトで `nil` のため、既定の動作は変わりません。

### その他の品質とコントリビューター向けの変更

* 修正しました。切り詰めテストの準備で、コミットタイムスタンプを破損させる前に台帳状態を閉じるようにし、テストの競合を防ぎました。製品の動作は変わりません。

* 明確化しました。簡潔で事実に基づくGitHubコミュニケーションとプライバシー制限に関するコントリビューター向けガイダンスを明確化しました。
