## v0.74.1

**タイトル:** イングレスのリソースを制限し、台帳検証を強化

**日付:** 2026-09-30

**バージョン:** v0.74.1

**リリース:** [v0.74.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.74.1)

このリリースでは、イングレス中のリソース使用を制限し、データベースメタデータの報告を改善し、台帳データの検証と回帰テストを強化します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### イングレスとデータベースの改善

* 改善しました。イングレスのリソース制御で、デコードキャッシュとピアヘッダー履歴をバイト単位で制限し、拒否されたブロックをキャッシュから削除します。Leiosの投票とアナウンスの検証を固定ウィンドウ内で制限および統合し、信頼されたローカルのNode-to-Client接続とリモート接続の割り当てを分離します。`--max-trusted-local-ntc-conns` または `DINGO_MAX_TRUSTED_LOCAL_NTC_CONNS` で設定でき、0以下の値にはデフォルトの `100` を使用します。バッファ済みバイト数のメトリクスで、信頼されたローカル接続とリモート接続を区別できます。

* 更新しました。Barkの `GetDatabaseInfo` レスポンスが、`Tier` フィールドで設定済みデータベースストレージ階層を報告します。`core` や `api` などの値を返します。

### 台帳検証とテストカバレッジ

* 拒否するようにしました。台帳状態のインポート時に、包括的な `[0,1]` の範囲外にある委員会クォーラム値を拒否し、ConwayとDijkstraの不正なデコードに対する回帰テストを追加しました。

* 拡充しました。ConwayとDijkstraの `ParameterChange` 値について、ゼロ値、整数幅、ドメインとタグの境界、コストモデルの言語ID制限を含む回帰テストを拡充しました。
