## v0.67.0

**タイトル:** コンセンサス制御、メモリプール、チェーン復旧の拡張

**日付:** 2026年7月24日

**バージョン:** v0.67.0

ステーク配分と委任、設定可能なメモリプール、チェーン復旧、Mithril 検証鍵を更新します。コンセンサスに関係する変更には、設定による有効化や安全な既定値を維持します。

### 主な変更

- 設定で有効にする CIP-163 の全報酬ポット配分と、CIP-50 の pledge leverage を追加しました。
- 順序付き処理用の FIFO メモリプールバックエンドを設定できます。
- メモリプールは終了前に新規受付を止めます。クエリには変更不能なスナップショットを返し、検証中はプールのロックを解放します。
- チェーン選択前に Genesis 取得元の裏付けを確認します。
- CIP-163 の委任者非活動処理は設定で有効にし、既定は無効です。
- ステークスナップショット検索で `GetCBOR` ラッパーを受け入れます。
- 報酬ステーク不一致のクラッシュと、主チェーン巻き戻し後の復旧を修正しました。
- Mithril 検証鍵 URL を現在の場所に更新しました。
- devnet と適合性ツールに Dingo 単独対応を追加し、Antithesis 専用ビルドタグを使用します。
- issue-close CI を削除しました。
- gRPC を v1.82.1、gouroboros を 0.189.2 に更新しました。
