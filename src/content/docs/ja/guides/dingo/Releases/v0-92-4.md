## v0.92.4

**タイトル:** アクセス、プロトコルの安全性、同期を改善

**バージョン:** v0.92.4

**リリース:** [v0.92.4](https://github.com/blinklabs-io/dingo/releases/tag/v0.92.4)

**比較:** [v0.92.3...v0.92.4](https://github.com/blinklabs-io/dingo/compare/v0.92.3...v0.92.4)

Dingo v0.92.4では、一部のHTTPアクセスを復元し、台帳と同期の信頼性を向上させ、入力とネットワークの保護を強化し、ランタイムと依存関係のサポートを更新しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### APIとサービスアクセス
* 復元: Blockfrostのトランザクション送信と評価、MCPエンドポイント、Barkサービス、Prometheusの`/metrics`、Mithrilの登録およびクロージャAPIで、匿名の平文HTTPアクセスを復元しました。従来の認証、トークン、相互TLS要件はこれらのエンドポイントをブロックしなくなりました。レート制限、オリジン確認、リクエスト検証、および公開リスナーに必要なネットワーク層の保護は維持されます。
* 追加: Blockfrostのプールおよびエポックのブロックリストエンドポイントに、上限付きの受付と15秒の期限を追加しました。範囲外のページングは効率的に応答し、過負荷のリクエストには`Retry-After`付きの`429`または`503`を返します。
* 解決: Blockfrost、Mesh、Midnightの高さをストレージIDではなくチェーン番号で解決するようにし、疎なID、Byronの重複する高さ、適用済みチップ、ページングを修正しました。

#### 台帳とプロトコルの正確性
* 訂正: エポックの最初のブロックが遅れて到着した場合に、前回のステーク報酬ラウンドを再実行するようにしました。報酬ポットと手数料の繰り越しを修正し、Byronプレフィックスの処理とロールバック時に決定的な境界処理を維持します。
* 拒否: 型付きデコードの前にサイズ超過のCBORタグ30有理数を拒否し、プロトコルバージョンと`MaxTxSize`を考慮した上限でCPU枯渇のリスクを低減します。
* 前進: フォージ検証状態を候補スロットまで進め、検証専用のエポック境界の影響と参照スクリプトの確認を含めました。

#### 同期とノードパリティ
* 取得: ノードパリティのジェネシスからのチェーン読み取り中に、上限付きでチェーン順の`/tx_info`取得をストリーミングし、待機時の診断を改善しました。
* 保存: ノードパリティの境界キャプチャを再起動後も保持し、進行中のキャプチャを待機して成果物を検証し、安全にクリーンアップするようにしました。
* 改善: Koiosの`/account_list`クロールを、永続化したカーソルと部分ページ、完了状態への昇格、変動への対応、延長したタイムアウトによって、堅牢かつ再開可能にしました。

#### ネットワーク相互運用性
* 安定化: 最後に受け入れたプールメッセージを基準に待機することでDMQ相互運用性テストを安定させ、`SigTooFrequent`エラーを回避しました。
* 組み込み: prime mainnet用Cardano構成、トポロジー、ジェネシスファイルを組み込み、検証カバレッジを追加しました。
* 防止: 古い広告を持つピアがGenesisモードの受信スロットを占有することを防ぎ、リサイクラーによる排出を追加しました。

#### 運用と依存関係
* 適用: Goを1.26.11に更新し、ワークフローを`go.mod`に連動させ、Dockerビルダーイメージとキャッシュ名前空間を更新し、報告された`net/http`の脆弱性に対処しました。
* 有効化: オプトインの`DINGO_LOG_FILE_APPEND=true`で既存の通常ログファイルを再利用できるようにしました。権限を保持し、途中で切れた行には改行を挿入し、シンボリックリンクと通常ファイル以外を拒否します。既定の排他的作成動作は変更しません。
* 対処: `golang.org/x/crypto`を、報告された脆弱性に対処する修正版リビジョンへ更新しました。
* 安定化: フェイククロックを使用して、所有者が1つだけの場合のOuroboros期限テストを安定させました。
* 更新: AWS SDKの認証情報を1.20.9から1.20.16へ更新しました。
* 統合: `gouroboros`をv0.219.0に、`plutigo`をv0.12.1に更新し、Dijkstraの検証動作とPlutusデータAPIの変更を取り込みました。
