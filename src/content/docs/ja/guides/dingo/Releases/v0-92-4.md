## v0.92.4

**タイトル:** アクセス、プロトコルの安全性、同期を改善

**バージョン:** v0.92.4

**リリース:** [v0.92.4](https://github.com/blinklabs-io/dingo/releases/tag/v0.92.4)

**比較:** [v0.92.3...v0.92.4](https://github.com/blinklabs-io/dingo/compare/v0.92.3...v0.92.4)

Dingo v0.92.4では、一部のHTTPアクセスを復元し、台帳と同期の信頼性を向上させ、入力とネットワークの保護を強化し、ランタイムと依存関係のサポートを更新しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### APIとサービスアクセス
* 復元: Blockfrostのトランザクション送信と評価、MCPエンドポイント、Barkサービス、Prometheusの`/metrics`、Mithrilの登録およびクロージャAPIで、匿名の平文HTTPアクセスを復元しました。従来の認証、トークン、相互TLS要件はこれらのエンドポイントをブロックしなくなりました。レート制限、オリジン確認、リクエスト検証、および公開リスナーに必要なネットワーク層の保護は維持されます。
* 追加: Blockfrostのプールおよびエポックのブロックリストエンドポイントに、上限付きの受付と15秒の期限を追加しました。範囲外のページングは効率的に応答し、過負荷のリクエストには`Retry-After`付きの`429`または`503`を返します。
* 解決: Blockfrost、Mesh、Midnightの高さをストレージIDではなくチェーン番号で解決するようにし、疎なID、Byronの重複する高さ、適用済みチップ、ページングを修正しました。
