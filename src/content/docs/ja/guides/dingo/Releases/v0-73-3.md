## v0.73.3

**タイトル:** ダッシュボードの健全性、ガバナンス境界、ブロック監視を改善

**日付:** 2026-09-27

**バージョン:** v0.73.3

**リリース:** [v0.73.3](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.3)

このリリースでは、ダッシュボードの健全性表示、Conwayガバナンスの境界処理、直近ブロックの遅延監視を改善します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ダッシュボード、ガバナンス、監視の改善

* 改善し、[ダッシュボードの健全性ステータス](https://github.com/blinklabs-io/dingo/pull/4744)の同期判定をチップとの差分と直近スロット進行率に基づいて行い、選択した時間範囲にわたって状態を評価するようにしました。メトリクスを利用できない場合は `UNKNOWN` を表示し、起動直後のサンプルを除外して、ツールチップには過去の状態シグナルを保持します。SQL待機時間が `null` の場合も安全に扱い、ジェネシス同期中に `SYNCED` や `STALLED` と誤判定する状況を減らします。

* 修正し、[Conwayガバナンスの期限処理](https://github.com/blinklabs-io/dingo/pull/4676)で期限前の最終エポック境界に批准を実行し、批准済み提案を期限処理から除外し、DRepを期限エポック中もアクティブとして扱うようにしました。子孫提案と孤立提案の処理では、正しい前エポックの提案セットを使用します。

* 追加し、[直近ブロックの遅延メトリクス](https://github.com/blinklabs-io/dingo/pull/4742)でチェーン先端の直近16ブロックを追跡するようにしました。履歴では各遅延値をブロック番号と対応付け、空の配信、重複配信、順序が前後した配信を安全に無視するため、運用担当者は対応関係が崩れない状態で遅延の急増をグラフ化できます。

* 改良し、[Grafanaダッシュボード](https://github.com/blinklabs-io/dingo/pull/4740)のメトリクスクエリ、単位、凡例、フィルター、アラートしきい値を修正しました。フォージギャップと直近のブロック取得ビュー、20個のシグナルを表示するステータスストリップ、選択したインスタンス全体の最悪状態の集約を追加し、選択した時間範囲とインスタンスをリンク間で保持します。
