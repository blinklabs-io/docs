## v0.73.4

**タイトル:** プロトコル互換性、耐障害性、運用安全性を改善

**日付:** 2026-09-28

**バージョン:** v0.73.4

**リリース:** [v0.73.4](https://github.com/blinklabs-io/dingo/releases/tag/v0.73.4)

このリリースでは、Dingoノードとサンプル全体で、プロトコル互換性、検証、ストレージ効率、ネットワーク安全性、運用上の耐障害性を改善します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### プロトコルとコンセンサスの改善

* 共有委員会ホットキー認証、Leiosバックフィルのフェイルオーバー、Barkアーカイブ時代の正しい処理、MIRクォーラムの網羅性に対応するプロトコルサポートを更新しました。

* Dijkstra Leiosの委員会選出に、鍵の経過期間フィルタリング、意味論的なエンドーサーブロック検証、証明書チェック、迅速な投票キャンセルを追加しました。

* SQLite `VACUUM` をオプトインに変更し、遅延永続化中にChainSyncのロックを解放し、準備済みUTxO検索を使用し、メトリクスを拡張することで、データベースとチェーン同期を改善しました。

* S3およびGCSのBLOB一覧取得を最初の読み取りまで遅延し、範囲を制限したシーク動作を維持しました。

* クラシックプロトコルのパラメータ更新期間とクォーラム選出を参照実装の動作に合わせ、エポック0の提案を保存できるようにしました。

* 最初の運用証明書にゼロの基準値を適用し、不完全なMithrilリストアの後は安全に停止するようにしました。

* Byronの初期化で空のジェネシス設定を受け入れつつ、Byron時代の後退と型付きnilヘッダーを拒否するように修正しました。

* Conway Plutusコンテキストとコストモデルの動作を参照実装に合わせて調整しました。

* プライベートおよび特殊用途のKoios宛先をデフォルトでブロックし、必要なデプロイメント向けに明示的なオプトインを用意しました。

### 依存関係とサンプルの更新

* 現行のデータベース計測機能を利用できるよう、otelsqlによるデータベーステレメトリ統合を更新しました。

* SQLiteドライバーの依存関係を現行の`modernc.org/sqlite`リリースに更新しました。

* BlockfrostサンプルのNode.js型定義を最新化しました。

* SundaeサンプルのNode.js型定義を改訂しました。

* v4ステーブルスワップの見積もりに対応するため、SundaeSwapのコア機能と数学機能を拡張しました。

* バックプレッシャーが高まった場合も必要なEventBusサブスクライバーを保持し、必要なイベントコンシューマーを利用できるようにしました。

* 現行のViteリリースにより、Blockfrostサンプルの開発ツールを高速化しました。

* Sundaeサンプルの開発ツールに現行のViteリリースを導入しました。

### 信頼性と運用

* 実行されたPlutusコンテキストに限定して、Dijkstra参照入力の重複チェックを行うようにしました。

* AWS SDKの認証情報モジュールを現行の実装に置き換えました。

* リトライ処理の改善と空ブロックへのフォールバックにより、フォージ処理からの復旧を強化しました。

* Conway委員会の投票と状態の強制を、必要なプロトコルルールに戻しました。

* 起動に失敗する前にブロックプロデューサーのクリーンアップを登録し、起動初期のエラーでもクリーンアップを維持するようにしました。

* Byronの標準クロックスキュー許容値を適用しました。

* Leiosエンドーサーブロックのトランザクション選択をスロットの期限までに制限しました。

* 各スナップショットをアトミックに適用し、トークンレジストリのスナップショット同期を安定させました。

* ChainManagerのメトリクス再利用を保護し、ノードが競合する登録を避けるようにしました。

* 報酬のクレジット計上をエポック境界から前倒しし、メトリクス付きの再開可能な事前計算を追加しました。

* READMEと設定のデフォルトを簡素化しました。
