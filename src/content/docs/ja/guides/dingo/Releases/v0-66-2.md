## v0.66.2

**タイトル:** 公開ツール、ノード動作、テストの更新

**日付:** 2026年7月21日

**バージョン:** v0.66.2

Go ツールチェーンと依存関係、Leios NtC CertRB、MySQL 検証、UTxO 後処理と報酬検索を更新します。

### 主な変更

- `go-cid` を v0.6.2 に更新しました。
- `actions/setup-go` を v7.0.0 に更新しました。
- `aws-sdk-go-v2/credentials` を v1.19.29 に更新しました。
- `golang.org/x/net` を v0.57.0 に更新しました。
- `aws/smithy-go` を v1.27.4 に更新しました。
- Leios NtC CertRB の closure を待ち、接続終了、メトリクス、アーキテクチャ説明を改善しました。
- MySQL 適合性テスト、コンテナ運用、CI 環境、README の対応を拡充しました。
- UTxO 後処理の順序ソートを削除して簡素化しました。
- ライブステーク索引のクエリを修正し、報酬検索に正しいステークデータを返します。
- v0.66.1 のノートを追加しました。
