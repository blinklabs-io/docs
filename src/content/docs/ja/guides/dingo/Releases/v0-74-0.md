## v0.74.0

**タイトル:** 台帳互換性、同期、可観測性を改善

**日付:** 2026-09-30

**バージョン:** v0.74.0

**リリース:** [v0.74.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.74.0)

このリリースでは、Dijkstra時代とByron時代の台帳互換性を強化し、同期とblockfetchの動作を改善し、運用上の可視性を拡張するとともに、関連する依存関係を更新します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 台帳、互換性、同期の改善

* Dijkstraのネストされたトランザクション処理を、サブトランザクション本体レベルで、ライブ適用、ロールバックとリプレイ、バックフィル、Mithrilのギャップ復旧、コンフォーマンスの各経路にわたって改善しました。直接入金と順序付きガバナンスが、各経路で同じ状態遷移に従うようになりました。

* ノードがすでに適用したヘッダーを受け入れ、必要なプールスナップショットをプルーニングした後に検証を延期することで、ピアを誤って除外する状況を減らしました。

* Vector TestnetのConwayジェネシスJSONを正規化し、`genDelegs`と従来の`committee.quorum`を受け入れながら、重複フィールドや未知のフィールドは引き続き拒否するようにしました。デコーダーはファイル末尾を待たずに1つのJSON値を読み取るようになりました。

* EBBおよびPBFTの上限、設定可能な`PBftSignatureThreshold`、従来のMusashi Dijkstraストレージデコード、厳密なピアデコード、正規化されたLeiosトランザクションにより、Byron互換性を拡張しました。

* 初期同期でピアを切り替える際に最小ヘッダーバッチを適用し、新しいピアが必要最小限のバッチで処理を継続できるようにしました。
