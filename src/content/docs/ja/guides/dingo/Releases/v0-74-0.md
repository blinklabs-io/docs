## v0.74.0

**タイトル:** 台帳互換性、同期、可観測性を改善

**日付:** 2026-09-30

**バージョン:** v0.74.0

**リリース:** [v0.74.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.74.0)

このリリースは、Dijkstra時代とByron時代の台帳互換性を強化し、同期とblockfetchの動作を改善し、運用上の可視性を拡張するとともに、関連する依存関係を更新します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### 台帳、互換性、同期の改善

* Dijkstraのネストされたトランザクション処理を、サブトランザクション本体レベルで、ライブ適用、ロールバックとリプレイ、バックフィル、Mithrilのギャップ復旧、コンフォーマンスの各経路にわたって改善しました。直接入金と順序付きガバナンスが、各経路で同じ状態遷移に従うようになりました。

* ノードがすでに適用したヘッダーを受け入れ、必要なプールスナップショットをプルーニングした後に検証を延期することで、ピアを誤って除外する状況を減らしました。

* Vector TestnetのConwayジェネシスJSONを正規化し、`genDelegs`と従来の`committee.quorum`を受け入れながら、重複フィールドや未知のフィールドは引き続き拒否するようにしました。デコーダーはファイル末尾を待たずに1つのJSON値を読み取るようになりました。

* EBBおよびPBFTの上限、設定可能な`PBftSignatureThreshold`、従来のMusashi Dijkstraストレージデコード、厳密なピアデコード、正規化されたLeiosトランザクションにより、Byron互換性を拡張しました。

* 初期同期でピアを切り替える際に最小ヘッダーバッチを適用し、新しいピアが必要最小限のバッチで処理を継続できるようにしました。

* OpenTelemetryの標準出力トレースをv1.45.0からv1.46.0に更新しました。

* Google Cloud Storageをv1.67.0からv1.68.0に更新しました。

* アクティブな総ステーク量をKoiosと比較して不足しているプールを検出し、Koiosがエポック情報を提供できない場合もプールごとの不一致を保持するようにしました。

* 推定ワイヤーサイズを基準にblockfetchの範囲を最適化し、上限を8 MiB、`ExpectedBytes`、範囲サイズの3倍の処理中予算を設定しました。

* `google.golang.org/api`を関連モジュールとともにv0.299.0へアップグレードしました。

* gRPCをv1.86.0-devへ進め、Envoy依存関係を更新しました。

* オプトイン方式のジェネシスからのPrometheusメトリクス、新しいlivenessアラート、参照ラベル、不完全なチェック用メトリクスを追加しました。

* BabbageとConwayの報酬計算で`d=0`を使用するように修正し、ブロックカウントにはパフォーマンス時代の値を引き続き使用するようにしました。

* Byronの更新システムの状態遷移を導入してプロトコルパラメータを採用し、境界、サイズ、手数料、`TxAux`値のチェックを厳格化しました。

* `gouroboros`をv0.208.3へ更新し、トランザクション送信パイプラインのエラー処理を変更しました。Dingoは`dingo_ledger_block_pipeline_apply_pending_limit_errors_total`メトリクスを出力しなくなりました。

* ByronのEBBの配置と順序を設定されたエポック長に合わせ、更新投票と採用境界の検証を追加しました。

* `aws/smithy-go`をv1.28.2へ更新しました。

* 古いサンプルアプリケーションを削除し、Preview Koiosのパリティ監視をオプトイン方式のDevNet Composeプロファイルへ移行しました。

* ブロックしないHomebrew tap更新ジョブを自動化し、リリースコミットハッシュを標準化しました。
