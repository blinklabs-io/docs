## v0.50.0

**タイトル:** ブラウザー対応 API、Gov Lens、Mithril 一括ロードの改善

**日付:** 2026年6月1日

**バージョン:** v0.50.0

Web 統合と Gov Lens を追加し、大規模な Mithril ロードと保守を改善します。

### 新機能

- Bark、Blockfrost、Mesh、UTXORPC でブラウザーからの要求を扱いやすくしました。
- ガバナンスダッシュボード Gov Lens と、そのデプロイ資産を追加しました。

### 改善と修正

- 一括インポート中の一部メタデータ検索を遅延し、再起動後に安全に復元します。
- Mithril バックフィルの進捗と時間情報を拡充しました。
- Gov Lens の起動例は、自動的に Mithril 同期の準備完了を待ちます。
- アーカイブとプルーニングのデプロイ説明を拡充しました。
- Badger の復旧と、読み取りが予期せず閉じた場合の処理を安全にしました。
- 生成ブロックの再デコード失敗に明確な診断情報を記録します。
- Plutus の検証結果と再実行検査を一貫させました。
- 重複インポートの保護を弱めず、一括ロード中のアセットポリシー検索を遅延します。

### サンプル、公開、依存関係

- Dingo Sundae Preview のパッケージを更新しました。
- リリースワークフローから npm パッケージ公開を削除しました。
- `blinklabs-io/nview` v0.14.0 と `blinklabs-io/go` 1.26.3-1 を採用しました。
- AWS SDK、`smithy-go`、`google.golang.org/api`、OpenTelemetry の HTTP および stdout トレースエクスポーターを更新しました。
