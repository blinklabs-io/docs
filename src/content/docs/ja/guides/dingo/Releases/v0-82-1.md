## v0.82.1

**タイトル:** データベース復旧時のトランザクション超過を防止

**バージョン:** v0.82.1

**リリース:** [v0.82.1](https://github.com/blinklabs-io/dingo/releases/tag/v0.82.1)

Dingo v0.82.1では、保持ブロックのインベントリを上限内のバッチで再構築することで、旧形式データベースの復旧を改善しました。このパッチリリースによるアプリケーションの変更は必要ありません。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### データベース復旧
* 改善: 保持ブロックのインベントリに対応する前の旧形式データベースで、起動時とコミット時刻の復旧時に保持ブロックの検索情報を上限内のバッチで構築します。1つのトランザクションにすべての検索情報を収められない場合のサイズ上限エラーを防ぎ、大規模なデータセットでもインベントリ件数、最古スロット、後続関係、検索結果を正しく維持し、初期化時に古い検索情報を削除します。
