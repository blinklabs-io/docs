## v0.63.1

**タイトル:** 誤ったエラー通知の削減と依存関係更新

**日付:** 2026年7月14日

**バージョン:** v0.63.1

### 主な変更

- 想定された重複接続の終了を、エラーではなく情報イベントとして扱います。
- 同梱のログ設定ファイルと Musashi ネットワーク設定を更新しました。
- 並行制御の不正な内部値を直ちに拒否し、状態の破損を防ぎます。
- サービスのヘルス依存関係を、既存のチェック動作を維持して更新しました。
- 低レベルのシステム、セキュリティ、端末、テキストの各ライブラリを更新しました。

### サンプル

Blockfrost エクスプローラーと Sundae Preview の Web 依存関係を更新し、Sundae Preview を現行の SundaeSwap core ライブラリに合わせました。
