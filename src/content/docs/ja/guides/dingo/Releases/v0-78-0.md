## v0.78.0

**タイトル:** APIアクセスを拡張し、ノードの信頼性を強化

**日付:** 2026-10-04

**バージョン:** v0.78.0

**リリース:** [v0.78.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.78.0)

Dingo v0.78.0では、オプトインのAPIアクセスを拡張し、ノードのシャットダウンとプロバイダーのクリーンアップを予測可能にし、ConwayおよびMithrilアンカーに基づく会計を修正し、遅延ヘッダー検証とピアの再同期を強化します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### APIアクセス
* 拡張: オプトインのModel Context Protocol (MCP) APIプラグインを追加し、`/mcp`ではStreamable HTTP、`/sse`ではSSEを提供します。Dingoは`/health`と`/healthz`でヘルスチェックを公開し、読み取り専用のSQLiteおよびCardanoツールと再開可能なUTxOクエリにより、より安全なデータアクセスをサポートします。認証、レート制限、オリジン検証でリクエストを保護し、ループバック以外のバインディングには認証とTLSが必要です。

### ノードのライフサイクルとインターフェースの変更
* 改善: コンテキストで制限されたシャットダウン、決定論的な接続完了処理、停止したハンドラーを報告する制限付きEventBusシャットダウン、協調的なプロバイダーのクリーンアップ、登録に失敗した場合もパニックを起こさずロールバックするメトリクス登録を実現しました。Mempoolの完了チャネルは`<-chan error`から`<-chan struct{}`に変更されたため、利用側は処理するチャネル型を更新する必要があります。
