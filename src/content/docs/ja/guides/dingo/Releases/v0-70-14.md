## v0.70.14

**タイトル:** インポート性能、チェーン選択の耐障害性、運用の可視性を改善

**日付:** Not provided

**バージョン:** v0.70.14

**リリース:** [v0.70.14](https://github.com/blinklabs-io/dingo/releases/tag/v0.70.14)

このリリースでは、インポート性能、ブロック処理、チェーン選択、ledgerとdatabaseの可観測性、ガバナンス処理、起動時の復旧処理を改善しました。また、プロトコル互換性を更新し、blockfetch、forging、genesis、socket、nonceの検証を強化しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ランタイムおよび運用面の改善

* 更新し、`gouroboros`を`v0.205.4`へ引き上げ、Plutusの適合性を復元しました。

* 再利用し、importerのUTxO statementを繰り返しのimportで準備する重複したdatabase operationを減らしました。

* キャッシュし、importしたasset statementに対するimport中のdatabase準備の繰り返しを減らしました。

* 読み取り、immutable blockを`ReadAt`でposition指定し、要求されたread offsetを保持するようにしました。

* 永続化し、Mithrilがgap blockを取り込む間のcertificate rowとera-derived depositを保持するようにしました。

* 登録し、post-intersect rollback後のrecycled peerと、chain selectionのstallおよびrollback registrationのmetricsを扱えるようにしました。

* 強化し、equal-slot alternative block forgingをfail closedにし、validなsibling blockを採用してstaleなblockfetch stateを無効化するようにしました。

* 報告し、SQL storeのreadおよびwrite connection-pool contentionを可視化するようにしました。

* 再構築し、truncationによって削除されたblockのnonceを残存するcanonical checkpointから復元するようにしました。

* 解放し、`DiskSize`の測定中に共有`readDB` connectionを保持しないようにし、WAL checkpointのガイダンスを明確にしました。

* 追加し、blockごとのledger composition metricsを提供するようにしました。

* queueに追加し、startup中に進行中のepoch stake-reward precomputationを処理するようにしました。

* decodeし、Conway committee authorizationのsum typeを処理し、resignationを保持し、malformedなcommittee dataを拒否し、feeがnilのtransactionを扱うようにしました。

* 関連付け、LeiosNotifyのcursor cleanupをconnection ownershipとconnection lifecycleに従わせました。

* 保持し、`epochStartSlot`を固定することでepoch boundaryをまたいだVRF-key reservationを維持するようにしました。

* 制御し、discretionaryなchain-selection switchにglobal rate limitを適用しました。

* 遅延させ、期限切れのgovernance proposal deposit refundを1 epoch後に実行し、`DROP` stateに対するmigration safetyを保持しました。

### テストおよび検証の改善

* 修正し、blockfetch endpoint testでmuxer segmentではなく完全なprotocol messageをparseするようにしました。

* 拡大し、operational certificateのpersistable-counter rejectionに対するapply-path coverageを強化しました。

* 固定し、embedded genesis hashとUnix socketのtest pathを検証しました。

* 統一し、sibling nonce fixtureを32-byte valueに揃えました。
