## v0.70.14

**タイトル:** インポート性能、チェーン選択のレジリエンス、運用可視性を改善

**日付:** Not provided

**バージョン:** v0.70.14

**リリース:** [v0.70.14](https://github.com/blinklabs-io/dingo/releases/tag/v0.70.14)

このリリースでは、インポート性能、ブロック処理、チェーン選択、ledgerとdatabaseの可視性、ガバナンス処理、startup recoveryを改善しました。また、プロトコル互換性を更新し、blockfetch、forging、genesis、socket、nonceの検証を強化しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### ランタイムおよび運用上の改善

* `gouroboros`を`v0.205.4`へ更新し、Plutusの適合性を復元しました。

* importerのUTxO statementを再利用し、繰り返しのimportで重複するdatabase operationの準備を減らしました。

* importしたasset statementをcacheし、import中に繰り返しdatabaseを準備する処理を減らしました。

* immutable blockを`ReadAt`でposition指定により読み取り、要求されたread offsetを保持するようにしました。

* Mithrilがgap blockを取り込む間、certificate rowとera-derived depositを永続化するようにしました。

* post-intersect rollback後にrecycled peerを登録し、chain selectionのstallとrollback registrationのmetricsを追加しました。

* equal-slot alternative block forgingをfail closedになるよう強化し、validなsibling blockを採用し、staleなblockfetch stateを無効化するようにしました。

* SQL storeのreadおよびwrite connection-pool contentionを報告するようにしました。

* truncationによって削除されたblockのnonceを、残存するcanonical checkpointから再構築するようにしました。

* `DiskSize`の測定中に共有`readDB` connectionを解放し、WAL checkpointのガイダンスを明確にしました。

* blockごとのledger composition metricsを追加しました。

* startup中に進行中のepoch stake-reward precomputationをqueueに追加するようにしました。

* Conway committee authorizationのsum typeをdecodeし、resignationを保持し、malformedなcommittee dataを拒否し、feeがnilのtransactionを処理するようにしました。

* LeiosNotifyのcursor cleanupをconnection ownershipとconnection lifecycleに関連付けました。

* `epochStartSlot`を固定することで、epoch boundaryをまたいでVRF-key reservationを保持するようにしました。

* discretionaryなchain-selection switchをglobal rate limitで制御するようにしました。

* 期限切れのgovernance proposal deposit refundを1 epoch遅延させ、`DROP` stateに対するmigration safetyを保持しました。

### テストおよび検証の改善

* blockfetch endpoint testを修正し、muxer segmentではなく完全なprotocol messageをparseするようにしました。

* operational certificateのpersistable-counter rejectionに対するapply-path coverageを拡大しました。

* embedded genesis hashを固定し、Unix socketのtest pathを制限しました。

* sibling nonce fixtureを32-byte valueに統一しました。
