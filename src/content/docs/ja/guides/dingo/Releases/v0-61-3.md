## v0.61.3

**タイトル:** ビルド依存関係と Mithril Mark の資格判定

**日付:** 2026年7月7日

**バージョン:** v0.61.3

現行のビルドと実行時依存関係に合わせ、インポートした Mithril の Mark スナップショットの資格判定を修正します。

### 更新

- `examples/dingo-sundae-preview` と `examples/dingo-blockfrost-explorer` の Vite: 8.1.0 → 8.1.3。
- `docker/setup-buildx-action`: 4.1.0 → 4.2.0。
- `docker/build-push-action`: 7.2.0 → 7.3.0。
- `docker/metadata-action`: 6.1.0 → 6.2.0。
- `github.com/aws/aws-sdk-go-v2`: 1.42.0 → 1.42.1。
- `github.com/aws/aws-sdk-go-v2/service/s3`: 1.104.0 → 1.105.0。
- `google.golang.org/grpc`: 1.81.1 → 1.82.0。`GRPC_GO_EXPERIMENTAL_DISABLE_STRICT_PATH_CHECKING` を設定しても厳格なパス検査は有効で、負荷分散ポリシー名は大文字と小文字を区別します。
- `google.golang.org/api`: 0.286.0 → 0.287.0。
- サンプルの `@types/node`: 26.0.1 → 26.1.0。

### 修正

Mithril の過去の Mark をインポートした場合、対象エポック開始後に限り、リーダー資格のステークしきい値検査だけを省略します。
