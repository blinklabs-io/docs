## v0.90.5

**タイトル:** ノードの同等性、プロトコル互換性、性能、運用を向上

**バージョン:** v0.90.5

**リリース:** [v0.90.5](https://github.com/blinklabs-io/dingo/releases/tag/v0.90.5)

**比較:** [v0.90.4...v0.90.5](https://github.com/blinklabs-io/dingo/compare/v0.90.4...v0.90.5)

Dingo v0.90.5では、ノード同等性ワークフロー、プロトコル互換性、トランザクション処理、ピア操作、開発ネットワークの検証を改善しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

#### ノード同等性と同期
* 追加: `node-parity from-genesis`で`--boundary-capture-dir`をサポートし、chainsyncセッションを維持し、境界処理前にUTxOを取得し、一時的なKoios `/tx_info` 失敗を再試行するようにしました。これらのワークフローで境界データを取得し、一時的なトランザクション情報の失敗が発生しても処理を継続できます。
* 除去: ノード同等性の再構築中にAllegraで償還されたByron UTxOを除外し、限定的な不一致サンプルを含めることで、差異を無制限に出力せず確認しやすくしました。
