## v0.79.0

**タイトル:** APIアクセス、同期、状態クエリ、台帳検証を改善

**日付:** 2026-10-06

**バージョン:** v0.79.0

**リリース:** [v0.79.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.79.0)

Dingo v0.79.0では、ページ単位のAPIアクセス、ピアの選択と復旧、状態クエリの分離、Mithrilバックフィルの完全性、パリティチェック、台帳検証を改善しました。また、Perasパッケージとコンフォーマンス用スキャフォールドを導入しました。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### APIアクセス
* 追加: `GET /api/v0/blocks/latest/txs`でトランザクションをページごとに取得できるようになりました。エンドポイントは`count`、`page`、`order`を検証し、ページネーションヘッダーを返し、要求された順序を維持します。利用可能な結果の範囲外を要求すると、空のページを返します。

### 同期とピアガバナンス
* 改善: ChainSyncとピアガバナンスでblockfetchピアの性能を測定し、設定済みのrootを優先し、停止したピアをバックオフし、再同期後に復旧し、ホストごとに受信接続をクールダウンするようになりました。

### 状態クエリ
* 分離: LocalStateQueryセッションをスナップショットで分離し、セッションの最大有効期間を設定可能にし、必要な依存関係が利用できない場合は明示的なエラーを返すようになりました。

### Mithril復旧
* 強化: 正しいアンカーを選択し、アーカイブと証明を検査し、設定可能なダウンロード上限を適用し、無効なアーティファクトを拒否することで、Mithrilバックフィルの堅牢性を高めました。

### Peras
* 導入: Perasパッケージとコンフォーマンス用スキャフォールドを導入しました。

### パリティチェック
* 拡充: `koios-parity`の再試行と重大な不一致の報告を改善し、一時的な障害に対する追加の試行を可能にし、重要な差異を明確にしました。

### 台帳検証
* 修正: エラールール、手数料とデポジットの計算、形式不正なハッシュ、Byronのリプレイ動作、オーバーフロー処理に関する台帳検証を修正しました。
