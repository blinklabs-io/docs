## v0.79.0

**タイトル:** APIアクセス、同期、状態クエリ、台帳検証を改善

**日付:** 2026-10-06

**バージョン:** v0.79.0

**リリース:** [v0.79.0](https://github.com/blinklabs-io/dingo/releases/tag/v0.79.0)

Dingo v0.79.0では、ページ単位のAPIアクセス、ピアの選択と復旧、状態クエリの分離、Mithrilバックフィルの完全性、パリティチェック、台帳検証を改善しました。また、Perasパッケージとコンフォーマンス用スキャフォールドを導入します。

### 推奨ネットワーク互換性 ⚠️

| Network             | Compatible |
|---------------------|------------|
| mainnet             | ⛔         |
| preprod-testnet     | ✅         |
| preview-testnet     | ✅         |
| musashi             | ✅         |

### APIアクセス
* 追加: `GET /api/v0/blocks/latest/txs`でトランザクションをページ単位で取得できるようになりました。エンドポイントは`count`、`page`、`order`を検証し、ページネーション用のヘッダーを返し、要求された順序を維持します。利用可能な結果の範囲外を要求した場合は空のページを返します。
