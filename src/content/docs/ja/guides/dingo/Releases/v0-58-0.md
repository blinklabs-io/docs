## v0.58.0

**タイトル:** 生成ブロックの安全性、Leios 復旧、ガバナンスとデータベース

**日付:** 2026年6月25日

**バージョン:** v0.58.0

### 主な変更

- 新規生成ブロックを、使用や共有の前に検証します。
- 復旧時に古い Leios endorsement データを補い、遅れたノードの履歴を完全に近づけます。

### 改善と修正

- プールのステークスナップショット検索を、正しいライブ残高経路に通します。
- 完全なステーク記録と適切なデータ検索を使い、Conway の委任投票力を正確に集計します。
- 復旧中のガバナンス、国庫移転、プール後処理の報酬入金を区別し、重複変更を防ぎます。
- 初期化時の空のジェネシス残高リンクを一貫して記録し、繰り返しセットアップを安定させます。
- ガバナンス更新が止まった単一ピアのセッションを、待機時間後に再接続して進行を再開します。
