## v0.56.0

**タイトル:** Leios/Musashi 互換性、チェックポイント検証、Mithril 復旧

**日付:** 2026年6月23日

**バージョン:** v0.56.0

### 主な変更

- 新しい Leios の動作と endorsement データ処理に合わせ、Preview の同期互換性を改善しました。
- 設定したチェックポイントに対してチェーン進行を検証し、不正な履歴を検出します。
- 製品全体で Musashi の名称を一貫させました。

### 改善と修正

- Mithril を使う追いつき処理の進捗を明確にしました。
- ネットワーク開始時刻の一貫性を検査し、設定不一致を早期に検出します。
- ガバナンス更新中のピア省略ログの繰り返しを減らしました。
- 任意のストレージを含めたビルドの準備を改善しました。
- 台帳先端が既に主チェーン上なら不要な Mithril 巻き戻しを避け、前向き再実行を保持します。
- 古くなった Leios endorsement データを待たずに進めます。

### ツールと文書

- Sundae Preview の Node.js 型定義と TypeScript、Blockfrost エクスプローラーの TypeScript を更新しました。
- 検証でパッケージ間のアーキテクチャ境界を強制します。
- v0.55.0 のノートを公開し、改善内容の文言を明確にしました。
