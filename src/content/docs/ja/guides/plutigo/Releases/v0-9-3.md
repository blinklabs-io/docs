## v0.9.3

**タイトル:** エンコーディングと暗号学的検証を改善

**バージョン:** v0.9.3

**リリース:** [v0.9.3](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.3)

**比較:** [v0.9.2...v0.9.3](https://github.com/blinklabs-io/plutigo/compare/v0.9.2...v0.9.3)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク | 互換性 |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

このリリースでは、`FLAT` エンコーディングを改善し、暗号機能と検証を拡張し、CBOR の `null` 処理を修正しました。

### パフォーマンス

* `FLAT` エンコーディングを改善し、大きなワードを線形時間で処理できるようにしました。

### 暗号

* `github.com/consensys/gnark-crypto` を v0.21.0 から v0.22.0 に更新し、必要な Go のバージョンを 1.26.8 以降に引き上げました。この依存関係の更新には、形式不正な入力をパニックや無効な証明の検証を許可することなく拒否する、より厳格なデシリアライズと証明検証も含まれます。

### 信頼性

* CBOR のデコードを修正しました。`null` と `undefined` の値をデコードすると、Go のインターフェースを以前の値のままにせず `nil` に設定するようになり、マップのデコードでは `null` のキーまたは値に対応する古いエントリを削除します。より包括的な検証により、以前は通過していた入力を拒否できるようになりましたが、API は変更していません。
