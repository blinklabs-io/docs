## v0.8.0

**タイトル:** Plutus V4 対応と API の更新

**バージョン:** v0.8.0

**リリース:** [v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**比較:** v0.7.2...v0.8.0

このリリースでは、Plutus V4 のコストモデルとコンテキスト処理を完成させ、API を更新し、レビューと通知の宛先を整理します。

### ✨ 新機能

* 完成 **Plutus V4 コストモデル:** 公開済みの Plutus V4 コストモデルを完成させました。`Policies` と `AssetCount` のコストモデルは、357 個ではなく 361 個のパラメーターを使用し、`policies-*` の CEK 予算を更新します。

* 拡張 **Plutus V4 のコンテキスト処理:** Plutus V4 のコンテキストビルダーとシリアライザーを追加し、`NoOutputDatum` を扱えるようにしました。

### ⚠️ 破壊的変更

* 移行 **V4 API:** V4 API のパッケージを `plutus/v4` から `lang` に移動しました。利用側ではインポートを更新し、型名を移行してください。`*V4` ヘルパーエイリアスも新しい API に合わせて移行します。

### 📦 追加の変更
* 更新 **レビューと通知のルーティング:** `.github/CODEOWNERS` はレビューと通知を `@agaffney` と `@wolf31o2` に振り分けます。この変更によって実行時の動作は変わりません。
