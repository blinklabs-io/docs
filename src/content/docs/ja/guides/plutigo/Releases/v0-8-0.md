## v0.8.0

**タイトル:** Plutus V4 対応と API の更新

**バージョン:** v0.8.0

**リリース:** [v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**比較:** v0.7.2...v0.8.0

このリリースでは、Plutus V4 のコストモデルとコンテキスト処理を完成させ、API を更新し、レビューと通知の宛先を整理しました。

### ✨ 新機能

* 完成 **Plutus V4 コストモデル:** 公開済みの Plutus V4 コストモデルを完成させ、`Policies` と `AssetCount` ではパラメーターベクトルを 357 個から 361 個に拡張し、4 つの `policies-*` 名称によって CEK のコスト計算を更新しました。

* 拡張 **Plutus V4 のコンテキスト処理:** Plutus V4 のコンテキストビルダーとシリアライザーを追加し、`NoOutputDatum` を扱えるようにしました。

### ⚠️ 破壊的変更

* 移行 **V4 API:** V4 API のパッケージを `plutus/v4` から `lang` に移動しました。利用側ではインポートと `*V4` 接尾辞付きの型名を更新してください。`Data` エイリアスと `List`、`Map`、`MapEntry` ヘルパーユーティリティは削除されたため、これらの使用箇所も移行してください。

### 📦 追加の変更

* 更新 **レビューと通知のルーティング:** `.github/CODEOWNERS` から `@agaffney` を削除し、対象パスの所有者を `@wolf31o2` のみにしました。レビューと通知のルーティングは変わりますが、実行時の動作は変わりません。
