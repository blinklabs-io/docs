## v0.8.0

**タイトル:** Plutus V4 対応と API の更新

**バージョン:** v0.8.0

**リリース:** [v0.8.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.0)

**比較:** v0.7.2...v0.8.0

このリリースでは、Plutus V4 のコストモデルとコンテキスト処理を完成させ、API を更新し、レビューと通知の宛先を整理します。

### ✨ 新機能

* 完成 **Plutus V4 コストモデル:** 公開済みの Plutus V4 コストモデルを完成させました。`Policies` と `AssetCount` のコストモデルは、357 個ではなく 361 個のパラメーターを使用し、`policies-*` の CEK 予算を更新します。
