## v0.6.2（2026年9月14日）

**タイトル:** Go の基準バージョンを引き上げ、評価のオーバーヘッドを削減し、依存関係を更新

**日付:** 2026年9月14日

**バージョン:** v0.6.2

**比較:** v0.6.1...v0.6.2

このリリースでは Go `1.26` 以降が必要となり、評価コンテキストの構築オーバーヘッドを削減し、SSH と x509 の依存関係を更新します。

### ⚠️ 破壊的変更

* 引き上げ **Go の要件:** Plutigo は Go `1.26.0` を最小バージョンとして宣言し、`go1.25.8` の toolchain 設定を削除し、Go のテストおよびベンチマークの CI マトリックスを Go `1.26.x` に限定し、`AGENTS.md`、`DEVELOPMENT.md`、`README.md` の前提条件を Go `1.26+` に更新します。`1.26` 未満の Go バージョンによるビルドは、リリース要件を満たさなくなります。

### ⚡ パフォーマンス

* 削減 **評価セットアップのオーバーヘッド:** Plutigo は V1 から V4 の各バージョンのコストモデルパラメーター名をハイフンで分割した要素を事前計算してキャッシュし、`MachineCosts.update` と `BuiltinCosts.update` で再利用します。また、未知の名前には `strings.Split` のフォールバックを引き続き使用します。`NewEvalContext` はディスパッチと短いリストの動作を維持しながら、割り当て回数と構築レイテンシを削減します。同等性、割り当て、分離、フィクスチャ、ベンチマークの各テストで変更を検証しています。

### 📦 追加の変更

* 更新 **セキュリティ依存関係:** `golang.org/x/crypto` を `v0.55.0` から `v0.57.0` に、`golang.org/x/sys` を `v0.47.0` から `v0.48.0` に更新しました。この更新で上流の SSH と x509 の改善を取り込み、Go `1.26+` の要件に適合します。

### 🙏 謝辞

初めて貢献した `chrisguiney` と、Plutigo を利用するすべての方に感謝します。
