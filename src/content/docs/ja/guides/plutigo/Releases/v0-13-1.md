## v0.13.1

**タイトル:** Value データ定数を一貫して拒否

**バージョン:** v0.13.1

**リリース日:** 2026-11-19

**リリース:** [v0.13.1](https://github.com/blinklabs-io/plutigo/releases/tag/v0.13.1)

**比較:** [v0.13.0...v0.13.1](https://github.com/blinklabs-io/plutigo/compare/v0.13.0...v0.13.1)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク          | 互換性     |
|-----------------------|------------|
| mainnet               | ⛔         |

| preview-testnet       | ✅         |

このリリースでは、CBOR タグ `1401` または `V [...]` で表される Value 形式の PlutusData を、解析、プログラム検証、FLAT エンコードで一貫して拒否します。また、検証中に呼び出し元が構築した `ProtoPair` グラフの循環を検出します。

### 解析時に Value データを拒否

* Value 形式の PlutusData を拒否するように解析を修正しました。

### プログラム検証時に Value データを拒否

* 台帳言語 V1–V4 の `ValidateProgram` を改善し、Value 形式の PlutusData を `errValueData` とともに拒否するようにしました。

### FLAT エンコード前に Value データを拒否

* Value 形式の PlutusData を含む `Data` 定数を FLAT エンコードでシリアライズできないようにし、ラウンドトリップできないバイト列が生成されるのを防ぎました。

### ProtoPair グラフの循環を検出

* 呼び出し元が構築した `ProtoPair` グラフのアクティブパス上で循環を検出する機能を追加し、循環グラフに対して検証が `errCyclicPair` を返すようにしました。

### Value データを使用するワークフローの破壊的変更

* Value 形式のデータの扱いを変更しました。これらの定数を使用するワークフローでは、解析、プログラム検証、FLAT エンコードの前に、サポートされている PlutusData 形式へ置き換える必要があります。
