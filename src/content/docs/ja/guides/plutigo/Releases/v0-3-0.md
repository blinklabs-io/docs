## v0.3.0

**タイトル:** デコーダー再利用と最終 slippage の修正

**日付:** 2026年8月7日

**バージョン:** v0.3.0

デコーダーの再利用と CEK の最終 slippage を参照実装に合わせ、反復実行と結果比較の信頼性を高めます。

### 改善

リセット後、再利用するデコーダーが保持していた数値状態を置き換えます。共有デコーダーの再利用もテストします。

### 修正

CEK の代替経路でも最終 slippage 検査を省略しないようにし、参照経路と結果を一致させます。

デコーダーを再利用する場合や参照経路と結果を比較する場合に関係する更新です。
