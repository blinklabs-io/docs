## v0.2.0

**タイトル:** V4 組み込み関数、再実行ツール、テストの整合

**日付:** 2026年7月31日

**バージョン:** v0.2.0

Plutus V4 の組み込み関数を現行仕様に合わせ、適合性と CI を更新し、CEK の実行を高速化して、mainnet 再実行ツールとコーパスを追加します。

### 新機能

- `plutigo-replay` CLI は、コーパスを厳格に読み込み、スクリプトを再実行して実行報告を生成します。実際の mainnet スクリプト経路を検証できます。
- リポジトリ内の mainnet コーパスにテスト、ベンチマーク、Variant D の従来の整数コストモデル対応を追加しました。
- Plutus V4 の組み込み関数の提供範囲とタグ、および適合性フィクスチャを上流仕様に合わせました。
- インデックス付きの祖先検索とアリーナ管理で、CEK 環境の検索処理を削減しました。

### 修正

- 適合性テストを PV11 の意味、組み込みコストモデル、パーサー検証、暗号動作に合わせました。
- `keccak_256` に `x/crypto` の従来の Keccak 実装を使用し、`go-ethereum` 依存を削除して、組み込み関数のテストを新経路に合わせました。

### その他

- `actions/setup-go` を `v7.0.0`、`actions/checkout` を `v7.0.1` に固定しました。
- issue close date の自動化を停止し、不要なリポジトリ自動処理を削減しました。

Plutigo をご利用いただきありがとうございます。
