## v0.12.2

**Title:** 評価器とデコーダーのパフォーマンスを改善

**Version:** v0.12.2

**Release date:** 2026-11-12

**Release:** [v0.12.2](https://github.com/blinklabs-io/plutigo/releases/tag/v0.12.2)

**Comparison:** [v0.12.1...v0.12.2](https://github.com/blinklabs-io/plutigo/compare/v0.12.1...v0.12.2)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク          | 互換性     |
|-----------------------|------------|
| mainnet               | ⛔         |
| preprod-testnet       | ✅         |
| preview-testnet       | ✅         |
| musashi               | ✅         |

このリリースでは評価器とデコーダーのパフォーマンスを改善し、プロファイル生成が mainnet のリプレイコーパスをより適切に反映するようにしました。プロファイルガイド最適化は引き続きオプトインです。

### プロファイルガイド最適化のワークフローを改善

* 改善: オプトインの PGO ワークフローを維持し、`bench-pgo` の対象を `tests/mainnet.pgo` に変更しました。また、CGO を無効にした `BenchmarkRecentMainnetCorpus` からプロファイルを記録し、`replay.test` をクリーンアップしてテスト状態を保持し、mainnet リプレイコーパスのプロファイルと更新ワークフローを README に記載しました。

### CEK リスト評価を最適化

* 最適化: cons リストが構築されるまで共有リストの検索をスキップし、head、tail、null のチェックで `List()` の結果をキャッシュしながら、要素の結果を保持するようにしました。

### FLAT デコードを高速化

* 高速化: FLAT の固定幅タグとインデックスの読み取りを 2 バイトのウィンドウと算術的なビット位置更新で効率化し、`incrementBufferByBit` を削除しました。バッファ末尾または `NotEnoughBits` 発生時には、デコーダーの位置状態を保持します。
