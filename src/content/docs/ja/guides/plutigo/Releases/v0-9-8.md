## v0.9.8

**タイトル:** 組み込み評価中のキャンセルを改善

**バージョン:** v0.9.8

**リリース:** [v0.9.8](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.8)

**比較:** [v0.9.7...v0.9.8](https://github.com/blinklabs-io/plutigo/compare/v0.9.7...v0.9.8)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク | 互換性 |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

v0.9.8 では、キャンセル時の評価の応答性を改善し、確実な検出のためにキャンセルエラーを保持します。

### 信頼性

* 改善したキャンセル処理は、アクティブなコンテキストのキャンセルまたは期限到達時に、評価がコストの高い組み込み処理を停止できるようにします。
* 拡張したキャンセルチェックは、BLS12-381 の多重スカラー乗算と Value 操作（コインの挿入、スケーリング、和集合、包含）を対象にします。

### エラー処理

* `errors.Is` による `context.Canceled` と `context.DeadlineExceeded` の直接一致を維持し、その他の Value 構築失敗には `InternalError` を返します。
