## v0.13.0

**タイトル:** Plutus batch 7 組み込み関数を有効化し、開発者向けガイダンスを更新

**バージョン:** v0.13.0

**リリース日:** 2026-11-18

**リリース:** [v0.13.0](https://github.com/blinklabs-io/plutigo/releases/tag/v0.13.0)

**比較:** [v0.12.4...v0.13.0](https://github.com/blinklabs-io/plutigo/compare/v0.12.4...v0.13.0)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク          | 互換性     |
|-----------------------|------------|
| mainnet               | ⛔         |
| preprod-testnet       | ✅         |
| preview-testnet       | ✅         |
| musashi               | ✅         |

このリリースでは、Dijkstra protocol version 12 で Plutus batch 7 の組み込み関数を有効化し、評価、FLAT 実行、Plutus V4 の参照、再現可能なベンチマークに関する開発者向けガイダンスを更新しました。

### Plutus Batch 7 の組み込み関数を有効化

* 追加: `multiIndexArray`、`policies`、`assetCount`、`keepPolicies`、`dropPolicies` を Plutus V1–V4 で利用可能にし、Dijkstra protocol version 12 で batch 7 プログラムを有効化しました。

### ポリシーを正しくフィルタリング

* 改善: `keepPolicies` と `dropPolicies` のフィルタリングを改善し、正しい結果を返すようにするとともに、256 policy IDs を超える入力を拒否するようにしました。

### 実行データとコンフォーマンスデータを整合

* 更新: CEK の実装、コストモデル、パラメータテーブル、コンフォーマンスフィクスチャを更新し、upstream の期待値に一致させました。

### 開発者向けガイダンスを更新

* 修正: Plutigo に Go 1.26.11 以降が必要であることを明確にし、`cek.NewEvalContext`、`cek.EvaluateText`、FLAT 実行、Plutus V4 のファイル参照、再現可能なベンチマーク手順に関するガイダンスを修正しました。
