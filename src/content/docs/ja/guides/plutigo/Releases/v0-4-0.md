## v0.4.0

**タイトル:** variant に応じたコンストラクタータグと依存関係の安全性

**日付:** 2026年8月25日

**バージョン:** v0.4.0

variant に応じたコンストラクタータグを導入し、公開 API と実行時動作を変更します。上流の検証、不正データ処理、依存関係の強化と書式整理も含みます。

### 新機能と互換性

Go の呼び出し元は、`uint64` の `data.NewConstr`、または任意の整数タグを使う `data.NewConstrFromBigInt` を使用します。`data.Constr.Tag` は `*big.Int`、`syn.Constr.Tag` は `uint64` です。Variant A～C は任意の整数を受け入れ、D～E は Word64 に収まる非負値を要求します。CBOR は Word64 範囲を強制し、JSON は任意の整数を保持し、FLAT はオーバーフロー検査付きの `uint64` を使用します。nil タグは 0 と扱います。

### 修正と保守

以下の依存関係と書式の更新は、Plutigo 自体の API、フラグ、設定、実行時動作を変更しません。タグに関する変更は前述のとおりです。

- `github.com/cloudflare/circl` を `v1.6.4` から `v1.6.5` に更新し、上流の暗号入力検証と不正データのエラー処理を強化しました。
- `github.com/consensys/gnark-crypto` を `v0.20.1` から `v0.21.0`、間接依存の `github.com/bits-and-blooms/bitset` を `v1.24.4` から `v1.24.6` に更新し、上流のセキュリティ、検証、入力チェックを取り込みます。
- `golang.org/x/crypto` を `v0.54.0` から `v0.55.0` に更新し、安全性と不具合修正を取り込みます。
- `github.com/fxamacker/cbor/v2` を `v2.9.2` から `v2.9.3` に更新しました。不正な CBOR の `time.Time` 変換で起こり得る上流のパニックを修正します。Plutigo は PlutusData に CBOR を使い、`time.Time` の参照はありません。
- `syn/builder.go` の項インターナーの型 switch から冗長な括弧を除き、動作を変えずに `gofumpt` に適合させました。

### 移行

タグを構築、読み取りするコードを更新してください。非負の `uint64` タグは `data.NewConstr`、任意の整数は `data.NewConstrFromBigInt` を使用します。`data.Constr.Tag` の `uint` から `*big.Int`、`syn.Constr.Tag` の `uint` から `uint64` への変更に対応する必要があります。

Plutigo をご利用いただきありがとうございます。
