## v0.9.1

**タイトル:** フルコーパス評価を高速化

**バージョン:** v0.9.1

**リリース:** [v0.9.1](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.1)

**比較:** v0.9.0...v0.9.1

### 推奨ネットワーク互換性 ⚠️

| ネットワーク | 互換性 |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

このリリースでは、フルコーパスでの Plutigo 評価を高速化し、FLAT のデコードを改善し、ユースケースのベンチマーク範囲を完全に復元し、オプションのパフォーマンスベンチマークワークフローを追加しました。

### パフォーマンス

* 改善 **Plutigo の評価スループット:** インデックス作成、予算チェック、引数処理、変数アクセス、環境検索、ループ制御のオーバーヘッドを削減しました。
* 最適化 **FLAT プログラムのデコード:** より高速な 64 ビットおよび 4 ビット処理パスを使用しました。

### ベンチマーク

* 復元 **ユースケースのベンチマークコーパス全体:** 89 個すべてのスクリプトを含みます。

* 追加 **オプトインの `make bench-pgo` ワークフローと `tests/use_cases.pgo` プロファイルデータ:** README にワークフローを記載しました。
* 測定 **フルコーパスの幾何平均時間:** 3 回の実行で `371.293`、`369.333`、`369.944` microseconds を記録し、89 個すべてのスクリプトが成功しました。

### 追加の変更

* 標準化 **リポジトリのレビュー担当:** コアチームがすべてのファイルを担当し、ドキュメントチームとプロダクトチームが Markdown を共同で担当し、コアチームとプロダクトチームが `LICENSE` を共同で担当します。
