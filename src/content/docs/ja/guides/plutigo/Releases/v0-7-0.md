## v0.7.0

**タイトル:** Plutus V4 のサポートを追加し、デコードと検証を改善

**バージョン:** v0.7.0

**比較:** v0.6.2...v0.7.0

このリリースでは Plutus V4 の `Value` をサポートし、PlutusData のデコード深度を `16384` レベルに引き上げ、デコード時の検証と実行時の検証を分離します。

### ✨ 新機能

* 追加 **Plutus V4 の `Value` サポート:** Plutigo は値を CBOR タグ `1401` でエンコードし、ポリシーとトークンの正規マップを検証し、テキスト形式の `V [...]` 構文を受け付け、V4 の `chooseData` をサポートし、Plutus のバージョンに応じた組み込み関数の引数個数規則を適用します。

### 🔧 修正

* 拡張 **PlutusData のデコード深度:** CBOR と JSON のデコードで、`256` レベルではなく最大 `16384` レベルのネストに対応し、JSON の深度制限エラーで一貫したエラーレスポンスを返すようになりました。

* 分離 **タームバージョンの検証:** Plutigo は `syn.ValidateTermVersionForExecution` を通じて van Rossem のタームバージョンの適法性を実行時に検証し、デコード時にはフェーズ固有の検証規則を適用するようになりました。

### 📦 追加の変更

* 明確化 **リポジトリコメントのガイダンス:** コントリビューターは、不変条件、明白ではないアルゴリズム、注意点を説明するコメントを残し、エクスポートされた識別子には正確なドキュメントコメントを付ける必要があります。

### 🙏 謝辞

Plutigo をご利用いただきありがとうございます。
