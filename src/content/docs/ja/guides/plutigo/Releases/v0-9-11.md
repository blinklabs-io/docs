## v0.9.11

**タイトル:** Plutigo の Go ツールチェーンを更新

**バージョン:** v0.9.11

**リリース:** [v0.9.11](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.11)

**比較:** [v0.9.10...v0.9.11](https://github.com/blinklabs-io/plutigo/compare/v0.9.10...v0.9.11)

| ネットワーク | 互換性 |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

このリリースでは、Go のバージョンを更新し、設定済みの安全性制限を変更せずに、深くネストされた PlutusData JSON の信頼性を向上させます。

### ツールチェーン

* Go のバージョンを `1.26.8` から `1.26.10` に更新します。
* 自動分析を Go のバージョン `1.26.x` に合わせます。
