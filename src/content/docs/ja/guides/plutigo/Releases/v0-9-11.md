## v0.9.11

**タイトル:** Plutigo の Go ツールチェーンを更新

**バージョン:** v0.9.11

**リリース:** [v0.9.11](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.11)

**比較:** [v0.9.10...v0.9.11](https://github.com/blinklabs-io/plutigo/compare/v0.9.10...v0.9.11)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク | 互換性 |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

このリリースでは、Go を更新し、設定済みの安全性制限を維持したまま、深くネストされた PlutusData JSON の信頼性を向上させます。

### ツールチェーン

* Go のバージョンを `1.26.8` から `1.26.10` に更新します。
* 自動分析を Go のバージョン `1.26.x` に合わせます。

### JSON のデコード

* 構造的に有効で深くネストされた PlutusData JSON のデコードを改善しました。デフォルトのデコーダーが内部のネスト上限に達した場合は別のデコード経路を使用し、設定済みの最大深度とノード数の制限を維持します。
* 別のデコード経路で発生するエラーを標準化し、不完全な入力に対して Go のバージョン間で一貫した結果を返します。
* JSON がオブジェクト以外の値で始まる場合も、`DecodeJSON` のエラーを安定させます。

### 検証

* デコードエラー、不完全な入力、深さ制限、深くネストされた値、深く不完全な入力に対する安定したエラーを対象として、テスト範囲を拡大します。
