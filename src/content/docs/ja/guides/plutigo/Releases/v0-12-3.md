## v0.12.3

**タイトル:** プログラムバージョンに応じた Data の case 評価を適用

**バージョン:** v0.12.3

**リリース日:** 2026-11-13

**リリース:** [v0.12.3](https://github.com/blinklabs-io/plutigo/releases/tag/v0.12.3)

**比較:** [v0.12.2...v0.12.3](https://github.com/blinklabs-io/plutigo/compare/v0.12.2...v0.12.3)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク          | 互換性     |
|-----------------------|------------|
| mainnet               | ⛔         |
| preprod-testnet       | ✅         |
| preview-testnet       | ✅         |
| musashi               | ✅         |

このリリースでは、プログラムとプロトコルのバージョンに応じた case-on-Data の評価規則を適用し、準備済みプログラムの評価で発生する割り当てを減らし、Plutus V3 として評価する FLAT ベンチマークを追加しました。

### プログラムバージョンに応じた Data の case 処理を適用

* 修正: case-on-Data の評価を修正し、プロトコルメジャー 12 以降では UPLC 1.1.0 のプログラムに `ScriptError 'Casing on data is not supported'` を返し、UPLC 1.2.0 のプログラムではプロトコルメジャー 12 からこの機能を使用できるようにしました。

### 準備済みプログラムの評価オーバーヘッドを削減

* 改善: 事前実行時の構造ウォークで発生する割り当てを減らし、準備済みプログラムの評価を効率化しました。

### Plutus V3 の FLAT ベンチマークを追加

* 追加: 準備済みプログラム用の FLAT ベンチマークを追加し、FLAT ベンチマークを Plutus V3 として評価するようにしました。
