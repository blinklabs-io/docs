## v0.11.2

**タイトル:** gzip 圧縮されたリプレイコーパスの読み込みと最新 mainnet 動作の検証

**バージョン:** v0.11.2

**リリース:** [v0.11.2](https://github.com/blinklabs-io/plutigo/releases/tag/v0.11.2)

**比較:** [v0.11.1...v0.11.2](https://github.com/blinklabs-io/plutigo/compare/v0.11.1...v0.11.2)

### 推奨ネットワーク互換性 ⚠️

| ネットワーク | 互換性 |
|---|---|
| mainnet | ⛔ |
| preprod-testnet | ✅ |
| preview-testnet | ✅ |
| musashi | ✅ |

このリリースでは、gzip 圧縮されたリプレイコーパスを直接読み込めるようになり、展開後のサイズ制限とキャンセル処理を維持します。また、1,360件の評価を含む最新の mainnet データセットに対して、パリティとスループットの検証を拡張します。

### 圧縮されたリプレイコーパスを読み込む

* 追加: `.gz` サフィックスを持つリプレイコーパスファイルを gzip で直接展開できるようにしました。別途展開する手順なしで圧縮 JSON を読み込めます。ローダーは既存の展開後サイズ制限を引き続き適用し、圧縮データの読み込み中もキャンセルを処理します。

### 最新の mainnet 動作を検証する

* 拡張: リプレイのパリティ確認とスループットベンチマークを、1,360件の評価を含む最新の mainnet コーパスに拡張しました。内訳は PlutusV1 が32件、PlutusV2 が962件、PlutusV3 が366件です。このコーパスには gzip 圧縮されたアセットが含まれ、パリティのリグレッションを検出し、現在の mainnet ワークロードに対する性能を測定できます。
