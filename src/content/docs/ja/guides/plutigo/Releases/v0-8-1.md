## v0.8.1

**タイトル:** リソース制限、コスト精度、検証を改善

**バージョン:** v0.8.1

**リリース:** [v0.8.1](https://github.com/blinklabs-io/plutigo/releases/tag/v0.8.1)

**比較:** v0.8.0...v0.8.1

このリリースでは、結果の放電をより予測可能にし、Plutus V4 のコスト計算をリファレンスモデルに合わせ、割り当てのオーバーヘッドを削減し、エンコーディングと Value の検証を強化しました。

### パフォーマンス

* 改善 **決定的な CEK 放電作業予算:** 各結果に `maxDischargeWork = 1,000,000` の決定的な CEK 放電作業予算を設定し、定数の具体化にも共有します。結果が予算を超えるか指数的に展開する場合、Plutigo は `ErrCodeBudgetExhausted` と `result term too large to discharge` を返します。
