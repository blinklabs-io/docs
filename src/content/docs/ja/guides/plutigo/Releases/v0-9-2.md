## v0.9.2

**タイトル:** パースとデータ正規化の堅牢性を向上

**バージョン:** v0.9.2

**リリース:** [v0.9.2](https://github.com/blinklabs-io/plutigo/releases/tag/v0.9.2)

**比較:** v0.9.1...v0.9.2

**日付:** 2026-10-11

このリリースでは、埋め込まれた U+0000 文字と入力終端を区別し、型付き nil のデータコンテナを正規化してもパニックを防ぎ、Go ソースファイルにライセンス表示を追加しました。

### 破壊的変更

* 改善 **パーサーの検証:** 字句解析器が、入力中に埋め込まれた U+0000 文字と入力終端を区別するようになりました。`syn.Parse` と `ParseWithContext` は、有効なプレフィックスの後に埋め込まれた U+0000 または末尾テキストが続く入力を拒否します。パーサーは文字列リテラル内の U+0000 を保持し、コメント内では読み飛ばし、バイト文字列内では拒否します。U+0000 による入力の切り詰めに依存する呼び出し側は、入力を更新する必要があります。

### 信頼性

* 保護 **データの正規化:** 型付き nil の `*Constr`、`*Map`、`*List` を受け取っても、nil ポインターによるパニックが発生しなくなりました。`data.Normalize` はこれらの値を変更せずに返し、nil の `*Value` に対する動作は従来どおり維持します。

### 追加の変更

* 追加 **ライセンス表示:** Blink Labs 標準の Apache 2.0 著作権ヘッダーを 137 個の Go ファイルに追加しました。実行時の動作や API は変更していません。
